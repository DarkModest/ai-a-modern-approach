# 术语表 — 《普林斯顿微积分读本》

按拼音排序。括号内为所在章节。

**ASTC 方法** — 判断三角函数在各象限正负的规则：All（一象限全正）、Sin（二）、Tan（三）、Cos（四）（第2章）

**不定积分 (indefinite integral)** — 函数全体反导数的集合，记 ∫f(x)dx = F(x) + C（第17章）

**不定式 (indeterminate form)** — 代入后无法定值的七种形式：0/0、±∞/±∞、∞−∞、0×∞、1^±∞、0⁰、∞⁰（第14章）

**部分分式 (partial fractions)** — 把真有理函数拆成简单分式之和再逐项积分的方法（第18章）

**参数方程 (parametric equations)** — x、y 都表示为参数 t 的函数；dy/dx = (dy/dt)/(dx/dt)（第27章）

**叉乘增长阶** — 常见函数增长速度排序：ln 幂 < 多项式 < 指数 < 阶乘（第9、21章）

**垂线检验 (vertical line test)** — 任一垂线与图像至多一个交点 ⟺ 图像是某函数的图像（第1章）

**单调性** — f′>0 递增，f′<0 递减；用于证明反函数存在（第10、11章）

**导数 (derivative)** — f′(x) = lim_{h→0} [f(x+h)−f(x)]/h，瞬时变化率/切线斜率（第5章）

**棣莫弗定理** — (r·e^{iθ})ⁿ = rⁿ·e^{inθ}；用于解 zⁿ = w（第28章）

**第 n 项判别法** — 若 lim aₙ ≠ 0 则级数发散；反之不能下结论（第22章）

**定积分 (definite integral)** — 黎曼和的极限，有向面积（第16章）

**对称性（奇偶函数）** — 奇 f(−x)=−f(x)，偶 f(−x)=f(x)；简化积分与图像（第1章）

**对数法则** — ln(xy)=ln x+ln y，ln(x/y)=ln x−ln y，ln(xʸ)=y·ln x（第9章）

**反导数 (antiderivative)** — 导数等于 f 的函数 F；彼此相差常数（第17章）

**反函数 (inverse function)** — f⁻¹(y)=x ⟺ f(x)=y；需通过水平线检验才存在（第1、10章）

**分部积分法** — ∫u dv = uv − ∫v du，乘积法则的积分版（第18章）

**分段函数可导性** — 分段点处须分别验证连续性与左右导数相等（第6章）

**符号表格 (sign chart)** — 用 f、f′、f″ 的零点/间断点分区标正负，绘图核心工具（第12章）

**拐点 (inflection point)** — 凹凸性改变的点；f″ 在该点两侧异号（第11章）

**极坐标 (polar coordinates)** — (r, θ) 表示；x=r·cos θ, y=r·sin θ；面积 = ½∫r²dθ（第27章）

**极值定理 (Extreme Value Theorem)** — 闭区间上连续函数必有全局最大、最小值（第5、11章）

**介值定理 (IVT)** — 连续函数取遍两端点函数值之间的一切值（第5章）

**局部/全局极值** — 局部最值只与邻域比较；全局最值在整个定义域比较（第11章）

**绝对收敛** — Σ|aₙ| 收敛则 Σaₙ 收敛（级数与反常积分同）（第20、22章）

**壳法 (shell method)** — 旋转体体积 = ∫2π·半径·高·dx（或 dy）（第29章）

**可分离变量方程** — dy/dx = f(x)g(y) 型，分离后两边积分（第30章）

**链式求导法则 (chain rule)** — dy/dx = (dy/du)·(du/dx)（第6章）

**临界点 (critical point)** — f′(x)=0 或 f′(x) 不存在的点（第11章）

**洛必达法则 (l'Hôpital's rule)** — 0/0 或 ±∞/±∞ 时 lim f/g = lim f′/g′（第14章）

**麦克劳林级数 (Maclaurin series)** — 关于 x=0 的泰勒级数（第24、26章）

**幂级数 (power series)** — Σaₙ(x−a)ⁿ；在收敛半径内绝对收敛（第24、26章）

**欧拉恒等式** — e^{iθ} = cos θ + i·sin θ；e^{iπ}+1=0（第28章）

**平均值（积分）** — fav = [1/(b−a)]∫ₐᵇ f(x)dx；积分中值定理保证取到（第16章）

**水平线检验 (horizontal line test)** — 任一水平线与图像至多一个交点 ⟺ 函数有反函数（第1章）

**三明治定理 (Squeeze Theorem)** — g≤f≤h 且 g,h→L，则 f→L（第3章）

**收敛半径 (radius of convergence)** — 幂级数在 |x−a|<R 内绝对收敛、|x−a|>R 发散（第26章）

**泰勒定理 (Taylor's theorem)** — f(x)=P_N(x)+R_N(x)，R_N(x)=f⁽ⁿ⁺¹⁾(c)(x−a)ᴺ⁺¹/(N+1)!（第24章）

**特征方程** — 常系数齐次方程 ay″+by′+cy=0 的 at²+bt+c=0（第30章）

**梯度（速度/加速度）** — 位移 x(t)：速度=x′(t)，加速度=x″(t)（第6章）

**梯形法则 / 辛普森法则** — 数值积分：用梯形/抛物线近似每个小区间（附录B）

**条件收敛** — Σaₙ 收敛但 Σ|aₙ| 发散（第22章）

**微积分基本定理 (FTC)** — 第一：积分上限函数的导数是被积函数；第二：∫ₐᵇf = F(b)−F(a)（第17章）

**微分 (differential)** — df = f′(x)dx；误差传播 Δf ≈ f′(x)Δx（第13章）

**线性化 (linearization)** — L(x) = f(a) + f′(a)(x−a)，一阶泰勒近似（第13、24章）

**相关变化率 (related rates)** — 对含多个变量的关系式关于 t 求导，代入瞬时数据（第8章）

**楔形体/圆盘法** — 旋转体体积 = ∫π·半径² dx（或 dy）（第29章）

**隐函数求导 (implicit differentiation)** — 对方程两边关于 x 求导，把 y 视为 x 的函数（第8章）

**有向面积 (signed area)** —  x 轴下方区域面积计为负（第15章）

**约化公式 (reduction formula)** — 把 ∫sinⁿx dx 等表示为更低次幂积分的递推式（第19章）

**中值定理 (MVT)** — [a,b] 连续、(a,b) 可导 ⟹ ∃c: f′(c) = (f(b)−f(a))/(b−a)（第11章）

**左/右极限** — 只从一侧趋近的极限；双侧极限存在 ⟺ 两侧相等（第3章）
