# 速查表 — 《普林斯顿微积分读本》

决策规则与默认结论。查术语用 glossary.md，查完整步骤用 patterns.md 与章节文件。

## 求极限：决策流程
1. 先直接代入 → 得确定值即结束。
2. 得 b/0（b≠0）→ 垂直渐近线，极限 ±∞ 或不存在（查左右极限）。
3. 得不定式 → 按类型处理：
   - **0/0、±∞/±∞** → 洛必达（分子分母分别求导）或代数化简（因式分解/有理化）。
   - **∞−∞** → 通分；有根号乘共轭。
   - **0×∞** → 简单因子移分母；**对数永远留分子**。
   - **1^∞、0⁰、∞⁰** → 取对数求 L，答案 e^L。
4. x→±∞ 的有理/多项式型 → 首项主导：次数相等→系数比；分母高→0；分子高→±∞。
5. 含 sin/cos 振荡 → 三明治定理（−1≤sin≤1）。
6. 已知重要极限：lim_{x→0} sin(x)/x = 1；lim_{x→0}(e^x−1)/x = 1；lim (1+1/x)^x = e。

## 增长阶梯（比较大小与判别法的默认直觉）
**ln 的任意正幂 ≪ 多项式 ≪ 指数（底>1）≪ 阶乘**（x→∞ 时）
- x→∞：e^{−x} 快于任何多项式趋于 0。
- x→0⁺：ln x → −∞，但比任何 1/xᵖ（p>0）慢。
- x→0：sin x ≈ x，tan x ≈ x，e^x−1 ≈ x，ln(1+x) ≈ x，1−cos x ≈ x²/2。

## 连续性 / 可导性判定
- 在 a 连续 ⟺ lim_{x→a}f(x) = f(a)（三件事：极限存在、函数有定义、两者相等）。
- 可导 ⟹ 连续；连续 ⇏ 可导（|x| 在 0 处）。
- 导数不存在的三种情形：角点、尖点（垂直切线）、间断。
- 分段点：先验连续，再验左右导数相等。

## 导数应用：默认动作
- f′>0 → 递增；f′<0 → 递减；f″>0 → 凹向上；f″<0 → 凹向下。
- 候选极值点 = f′=0 或 f′不存在的点 + 区间端点；**全局最值必须连端点一起比**。
- f′(c)=0 ⇏ 极值（x³ 在 0 处）；f″(c)=0 ⇏ 拐点（x⁴ 在 0 处）。
- 二阶导判别法在 f″(c)=0 时**失效**，退回一阶导符号表。
- 罗尔定理：端点等值 ⟹ 内部有 f′(c)=0；MVT：f(b)−f(a) = f′(c)(b−a)。
- 相关变化率：**先求导，后代入**瞬时数值。
- 线性化 L(x)=f(a)+f′(a)(x−a)；误差 ≈ ½f″(c)(x−a)²。
- 牛顿法：x₁ = x₀ − f(x₀)/f′(x₀)；f′(x₀)=0 即失败。

## 积分技巧选择
| 见到 | 用 |
|---|---|
| 函数套函数且内层导数在场 | 换元法（定积分换上下限） |
| 多项式×eˣ/sin/cos；ln x；反三角 | 分部积分 |
| 有理函数分母可分解 | 部分分式（假分式先除法） |
| √(a²−x²) / √(a²+x²) / √(x²−a²) | x = a sin θ / a tan θ / a sec θ |
| sin/cos 奇次幂 | 拆一个因子换元；全偶次→倍角降幂 |
| ∫e^{ax}sin bx | 两次分部 + 移项 |

- 不定积分**必写 +C**；面积问题先加绝对值再分段。
- FTC：d/dx ∫ₐˣ f(t)dt = f(x)；上限是 u(x) 则乘 u′(x)。

## 反常积分与级数：判别速查
- **先找所有瑕点**（分母零点 + ±∞），拆分后每段一个瑕点；一段发散全发散。
- p 判别法：∞ 处 p>1 收敛；0 处 p<1 收敛（**方向相反，别记混**）。
- Σ1/nᵖ：p>1 收敛（p=1 调和级数发散）。
- 几何级数 Σarⁿ：|r|<1 收敛于 a/(1−r)。
- 第 n 项判别法**单向**：lim aₙ≠0 → 发散；lim aₙ=0 无结论。
- 比式/根式：L<1 收敛，L>1 发散，L=1 换方法。阶乘/指数项首选比式。
- 交错级数：|aₙ| 递减且→0 即收敛；误差 ≤ 首项被舍项。再查 Σ|aₙ| 判绝对/条件收敛。
- 幂级数：R 内绝对收敛，R 外发散，**端点逐一代入单查**。

## 泰勒：五个基本麦克劳林级数
- e^x = Σxⁿ/n!（所有 x）
- sin x = Σ(−1)ⁿx²ⁿ⁺¹/(2n+1)!（所有 x）
- cos x = Σ(−1)ⁿx²ⁿ/(2n)!（所有 x）
- 1/(1−x) = Σxⁿ（|x|<1）
- ln(1+x) = Σ(−1)ⁿ⁻¹xⁿ/n（−1<x≤1）
误差项：|R_N(x)| ≤ M|x−a|ᴺ⁺¹/(N+1)!。合成新级数优先用代换/求导/积分，不硬算高阶导。

## 体积/弧长/方程：默认值
- 圆盘法（⊥轴切片）：V=∫πr²d轴变量；壳法（∥轴柱壳）：V=∫2π·半径·高 d变量。
- 弧长：∫√(1+(dy/dx)²)dx；参数式：∫√((dx/dt)²+(dy/dt)²)dt。
- 极坐标面积：½∫r²dθ；dy/dx = (dy/dt)/(dx/dt)。
- 微分方程选型：能分离先分离；dy/dx+p(x)y=q(x) 用积分因子；常系数用特征方程（重根乘 x，复根出三角）；特解与 y_H 冲突乘 x。
