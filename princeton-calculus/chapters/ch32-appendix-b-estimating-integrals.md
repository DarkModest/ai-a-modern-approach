# 附录B：估算积分

## 核心思想
当反导数不存在初等形式（如 ∫e^(−x²)dx）时，定积分只能通过黎曼和做数值近似；条纹法、梯形法则、辛普森法则是三级精度递增的方案，且误差可用 f 的各阶导数上界严格界定。

## 本节框架与方法
- **条纹法（黎曼和近似）**: ∫[a,b] f(x)dx ≈ Σ f(c_j)(x_j − x_{j−1})，其中 c_j 在 [x_{j−1}, x_j] 中任选
  - 何时使用: 最直接、概念最简单的方法，精度要求不高时
  - 怎么做: 对 [a, b] 做划分 a = x_0 < x_1 < ··· < x_n = b，每条小区间选取 c_j（左端点、右端点或中点），求和
- **均匀划分条纹法**: h = (b−a)/n，近似 = h × Σ f(c_j)
  - 何时使用: 实践中总是用均匀划分，省去记每条宽度
  - 怎么做: 递减函数用右端点必然低估、左端点必然高估；中点法误差减半（仅为 ¼M₁(b−a)h，见 B.4.2）
- **梯形法则**: 条纹上边允许倾斜，用连接 (x_{j−1}, f(x_{j−1})) 与 (x_j, f(x_j)) 的线段作上边
  - 何时使用: 需要比条纹法更好的精度，且不想选 c_j
  - 怎么做: ∫[a,b] f(x)dx ≈ (h/2)(f(x_0) + 2f(x_1) + 2f(x_2) + ··· + 2f(x_{n−1}) + f(x_n))；内部点系数为 2（相邻条纹共用边），端点为 1
- **辛普森法则**: 每两个相邻条纹用一条二次曲线拟合上边
  - 何时使用: 要求高精度时；n 必须为偶数
  - 怎么做: ∫[a,b] f(x)dx ≈ (h/3)(f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + ··· + 2f(x_{n−2}) + 4f(x_{n−1}) + f(x_n))；奇数 j 系数 4，偶数 j 系数 2，端点 1
- **误差估算**: 设 M_k = max|f^(k)(x)| 于 [a,b]，套对应误差界公式
  - 何时使用: 报告近似值时必须附带的精度保证
  - 怎么做: 对 f 逐阶求导，用一阶导找临界点（含端点）定位 |f^(k)| 的最大值，代入界公式

## 关键概念
- **划分**: 区间 [a, b] 上的点列 a = x_0 < x_1 < ··· < x_n = b，把区间切成 n 个小区间
- **条纹（黎曼和）**: 以 (x_j − x_{j−1}) 为宽、f(c_j) 为高的矩形，积分是条纹面积和当条宽趋 0 的极限；不取极限即得近似
- **均匀划分**: 每个小区间等宽 h = (b−a)/n，黎曼和化简为 h × Σf(c_j)
- **梯形法则**: 用直线段连接相邻曲线点，每条条纹面积 = (h/2)(f(x_{j−1}) + f(x_j))，系数模式 1,2,2,…,2,1
- **辛普森法则**: 用抛物线拟合每对条纹，两条纹面积 = (h/3)(f(x_0) + 4f(x_1) + f(x_2))，系数模式 1,4,2,4,…,2,4,1
- **误差的绝对值**: |误差| = |∫[a,b] f(x)dx − A|，A 为近似值
- **M₁, M₂, M₄**: |f′(x)|、|f′′(x)|、|f⁗(x)| 在 [a, b] 上的最大值，分别控制条纹法、梯形法则、辛普森法则的误差界
- **中点法**: 取 c_j 为小区间中点的条纹法，误差界 ¼M₁(b−a)h，是端点法的一半

## 心智模型
- 当函数**没有初等反导数**（e^(−x²)、sin(x)/x 等）时，别浪费时间找闭形式——直接数值估算并给出误差界
- 当要在三种方法间选择时，看**h 的幂次**：h⁴ ≪ h² ≪ h（h 小时），辛普森 ≫ 梯形 ≫ 条纹；条纹加倍 n 只把误差减半，辛普森加倍 n 把误差缩小 16 倍
- 当需要"这个近似有多可靠"时，**求导数上界 M_k**：用 f 的下一阶导数找临界点，把临界点和端点都代入取绝对值最大者
- 当 f 单调时，左/右端点条纹法分别给出**上界和下界**（递减函数：左高右低），真实值被夹在两者之间

## 常见错误与陷阱
- **辛普森法则用奇数 n**: 公式要求每对条纹共用一条抛物线，n 必须偶数；n = 5 时不能用辛普森（书中因此改用 n = 8）
- **忘记合并共用边的系数**: 直接对每条条纹套 (h/2)(f(x_{j−1})+f(x_j)) 或 (h/3)(...) 却不把相邻项合并，会得到双倍计数；正确结果是内部点系数 2（梯形）或 4/2 交替（辛普森）
- **梯形法则除以 3、辛普森除以 2**: 两个分母极易记反——梯形 h/2，辛普森 h/3
- **只代入临界点求 M_k 而漏掉端点**: |f^(k)| 的最大值可能在区间端点取到（如 M₂ 的候选要检验 f′′(0)、f′′(√(3/2))、f′′(2)，最大者在端点 x = 0）
- **用单一条纹做估算并期待好结果**: n = 1 时 c₁ 的选取让 ∫₀² e^(−x²)dx 的估算在 2、2/e、2/e⁴ 之间剧烈摆动——单条纹估算几乎无意义
- **混淆误差界与真实误差**: 界公式给出的是"不可能更糟"的上界；实际 M₄ 可能远小于估计值（书中粗估 76，实际为 12），故误差界是保守保证

## 公式与参考表

**梯形法则**（均匀划分，h = (b−a)/n）：
∫[a,b] f(x)dx ≈ (h/2)[f(x₀) + 2f(x₁) + 2f(x₂) + ··· + 2f(x_{n−1}) + f(xₙ)]

**辛普森法则**（n 为偶数）：
∫[a,b] f(x)dx ≈ (h/3)[f(x₀) + 4f(x₁) + 2f(x₂) + 4f(x₃) + ··· + 2f(x_{n−2}) + 4f(x_{n−1}) + f(xₙ)]

**误差界对照表**（h = (b−a)/n，M_k = max|f^(k)| 于 [a,b]）：

| 方法 | 系数模式 | 前面常数 | 涉及导数 | h 的幂 | 误差界 |
|---|---|---|---|---|---|
| 均匀条纹（端点） | — | — | M₁ | h¹ | ½M₁(b−a)h |
| 均匀条纹（中点） | — | — | M₁ | h¹ | ¼M₁(b−a)h |
| 梯形法则 | 1,2,2,…,2,1 | h/2 | M₂ | h² | (1/12)M₂(b−a)h² |
| 辛普森法则 | 1,4,2,4,…,4,1 | h/3 | M₄ | h⁴ | (1/180)M₄(b−a)h⁴ |

辛普森单对条纹的原型公式（B.3.1 证明所得）：两条纹面积 = (h/3)(P + 4Q + R)，其中 P、Q、R 为左、中、右三点函数值。

## 精讲例题

估算 ∫₀² e^(−x²)dx 并给出各方法的误差保证（f(x) = e^(−x²)）。

第一步，算各阶导数（为误差界做准备）：
f′(x) = −2xe^(−x²)；f′′(x) = (4x²−2)e^(−x²)；f⁗(x) = 4(4x⁴−12x²+3)e^(−x²)。

第二步，求 M 值：
- M₁：f′′(x) = 0 于 x = 1/√2，f′ 在此取最小值 −√2 e^(−1/2)，故 M₁ = √2 e^(−1/2)。
- M₂：f′′′ 的零点为 x = 0 与 x = √(3/2)；检验 f′′(0) = −2，f′′(√(3/2)) = 4e^(−3/2)，f′′(2) = 14e^(−4)，绝对值最大者为 2，故 M₂ = 2。
- M₄：对 4(4x⁴−12x²+3)e^(−x²) 分因子估界：|4x⁴−12x²+3| 在 [0,2] 上的最大值为 19（x = 2 处），e^(−x²) ≤ 1，故 M₄ ≤ 4×19×1 = 76（实际 M₄ = 12，但粗界够用）。

第三步，应用各方法并套误差界：
- 10 个条纹（h = 1/5）：估算 0.783 670（右端点）或 0.882 202（中点）；误差 ≤ ½·√2 e^(−1/2)·2·(1/5) = (√2/5)e^(−1/2) ≈ 0.171 553。
- 5 个梯形（h = 2/5）：估算 0.881 131；误差 ≤ (1/12)·2·2·(2/5)² = 4/75 ≈ 0.053 333。
- 辛普森 n = 8（h = 1/4）：估算 (1/12)[e^0 + 4e^(−1/16) + 2e^(−1/4) + 4e^(−9/16) + 2e^(−1) + 4e^(−25/16) + 2e^(−9/4) + 4e^(−49/16) + e^(−4)] ≈ 0.882 066；误差 ≤ (1/180)·76·2·(1/4)⁴ = 19/5760 ≈ 0.003 299。

真实值 0.882 081：辛普森（n=8）误差仅 0.000 015，远好于梯形（n=5），且误差界公式在每种情况下都确实成立。

## 要点速记
1. 三种方法是同一条升级路线：水平顶（条纹）→ 斜直边（梯形）→ 抛物线顶（辛普森），精度按 h、h²、h⁴ 逐级跳升
2. 辛普森法则的系数口诀："1, 4, 2, 4, 2, …, 2, 4, 1"，除以 3，n 必须偶数；梯形是 "1, 2, 2, …, 2, 1"，除以 2
3. 报告数值积分结果必须配误差界：误差 ≤ C·M_k·(b−a)·h^k，其中 M_k 是相应阶导数的绝对值上界
4. 求 M_k 的标准流程：对 |f^(k)| 求导找临界点，候选点 = 临界点 + 两端点，逐一代入取最大
5. h 减半时：条纹法误差减半，梯形法则误差除以 4，辛普森法则误差除以 16——大 n 时辛普森完胜
6. 单调函数用左右端点条纹法可直接夹出积分的上下界，是最便宜的"免费保证"
7. 中点法常被忽视但值得记：同为条纹法，误差界却是端点法的一半（¼M₁(b−a)h）

## 关联
- **第16章（定积分）**: 条纹法就是 16.2 节黎曼和的"不取极限"版本；16.5.1 节已指出 e^(−x²) 无初等反导数，正是本附录的动机
- **第13章（线性化）**: 线性化是"用直线近似函数"，梯形法则是"用直线近似曲边"，误差分析思路一脉相承（13.2 节）
- **第25章（泰勒级数）**: 误差界用导数上界控制余项，与泰勒定理的余项估计同一精神（25.3 节）；辛普森法则本质是分段二次（泰勒二阶）插值
- **第11章（中值定理）**: B.4.2 节条纹法误差界的证明直接使用中值定理（11.3 节）把函数夹在两直线之间
