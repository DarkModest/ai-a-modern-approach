# 第21章：反常积分：如何解题

## 核心思想
解决反常积分敛散性问题的标准流程：先把积分拆成"每个只含一个瑕点"的小积分，再对每个小积分根据瑕点位置（∞、0 或一般有限值）和函数类型（多项式/三角/指数/对数）选用比较判别法、极限比较判别法或 p 判别法。

## 本节框架与方法
- **拆分积分法 (21.1.1)**: 找出区间 [a,b] 上所有瑕点（含 ±∞ 和垂直渐近点），在瑕点之间任选分点拆成若干积分之和，使每个积分至多有一个瑕点且瑕点在端点
  - 何时使用: 任何瑕点多于一个的反常积分，如 ∫₀^∞ 1/(√x+x²)dx 在 0 和 ∞ 两个瑕点，可拆为 [0,5] 与 [5,∞)
  - 怎么做: 分点任选（取 5、取 1 均可）；每段单独判别；**只要有一段发散，整个积分发散，无需再看其余段**；全部收敛才收敛
- **负被积函数三对策 (21.1.2)**:
  - 何时使用: f 在区间上变号（常见于含三角、对数的积分）
  - 怎么做: (1) 变号 → 用绝对收敛判别法（判 |f| 收敛则 f 收敛，**不能用于证发散**）；(2) 恒负 → 提负号化为正函数，如 -ln(x) 写成 |ln(x)|；(3) 两者都不行 → 回到反常积分正式定义
- **比较判别法定向选择 (21.2)**: 猜发散则找更小的发散函数 g（f≥g≥0），猜收敛则找更大的收敛函数 g（f≤g）
  - 何时使用: 被积函数含指数衰减、|sin|/|cos| 等没有渐近等价对象但有天然上界的情形
  - 怎么做: 先预判敛散方向，再选不等式方向；方向搞反（如证收敛却找更小的下界）就是做无用功
- **极限比较判别法 (21.2)**: 找形式简单的 g 使 x→瑕点时 f(x)~g(x)，则 f 与 g 同敛散
  - 何时使用: f 形式复杂但在瑕点附近有明确渐近主项（多项式主项、sin(x)~x 等）
  - 怎么做: 确定渐近等价式 → 取 g=1/x^p 型 → 用 p 判别法判 g → 结论传回 f；注意 g 不得引入原积分没有的瑕点（若有，须重新拆分）
- **指数比较技巧 (21.3.3)**: 对任意 n，存在 C 使 e^(-x) ≤ C/x^n（x>0）；证 ∫x^a·e^(-x)dx 收敛时取 n = a+2
  - 何时使用: 含衰减指数的积分，如 ∫₁^∞ x³e^(-x)dx
  - 怎么做: 令 e^(-x)≤C/x^(a+2)，得 x^a·e^(-x)≤C/x²，p=2>1 收敛；**幂必须选得比要消去的幂大至少 1**（如用 x^4 则得 C∫1/x=∞，白费功夫）；x^a·e^(-x) **不能**渐近等价于 e^(-x)
- **对数比较技巧 (21.3.4, 21.4.4)**: 对任意 α>0 存在 C 使 ln(x)≤Cx^α（x>1）、|ln(x)|≤C/x^α（0<x<1）
  - 何时使用: 含 ln 因子且 ln 是"干扰项"的积分
  - 怎么做: α 要取得足够小，使加上/减去 α 后不跨过临界值 1（如 ∫ln(x)/x^1.001dx 用 ln(x)≤Cx^0.0005 使分母仍 >1）；若 ln 在分母且幂已跨过 1（如 ∫1/(x ln x)dx），改用换元 t=ln(x) 化回 p 积分
- **一般有限瑕点的换元 (21.5)**: 瑕点在 x=a 令 t=x-a；瑕点在 x=b 令 t=b-x（dt=-dx，用负号交换上下限）
  - 何时使用: 唯一瑕点既非 0 也非 ∞，如 ∫₂³ 1/(x(x-1)(x+1)(x-2))dx 瑕点在 2
  - 怎么做: 换元后瑕点移到 0，再用"0 附近最低次项起决定作用"

## 关键概念
- **瑕点**: 被积函数在区间上未定义或无界的点，含垂直渐近点与 ±∞；每个反常积分每段只许一个瑕点。
- **渐近等价 f(x)~g(x)**: 当 x→a（或 ±∞）时 lim f(x)/g(x)=1；等价关系对乘、除、取倒数成立，**对加、减不成立**。
- **绝对收敛判别法**: ∫|f|dx 收敛 ⇒ ∫f dx 收敛；只能证收敛不能证发散。
- **p 判别法（∞型）**: ∫ₐ^∞ 1/x^p dx 当 p>1 收敛、p≤1 发散。
- **p 判别法（0型）**: ∫₀^a 1/x^p dx 当 p<1 收敛、p≥1 发散（方向与 ∞ 型相反）。
- **最高次项原理（∞）**: 多项式 p(x) 在 x→±∞ 时 ~ 最高次项 ax^n。
- **最低次项原理（0）**: 多项式 p(x) 在 x→0 时 ~ 最低次项 bx^m（常数项视为 x^0，次数最低）。
- **指数优于多项式**: lim x^n/e^x = 0（x→∞，任意 n）；多个指数并存时底数最大的起决定作用，如 7^x-4^x~7^x。
- **对数慢于任意幂**: lim ln(x)/x^α = 0（x→∞）且 lim x^α ln(x) = 0（x→0+），α 任意小都行。
- **无界区间上有界函数无例外**: 若区间有界且 f 在闭区间上有界（无瑕点），积分必收敛，无需动用判别法。

## 心智模型
- 当含 e^(-x) 或 x 的任意大幂次多项式相乘时，用"指数衰减快于一切多项式增长"——选 n = 多项式次数 + 2 的比较不等式。
- 当含 |sin(·)| 或 |cos(·)| 时，用 |sin|≤1、|cos|≤1 直接抹掉三角因子，再走 p 判别法；三角项对渐近主项永远可忽略。
- 当含 ln 因子且"差一点就跨过 p=1"时，用"对数慢于任意小幂次"——取 α 小到不改变 p 与 1 的大小关系。
- 当瑕点在 ∞ 时想"谁最大谁做主"（最高次幂），当瑕点在 0 时想"谁最小谁做主"（最低次幂）——两个方向恰好相反。
- 当比较函数 g 自带原积分没有的瑕点（典型：g=1/x^p 在 0 处），先拆分积分避开它。

## 常见错误与陷阱
- **用绝对收敛证发散**: ∫|f| 发散推不出 ∫f 发散（条件收敛存在，如 ∫₁^∞ sin(x)/x dx 收敛但不绝对收敛）。
- **对指数项用渐近等价**: 写 x³e^(-x) ~ e^(-x) 会推出 x³~1 的荒谬结论；指数无渐近等价对象，只能用比较判别法。
- **不等式方向搞反**: 证收敛却构造 f≥g、证发散却构造 f≤g，得到 ∫f ≤ ∞ 之类的废话，纯属无用功。
- **幂次选择不够大**: 用 e^(-x)≤C/x^4 去控 x³e^(-x) 得 C∫1/x dx = ∞，一无所获；要比要消去的幂大至少 1，习惯加 2。
- **α 选择不够小**: 对 ∫ln(x)/x^1.001 dx 用 ln(x)≤Cx^0.5 得 ∫1/x^0.501=∞；α 必须小到 p-α（或 p+α）不跨过 1。
- **渐近等价用于加减**: sin(x)-x 不 ~ 0，√(x⁴+8x³-9)+x² ~ 2x² 之类结论必须直接用比值极限验证，不能由分项等价相加。
- **让 g 引入新瑕点**: ∫₀^∞ 1/(x⁵+4x⁴+1)dx 若直接取 g=1/x⁵，g 在 0 有瑕点而原函数没有，必须先拆成 [0,1] 与 [1,∞)。
- **对无负号情况错用 ex~1**: ∫₀¹ e^(-1/x)/x⁵ dx 中 e^(-1/x) 不 ~ 1（1/x→∞），须用 e^(-大量)≤C/(大量)^n。
- **√(ex-1) 处错写 ex-1~0**: 应用经典极限 ex-1~x（x→0），得 1/√(ex-1) ~ 1/√x，收敛。
- **被"巨大上限"误导**: ∫₂^(e^e⁸) 1/(x ln x)dx 值还不到 8，看似收敛，但上限为 ∞ 时发散——发散可以极慢。

## 公式与参考表

### 判别法速查
| 判别法 | 条件 | 结论 |
|---|---|---|
| 比较判别法（收敛） | 0≤f≤g，∫g 收敛 | ∫f 收敛 |
| 比较判别法（发散） | f≥g≥0，∫g 发散 | ∫f 发散 |
| 极限比较判别法 | x→瑕点时 f(x)~g(x) | ∫f 与 ∫g 同敛散 |
| p 判别法（∫ₐ^∞ 1/x^p） | — | p>1 收敛；p≤1 发散 |
| p 判别法（∫₀^a 1/x^p） | — | p<1 收敛；p≥1 发散 |
| 绝对收敛判别法 | ∫|f| 收敛 | ∫f 收敛（不可逆） |

### 常见函数在 ∞ 附近的渐近行为
| 函数类型 | 规则 | 示例 |
|---|---|---|
| 多项式/多项式型 | 最高次项主导：p(x)~ax^n | x⁵+4x⁴+1 ~ x⁵；3√x-2x^{1/3}+4 ~ 3√x |
| 三角 | |sin|、|cos|≤1，与幂次相比可忽略 | 2x³-3x^0.1+sin(100x²⁰⁰) ~ 2x³ |
| 指数 | 底数大者主导；e^x 胜过一切幂 | e^x-5x²⁰ ~ e^x；7^x-4^x ~ 7^x |
| 衰减指数 | e^(-x) ≤ C/x^n（n 任选） | x¹⁰⁰⁰e^(-x²⁺⁶) ≤ C/x² |
| 对数 | ln(x) ≤ Cx^α（α 任意小） | ln(x)/x^1.001 ≤ C/x^1.0005 |

### 常见函数在 0⁺ 附近的渐近行为
| 函数类型 | 规则 | 示例 |
|---|---|---|
| 多项式/多项式型 | 最低次项主导：p(x)~bx^m | 5x⁴-x³+2x² ~ 2x²；x²+√x ~ √x；2x^{1/3}+4 ~ 4 |
| 三角 | sin(x)~x，tan(x)~x，cos(x)~1 | sin(x)/x^{3/2} ~ 1/x^{1/2} |
| 指数 | e^x~1，e^(-x)~1；e^x-1~x | 1/√(e^x-1) ~ 1/√x |
| 对数 | |ln(x)| ≤ C/x^α（α 任意小） | |ln(x)|/x^0.9 ≤ C/x^0.95 |
| 换元 sin(1/x) | x→∞ 时 sin(1/x)~1/x | ∫₁^∞ sin(1/x)dx 发散 |
| 麦克劳林最低项 | f(x)=aₙxⁿ+… ⇒ f~aₙxⁿ | 1-cos(x) ~ x²/2 |

## 精讲例题
**判断 ∫₀^∞ 1/(√x+x²) dx 的敛散性**（21.1.1 + 21.3 + 21.4 的综合例）。

1. 找瑕点：被积函数在 x=0 有垂直渐近线，∞ 恒为瑕点 → 两个瑕点，需拆分。任取分点 5：
   ∫₀^∞ = ∫₀⁵ + ∫₅^∞。
2. 判 ∫₀⁵ 1/(x²+√x)dx（瑕点 0）：x→0⁺ 时最低次项主导，x²+√x ~ √x（因 1/2<2），故被积函数 ~ 1/√x。∫₀⁵ 1/x^{1/2}dx 中 p=1/2<1 收敛，由极限比较判别法知该段收敛（√x 项救了 0 处）。
3. 判 ∫₅^∞ 1/(x²+√x)dx（瑕点 ∞）：x→∞ 时最高次项主导，x²+√x ~ x²，被积函数 ~ 1/x²。p=2>1 收敛，由极限比较判别法知该段收敛（x² 项救了 ∞ 处）。
4. 两段都收敛 ⇒ 原积分收敛。

**要点**：同一被积函数在不同瑕点由不同项主导——0 处靠最低次幂，∞ 处靠最高次幂；拆分点（5 还是别的数）不影响结论。

## 要点速记
1. 先拆分再判别：每个子积分只留一个端点瑕点；一段发散则全局发散。
2. 收敛方向先行：先猜敛散性，再决定比较不等式的方向，方向反了就是无用功。
3. ∞ 看最高次幂、0 看最低次幂；含三角用 |sin|≤1 抹掉；含 e^(-x) 用 e^(-x)≤C/x^(n+2)；含 ln 用任意小幂 α 控制。
4. 渐近等价只用于乘除（与倒数），加减时必须直接算比值极限。
5. ∫₁^∞ 1/(x(ln x)^p)dx 用 t=ln(x) 换元：p>1 收敛，p≤1 发散——ln 的幂只要比 1 大一点点（如 1.1）就足以收敛。
6. 瑕点在非 0 有限值时换元平移到 0：t=x-a（左端点）或 t=b-x（右端点，注意负号交换上下限）。
7. 无界区间未必反常：有界区间上有界函数的积分自动收敛，别滥用判别法。
