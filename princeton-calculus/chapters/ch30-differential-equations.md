# 第30章：微分方程

## 核心思想
微分方程是包含导数的方程。一般情形基本无法求解，但三类特定类型可系统求解：一阶可分离变量方程、一阶线性方程（积分因子法）、常系数线性方程（特征方程 + 特解猜测 y = yH + yP）。IVP 用初始条件消去不定常数。

## 本节框架与方法

- **可分离变量法（30.2）**: 方程能整理为 g(y)dy = h(x)dx
  - 何时使用: 一阶方程中能把所有 y（含 dy）放一边、所有 x（含 dx）放另一边
  - 怎么做: (1) 分离变量；(2) 两边各自积分（只加一次 +C）；(3) 整理解出 y，注意除以某量可能丢失常数解（如 y=0、y=nπ/2）；(4) 隐式解（如 tan(y)=sin(x)+C）常常比显式解更安全
- **一阶线性方程积分因子法（30.3）**: 标准形 dy/dx + p(x)y = q(x)
  - 何时使用: y 和 dy/dx 的幂次都是 1 但不可分离变量
  - 怎么做: (1) 化为标准形（y 项在左、dy/dx 系数为 1）；(2) 积分因子 f(x) = e^{∫p(x)dx}（指数上不加 C）；(3) 两边乘 f(x)，左边变为 d/dx[f(x)·y]；(4) 两边积分（右边加 +C）；(5) 除以积分因子解出 y
- **常系数齐次方程特征方程法（30.4.1–30.4.2）**: ay′′ + by′ + cy = 0
  - 何时使用: 系数为常数的齐次线性方程
  - 怎么做: 一阶 y′+ay=0 → y = Ae^{-ax}；二阶解特征二次方程 at²+bt+c=0，按根的三种情形套公式（见参考表）
- **非齐次方程 y = yH + yP（30.4.4–30.4.6）**: ay′′+by′+cy = f(x)
  - 何时使用: 常系数线性方程且右边 f(x) 为多项式、指数、三角函数或其和/积
  - 怎么做: (1) 整理为标准形；(2) 解齐次方程得 yH（含不定常数）；(3) f=0 则完成；否则按猜测表写出 yP 形式；(4) 将 yP 代入原方程比较系数求常数；(5) y = yH + yP
- **yP 与 yH 冲突处理（30.4.7）**
  - 何时使用: 猜测的 yP 形式已包含在 yH 中（代入会得到 0）
  - 怎么做: 将 yP 乘以 x；若仍冲突（双重根情形，yH 含 xe^{αx}），再乘以 x 得 x² 因子
- **IVP（30.4.8）**
  - 何时使用: 有初始条件；n 阶方程需 n 条信息（一般给 y(0) 与 y′(0)）
  - 怎么做: 先求通解（忽略初始条件），再代初始条件解出 A、B；二阶需先求 y′ 再代入
- **微分方程建模（30.5）**
  - 何时使用: 增长率/衰减率依赖当前量或时间的现实问题
  - 怎么做: 把文字描述翻译成方程（如 dP/dt = 2P − 200000t），解出后分析常数临界值

## 关键概念
- **阶（order）**: 方程中最高阶导数的阶，与导数的幂次无关
- **一阶线性**: 形如 dy/dx + p(x)y = q(x)；y 与 dy/dx 幂次均为 1（y³ 或 (dy/dx)² 出现即非线性）
- **可分离变量**: 能整理成 g(y)dy = h(x)dx 的一阶方程
- **积分因子**: f(x) = e^{∫p(x)dx}，使 f·y′ + f·p·y = d/dx(f·y)，本质是乘积法则逆用
- **齐次方程**: 常系数线性方程右边 f(x)=0 的情形
- **特征二次方程**: ay′′+by′+cy=0 对应 at²+bt+c=0，根决定 yH 的形式
- **齐次解 yH**: 对应齐次方程的通解，含不定常数（一阶 1 个、二阶 2 个）
- **特解 yP**: 非齐次方程的任一解，绝不含未知常数
- **IVP（初值问题）**: 微分方程 + 初始条件，用来确定通解中的常数，得到唯一解
- **通解结构**: 非齐次方程全解 = yH + yP

## 心智模型
- 看到一阶方程，先问"能分离变量吗？"能则分离积分；不能再看是否线性，线性则用积分因子
- 乘积分因子的本质是"凑出乘积法则"：目标是把左边写成 d/dx(f·y)，使积分一步消去导数
- 解常系数方程 = "解代数方程 + 猜形状"：特征方程管齐次部分，猜测表管特解，二者相加得全解
- yP 与 yH 冲突时"升幂升级"：乘 x 一次不行就乘 x²，直到形式不再包含于 yH

## 常见错误与陷阱
- **yP 与 yH 冲突未处理**: 直接猜 yP = Ce^{2x} 而 e^{2x} 已在 yH 中时，代入得 0 ≠ f(x)，解无效；必须乘 x（双重根情形乘 x²），如 y′′+6y′+9y=e^{-3x} 需 yP = Cx²e^{-3x}
- **分离变量时丢解**: 除以 y（或 cos²(y) 等）假设其不为 0，会丢掉常数解（y=0、y=nπ/2）；必要时单独检验
- **反三角函数值域陷阱**: y = tan⁻¹(sin(x)+1) 的值域限制会给出错误分支；初始条件 y(0)=5π/4 时需要 +π 修正。隐式形式 tan(y)=sin(x)+C 更安全
- **特解含未知常数**: yP 必须完全确定（常数由代入比较系数求得），不定常数只出现在 yH 中
- **积分因子的指数误加 +C**: f(x)=e^{∫p(x)dx} 中积分不加 C；+C 只在第四步积分右边时加
- **未化标准形就取 p(x)**: dy/dx 系数必须为 1 后才能读 y 的系数（如 tan(x)y′=… 需先除以 tan(x)）
- **乘积形式多写常数**: 猜测积的形式时（如 2x²e^{-6x}），外面的常数 C 可并入多项式系数，应删掉
- **二阶 IVP 忘记求 y′**: 两个初始条件 y(0)、y′(0) 需分别代入 y 与 y′ 的表达式联立求解

## 公式与参考表

### 一阶线性方程
- 标准形: dy/dx + p(x)y = q(x)
- 积分因子: f(x) = e^{∫p(x)dx}
- 解: f(x)·y = ∫f(x)q(x)dx + C

### 齐次方程 ay′′+by′+cy=0 的三种情形（特征方程 at²+bt+c=0）

| 根的情形 | 齐次解 yH |
|---|---|
| 两不同实根 α, β | y = Ae^{αx} + Be^{βx} |
| 双重实根 α | y = Ae^{αx} + Bxe^{αx} |
| 共轭复根 α±iβ | y = e^{αx}(A cos(βx) + B sin(βx)) |

一阶：y′+ay=0 → y = Ae^{-ax}

### 特解 yP 猜测形式表

| f(x) 类型 | yP 形式 | 示例 |
|---|---|---|
| n 次多项式 | n 次一般多项式 | f=10x² → yP=ax²+bx+c |
| e^{kx} 的倍数 | Ce^{kx} | f=10e^{-4x} → yP=Ce^{-4x} |
| cos(kx)/sin(kx) 的倍数 | C cos(kx)+D sin(kx) | f=2 sin(11x) → yP=C cos(11x)+D sin(11x) |
| 上述之和/积 | 形式之和/积（积时删多余常数） | f=2x²e^{-6x} → yP=(ax²+bx+c)e^{-6x}；f=7e^{2x}sin(3x) → yP=e^{2x}(C cos(3x)+D sin(3x)) |
| 与 yH 冲突 | 形式乘 x 或 x² | yH 含 e^{2x} 时，f=7e^{2x} → yP=Cxe^{2x} |

局限：仅适用于多项式、指数、三角函数及其和积；更一般的参数变异法超出本书范围。

## 精讲例题

**例（30.4.6）**: 解 y′′ − 4y′ + 4y = 25e^{3x} sin(2x)

1. **齐次部分**: 特征方程 t²−4t+4 = (t−2)² = 0，双重根 t=2 → yH = Ae^{2x} + Bxe^{2x}
2. **猜特解**: 右边为指数 × 三角函数的积，取 yP = e^{3x}(C cos(2x) + D sin(2x))
3. **求导**:
   - y′P = e^{3x}((3C+2D) cos(2x) + (3D−2C) sin(2x))
   - y″P = e^{3x}((5C+12D) cos(2x) + (5D−12C) sin(2x))
4. **代入并比较系数**: 化简得 e^{3x}(4D−3C)cos(2x) + e^{3x}(−4C−3D)sin(2x) = 25e^{3x}sin(2x)，故 4D−3C=0 且 −4C−3D=25，解得 C=−4, D=−3
5. **全解**: y = Ae^{2x} + Bxe^{2x} − e^{3x}(4 cos(2x) + 3 sin(2x))

**建模例（30.5）**: 细菌增长率 2P，抗生素注入使死亡率为 200000t → dP/dt − 2P = −200000t。积分因子 e^{-2t}，解得 P = 100000t + 50000 + (P₀−50000)e^{2t}。临界值 P₀=50000：低于此值则 (负常数)e^{2t} 最终主导，细菌灭绝；等于或高于则存活。

## 要点速记
1. 一阶方程决策顺序：可分离？→ 线性？→ 都不是则本书方法不适用
2. 积分因子法五步：化标准形 → 算 e^{∫p dx} → 相乘 → 左边写成 d/dx(f·y) 积分 → 除以 f
3. 常系数非齐次方程的通解永远是 y = yH + yP，yH 带常数、yP 不带
4. 特征方程三种根对应三种 yH 模板，直接背表套用
5. 代 yP 入方程后若左边为 0，说明与 yH 冲突，乘 x（不够再乘 x²）重来
6. IVP 一定最后处理初始条件：先通解，后代入；二阶需对 y′ 也代一次
7. 建模题的关键是翻译：增长率项写 +kP，外部消耗/注入写为时间函数项
