# 第16章：定积分

## 核心思想
定积分 ∫ₐᵇ f(x)dx 是曲线 y = f(x)、x 轴与垂线 x = a、x = b 所围成的**有向面积**(x 轴下方算负),其严格定义是黎曼和在最大子区间趋于 0 时的极限。本章建立定积分的定义、性质,并用它解决求(实际)面积、两曲线间面积、估算与平均值问题。

## 本节框架与方法
- **定积分的黎曼和定义**: ∫ₐᵇ f(x)dx = lim_{mesh→0} Σ_{j=1..n} f(cⱼ)(xⱼ − xⱼ₋₁),其中 a = x₀ < x₁ < … < xₙ = b,cⱼ ∈ [xⱼ₋₁, xⱼ]
  - 何时使用: 建立积分的严格基础;计算不能用几何面积(三角形、长方形)求解的积分
  - 怎么做: 把 [a,b] 等分为 n 份(每份宽 (b−a)/n),选 cⱼ(通常取右端点 cⱼ = a + j(b−a)/n),写出黎曼和,化简后用求和公式(如 Σj² = n(n+1)(2n+1)/6),最后令 n→∞ 求极限。mesh = 最长子区间的长度;mesh→0 时 n→∞
- **用定义直接计算定积分(等分法)**
  - 何时使用: 低次多项式被积函数,能用已知求和公式闭合 Σj、Σj² 等
  - 怎么做: 等分区间 → 写出 Σ f(cⱼ)·(b−a)/n → 提出 n 的幂 → 套求和公式 → 求 n→∞ 的极限(用第4章多项式极限法)。例: ∫₀² x²dx = 8/3。此法繁琐,是基本定理(第17章)出现前的"笨办法"
- **拆分区间性质(可加性)**: ∫ₐᵇ f = ∫ₐᶜ f + ∫cᵇ f,**c 不必在 [a,b] 内**(只要求各部分可积)
  - 何时使用: 已知相邻区间的积分值反求目标;分段处理变号函数
  - 怎么做: 选一个已知积分的分割点 c,写成 ∫ₐᵇ = ∫ₐᶜ + ∫cᵇ,解出未知项。例: ∫₁² x²dx = ∫₀² x²dx − ∫₀¹ x²dx = 8/3 − 1/3 = 7/3
- **求通常(无向)面积: ∫ₐᵇ |f(x)|dx**
  - 何时使用: 曲线在 [a,b] 内穿过 x 轴,要求实际面积而非有向面积
  - 怎么做: (1) 求 f(x)=0 在 [a,b] 内的所有根;(2) 按根把积分拆成若干段(用 f 而非 |f|);(3) 分别计算各段积分;(4) 各段取绝对值后相加
- **两曲线之间的面积**: 面积 = ∫ₐᵇ |f(x) − g(x)|dx
  - 何时使用: 求 y = f(x) 与 y = g(x) 及 x = a、x = b 围成的区域
  - 怎么做: 若整个区间上 f ≥ g,直接 ∫(f−g);否则先求交点 f(x)=g(x),分段积分后各段取绝对值相加。口诀: 上曲线减下曲线,不知谁在上就加绝对值分段
- **对 y 积分(曲线与 y 轴之间的面积)**: 若 f 有反函数,面积 = ∫_A^B f⁻¹(y)dy = ∫_A^B x dy
  - 何时使用: 求 y = f(x)、y 轴、水平线 y = A 和 y = B 围成的面积
  - 怎么做: 水平切条(长 x、宽 dy),把 x 表示为 y 的函数 x = f⁻¹(y),**积分上下限用 y 值(A、B),不是 x 值**
- **积分估算(夹逼原理)**: 若在 [a,b] 上 m ≤ f(x) ≤ M,则 m(b−a) ≤ ∫ₐᵇ f(x)dx ≤ M(b−a)
  - 何时使用: 积分无法精确计算(如 ∫₀^{1/2} e^{−x²}dx)或只需范围
  - 怎么做: 求 f 在 [a,b] 上的最大/最小值(用导数判单调性),各乘区间长度即得上下界。更精确可用更多长方形、梯形或抛物线条(见附录B)
- **函数平均值**: f_av = (1/(b−a)) ∫ₐᵇ f(x)dx
  - 何时使用: 平均速度 = 位移/总时间的推广;任意可积函数在区间上的平均
  - 怎么做: 算积分再除以区间长度。几何意义: 高为 f_av、底为 b−a 的长方形面积等于曲线下有向面积
- **积分中值定理**: f 在 [a,b] 连续 ⇒ 存在 c ∈ (a,b) 使 f(c) = (1/(b−a)) ∫ₐᵇ f(x)dx = f_av
  - 何时使用: 断言平均值必被取到;第17章用它证明微积分第一基本定理
  - 怎么做: 由 m ≤ f_av ≤ M(m、M 为最值),连续函数用介值定理即得 c。速度版: 任何旅程中必有某时刻的即时速度等于平均速度

## 关键概念
- **定积分**: ∫ₐᵇ f(x)dx,由曲线 y = f(x)、垂线 x = a、x = b 及 x 轴围成的**有向面积**;积分只是一个数,面积才有单位(平方单位)
- **被积函数与积分限**: f(x) 是被积函数;a、b 是积分限(端点);dx 指明积分变量
- **虚拟变量**: ∫ₐᵇ f(x)dx = ∫ₐᵇ f(t)dt = …,变量名可任意更换,不影响数值
- **有向面积**: x 轴上方为正、下方为负的代数面积;∫_{−π}^{π} sin(x)dx = 0(正负抵消)但∫|sin| 才是实际面积
- **划分与最大区间(mesh)**: a = x₀ < x₁ < … < xₙ = b 把区间分成 n 个子区间;mesh 是最长子区间的长度,极限过程是 mesh→0
- **黎曼和**: Σ_{j=1..n} f(cⱼ)(xⱼ − xⱼ₋₁),定积分的近似值;mesh 越小越精确
- **可积性**: f 有界且只有有限个不连续点 ⇒ 可积(无界的见反常积分,第20–21章);处处不连续的函数可能不可积(上和≠下和)
- **位移 vs 路程**: 位移 = ∫ₐᵇ v(t)dt;路程 = ∫ₐᵇ |v(t)|dt(关键差别在绝对值)
- **平均值**: f_av = (1/(b−a)) ∫ₐᵇ f(x)dx,几何上是使长方形面积等于曲线下面积的水平线高度

## 心智模型
- 当题目说"求面积"而非"计算积分"时,想**有向 vs 无向**: 积分自带符号,面积必须非负——先找零点分段,再取绝对值相加
- 当曲线穿过 x 轴或两曲线交叉时,把**交点当分段开关**: 每个交点处"谁在上"会翻转,必须分段积分
- 当面积贴着 y 轴(水平边界)时,**换元换轴**: 对 y 积分,条带横着切,上下限用 y 值
- 当积分算不出来(如 e^{−x²})时,退而求其次用**最值夹逼**: m(b−a) 与 M(b−a) 给出可靠范围
- 奇函数在对称区间 [−a, a] 上的积分为 0 —— 先看对称性再动手算,能省大量时间

## 常见错误与陷阱
- **混淆有向面积与实际面积**: ∫₀²(−x²−2x+3)dx = −2/3 不是面积;实际面积要按零点 x=1 分段后取绝对值: |5/3| + |−7/3| = 4
- **两曲线间面积忘记判断谁在上**: ∫₀²(x−x²)dx = −2/3 是错的;正确是 ∫₀²|x−x²|dx = 1/6 + 5/6 = 1。出现负"面积"必是此处出错
- **与 y 轴围成的面积却对 x 积分**: y = √x 与 y 轴、y = 2 围成的面积不是 ∫₀²√x dx 也不是 ∫₀⁴√x dx;应化为 ∫₀² y²dy = 8/3(上下限是 y 的范围)
- **常数倍性质误用于非常数**: ∫ C·f(x)dx = C∫f(x)dx 仅当 C 是常数;若 C 含 x 则不成立
- **以为不连续就不可积**: 有有限个不连续点的有界函数仍可积;不可积的判据是黎曼上和与下和的极限不同(如有理数取1、无理数取2的函数,上和=2、下和=1)
- **翻转上下限忘加负号**: ∫ₐᵇ f = −∫ᵦₐ f;同样 ∫ₐᵃ f = 0
- **把黎曼和定义中的 n→∞ 与 mesh→0 混为一谈**: 正确的极限过程是最大子区间趋于 0(等分时两者等价)

## 公式与参考表

定积分基本性质(a、b、c 为常数,f、g 可积):

| 性质 | 公式 |
|---|---|
| 翻转上下限 | ∫ₐᵇ f(x)dx = −∫ᵦₐ f(x)dx |
| 零宽度 | ∫ₐᵃ f(x)dx = 0 |
| 区间可加 | ∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫cᵇ f(x)dx(c 可在区间外) |
| 常数倍 | ∫ₐᵇ Cf(x)dx = C∫ₐᵇ f(x)dx(C 必须是常数) |
| 和差 | ∫ₐᵇ (f ± g)dx = ∫ₐᵇ f dx ± ∫ₐᵇ g dx |
| 保号/保序 | f(x) ≤ g(x) ⇒ ∫ₐᵇ f dx ≤ ∫ₐᵇ g dx |
| 最值夹逼 | m ≤ f ≤ M ⇒ m(b−a) ≤ ∫ₐᵇ f dx ≤ M(b−a) |
| 奇函数对称 | f 为奇 ⇒ ∫_{−a}^{a} f(x)dx = 0 |

面积与平均值公式:

| 目标 | 公式 |
|---|---|
| 曲线与 x 轴间实际面积 | ∫ₐᵇ \|f(x)\|dx(按零点分段,各段取绝对值相加) |
| 两曲线间面积 | ∫ₐᵇ \|f(x) − g(x)\|dx(f ≥ g 恒成立时可去绝对值) |
| 曲线与 y 轴间面积 | ∫_A^B f⁻¹(y)dy = ∫_A^B x dy(上下限为 y 值) |
| 位移 / 路程 | ∫ₐᵇ v(t)dt / ∫ₐᵇ \|v(t)\|dt |
| 平均值 | f_av = (1/(b−a)) ∫ₐᵇ f(x)dx |
| 积分中值定理 | f 连续 ⇒ ∃c ∈ (a,b): f(c) = f_av |

本章算出的常用值: ∫₀¹ x dx = 1/2, ∫₀² x dx = 2, ∫₀¹ x²dx = 1/3, ∫₀² x²dx = 8/3, ∫₁² x²dx = 7/3, ∫₁² x dx = 3/2, ∫ₐᵇ dx = b − a。

## 精讲例题
**用黎曼和定义计算 ∫₀² x²dx。**

1. 等分 [0,2] 为 n 份,每份宽 2/n,分点 xⱼ = 2j/n;取右端点 cⱼ = 2j/n(此时是上和,因为 f 递增)。
2. 黎曼和: Σ f(cⱼ)(xⱼ − xⱼ₋₁) = Σ (2j/n)² · (2/n) = Σ 8j²/n³ = (8/n³) Σ j²。
3. 套公式 Σ_{j=1..n} j² = n(n+1)(2n+1)/6:
   和 = (8/n³)·n(n+1)(2n+1)/6 = 4(n+1)(2n+1)/(3n²)。
4. 令 n→∞(即 mesh = 2/n→0): 极限 = 4·2/3 = 8/3。
   
结论: ∫₀² x²dx = 8/3(平方单位)。同理可证 ∫₀¹ x²dx = 1/3。此法对高次或三角函数极繁琐,正是下一章微积分基本定理要解决的痛点。

## 要点速记
1. 定积分 = 有向面积;凡问"面积"先检查曲线是否变号,变号就分段取绝对值
2. 翻转上下限变号,上下限相等为 0,区间可在任意点 c 拆分——这三条性质是分段计算的基石
3. 奇函数 × 对称区间 ⇒ 积分为 0,遇到 [−a, a] 先查奇偶性
4. 两曲线间面积: 上减下;交叉时求交点分段,或直接用 |f − g|
5. 对 y 轴的面积对 y 积分: x = f⁻¹(y),上下限用 y 值,条带横切
6. 算不出的积分用最值夹逼 m(b−a) ≤ ∫ ≤ M(b−a) 给出范围
7. 平均值 f_av = 积分 ÷ 区间长;连续函数必在某点 c 取到它(积分中值定理)
