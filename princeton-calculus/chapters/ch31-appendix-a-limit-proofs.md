# 附录A：极限及其证明

## 核心思想
全书一直依赖极限的直观概念，本附录给出 ε-δ 严格定义，并用它把"理所当然"的运算法则、连续性、微分法则、中值定理、洛必达法则、泰勒近似等全部重新证明——把直观升级为可检验的命题。

## 本节框架与方法
- **极限的正式定义 (ε-δ 挑战-回应)**: lim_{x→a} f(x)=L 表示：对任意 ε>0，存在 δ>0，使得对所有满足 0<|x−a|<δ 的 x，有 |f(x)−L|<ε
  - 何时使用: 需要严格证明某个极限等于 L，或证明极限不存在/不是 L 时
  - 怎么做: 对方先选 ε（容忍窗 (L−ε, L+ε)），我方回应选 δ（收缩定义域窗 (a−δ, a+δ)，x=a 除外），验证窗内一切 x 使 f(x) 落入容忍窗；对每个 ε 都能回应才算极限成立
- **由定义直接证明极限（找 δ 的程序）**: 把 |f(x)−L| 化简为含 |x−a| 的式子，用界约束其他因子，反解 δ=δ(ε)
  - 何时使用: 证明如 lim_{x→3} x²=9 之类具体极限
  - 怎么做: 先取试探 δ（如 δ=1）把 |x−a| 限制到 ≤1，由此给 |f(x)−L| 中其余因子定出常数上界；再令 δ=min(1, ε/K)，其中 K 是上界系数；大 ε 用 δ=1，小 ε 用 δ=ε/K（书中即 δ=min(1, ε/8)）
- **ε/2 与 ε/K 技巧（多目标容忍预算分配）**: 证明和/积/商的极限时，先按"宽松"预算 ε 估计，发现多余因子（2ε 或 ε(|M|+|L|+1) 等），再把各来源的预算收紧为 ε/2、ε/(|M|+|L|+1) 等，重做一遍正好得到 ε
  - 何时使用: 证明和的极限、乘积的极限、商的极限
  - 怎么做: 用三角不等式 |a+b|≤|a|+|b| 把误差拆项；对乘积加一项减一项：f g−LM=(f−L)g+L(g−M)；对商先通分再加减 LM；用 |g(x)|<|M|+1 给乘积定界，用 |g(x)|>|M|/2 给商的分母定下界
- **三明治定理的 ε-δ 证明**: g(x)≤f(x)≤h(x) 且 g,h 同趋于 L，则 f→L
  - 怎么做: 取 δ 使 |g−L|<ε 且 |h−L|<ε；只需单边：f≤h<L+ε 与 L−ε<g≤f，合起来即 |f−L|<ε
- **用定义证明极限不存在（反证 + 双值夹击）**: 假设极限为 L，选 ε=1/2，找出任意接近 a（或任意大）的两点使函数值分别为 1 与 −1，二者不可能同落长度为 1 的窗 (L−1/2, L+1/2)
  - 何时使用: 证明 lim_{x→∞} sin(x)、lim_{x→0+} sin(1/x) 不存在（后者也可用代换 u=1/x 化归前者）
- **连续性即"保持极限"**: f 在 a 连续 ⇔ lim_{x→a} f(x)=f(a)；复合连续性用"三人游戏"（你挑战 Smiddy 得 λ，我挑战 Smiddy 得 δ），从而 lim f(g(x))=f(lim g(x))
  - 何时使用: 求复合函数极限，如 lim_{x→∞} sin(1/x)=sin(0)=0
- **介值/最大-最小定理的证明工具**: 实数完备性（上确界）+ 区间套二分法 + 连续性反证（取 ε=f(c)/2 之类使容忍窗全正或全负）
- **从极限证微分法则**: 和/差法则直接拆分极限；乘积法则由 Δ(uv)=vΔu+uΔv+ΔuΔv 取极限（末项多一个 Δx→0）；链式法则用 ε=g(x+Δx)−g(x)→0 换元避开 Δu=0 的陷阱
- **柯西中值定理 → 洛必达法则**: 构造 h(x)=f(x)−[(f(B)−f(A))/(g(B)−g(A))]g(x)，用罗尔定理得 f′(C)/g′(C)=(f(B)−f(A))/(g(B)−g(A))；再在 [a,x] 上应用并令 x→a（此时 c→a）得 0/0 型洛必达法则
- **泰勒近似定理的证明思路**: 误差 |f−P_N|∼|C||x|^{N+1}，而对任何其他次数 ≤N 的多项式 Q，|f−Q|∼|a_m||x|^m（m≤N）；比值 ~C₁|x|^{N+1−m}→0，故 P_N 最优

## 关键概念
- **ε-δ 定义**: 极限存在的判据——任意 ε>0 都能配到 δ>0，使 0<|x−a|<δ ⇒ |f(x)−L|<ε。
- **次序依赖性**: δ 由 ε 决定且只能在 ε 选定之后选取；不存在对所有 ε 通用的 δ。
- **无穷极限 (M-δ)**: lim f(x)=∞ 表示对任意 M>0 存在 δ>0，0<|x−a|<δ ⇒ f(x)>M；−∞ 时改为 f(x)<−M。
- **单侧极限**: 右极限把 0<|x−a|<δ 换成 0<x−a<δ（只看 (a,a+δ)）；左极限换成 0<a−x<δ。
- **无穷远处极限 (ε-N)**: lim_{x→∞} f(x)=L 表示对任意 ε>0 存在 N，x>N ⇒ |f(x)−L|<ε；x→−∞ 时换成 x<−N。x→∞ 的极限本质上必为左极限。
- **数列极限**: lim_{n→∞} a_n=L 即对任意 ε>0 存在 N，n>N ⇒ |a_n−L|<ε——连续变量 x 换成整值变量 n。
- **连续性**: f 在 a 连续 ⇔ lim_{x→a} f(x)=f(a)，即函数保持极限。
- **实数完备性**: 区间套/二分必收敛到唯一公共点；集合有上确界——介值定理、最大-最小定理证明的地基。
- **柯西中值定理**: 存在 C 使 f′(C)/g′(C)=(f(B)−f(A))/(g(B)−g(A))；g(x)=x 时退化为普通中值定理。

## 心智模型
- 当要理解 ε-δ 时，把它当作**挑战-回应游戏**：对手选 ε（画两条水平线 L±ε），你回应 δ（只保留 (a−δ,a+δ) 内的函数）；你能永远回应 ⇔ 极限成立；某次被卡住 ⇔ 极限不是 L。
- 当证明运算法则时，把 ε 当作**预算**：每个误差来源分配 ε/2 或 ε/K，总和正好不超 ε——先按 ε 走一遍发现多余因子，再回头收紧预算。
- 当证明"不存在"时，用**夹击测试**：找一串任意逼近的点，其函数值在两个相距 >2ε 的值之间来回跳，则任何窗都装不下。
- 当处理复合/换元时，记住 **Smiddy 中介**：外层函数在 g(a) 处的容忍窗（λ）就是内层函数要满足的目标，两段 ε-δ 游戏串联即可。

## 常见错误与陷阱
- **δ 与 ε 次序颠倒**: δ 依赖于 ε，必须"你移动之后我才移动"；妄图找一个普遍 δ 对所有 ε 成立是错的。
- **取极限时代入 x=a**: 极限只关心 x 接近而非等于 a 的行为，定义里是 0<|x−a|<δ；证明 lim x²=9 不能只算 3²=9。
- **乱用极限运算法则**: 和/积/商的拆分要求右侧各极限存在且有限；商还要求分母极限 M≠0。某极限为 ±∞ 或不存在时公式不适用。
- **三角不等式用错形式**: 差的情形用 |a−b|≤|a|+|b|（即对 a 与 −b 用基本版），别漏掉。
- **商法则证明中忽略分母下界**: 必须先保证 |g(x)|>|M|/2，否则 1/|g(x)| 无法控制。
- **链式法则的 Δu=0 陷阱**: 直接把 Δy/Δx 写成 (Δy/Δu)(Δu/Δx) 在 Δu=0 时无效；正确做法是换元 ε=g(x+Δx)−g(x)，并利用 g 连续 ⇒ ε→0。
- **线性化误差证明中的多余因子**: 得到 (x−a)(x−c)(f″(c)−2K) 后，必须令 K=g(a)/(x−a)² 使左端为 0 才能消去 (x−c)。
- **循环论证**: 用 ∫1/t dt=ln|t|+C 来"证明"ln 的导数是 1/x 属于循环论证；正确路线是先定义 F(x)=∫₁ˣ (1/t)dt，由微积分第一基本定理得 F′=1/x，再由 F(e)=1 定义 e，最后证明 F 是 eˣ 的反函数即 ln。
- **洛必达法则证明不全**: 书中只证了 0/0 且 x→a 的情形；∞/∞ 与 x→±∞ 需另行推广。

## 公式与参考表

有限点极限：
```
lim_{x→a} f(x) = L  ⇔  ∀ε>0, ∃δ>0: 0<|x−a|<δ ⇒ |f(x)−L|<ε
```

单侧极限：右极限把条件换成 0<x−a<δ；左极限换成 0<a−x<δ（其余不变）。

无穷极限：
```
lim_{x→a} f(x) = ∞  ⇔  ∀M>0, ∃δ>0: 0<|x−a|<δ ⇒ f(x)>M
lim_{x→a} f(x) = −∞ ⇔  ∀M>0, ∃δ>0: 0<|x−a|<δ ⇒ f(x)<−M
```

无穷远处：
```
lim_{x→∞} f(x) = L  ⇔  ∀ε>0, ∃N: x>N ⇒ |f(x)−L|<ε
lim_{x→−∞} f(x) = L ⇔  ∀ε>0, ∃N: x<−N ⇒ |f(x)−L|<ε
(x→±∞ 且极限为 ±∞ 时，把 |f(x)−L|<ε 换成 f(x)>M 或 f(x)<−M)
```

数列极限：
```
lim_{n→∞} a_n = L  ⇔  ∀ε>0, ∃N: n>N ⇒ |a_n−L|<ε
```

连续性的正式定义：
```
f 在 a 连续  ⇔  lim_{x→a} f(x) = f(a)
            ⇔  ∀ε>0, ∃δ>0: |x−a|<δ ⇒ |f(x)−f(a)|<ε   (允许 x=a)
复合保持: lim_{x→a} f(g(x)) = f(g(a))；lim_{x→∞} f(g(x)) = f(lim_{x→∞} g(x))
```

极限运算法则（要求右端各极限存在有限，商还要求 M≠0）：
```
lim(f±g) = L±M;  lim(f·g) = LM;  lim(cf) = cL;  lim(f/g) = L/M
```

e 的正式定义：
```
e 是唯一使 ∫₁ᵉ (1/t) dt = 1 的数；lim_{h→0+} (1+h)^{1/h} = e
```

线性化误差：|误差| = (1/2)|f″(c)|·|x−a|²，c 介于 x 与 a 之间。

## 精讲例题

**用定义证明 lim_{x→3} x² = 9**（书中 A.1.3，直接找 δ 的范例）

1. 对手选 ε>0，给出容忍窗 (9−ε, 9+ε)；我方需选 δ 使 (3−δ, 3+δ) 内 x² 落入该窗。
2. 若 ε≥8：取 δ=1，则 x∈(2,4)，x²∈(4,16)⊂(1,17)，成立。
3. 若 0<ε<8：取 δ=ε/8。此时 x<3+ε/8<4，故
   (x−3)(x+3) < (ε/8)(4+3) = 7ε/8，即 x² < 9+7ε/8 < 9+ε（上界达成）。
4. 下界：x>3−ε/8 且 x>2（因 ε<8 故 x>3−1=2），故
   (x−3)(x+3) > (−ε/8)(2+3) = −5ε/8，即 x² > 9−5ε/8 > 9−ε。
5. 合起来：x²∈(9−5ε/8, 9+7ε/8)⊂(9−ε, 9+ε)。故取 δ=min(1, ε/8) 即可。由定义极限得证。

要点：把 |x²−9|=|x−3||x+3| 中不受控的因子 |x+3| 用常数界（x<4 或 x>2）替换，才能反解出 δ 与 ε 的线性关系。

## 要点速记
1. ε-δ 的游戏规则是"任意 ε 在先，δ 在后"——δ 是 ε 的函数，这是整个严格化的心脏。
2. 具体找 δ：先把 |f(x)−L| 中除 |x−a| 外的因子用试探 δ=1 定出常数界 K，再取 δ=min(1, ε/K)。
3. 组合多个极限时，把总预算 ε 分配成 ε/2、ε/(|M|+|L|+1) 等，用三角不等式逐项吸收。
4. 证明极限不存在的利器：ε=1/2 加上一对函数值相差 2 的逼近点列。
5. 连续 = 保持极限；复合极限可"穿过"连续函数：lim f(g(x)) = f(lim g(x))。
6. 微分法则的证明清一色靠极限运算：乘积/商法则的多余项因 Δx→0 或因子 ×0 而消失；链式法则须换元绕开 Δu=0。
7. 中值定理家族（罗尔→中值→柯西）→ 洛必达法则 → 泰勒余项，是本附录证明链的主干。
