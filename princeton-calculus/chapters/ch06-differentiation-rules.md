# 第6章：求解微分问题

## 核心思想
不必每次都回到极限定义求导：掌握一套求导法则（幂法则、乘积法则、商法则、链式求导法则），就能把任何由 xa 这类"原子"合成的复杂函数拆解后快速求导；同时，导数给出切线斜率、速度与加速度，而许多看似困难的极限其实是"伪装的导数"。

## 本节框架与方法

- **幂法则（用定义推导）**: d/dx (x^a) = a·x^(a−1)（a 为任意实数，a 为正整数时用二项展开只保留 x^n 与 nhx^(n−1) 项即可证明；一般证明见第9章）
  - 何时使用： 求 xa 及其常数倍、和差的导数；处理根式/分式时先改写为幂形式（√x = x^(1/2), 1/√x = x^(−1/2)）
  - 怎么做： "提取次数放前面作系数，再把次数减1"；特例 d/dx(C)=0、d/dx(x)=1、d/dx(1/x)=−1/x²、d/dx(√x)=1/(2√x) 要熟记

- **常数倍与和差法则**: d/dx(C·f) = C·f′；和差的导数 = 导数的和差
  - 何时使用： 多项式与多项式型表达式（含 x^(3/2)、x^(−1/2) 等分指数）
  - 怎么做： 先把每项统一写成 x^a 形式，再逐项套用幂法则；末项的常数直接消失

- **乘积法则**: 若 h(x) = f(x)g(x)，则 h′(x) = f′(x)g(x) + f(x)g′(x)；等价形式 y = uv 时 dy/dx = v·du/dx + u·dv/dx
  - 何时使用： 两（或多）个可导函数相乘且无法/不愿展开时（如 x·sin(x) 根本不能展开）
  - 怎么做： 各因子的导数"交叉相乘再相加"；三因子版 d/dx(uvw) = u′vw + uv′w + uvw′——把 uvw 写三遍，每遍只对一个因子求导。可由矩形面积变化 Δ(uv) = vΔu + uΔv + ΔuΔv 直观理解

- **商法则**: 若 h(x) = f(x)/g(x)，则 h′(x) = [f′(x)g(x) − f(x)g′(x)] / (g(x))²；等价形式 y = u/v 时 dy/dx = (v·u′ − u·v′)/v²
  - 何时使用： 分子分母都含 x 的分式
  - 怎么做： 分子与乘积法则同构但中间是减号、顺序不可交换，分母是原分母的平方；复杂问题用"汇总表"分列 u、v、u′、v′ 再代入

- **链式求导法则**: 若 h(x) = f(g(x))，则 h′(x) = f′(g(x))·g′(x)；等价形式 dy/dx = (dy/du)(du/dx)
  - 何时使用： 复合函数，如 (x²+1)^99、√(x³−7x)；可多层嵌套 dy/dx = (dy/dv)(dv/du)(du/dx)
  - 怎么做： 识别"内层函数" u，对外层求导（保持 u 不动）再乘内层的导数；最后务必把 u 代回 x。直观： x 的变化先被 g′(x) 拉伸，再被 f′(u) 拉伸，总效果是两者之积

- **求切线方程**:
  - 何时使用： 求曲线 y = f(x) 在指定 x 处的切线
  - 怎么做： (1) 求 f′ 并代入 x 得斜率 m；(2) 把 x 代入**原函数**得 y₀；(3) 点斜式 y − y₀ = m(x − x₀)

- **速度/加速度问题**: v = dx/dt，a = dv/dt = d²x/dt²
  - 何时使用： 已知位置函数求运动状态，或抛体运动
  - 怎么做： 抛体公式（初始高度 h、初速度 u）：a = −g，v = −gt + u，x = −½gt² + ut + h。落地时刻解 x=0（舍去负根）；最高点即 v=0 的时刻；速率是 |v|

- **导数伪装的极限**:
  - 何时使用： 极限中虚拟变量单独出现在分母、分子是两个量之差（或倒数结构）
  - 怎么做： 认出它是 f′(x) = lim [f(x+h)−f(x)]/h 在特定点的取值；先求一般情况的 f′(x)，再代入具体 x；若虚拟变量在分子上，先取倒数识别再翻回来

- **分段函数求导**:
  - 何时使用： 分段定义函数在连接点是否可导；绝对值 |x| 是伪装的分段函数，含 |表达式| 要先拆段
  - 怎么做： 两步检验——(1) 各段在连接点取值相等（连续）；(2) 各段导数在连接点的左右极限相等（可导）。多于两段时逐点检验

- **由函数图像画导函数图像（登山者模型）**:
  - 何时使用： 只有图像没有方程
  - 怎么做： 想象登山者报"难度"——平坦处导数为0（x轴截距），上坡为正、越陡越大，下坡为负、越陡越负；直线段导数为常数；原图的垂直渐近线通常对应导函数同位置的垂直渐近线；水平渐近线对应导函数 y=0 处的渐近线

## 关键概念
- **幂法则**: d/dx(x^a) = a·x^(a−1)，对任意实数 a 成立，是所有多项式/根式/分式求导的原子。
- **乘积法则**: (fg)′ = f′g + fg′——积的导数绝不是导数之积。
- **商法则**: (f/g)′ = (f′g − fg′)/g²，分子顺序敏感、分母取平方。
- **链式求导法则**: 复合函数 f(g(x)) 的导数 = 外层导数（在内层处取值）× 内层导数；dy/du 不是真正的分数但可像分数一样"链式相乘"。
- **瞬时速度与加速度**: v = dx/dt 是位置的瞬时变化率；a = dv/dt = d²x/dt² 是位置的二阶导，时间单位要平方（如 米/秒²）。
- **伪装的导数**: 形如 lim_{h→0} [f(x+h) − f(x)]/h 的极限就是 f 在某点的导数，可用求导替代极限技巧。
- **左导数与右导数**: 连接点上两侧导数的单边极限；二者相等才在连接点可导。
- **登山者模型**: 导数值 = 登山难度（陡峭程度），与山的高度（y 截距）无关——图像整体上下平移不改变导函数。

## 心智模型
- 当面对复杂函数时，把它**看作由 xa 原子经"常数倍、和差、乘、除、复合"五步运算组装而成**，按组装的逆序逐层拆用法则（6.2.6 节的大例子：商→和→积→链）。
- 当极限式中虚拟变量 h 单独出现在分母、分子是两项之差时，把它**看作一个伪装的导数**，先识别 f 与 x，再求导代入。
- 当从图像看导数时，把导数**看作登山难度而非高度**：只关心陡不陡，不关心多高。
- 当处理 |表达式| 时，把绝对值**看作伪装的分段函数**，先按表达式符号拆段再检验连接点。

## 常见错误与陷阱
- **误以为 (fg)′ = f′g′**: 积的导数不是导数之积，必须交叉相加 f′g + fg′。
- **商法则分子顺序写反或写成加号**: 是 f′g − fg′ 且分母为 g²；写反顺序结果差一个负号。
- **链式法则忘记乘内层导数或忘记把 u 代回 x**: 对 (x²+1)^99，只写 99(x²+1)^98 而漏掉 2x 是典型错误；用 dy/du 记号算完必须代回 u = g(x)。
- **把 dy/du 当普通分数消去 du 来证明链式法则**: dy/du、du/dx 是分数的极限而非分数——形式上常像分数，但逻辑上不是。
- **初始速度的符号错误**: 向下抛出时初速度 u 必须取负（如 u = −3），忽略负号是常见错误；求"速率"用 |v|。
- **分段函数只看连接点 x=1 而漏掉绝对值引入的新连接点**: |x²−4| 会在 x=±2 处产生额外分段；连接点可导须先连续，且左右导数极限都存在并相等。
- **认为图像的高度影响导数**: 把原图整体上移，导函数不变——y 截距无关。
- **误以为有垂直渐近线必推出导函数在同位置有垂直渐近线**: 一般不成立（反例 y = 1/x + sin(1/x) 在 x=0 处）。

## 公式与参考表

**核心求导法则**
- 常数： d/dx(C) = 0；d/dx(x) = 1
- 幂法则： d/dx(x^a) = a·x^(a−1)
- 常数倍： d/dx(Cf) = C·f′
- 和差： (f ± g)′ = f′ ± g′
- 乘积： (fg)′ = f′g + fg′；三项 (uvw)′ = u′vw + uv′w + uvw′
- 商： (f/g)′ = (f′g − fg′)/g²
- 链式： [f(g(x))]′ = f′(g(x))·g′(x)，即 dy/dx = (dy/du)(du/dx)；三层 dy/dx = (dy/dv)(dv/du)(du/dx)

**常用特例（要背）**
- d/dx(1/x) = −1/x²
- d/dx(√x) = 1/(2√x)
- d/dx(∛x) = 1/(3∛(x²))

**切线方程**： y − y₀ = f′(x₀)(x − x₀)，其中 y₀ = f(x₀)

**运动学**
- v = dx/dt；a = dv/dt = d²x/dt²
- 抛体（初速 u、初始高度 h、向上为正）： a = −g，v = −gt + u，x = −½gt² + ut + h（地球上 g ≈ 9.8 m/s²）
- 最高点 ⟺ v = 0；落地 ⟺ x = 0；速率 = |v|

**导数定义（识别伪装极限用）**
- f′(x) = lim_{h→0} [f(x+h) − f(x)]/h

## 精讲例题

**例（6.5 节）**：求 lim_{h→0} ( ⁵√(32+h) − 2 ) / h。

共轭乘除技巧对五次根失效。观察结构： h 单独在分母、分子是两量之差——这是伪装的导数。

1. 设 f(x) = ⁵√x = x^(1/5)，则 f′(x) = (1/5)x^(−4/5)，即一般式
   lim_{h→0} ( ⁵√(x+h) − ⁵√x ) / h = (1/5)x^(−4/5)。
2. 代入 x = 32： ⁵√32 = 2，且 32^(−4/5) = 1/16。
3. 所以原极限 = (1/5)·(1/16) = **1/80**。

注意这是"双重伪装"：既是导数，又是在特定点 x=32 处的取值——先解一般情况再代值，顺序不能反。

## 要点速记
1. 求导前先把一切根式、分式改写成幂形式 x^a，再逐项套幂法则。
2. 乘积法则交叉相加、商法则减号顺序敏感且分母平方——两者都不能拆成"导数之积/商"。
3. 链式法则三步： 认内层 u → 外导 × 内导 → 把 u 代回 x；复合顺序很重要（g(√x) 与 √(g(x)) 结果不同）。
4. 复杂函数用"汇总表"列 u、v 及其导数，按组装结构逆序逐层拆（商→和→积→链）。
5. 切线 = 导数给斜率 + 原函数给点，点斜式收工；求斜率代 x 进 f′，求点代 x 进 f，别混淆。
6. 落地解 x=0 要舍负根；最高点即 v=0；同速率上抛/下抛撞地速率相同，时间不同。
7. 分母单独出现虚拟变量 + 分子两项之差 ⟹ 多半是伪装的导数，先求一般导数再代入。
