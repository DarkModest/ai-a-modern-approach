# 第8章：隐函数求导和相关变化率

## 核心思想
当变量之间的关系无法用 y = f(x) 显式表示时，在方程两边直接施加 d/dx（或 d/dt），把 y 看作 x 的函数并使用链式法则，即可解出 dy/dx；这一技巧同样把"相关量"的方程转化为"相关变化率"的方程。

## 本节框架与方法
- **隐函数求导技巧（8.1）**: 对整个方程两边关于 x 求导，凡含 y 的项都用链式法则带出 dy/dx，再代数整理解出 dy/dx。
  - 何时使用: y 不是（或无法解出为）x 的显式函数；或显式解太繁琐（如 x² + y² = 4）。
  - 怎么做:
    1. 等号两边同时施加 d/dx，逐项拆开；
    2. 对含 y 的项用链式法则：d/dx(g(y)) = g'(y)·dy/dx（例如 d/dx(y²) = 2y·dy/dx，d/dx(3 sec y) = 3 sec y tan y·dy/dx）；
    3. 必要时叠加乘积法则（y cot x 型）或商法则（y/x⁴ 型）；
    4. 把所有含 dy/dx 的项移到一边，提取公因式，做除法解出 dy/dx。
- **特定点求导的省时法则**: 如果只要某一点的 dy/dx（求切线斜率），求导后立即代入 x、y 的值，再整理求解——不要先求出 dy/dx 的一般表达式再代入。
  - 何时使用: 题目问"曲线在某点处的切线方程"。
  - 怎么做: 求导 → 代入数值 → 解 dy/dx → 用点斜式写切线。
- **隐函数求二阶导（8.1.2）**: 对一阶导后的方程再求一次导（此时严禁代入数值），得到含 d²y/dx² 的方程；最后才代入 x、y 以及从一阶导方程算出的 dy/dx。
  - 何时使用: 求某点处 d²y/dx² 的值。
  - 怎么做: 先求一阶导方程 → 再对其整体求导（注意 (dy/dx)² 与 d²y/dx² 完全不同）→ 由一阶方程算出该点 dy/dx → 代入二阶方程求解。
- **相关变化率一般方法（8.2）**: 四步法。
  - 何时使用: 两个或多个量随时间变化且相互关联，已知一个量的变化率，求另一个的变化率。
  - 怎么做:
    1. 读题，识别所有量，明确要求哪个量的变化率；需要时画图；
    2. 写出关联所有量的方程（几何公式、勾股定理、相似三角形等）；有多个方程时联立消去多余变量，只保留一个方程；
    3. 对方程关于时间 t 做隐函数求导（两边各加 d/dt），得到关联各变化率的方程；
    4. 最后才代入已知数值，解出所求变化率，并写出带单位的结论句。

## 关键概念
- **隐函数**: 由方程（如 x² + y² = 4）隐含定义的 x 与 y 的关系，y 未必能写成 x 的单值函数。
- **d/dx(y²) = 2y·dy/dx**: 链式法则的直接推论；对 y 的函数关于 x 求导时必须乘上 dy/dx，这是隐函数求导的全部关键。
- **变化率**: 量 Q 关于时间的导数 dQ/dt；看到"变化率"三个字就自动想到 d/dt。
- **相关变化率**: 两个（或多个）相关量的变化率之间的关系，由对关联方程关于 t 隐函数求导得到。
- **切线斜率公式**: 对圆 x² + y² = 4，dy/dx = −x/y，只在圆上的点才有意义。
- **负号规则**: 量减小时其变化率为负（接近的汽车 db/dt = −45，跳伞员下降 dh/dt = −10），漏掉负号会毁掉整个求解。
- **相似三角形消元**: 圆锥水罐问题中 H/R = h/r，用几何约束消去一个变量，把 v 表示成单变量函数（v = πh³/12）。

## 心智模型
- 当看到 dy/dx 出现在结果里不要惊慌时，把它看作"必须已知 y 如何变化才能知道 y² 如何变化"的必然产物——它正是要解出的未知数。
- 当题目说"某量以多快的速率变化"时，把每个量看作时间的函数，把方程看作随时成立的恒等式，d/dt 一施加，变化率方程自动浮现。
- 把相关变化率问题看作普通应用题加上第 3 步（关于 t 求导）——唯一的新东西就是这一步，其余都是几何和代数。
- 当算出的变化率依赖变量本身时（dr/dt = 3/r²），把它看作"吹气球越吹越费劲"这类经验的数学验证：变化率本身也是变化的量。

## 常见错误与陷阱
- **过早代入数值**: 相关变化率中在求导之前代入 a = 21、v = 18π 等具体值——这会把变量"冻结"成常数，求导后所有变化率都变成 0。务必先求导（第 3 步）后代入（第 4 步），次序不可调换。二阶隐函数求导同理：求第二次导之前不能代入。
- **对常数求导写成常数本身**: d/dx(4) = 0 而不是 4，非常常见。
- **对 y 的函数忘记乘 dy/dx**: d/dx(y²) 写成 2y 而非 2y·dy/dx。
- **漏掉负号**: 量减小时忘记 dQ/dt < 0（接近、下降、流出），导致答案符号全错。
- **混淆 (dy/dx)² 与 d²y/dx²**: 前者是一阶导的平方，后者是二阶导，是完全不同的量。
- **只求一般表达式**: 只需某点斜率时先费力解出 dy/dx 的一般公式再代入——浪费时间且增加出错机会，应先代入再整理。
- **多变量问题不消元**: 圆锥水罐中直接对 v = (1/3)πr²h 求导而不先用 h = 2r 消去 r，会引入不需要的 dr/dt。

## 公式与参考表
- 链式法则（隐函数核心）: d/dx(g(y)) = g'(y)·dy/dx；特例 d/dx(yⁿ) = n·yⁿ⁻¹·dy/dx
- 圆 x² + y² = r² 的切线斜率: dy/dx = −x/y
- 变化率定义: Q 的变化率 = dQ/dt
- 球体积: V = (4/3)πr³ ⇒ dV/dt = 4πr²·dr/dt
- 圆锥体积: v = (1/3)πr²h
- 勾股定理（两车距离型）: a² + b² = c² ⇒ a·da/dt + b·db/dt = c·dc/dt
- 三角角度型: tan α = 对边/邻边 ⇒ sec²α·dα/dt = 右端关于 t 的导数
- 三角恒等式（求 sec² 用）: sec²θ = 1 + tan²θ
- 净变化率（有进有出）: dv/dt = 流入速率 − 流出速率（如 dv/dt = 8π − v）

## 精讲例题
**圆锥水罐问题（8.2.3）**: 锥形水罐（锥尖朝下），高是半径的两倍（H = 2R），水以 8π 立方英尺/秒注入。求水的体积为 18π 立方英尺时水位 h 的变化率。

1. **读题设量**: 水位高 h，水面半径 r，水体积 v；要求 dh/dt。
2. **关联方程**: 由相似三角形 H/R = h/r，且 H = 2R，得 h = 2r，即 r = h/2。代入圆锥体积公式消去 r：
   v = (1/3)πr²h = (1/3)π(h/2)²h = πh³/12。
3. **关于 t 求导**: dv/dt = (π/12)·3h²·dh/dt = (πh²/4)·dh/dt。
4. **代入数值**: v = 18π ⇒ h³ = 18×12 = 216 ⇒ h = 6；又 dv/dt = 8π，故
   8π = (π/4)·36·dh/dt ⇒ dh/dt = 8/9 英尺/秒。

**变体（底部有洞）**: 每立方英尺水以 1 立方英尺/秒流出，故 dv/dt = 8π − v；v = 18π 时 dv/dt = −10π，同样 h = 6，得 dh/dt = −10/9 英尺/秒——尽管仍在注水，水位反而下降。关键教训：第 1–3 步完全相同，只有第 4 步的代入值改变。

## 要点速记
1. 隐函数求导的全部秘诀就一句：对 y 的函数关于 x 求导时，乘上 dy/dx。
2. 只要特定点的导数，先代入数值再整理；要求二阶导或变化率，先求导再代入——代入时机由你"还需要看到变化"与否决定。
3. "变化率" = d/dt；相关变化率 = 关联方程两边关于 t 隐函数求导。
4. 相关变化率四步：读题设量 → 写关联方程并消元 → 关于 t 求导 → 最后代入数值求解；第 3、4 步顺序绝不能换。
5. 减小量的变化率带负号；流出、接近、下降都是负的。
6. 几何约束（相似三角形、勾股定理）的作用是消元，把方程化到只剩目标变量。
7. 用 sec²θ = 1 + tan²θ 从已知的 tan 值直接得到 sec²，无需反解角度。

- **第5章**: 链式法则、乘积法则、商法则是隐函数求导的运算基础；5.2.7 节的"变化倍数"直觉被直接借用。
- **第6章**: 常规求导问题的直接一般化；切线方程与点斜式在此延续使用。
- **第2章**: 三角函数值与恒等式（sec²θ = 1 + tan²θ）在角度型相关变化率中必不可少。
- **第7章**: 三角函数的求导公式（sec y tan y、csc y cot y 等）在本章隐函数求导中反复使用。
