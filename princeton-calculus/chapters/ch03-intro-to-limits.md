# 第3章：极限导论

## 核心思想
极限描述的是当 x 无限接近 a（但不等于 a）时 f(x) 的行为——函数在 a 点的值完全无关紧要。本章只建立直观理解（正式定义见附录A），涵盖左右极限、双侧极限、无穷远处的极限、极限不存在的判别，以及三明治定理（夹逼定理）。

## 本节框架与方法

- **双侧极限存在的充要条件**: lim(x→a) f(x) = L 当且仅当 lim(x→a⁻) f(x) = L 且 lim(x→a⁺) f(x) = L，三者全相等。
  - 何时使用: 判断分段函数或含 1/x 型函数在某点的双侧极限是否存在。
  - 怎么做: 分别求左极限（x→a⁻，只看 x < a 的值）与右极限（x→a⁺，只看 x > a 的值）；不等则写 DNE（不存在）。

- **三明治定理（夹逼定理）**: 若对 a 附近所有 x 有 g(x) ≤ f(x) ≤ h(x)，且 lim(x→a) g(x) = lim(x→a) h(x) = L，则 lim(x→a) f(x) = L。
  - 何时使用: 求含 sin、cos 等有界振荡因子乘上趋于 0 或趋于 ∞ 的因子的极限，如 x·sin(1/x)、sin(x)/x。
  - 怎么做: ① 利用 −1 ≤ sin(任意量) ≤ 1 建立不等式；② 乘（或除）以相应因子得到夹逼不等式（注意乘负数要变号，单侧极限只需不等式在对应一侧成立）；③ 验证两侧夹逼函数极限同为 L；④ 下结论。
  - 变体: 适用于左/右极限（不等式只需一侧成立），也适用于 x→∞ 或 x→−∞（不等式只需对充分大的正/负 x 成立）。

- **极限不存在的三种典型情形**:
  - 左右极限都存在但不相等（跳跃，如 h 在 x=3 处左极限 1、右极限 −2）→ 双侧 DNE。
  - 单侧趋于 ±∞（如 lim(x→0⁺) 1/x = ∞，lim(x→0⁻) 1/x = −∞）→ 双侧 DNE，产生垂直渐近线。
  - 无限振荡（如 lim(x→0⁺) sin(1/x) 在 −1 与 1 之间越振越快）→ 无渐近线，DNE。

## 关键概念
- **极限 lim(x→a) f(x) = L**: 当 x 充分接近 a（但不等于 a）时，f(x) 想多接近 L 就能多接近；f(a) 是否有定义、取何值与此无关。
- **虚拟变量**: 极限式中的 x 只是临时记号，换成任意字母结果不变；求出极限后结果中不含该变量。
- **左极限 / 右极限**: 记作 lim(x→a⁻) 与 lim(x→a⁺)；减号/加号写在 a 的后面（x→3⁻ 表示在 3 处的左极限，x→−3 则是 −3 处的双侧极限，两者完全不同）。
- **垂直渐近线**: f 在 x = a 处有垂直渐近线 ⇔ lim(x→a⁺) 与 lim(x→a⁻) 中至少一个为 ∞ 或 −∞。一个函数可以有无穷多条垂直渐近线（如 tan x）。
- **水平渐近线**: 右侧水平渐近线 y = L ⇔ lim(x→∞) f(x) = L；左侧水平渐近线 y = M ⇔ lim(x→−∞) f(x) = M。最多两条（左右各一），可不同、可只有一条或没有。
- **大的数 / 小的数（非正式）**: 绝对值非常大的数称为大的（含大的负数，如 −10¹²）；非常接近 0（但不等于 0）的数称为小的；0 本身不算小的数。"大"和"小"必须相对于具体函数或极限而言——没有最大，只有更大。
- **DNE**: "不存在"（does not exist）的缩写。
- **∞ 极限不是数**: lim(x→0⁺) 1/x = ∞ 是说函数无限增大而不趋于任何数，形式上仍属极限不存在，但记录了发散方式。

## 心智模型
- 当求 lim(x→a) 时，把 a 点本身"挖掉"——极限只看 a 附近的值，f(a) 是干扰信息（如 g(2)=3 但 lim(x→2) g(x)=1）。
- 当函数含 sin(1/x)、cos(x) 等有界振荡因子时，把它看作被包络线 ±|因子| 夹住的波形，用三明治定理。
- 把水平渐近线看作"x→±∞ 时的极限值"的几何化身；把垂直渐近线看作"单侧极限为 ±∞"的几何化身——所有渐近线问题都翻译成极限式再回答。
- 当想象"接近 a"或"很大"时，把它看作一个可以按需收紧的挑战：你要 f(x) 离 L 多近，我就能把 x 取得离 a 多近（或多大）。

## 常见错误与陷阱
- **误以为极限等于函数值**: lim(x→2) g(x) = 1 即使 g(2) = 3；f(2) 无定义时极限照样存在。极限与该点函数值无关。
- **误解一：水平渐近线左右必须相同**: 错误。arctan(x) 右侧渐近线 y = π/2、左侧 y = −π/2；y = 2ˣ 只有左侧渐近线。水平渐近线最多两条且可不同。
- **误解二：函数不能与渐近线相交**: 对水平渐近线错误。sin(x)/x 的图像与 x 轴（其水平渐近线）相交无穷多次，仍有 lim(x→∞) sin(x)/x = 0。渐近线只描述"最终趋近"，不禁止相交。
- **混淆 x→3⁻ 与 x→−3**: 减号写在 3 后面表示 x=3 处的左极限；写在前面表示在 −3 处的普通双侧极限，是两个完全不同的概念。
- **忽略三明治定理中乘数的符号**: 对 −1 ≤ sin(1/x) ≤ 1 乘以 x 时，x > 0 得 −x ≤ x·sin(1/x) ≤ x；若 x < 0 不等号要翻转（三明治"翻个身"）。
- **以为去掉因子后极限仍在**: lim(x→0⁺) x·sin(1/x) = 0 成立，但 lim(x→0⁺) sin(1/x) 不存在——前面的因子 x 正是让三明治定理生效的关键。
- **把"大的数"绝对化**: 10¹² 相对古戈尔 10¹⁰⁰ 很小；"足够大"取决于具体函数多快贴近渐近线，不能脱离语境指定一个数。

## 公式与参考表

**核心极限式：**

| 极限 | 值 | 说明 |
|---|---|---|
| lim(x→2) (x−1) | 1 | f 在 x=2 可无定义，极限照样存在 |
| lim(x→0⁺) 1/x | ∞ | 垂直渐近线 x=0 |
| lim(x→0⁻) 1/x | −∞ | 双侧极限 DNE |
| lim(x→0) 1/x² | ∞ | 左右同为 ∞，双侧可写 ∞ |
| lim(x→0⁺) sin(1/x) | DNE | 无限振荡 |
| lim(x→0⁺) x·sin(1/x) | 0 | 三明治定理 |
| lim(x→∞) sin(x)/x | 0 | 三明治定理（∞ 版） |
| lim(x→∞) sin(1/x) | 0 | 水平渐近线 y=0 |
| lim(x→∞) 1/x = lim(x→−∞) 1/x | 0 | |
| lim(x→∞) tan⁻¹(x) | π/2 | 右水平渐近线 |
| lim(x→−∞) tan⁻¹(x) | −π/2 | 左水平渐近线 |
| lim(x→∞) x² | ∞ | 无水平渐近线 |
| lim(x→∞) sin(x) | DNE | 振荡，无渐近线 |

**渐近线 ⇔ 极限对照：**
- f 在 x=a 有垂直渐近线 ⇔ lim(x→a⁺) 或 lim(x→a⁻) 为 ±∞
- 右侧水平渐近线 y=L ⇔ lim(x→∞) f(x) = L
- 左侧水平渐近线 y=M ⇔ lim(x→−∞) f(x) = M

**极限基本类型小结（3.7 节）：**
1. 右极限：x=a 左侧及 a 处的值无关紧要（x ≤ a 处甚至不必有定义）。
2. 左极限：x=a 右侧及 a 处的值无关紧要。
3. 双侧极限：左右极限都存在且相等才存在；f(a) 的值无关紧要。
4. x→∞ 时的极限：对应右侧水平渐近线。
5. x→−∞ 时的极限：对应左侧水平渐近线。

## 精讲例题

**例：求 lim(x→0⁺) x·sin(1/x)。**

解：直接代入失败（0 × 无定义），且 sin(1/x) 本身振荡无极限。用三明治定理：

1. 对任意数都有 −1 ≤ sin(1/x) ≤ 1。
2. 因只求右极限，设 x > 0，不等式乘以 x（正数，不变号）：
   −x ≤ x·sin(1/x) ≤ x。
3. 取 g(x) = −x，h(x) = x，验证：
   lim(x→0⁺) (−x) = 0，lim(x→0⁺) x = 0。
4. 两夹逼函数同趋于 0，由三明治定理得
   lim(x→0⁺) x·sin(1/x) = 0。

要点：因子 x 形成的包络 y=±x 抑制了 sin(1/x) 的激烈振荡；没有它，极限不存在（见 3.3 节）。

**例（∞ 版）：证 lim(x→∞) sin(x)/x = 0。** 由 −1 ≤ sin(x) ≤ 1，对 x > 0 除以 x：−1/x ≤ sin(x)/x ≤ 1/x；两端极限均为 0，故所求极限为 0——尽管图像无数次穿过其水平渐近线 y=0。

## 要点速记
1. 极限只看"附近"不看"点上"：求 lim(x→a) 前先忘掉 f(a)。
2. 双侧极限 = 左极限 + 右极限同时存在且相等；任何一个失败就写 DNE。
3. 见到 sin、cos 乘其他因子求极限，先试三明治定理：−1 ≤ sin ≤ 1 是万能起点。
4. 渐近线问题全部翻译成极限语言：垂直 ⇔ 单侧极限 ±∞；水平 ⇔ x→±∞ 的极限。
5. 水平渐近线最多两条，左右可以不同，图像还可以穿过它；垂直渐近线可以有无穷多条。
6. 注意记号：x→a⁻ 的负号在 a 后；乘负数时不等式要变号。
7. "大"与"小"是相对于具体函数/极限的概念，没有绝对标准——这正是正式 ε-δ 定义（附录A）要解决的。
