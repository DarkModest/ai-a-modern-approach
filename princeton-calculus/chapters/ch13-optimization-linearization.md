# 第13章：最优化和线性化

## 核心思想
最优化是把现实问题翻译成"求某量 Q 在约束下的全局最大值/最小值"并系统求解；线性化是用切线 L(x)=f(a)+f′(a)(x−a) 在 a 附近近似 f(x)，由此派生出微分（误差估算）与牛顿法（求零点近似）。

## 本节框架与方法
- **最优化问题一般方法（13.1.2 七步法）**: 求解文字型最优化问题的标准流程
  - 何时使用: 要求最大化/最小化某个量（面积、成本、时间等）的应用题
  - 怎么做:
    1. 识别所有变量，明确要最优化的量 Q
    2. 试探极端情形，确定变量的取值范围（定义域）
    3. 写出关联变量的各方程（其一为 Q 的方程）
    4. 用约束方程消元，把 Q 表为单变量函数（难以消元时改用隐函数求导，见下）
    5. 对 Q 求导，找临界点（导数为 0 或不存在的点）
    6. 求 Q 在临界点和端点的值，比较出全局最值；用一阶/二阶导数符号检验临界点
    7. 用文字（而非自造符号）写出最终结论
- **隐函数求导法解最优化（13.1.5）**: 不消元，对目标式与约束式同时关于保留变量 r 隐求导
  - 何时使用: 第(4)步消元困难或消元后代数式繁琐时
  - 怎么做: 由约束式解出 dh/dr（如 dh/dr = −2h/r），代入 dC/dr 表达式化简；令 dC/dr = 0 得到变量间关系（如 2r = h），再代回约束式解出具体值；二阶导检验凹性
- **线性化（13.2）**: 在已知点 a 处用切线近似函数
  - 何时使用: 估算 f(x) 在难算点 x 的值（如 √11、sin(11π/30)、ln(0.99)）
  - 怎么做: ①写公式 f(x) ≈ L(x) = f(a) + f′(a)(x−a)；②选 f 与 x 使目标量 = f(x)，选接近 x 且 f(a) 易算的 a；③求 f′；④代入公式；⑤代入 x 计算。微分 df = f′(a)(x−a) 即修正量
- **微分估算误差传播（13.2.2）**: df = f′(a)Δx，相对误差 dV/V
  - 何时使用: 已知某测量量的误差（如直径 ±0.5%），估算由它算出的量（体积）的误差
  - 怎么做: 建立 V(D)，算 dV = V′(a)ΔD，再除以 V 得相对误差百分比
- **线性化的误差分析（13.2.4）**: r(x) = f(x) − L(x) = ½f″(c)(x−a)²，c 介于 x 与 a 之间
  - 何时使用: 需要判断近似值偏高/偏低及误差上界时
  - 怎么做: 看 f″ 符号定高低估；取 |f″| 在区间上的最大值 M，用 |误差| ≤ ½M|x−a|² 给界
- **牛顿法（13.3）**: 用线性化的 x 轴截距迭代逼近 f(x)=0 的解
  - 何时使用: 解方程 f(x)=0 无解析解，需数值近似时
  - 怎么做: 取初始猜测 x₀（接近目标根且远离临界点），迭代 x_{n+1} = x_n − f(x_n)/f′(x_n)，直至 f(x_n) 足够接近 0

## 关键概念
- **最优化**: 在给定约束下使某量 Q 最大化（好事）或最小化（坏事），通常指全局最值
- **临界点**: 导数为 0 或不存在的点；全局最值候选 = 临界点 + 端点
- **线性化 L(x)**: f 在 x = a 处的切线函数 L(x) = f(a) + f′(a)(x−a)，x 接近 a 时是 f(x) 的良好近似
- **微分 df**: df = f′(a)Δx，是 x 从 a 变到 a+Δx 时 f 变化量的近似
- **相对误差**: df/f，常用百分比表示；一维测量误差算三维量时会放大（直径 0.5% 误差 → 体积 1.5% 误差，3 倍）
- **误差项 r(x)**: r(x) = f(x) − L(x) = ½f″(c)(x−a)²，c 介于 x 与 a 之间
- **高估/低估**: f″ 在 a 与 x 之间为负 ⇒ 线性化高估；f″ 为正 ⇒ 低估（因 r(x) 与 f″(c) 同号）
- **牛顿法迭代**: x_{n+1} = x_n − f(x_n)/f′(x_n)，即线性化与 x 轴的截距作为下一近似
- **开区间端点处理**: 区间 (0,∞) 无端点可代入时，用极限 lim 判断趋势（如 lim C = ∞ 则端点不可取）

## 心智模型
- 当面对应用最优化题时，用七步法：核心动作是"把 Q 表成单变量函数"，一切技巧（消元、勾股定理、隐求导）都服务于这一步
- 当估算难算的数时，用线性化：找最近的"好算锚点" a，沿切线走一步 df = f′(a)Δx——x 离 a 越远近似越差（√62 不能用 a=9，要换 a=64）
- 当问"近似有多准"时，看 f″：符号定高估/低估，大小定误差界，且误差随 |x−a|² 缩小——靠近 a 一点，精度平方级提升
- 当解 f(x)=0 无解析解时，用牛顿法：每步沿切线跳到 x 轴，但初始猜测必须避开临界点和别的根

## 常见错误与陷阱
- **忘记检查端点**: 一阶/二阶导数检验只适用于临界点，端点必须单独代入比较（如 P=x(10−x) 的最小值 16 出现在端点 x=2、8）
- **忽略定义域**: 变量常有隐含范围（x∈[2,8]、h∈[0,150]、r∈(0,∞)），不先确定范围会漏掉端点极值或取到无意义解
- **开区间端点直接代入**: (0,∞) 的端点不能代入，必须取极限判断（如 r→0⁺ 时 C→∞）
- **结论用自造符号表述**: 最终答案要用题目原有的文字量陈述，不能提自己引入的 x、y、Q
- **线性化选错锚点 a**: x 离 a 太远时近似完全失真（用 a=9 估 √62 得 11⅚ > 8，荒谬）；a 必须接近 x 且 f(a) 易算
- **牛顿法失效的四种情况**: ① f′(a)≈0（切线近水平，b 远离真根）——初始猜测勿在临界点附近；② 多根时收敛到错误的根——初始猜测要贴近目标根；③ 近似越来越糟（如 f(x)=x^{1/3}，迭代给出 −2a，发散）；④ 陷入循环（a→b→a，如特定奇函数从 a=1 出发）
- **用 d 作变量名**: dd/dx 极易混淆，微积分中避免把 d 当变量

## 公式与参考表
- 线性化: **L(x) = f(a) + f′(a)(x − a)**，f(x) ≈ L(x)（x 接近 a 时）
- 微分: **df = f′(a)Δx**，其中 Δx = x − a；f(a+Δx) ≈ f(a) + f′(a)Δx
- 误差（余项）: **r(x) = f(x) − L(x) = ½f″(c)(x−a)²**，c 介于 x 与 a 之间
- 误差界: **|误差| ≤ ½M|x−a|²**，M = max|f″(t)|（t 在 x 与 a 之间）
- 高估/低估判据: f″ 在 a 与 x 之间为负 ⇒ 高估；为正 ⇒ 低估
- 牛顿法: **x_{n+1} = x_n − f(x_n)/f′(x_n)**
- 常用小量近似: h 很小时 ln(1+h) ≈ h；ln(e+h) ≈ 1 + h/e
- 常用几何式: 圆柱 V=πr²h，封闭圆柱表面积 A=2πrh+2πr²；球 V=πD³/6；勾股定理消元

## 精讲例题
**圆柱罐成本最小化（13.1.4）**: 生产封闭中空圆柱罐，体积必为 16π 立方英寸，金属 2 美分/平方英寸，求成本最低的尺寸与成本。

解：
1. 变量：半径 r、高 h（英寸），成本 C（美分）要最小化；r, h ∈ (0, ∞)
2. 方程：约束 πr²h = 16π ⇒ h = 16/r²；成本 C = 2A = 4πrh + 4πr²
3. 消元：C = 4π(16/r + r²)
4. 求导：dC/dr = 4π(−16/r² + 2r) = 0 ⇒ 2r³ = 16 ⇒ r = 2（唯一临界点）
5. 端点：lim_{r→0⁺} C = ∞，lim_{r→∞} C = ∞，两端均不可取
6. 检验：d²C/dr² = 4π(32/r³ + 2) > 0（凹向上），故 r=2 为全局最小
7. 回代：h = 16/4 = 4，C = 4π(8+4) = 48π ≈ 1.50 美元

结论：半径 2 英寸、高 4 英寸（直径等于高）时成本最低，为 48π 美分。变体（焊接费 14 美分/英寸）则 C = 4π(16/r + r² + 14r)，临界点方程化为 r³+7r²−8=0，解得 r=1，h=16，C=124π 美分——焊接成本使最优半径变小，符合直觉。

## 要点速记
1. 最优化 = 先确定义域，再找临界点+端点比大小；导数检验只管临界点，端点必须单独算
2. 消元困难时别硬消：目标式与约束式同时隐求导，往往直接得到变量间关系（如 2r = h）
3. 线性化三要素：好算的锚点 a、公式 L(x)=f(a)+f′(a)(x−a)、x 必须靠近 a
4. 误差由 f″ 决定：符号定高低估，|误差| ≤ ½M|x−a|²；锚点靠近一点，误差平方级减小
5. 牛顿法迭代 x_{n+1}=x_n−f(x_n)/f′(x_n)，初始猜测要贴近目标根、远离临界点，否则发散或收敛错根
6. 相对误差会随维度放大：线性测量 ε% 的误差，算体积时约放大为 3ε%
7. 唯一性论证：f′ 恒正 ⇒ 至多一根；配合介值定理（端点异号）⇒ 恰好一根
