# 第15章：积分

## 核心思想
积分是微分的另一半：用求和符号和分区逼近，把"已知速度求位移"转化为"求速度-时间图像下的有向面积"；当分区的最大区间（mesh）趋于 0 时，阶梯函数的面积和收敛为定积分。

## 本节框架与方法
- **求和符号（sigma 求和）**: $\sum_{j=a}^{b} f(j)$ 表示把 f(j) 从 j=a 到 j=b 逐一代入相加
  - 何时使用: 缩写有规律的级数，尤其是改变求和起点/终点或剔除部分项时
  - 怎么做: j 是虚拟变量（求和指标），可任意换字母（j、k、a、α）而不改变和式；真实变量只有上下限。写完后务必代入 j=a、j=a+1 及末尾几项校验展开式是否正确
- **伸缩求和法（telescoping series）**: $\sum_{j=a}^{b}(f(j)-f(j-1)) = f(b)-f(a-1)$
  - 何时使用: 通项能写成"相邻两项函数值之差"的求和，以及由此推导幂和公式
  - 怎么做: 展开后中间项全部消掉，只剩首末；反用即可从 $\sum j^k$ 的低阶公式推出高阶公式（见精讲例题）
- **分区求位移**: 总位移 $= \sum_{j=1}^{n} v_j(t_j - t_{j-1})$，其中 $a=t_0<t_1<\cdots<t_n=b$
  - 何时使用: 速度在若干小区间内分别恒定时（阶梯状速度图）
  - 怎么做: 把时间段分成小区间，每段用 位移=速率×时间 求长方形面积，再累加
- **样本点逼近（黎曼和的雏形）**: 速度曲线下的面积 $\approx \sum_{j=1}^{n} v(c_j)(t_j - t_{j-1})$，$c_j$ 是 $[t_{j-1}, t_j]$ 内任取的时刻
  - 何时使用: 速度 v(t) 是连续函数而非分段常数时
  - 怎么做: 在每个小区间取样本速度 v(c_j) 把曲线"画平"成台阶，用台阶面积逼近真实面积
- **最大区间极限**: 实际面积 $= \lim_{\text{mesh}\to 0} \sum_{j=1}^{n} v(c_j)(t_j - t_{j-1})$
  - 何时使用: 从估算过渡到精确值
  - 怎么做: 要求每一个分区间隔都很小（而不是大部分小）——只要有一个大长方形就会严重破坏估算；让 mesh 趋于 0，划分份数 n 自动趋于无穷
- **上和与下和**: 在每个小区间取最大速度得上和（长方形在曲线之上），取最小速度得下和（长方形在曲线之下）
  - 何时使用: 需要判断某次估算偏大还是偏小，或证明极限与样本点选取无关时
  - 怎么做: 对任意样本点选择都有 下和 ≤ 实际面积 ≤ 上和；mesh→0 时上下和趋于同一极限，由三明治定理夹出真实面积

## 关键概念
- **求和指标（虚拟变量）**: sigma 中遍历上下限的临时变量，展开式中并不出现，换字母不影响结果
- **伸缩级数**: 形如 $\sum(f(j)-f(j-1))$ 的级数，展开后相邻项相消，只剩 $f(b)-f(a-1)$
- **分区（partition）**: 把 $[a,b]$ 切成小时间段 $a=t_0<t_1<\cdots<t_n=b$ 的一组点
- **有向面积**: 横坐标轴下方的面积记为负，上方的记为正；有向面积对应位移
- **位移 vs 路程**: 位移用速度 v 的图像下（带符号）面积，路程用速率 $|v|$ 的图像下（全正）面积
- **样本速度 v(c_j)**: 在小区间 $[t_{j-1}, t_j]$ 内任选时刻 $c_j$，以该时刻速度代表整个区间
- **最大区间（mesh）**: 所有小区间长度 $(t_j - t_{j-1})$ 的最大值；逼近精度的控制量
- **上和 / 下和**: 同一分区下取各区间最大/最小速度所得的长方形面积和，把真实面积夹在中间

## 心智模型
- 当看到"已知每个时刻的速度，求走了多远"时，画 v-t 图像，位移就是曲线下的**有向面积**
- 当结果可能是"往回走"时，区分**位移（带符号，v 的图像）**与**路程（取绝对值，|v| 的图像）**
- 当速度连续变化时，用**台阶函数**逼近：每个小台阶的高度是某样本点的速度——这就是从求和到积分的桥梁
- 当担心"取样点不同结果会不会不同"时，用**上和下和夹击**：连续函数保证 mesh→0 时夹逼出唯一极限（三明治定理）

## 常见错误与陷阱
- **把 $\sum_{m=1}^{200} 5$ 答成 5**: 每一项都是 5，共 200 项，结果是 200×5=1000——常数求和要乘以项数
- **数错项数**: 从 A 到 B（含两端）共有 B−A+1 项；$\sum_{q=100}^{1000} 1$ 是 901 项而非 900
- **写 $\sum_{j=1}^{3001}\sin(j)$ 想表示奇数项**: 这会包含偶数项；奇数项要用 $\sin(2j-1)$ 并把上限改为 1501（解 2j−1=3001）
- **改写完求和式不校验**: 必须代入首几项和末几项核对展开式两端一致
- **用单一"平均速率×时间"算分段变速行程**: 除非真的匀速，否则必须分段求和；总位移/总时间给出的平均速率未必等于任何一段的速率
- **只缩小大部分分区而留下一个大区间**: 一个宽大长方形就会毁掉整个估算，必须让**最大区间**（而非仅仅分区间数的多少）趋于 0
- **忽略面积符号**: 轴下方面积计为负才能得到位移；若要路程，先对速度取绝对值再算面积

## 公式与参考表
求和公式（由伸缩求和法推出）：

| 公式 | 结果 |
|---|---|
| $\sum_{j=1}^{n} 1$ | $n$ |
| $\sum_{j=1}^{n} j$ | $\dfrac{n(n+1)}{2}$ |
| $\sum_{j=1}^{n} j^2$ | $\dfrac{n(n+1)(2n+1)}{6}$ |
| $\sum_{j=1}^{n}(2j-1)$（前 n 个奇数） | $n^2$ |
| $\sum_{j=a}^{b}(f(j)-f(j-1))$ | $f(b)-f(a-1)$ |

项数：从 A 到 B（含）共 B−A+1 项。

有向面积与位移框架：

- 阶梯速度下总位移 $=\sum_{j=1}^{n} v_j(t_j - t_{j-1})$
- 连续速度下估算 $\approx\sum_{j=1}^{n} v(c_j)(t_j - t_{j-1})$，精确值 $=\lim_{\text{mesh}\to 0}\sum_{j=1}^{n} v(c_j)(t_j-t_{j-1})$
- 位移 = v(t) 图像下的有向面积；路程 = |v(t)| 图像下的面积
- 夹逼关系：下和 ≤ 实际面积 ≤ 上和；v 连续 ⇒ 极限与分区和样本点选取无关

## 精讲例题
用伸缩求和法推出平方和公式 $\sum_{j=1}^{n} j^2 = \frac{n(n+1)(2n+1)}{6}$：

1. 由伸缩性：$\sum_{j=1}^{n}(j^3 - (j-1)^3) = n^3 - (1-1)^3 = n^3$
2. 展开被加项：$j^3-(j-1)^3 = 3j^2 - 3j + 1$，故 $\sum_{j=1}^{n}(3j^2-3j+1) = n^3$
3. 拆分求和并提常数：$3\sum j^2 - 3\sum j + \sum 1 = n^3$
4. 移项除以 3：$\sum j^2 = \frac{1}{3}\left(n^3 + 3\sum j - \sum 1\right)$
5. 代入已知 $\sum_{j=1}^n j = \frac{n(n+1)}{2}$ 和 $\sum 1 = n$：
   $\sum j^2 = \frac{1}{3}\left(n^3 + \frac{3n(n+1)}{2} - n\right) = \frac{2n^3+3n^2+n}{6} = \frac{n(n+1)(2n+1)}{6}$
6. 验证 n=100：$1^2+2^2+\cdots+100^2 = \frac{100\cdot 101\cdot 201}{6} = 338\,350$

同样的技巧（用 $j^2-(j-1)^2=2j-1$）先推出了 $\sum j = n(n+1)/2$，印证了高斯 10 岁时"倒序相加"算 1+…+100=5050 的方法。

## 要点速记
1. 求和指标是虚拟变量：$\sum_{j=1}^6 1/j^2$ 中 j 可任意换名，真实变量是上下限
2. 写完任何求和式，代入首尾几项校验——大多数错误出在上限换算
3. 见到 $f(j)-f(j-1)$ 形式的通项，立刻想到伸缩求和，答案只剩 $f(b)-f(a-1)$
4. 位移看带符号面积，路程看 |v| 的面积；两者只在始终同向行驶时相等
5. 逼近精度由最大区间（mesh）控制，而不是分区个数 n；mesh→0 已隐含 n→∞
6. 上和/下和 + 三明治定理是"极限与取样方式无关"的直观证明
7. 幂和公式呈阶梯式推导：$\sum 1 \to \sum j \to \sum j^2 \to \cdots$，每升高一阶靠一次伸缩求和
