# 第7章：三角函数的极限和导数

## 核心思想
三角函数极限的求解取决于三角函数"作用在什么样的量上"而非 x 趋向哪里：x→0 时 sin(小数) ≈ 小数（核心极限 sin(x)/x→1），大数上则只有有界性可用（三明治定理）；六个三角函数的导数都可从这两个核心极限导出，并据此描述简谐运动。

## 本节框架与方法

- **小数情况匹配法**: lim(x→0) sin(小数)/同样的小数 = 1（tan 同理，cos 只有 lim(x→0) cos(小数) = 1，无匹配要求）
  - 何时使用: 三角函数的变量在 x→0 时是趋于 0 的量（含 x→∞ 时变量为 5/x 这类"隐形小数"）
  - 怎么做: 对不匹配的分式做"乘除同一个量"（如 sin(5x)/x 改写成 [sin(5x)/5x]·5）；分子分母中的每个 sin/tan 因子分别配对到自己的变量上，剩余 x 的幂次提到外面约分；cos(小数) 因子直接替换为 1；sec/csc/cot 先化成 sin/cos/tan 再用此法

- **大数情况三明治法**: 对任意 x，−1 ≤ sin(x) ≤ 1 且 −1 ≤ cos(x) ≤ 1
  - 何时使用: 三角函数作用在大数上（x→∞ 时 sin(x)，或 x→0 时 sin(5/x) 这种隐形大数）
  - 怎么做: 从 −1 ≤ sin(任何东西) ≤ 1 出发，对不等式三方做同样的运算（注意：乘以负数要反转不等号），把目标函数夹在两个极限已知的函数之间，用三明治定理。一般原理：对任意正指数 α，lim(x→∞) sin(任何东西)/x^α = 0

- **多项式+三角函数的∞极限**: 若 p、q 是（多项式型）函数且附带加减的 sin/cos 项，这些三角项不改变次数，直接忽略（除非 p 或 q 次数为 0，那时三角项举足轻重）
  - 何时使用: lim(x→∞) p(x)/q(x) 且分子分母含附加的（非相乘的）sin/cos
  - 怎么做: 只保留最高次项做 4.3 节的除法技巧，三角项/最高次项 → 0（严格证明需对每项用三明治定理）

- **其他情况（x→a, a≠0）替换法**: 设 t = x − a，化为 t→0 的小数情况
  - 何时使用: 在非零点求三角函数极限且代入得 0/0
  - 怎么做: 换元后用三角恒等式（如 cos(π/2 + t) = −sin(t)，注意正弦是奇函数）化为标准极限

- **三角函数求导**: 只用两个极限 + 商/链式法则，不再回到定义
  - sin/cos 用导数定义 + 和角公式推出；tan = sin/cos 用商法则；sec、csc 用链式法则优于商法则（尽管商法则也可行）；cot 可用商法则/链式法则/乘积法则任一种

- **复合三角函数快捷法则**: d/dx sin(ax) = a cos(ax)（对 tan、sec 等都成立，最前面多乘一个 a）
  - 何时使用: 内函数是线性函数 ax
  - 怎么做: 直接写答案，免去显式链式法则

## 关键概念
- **核心极限**: lim(x→0) sin(x)/x = 1，是整个三角微积分的基石（7.1.5 节几何证明）
- **匹配原则**: 分母必须与分子中正弦/正切作用的变量完全相同，且该变量须随 x→0 趋于 0
- **有界性**: 对任意 x，−1 ≤ sin(x) ≤ 1、−1 ≤ cos(x) ≤ 1；tan 无此性质（有垂直渐近线）
- **隐形小数/大数**: 判断大小看的是三角函数内部的变量而非 x 本身：x→0 时 5/x 是大数，x→∞ 时 5/x 是小数
- **cos 的不对称性**: cos(x)/x 在 x→0 时双侧极限不存在（右极限 +∞，左极限 −∞），与 sin、tan 截然不同
- **关键不等式**: sin(x) < x < tan(x)（0 < x < π/2），由面积比较得来，是 sin(x)/x 极限证明的核心
- **简谐运动**: 位移形如 x = 3 sin(4t) 的振荡运动，满足 a = −16x（加速度与位移反向且成正比）
- **可导但导数不连续**: f(x) = x²sin(1/x)（补定义 f(0)=0）处处可导，但 lim(x→0) f′(x) 不存在

## 心智模型
- 当三角函数内部是趋于 0 的量时，把 sin(小数) 和 tan(小数) 看作"小数本身"（仅限乘积或商的语境），把 cos(小数) 看作 1
- 当三角函数内部是趋于 ∞ 的量时，把 sin、cos 看作"夹在 −1 和 1 之间的死重"，靠三明治定理挤掉
- 把三明治定理看作"用大数的有界性换取极限"：sin(任何东西)/x^α（α>0）→ 0
- 把互余函数求导看作"加 co 加负号"的变换：sec′ = sec·tan ⟹ csc′ = −csc·cot；cos′ 与 cot′ 同理

## 常见错误与陷阱
- **只看 x→0 或 x→∞ 判断大小**: 错。lim(x→0) x sin(5/x) 是大数情况（5/x→∞），lim(x→∞) x sin(5/x) 才是小数情况。判断依据永远是三角函数作用的量
- **在和/差语境中替换等价量**: "sin(x) 表现得像 x" 只在乘积或商中成立。lim(x→0) (x−sin(x))/x³ 不能说成 0/x³ = 0（除常数 0 外没有函数"表现得像 0"），此极限需洛必达法则（第14章）或麦克劳林级数（第24章）；同理 1−cos²(x) 表现得像 x² 而非 0
- **不等式乘负数不反向**: x→0⁻ 时用 x（负）乘 −1 ≤ sin(5/x) ≤ 1 必须反转不等号，否则得 2 ≤ … ≤ −2 之类的荒谬结论；稳妥做法是先算右极限再算左极限
- **cos 套用匹配公式**: lim(x→0) cos(小数)/同样的小数 不存在；只有 lim(x→0) cos(小数) = 1
- **忘记复合求导前面的系数**: d/dx sin(ax) = a cos(ax)，漏掉 a 是最常见的错误
- **补定义后忘了用定义求特殊点导数**: x²sin(1/x) 在 x=0 处无法用乘积法则公式，必须回到 f′(0) = lim(h→0) [f(h)−f(0)]/h = lim(h→0) h sin(1/h) = 0

## 公式与参考表

### 关键三角极限
| 极限 | 值 |
|---|---|
| lim(x→0) sin(x)/x | 1 |
| lim(x→0) tan(x)/x | 1 |
| lim(x→0) cos(x) | 1 |
| lim(x→0) cos(x)/x | 不存在（±∞） |
| lim(x→0) (1−cos(x))/x | 0 |
| lim(x→0) (1−cos(x))/x² | 1/2 |
| lim(x→0) (1−cos²(x))/x² | 1 |
| lim(x→∞) sin(任何东西)/x^α (α>0) | 0（cos 同理） |
| lim(x→0) x sin(5/x) | 0 |

### 三角函数导数（六个框公式）
| 函数 | 导数 |
|---|---|
| sin(x) | cos(x) |
| cos(x) | −sin(x) |
| tan(x) | sec²(x) |
| sec(x) | sec(x)tan(x) |
| csc(x) | −csc(x)cot(x) |
| cot(x) | −csc²(x) |

记忆法：三个互余（co-）函数的导数都带负号，且是正常导数的 co- 化。
另有：d²/dx² sin(x) = −sin(x)，d²/dx² cos(x) = −cos(x)（二阶导等于负的原函数，多项式无此性质）。
复合速记：d/dx sin(ax) = a cos(ax)，对任意常数 a。

### 重要不等式
sin(x) < x < tan(x)（0 < x < π/2）；扇形面积 xr²/2（夹角 x 弧度、半径 r）。

## 精讲例题

求 lim(x→0) sin³(2x) cos(5x¹⁹) / [x tan(5x²)]。

解：逐因子处理。
1. sin³(2x) 配自己的变量：写成 [sin(2x)/(2x)]³ · (2x)³；
2. cos(5x¹⁹)：5x¹⁹ 是小数，cos → 1，不处理；
3. tan(5x²) 写成 [tan(5x²)/(5x²)] · (5x²)；
4. 提出不匹配的 x 幂次：分子 (2x)³ = 8x³，分母 x·5x² = 5x³，约分得 8/5；
5. 所有三角分式极限为 1（cos 因子为 1），故

极限 = (1)³·(1)/1 × 8/5 = 8/5。

要点：这就是 4.3 节有理函数"除以并乘以最高次项"技巧的三角版本——每个 sin/tan 因子必须配对自己的变量。

## 要点速记
1. 判断"小数/大数情况"永远看三角函数的内部变量，不看 x 的趋向
2. sin(小数)/同样的小数 = 1 是万能钥匙：不匹配就乘除同一个量凑出匹配
3. 大数情况只有一张牌：−1 ≤ sin, cos ≤ 1 + 三明治定理；乘负数记得反转不等号
4. 等价替换（sin(x)≈x）只限乘除语境，和差中禁用
5. 6 个三角导数公式：co- 函数带负号；复合线性内函数直接前面乘 a
6. 1−cos(x) 类极限的标准武器：分子分母同乘 1+cos(x)，化为 sin²(x)
7. 可导 ≠ 导数连续：x²sin(1/x) 是标准反例
