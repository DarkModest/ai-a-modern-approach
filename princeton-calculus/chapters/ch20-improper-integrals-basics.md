# 第20章：反常积分：基本概念

## 核心思想
反常积分（被积函数无界或积分区间无界）通过极限来定义：在瑕点附近"切掉一小段"或把无穷上限换成有限数 N，再取极限；核心问题永远是**收敛还是发散**，而不是收敛于多少。本章给出四大判别法（比较、极限比较、p、绝对收敛）的理论基础。

## 本节框架与方法

- **定义法（极限）**: 用极限把反常积分转化为正常积分的极限
  - 何时使用: 判断任何反常积分的第一步；被积函数简单到可直接求反导数时
  - 怎么做:
    - 仅在 x = a 处破裂: ∫[a,b] f(x)dx = lim(ε→0⁺) ∫[a+ε,b] f(x)dx
    - 仅在 x = b 处破裂: ∫[a,b] f(x)dx = lim(ε→0⁺) ∫[a,b−ε] f(x)dx
    - 上限为 ∞: ∫[a,∞) f(x)dx = lim(N→∞) ∫[a,N] f(x)dx
    - 下限为 −∞: ∫(−∞,b] f(x)dx = lim(N→∞) ∫[−N,b] f(x)dx
    - 极限存在 → 收敛；不存在（为 ±∞ 或振荡） → 发散

- **拆分法（处理多个瑕点）**: 在每个瑕点处把积分切开
  - 何时使用: 区间内部有破裂点，或有多个瑕点（包括 ∞ 和 −∞，它们也算瑕点）
  - 怎么做: 拆分使**每部分至多一个瑕点，且瑕点在积分限上**；原积分收敛 ⟺ 所有部分都收敛，任何一个发散则整体发散。拆分点任选（如 1/2, 3/2），不影响敛散性

- **比较判别法**: 非负函数，比大小的方向决定一切
  - 何时使用: f, g 在区间上非负，且已知其中一个的敛散性
  - 怎么做:
    - 证发散: 找更小的 g，若 f(x) ⩾ g(x) ⩾ 0 且 ∫g 发散（=∞），则 ∫f ⩾ ∞ 发散
    - 证收敛: 找更大的 g，若 0 ⩽ f(x) ⩽ g(x) 且 ∫g 收敛（<∞），则 ∫f 收敛
    - 方向反了（f ⩾ g 且 g 收敛，或 f ⩽ g 且 g 发散）→ **得不到任何结论**
    - 有多个瑕点时先拆分再用

- **极限比较判别法**: 渐近等价的函数同敛散
  - 何时使用: 难以找到严格大/小于 f 的比较函数，但能找到一个走势"非常接近"的简单函数 g
  - 怎么做: 找 g 使 lim(x→a) f(x)/g(x) = 1（即 f(x) ∼ g(x)），且两函数在区间上无其他瑕点，则 ∫f 与 ∫g 同时收敛或同时发散（收敛值可不同）。极限为任意正数也成立
  - 原理: f ∼ g 蕴含存在 c 使 1/2 g(x) ⩽ f(x) ⩽ 2g(x)（x∈(a,c]），于是可用比较判别法

- **p 判别法**: 提供现成的标准比较函数 1/xᵖ (p > 0)
  - 何时使用: 几乎所有判别题的最终归宿——把 f 与 1/xᵖ 比较
  - 怎么做: 见"公式与参考表"

- **绝对收敛判别法**: 处理变号振荡函数
  - 何时使用: f 在积分区间上正负振荡，比较/极限比较判别法（要求非负）失效
  - 怎么做: 若 ∫[a,b] |f(x)|dx 收敛，则 ∫[a,b] f(x)dx 收敛。对 |f| 用比较判别法（如 |sin x| ⩽ 1）
  - 注意逆命题不成立：|f| 发散推不出 f 发散（条件收敛情形，见 23.7 节），此时判别法失效需回到定义

## 关键概念
- **反常积分**: 满足以下任一条件的积分 ∫[a,b] f(x)dx: (1) f 在 [a,b] 内无界; (2) b = ∞; (3) a = −∞
- **破裂点**: 若 f(x) 在 x 接近 c 时无界（通常即有垂直渐近线），则 f 在 x = c 有破裂点
- **瑕点**: 需要"分别对待"的点——破裂点，以及 ∞ 和 −∞（无穷限恒视为瑕点）
- **收敛**: 定义中的极限存在且有限；正常积分天然收敛
- **发散**: 定义中的极限不存在、为 ±∞ 或振荡；发散积分没有有意义的"面积"
- **敛散性与端点无关**: 在只有 x = a 一个破裂点的情形，把上限 b 换成任意 c > a（不引入新瑕点）不改变敛散性——敛散完全由 f 在瑕点附近的走势决定；同理 ∫[a,∞) 中 a 的取值无关
- **渐近等价 f(x) ∼ g(x) (x→a)**: lim(x→a) f(x)/g(x) = 1；指比值接近 1，**不是差值小**
- **渐近等价的运算**: 可乘、除、取幂、替换变量（如 sin(4x⁷) ∼ 4x⁷）；**不可加减**（tan x − sin x ∼ x − x = 0 无意义，没有函数与 0 渐近等价）
- **绝对收敛**: ∫|f| 收敛；蕴含 ∫f 收敛
- **常用渐近等价**: x→0 时 sin x ∼ x, tan x ∼ x, eˣ−1 ∼ x, ln(1+x) ∼ x；x→∞ 时多项式 ∼ 最高次项（如 3x³−1000x²+5x−7 ∼ 3x³）

## 心智模型
- **"狭长到足够窄"模型**: 无穷区域面积未必无穷——只要区域向渐近线/无穷远处收得足够快。判别就是问"函数是否足够贴近 y 轴（对 0 处瑕点）或 x 轴（对 ∞ 处瑕点）"
- **当需要判断敛散时，用"先拆分、再逐段判别"**：每段只留一个瑕点在端点上
- **当函数在瑕点附近走势难看时，用渐近等价替身**：sin√x 难求反导，但 x→0⁺ 时 sin√x ∼ √x，换成 1/√x 即可
- **当函数正负振荡时，先加绝对值**：|sin|、|cos| 一律 ⩽ 1，常常立刻化归为 p 判别法
- **记忆锚点**: 只记 ∫[1,∞) 1/x² 收敛 和 ∫[0,1] 1/√x 收敛 两个事实，加上"0 处与 ∞ 处情形相反、p=1 两头皆散"，即可重建整个 p 判别法

## 常见错误与陷阱
- **忽略区间内部的瑕点**: 如 ∫[0,3] 1/[x(x−1)(x+1)(x−2)]dx 在 x = 0, 1, 2 有瑕点，必须拆分；区间外的瑕点（x = −1）不用管。直接对全区间用牛顿-莱布尼茨公式会得出荒谬结果
- **误以为只有部分发散时整体还能收敛**: 拆分后任何一部分发散，整个积分就发散——"不能把不存在的东西加到别的东西上"
- **比较判别法用错方向**: f ⩾ g 且 g 收敛 ⇒ 无结论；f ⩽ g 且 g 发散 ⇒ 无结论。只有"大于发散 ⇒ 发散"和"小于收敛 ⇒ 收敛"两条有效
- **混淆 p 判别法两个方向**: ∞ 处要 p > 1 才收敛，0 处要 p < 1 才收敛，方向恰好相反；p = 1（1/x）两处都发散
- **对渐近等价做加减**: tan x − sin x ∼ 0 之类的推导毫无意义；∼ 只支持乘、除、幂、变量替换
- **以为 f ∼ g 意味着 f − g 很小**: 比值→1 不代表差值小（万亿与万亿加一百万渐近等价，差一百万）
- **|f| 发散就断言 f 发散**: 绝对收敛判别法是单向蕴含；|f| 发散时判别法失效（如 ∫[0,∞) cos x dx，须回到定义看 lim sin(N) 不存在——因振荡而发散）
- **过度关心收敛值**: 判别阶段只问收敛/发散；用计算机硬算发散积分会得到无意义的结果

## 公式与参考表

**反常积分定义（瑕点在端点）**

| 情形 | 定义 |
|---|---|
| 瑕点仅在 a | ∫[a,b] f dx = lim(ε→0⁺) ∫[a+ε,b] f dx |
| 瑕点仅在 b | ∫[a,b] f dx = lim(ε→0⁺) ∫[a,b−ε] f dx |
| 上限 ∞ | ∫[a,∞) f dx = lim(N→∞) ∫[a,N] f dx |
| 下限 −∞ | ∫(−∞,b] f dx = lim(N→∞) ∫[−N,b] f dx |

**p 判别法**（a > 0 任意有限值）

| 积分 | 收敛 | 发散 |
|---|---|---|
| ∫[a,∞) 1/xᵖ dx | p > 1 | p ⩽ 1 |
| ∫[0,a] 1/xᵖ dx | p < 1 | p ⩾ 1 |

注意两组条件恰好相反；p = 1 时两者皆发散。证明核心：∫x⁻ᵖdx = x¹⁻ᵖ/(1−p)，看 lim(N→∞) N¹⁻ᵖ 是否存在（p=1 时对数发散）。微妙例：∫[1,∞) 1/x¹·⁰⁰⁰⁰⁰⁰¹ dx 收敛——指数从 1 变到 1.0000001 即引起质变。

**比较判别法**（f, g 非负）
- 0 ⩽ f(x) ⩽ g(x) 且 ∫g 收敛 ⇒ ∫f 收敛
- f(x) ⩾ g(x) ⩾ 0 且 ∫g 发散 ⇒ ∫f 发散

**极限比较判别法**: x→a 时 f(x) ∼ g(x)（即 f/g → 1，极限为任意正数亦可），且区间内无其他瑕点 ⇒ ∫[a,b] f 与 ∫[a,b] g 同敛散。

**绝对收敛判别法**: ∫[a,b] |f(x)|dx 收敛 ⇒ ∫[a,b] f(x)dx 收敛（对无穷区间同样成立）。
证明技巧: 设 g(x) = |f(x)| + f(x)，则 0 ⩽ g(x) ⩽ 2|f(x)|，由比较判别法 ∫g 收敛，而 f = g − |f| 是两个收敛积分之差。

## 精讲例题

**例**：判断 ∫[1,∞) sin(x)/x² dx 的敛散性。

解：
1. 唯一瑕点是 ∞；但 sin(x) 正负振荡，比较/极限比较判别法要求非负函数，不能直接用 → 改用绝对收敛判别法
2. 考察 ∫[1,∞) |sin(x)|/x² dx（x² 非负，故 |sin/x²| = |sin|/x²）
3. 对所有 x，|sin(x)| ⩽ 1，故 |sin(x)|/x² ⩽ 1/x²
4. 由 p 判别法（∞ 处，p = 2 > 1），∫[1,∞) 1/x² dx 收敛
5. 比较判别法 ⇒ ∫[1,∞) |sin(x)|/x² dx 收敛
6. 绝对收敛判别法 ⇒ 原积分 ∫[1,∞) sin(x)/x² dx 收敛。注意这里必须真的取绝对值，步骤不可省

**对照例**: ∫[0,∞) cos(x)dx。取绝对值得 ∫|cos x|dx，无数个小山丘面积之和发散 → 绝对收敛判别法失效；回到定义 lim(N→∞) ∫[0,N] cos x dx = lim(N→∞) sin(N) 不存在（在 −1 与 1 间振荡）→ 发散，原因是**振荡**而非趋于无穷。

## 要点速记
1. 见到反常积分，第一问永远是"收敛还是发散"，收敛值是次要的
2. 先找所有瑕点（破裂点 + ∞/−∞），拆分使每段恰有一个瑕点且位于端点；任何一段发散则全盘发散
3. 敛散性只取决于瑕点附近的局部行为——换掉远处的端点（不引入新瑕点）毫无影响
4. 标准比较对象是 1/xᵖ：∞ 处 p > 1 收敛，0 处 p < 1 收敛，p = 1 两头皆散
5. 难算的 f 在瑕点附近换成渐近等价的简单 g（x→0 时 sin、tan、eˣ−1、ln(1+x) 都 ∼ x），敛散结论直接搬过来
6. 函数振荡变号时先取绝对值；|f| 收敛即 f 收敛，|f| 发散则此路不通，须回到极限定义
7. 比较判别法只有两条有效方向：比发散函数还大 ⇒ 发散；比收敛函数还小 ⇒ 收敛
