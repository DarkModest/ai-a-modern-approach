# 第22章：数列和级数：基本概念

## 核心思想
级数收敛的本质是部分和数列存在极限；无穷级数与反常积分高度平行，反常积分的比较、极限比较、p 判别、绝对收敛判别法可平移使用，另有级数特有的比式、根式、积分、交错级数判别法。

## 本节框架与方法
- **第n项判别法**: 若 lim(n→∞) a_n ≠ 0（或极限不存在），则 Σa_n 发散
  - 何时使用: 判断级数发散的第一道快速筛选，尤其当通项明显不趋于 0 时
  - 怎么做: 求通项极限；≠0 或不存在 ⇒ 发散；=0 ⇒ 判别法失效（可能收敛也可能发散，如 Σ1/n² 收敛、Σ1/√n 发散），**绝不能**用它证明收敛
- **比较判别法**: 各项为正；0 ≤ b_n ≤ a_n 且 Σb_n 发散 ⇒ Σa_n 发散；0 ≤ a_n ≤ b_n 且 Σb_n 收敛 ⇒ Σa_n 收敛
  - 何时使用: 通项含 |sin(n)|、|cos(n)| 等可控因子时（用 ≤1 放缩）
  - 怎么做: 猜敛散方向，再找更大收敛级数（证收敛）或更小发散级数（证发散）
- **极限比较判别法**: 若 n→∞ 时 a_n ~ b_n（即 lim a_n/b_n = 1），则 Σa_n 与 Σb_n 同敛散
  - 何时使用: 大 n 时通项渐近等价于某个已知级数的项（如 sin(1/2ⁿ) ~ (1/2)ⁿ）
  - 怎么做: 用第21章函数渐近关系（x→0 时 sin x ~ x 等）把通项换成简单项，与几何级数或 p 级数比较；注意只知敛散性，不知收敛值
- **p判别法**: Σ1/n^p 当 p > 1 收敛，p ≤ 1 发散
  - 何时使用: 幂函数型通项，或作为其他判别法的比较基准
  - 怎么做: 读出幂次 p 直接下结论；p ≤ 0 时用第n项判别法；调和级数 Σ1/n 为 p=1 边界情形，发散
- **绝对收敛判别法**: 若 Σ|a_n| 收敛，则 Σa_n 收敛（称为绝对收敛）
  - 何时使用: 通项正负不规则出现（如 sin(n)(1/2)ⁿ）或含 (−1)ⁿ 时先试
  - 怎么做: 对通项取绝对值后用正项级数判别法；Σ|a_n| 发散时不能得出原级数发散，只能说明不绝对收敛
- **比式判别法**: 令 b_n = |a_{n+1}/a_n|，L = lim b_n。L < 1 ⇒ 绝对收敛；L > 1 ⇒ 发散；L = 1 或极限不存在 ⇒ 无结论
  - 何时使用: 通项含阶乘、指数（相邻项比值易化简）时首选；反常积分无对应物
  - 怎么做: 求相邻项之比绝对值的极限；L=1 的失效例：Σ1/n^p 对任何 p 比值极限都是 1
- **根式判别法(n次方根判别法)**: 令 b_n = |a_n|^{1/n}，L = lim b_n。L < 1 ⇒ 绝对收敛；L > 1 ⇒ 发散；L = 1 ⇒ 无结论
  - 何时使用: 通项整体带 n 次幂时
  - 怎么做: 取第 n 项绝对值的 n 次方根求极限；同样在 Σ1/n^p 上失效（极限恒为 1）
- **积分判别法**: 若 f 为正、递减、连续且 f(n) = a_n，则 ∫₁^∞ f(x)dx 与 Σa_n 同敛散
  - 何时使用: 通项对应函数的正性、递减性易验证，且积分易算时（是 p 判别法的最简证明工具）
  - 怎么做: 验证 f 正且递减（可求导），再对积分用反常积分判别法；级数起点可变，只需同步改积分下限
- **交错级数判别法**: 若级数各项正负交错，|a_n| 递减且 lim |a_n| = 0，则级数收敛
  - 何时使用: 仅当已验证级数**不绝对收敛**、但各项严格交错时
  - 怎么做: 验证三条件：交错、绝对值递减、绝对值趋于 0；满足 ⇒ 收敛（可能只是条件收敛，如 Σ(−1)ⁿ/n）

## 关键概念
- **数列收敛**: lim(n→∞) a_n = L 存在且有限，称 {a_n} 收敛于 L，否则发散（可发散到 ±∞ 或振荡无极限）
- **级数收敛**: 部分和数列 A_N = Σ_{n=1}^N a_n 的极限 lim A_N 存在且等于 L，则级数收敛于 L，否则发散
- **部分和数列**: A_N = a_1 + ... + a_N，级数敛散性完全由该数列的极限决定
- **几何级数**: Σ_{n=0}^∞ ar^n，当 −1 < r < 1 时收敛于 a/(1−r)，r ≥ 1 或 r ≤ −1 时发散
- **调和级数**: Σ1/n，发散（可用分组技巧直接证明：每组缩到 ≥ 1/2）
- **渐近等价**: a_n ~ b_n 指 lim a_n/b_n = 1，是极限比较判别法的基础
- **绝对收敛**: Σ|a_n| 收敛 ⇒ 原级数收敛
- **条件收敛**: 原级数收敛但 Σ|a_n| 发散，典型例子 Σ(−1)ⁿ/n
- **交错级数**: 各项正负严格交替出现的级数，形如 Σ(−1)ⁿb_n（b_n > 0）
- **数列与函数极限的联系**: 若 a_n = f(n) 且 lim(x→∞) f(x) = L，则 lim a_n = L；洛必达法则须先嵌入函数再对 x 使用

## 心智模型
- **级数 ↔ 反常积分类比**: 级数是离散的反常积分。第20–21章关于 ∞ 处瑕点的全部结论（比较、极限比较、p 判别、绝对收敛）平移到级数；遇到级数问题先想"对应的积分怎么做"
- **高速公路行走模型**: 部分和 A_N 是你第 N 步后的位置，a_n 是步长。级数收敛 ⇔ 最终无限接近某位置，这要求步长 → 0（第n项判别法的直觉）；交错级数中步长递减 ⇔ 左右脚越走越近直至并拢
- **比式/根式判别法 = 伪装的几何级数**: L < 1 时取 r = (L+1)/2，去掉前面有限项后级数被公比 r 的收敛几何级数控制；比值/方根本质是"有效公比"
- **判别法决策序**: 先看通项是否 → 0（第n项判别法）→ 含阶乘/指数用比式或根式 → 正负不规则先验绝对收敛 → 多项式型用极限比较对 p 级数 → 单调正项可用积分判别法 → 严格交错且不绝对收敛才用交错级数判别法

## 常见错误与陷阱
- **误以为 a_n → 0 就能推出级数收敛**: 第n项判别法是单向的求真判定，只能证发散；反例调和级数 Σ1/n，通项 → 0 但级数发散
- **误以为通项 → 0 则级数和为 0**: 数列收敛于 0 与级数收敛值无关，如 Σ(1/2)ⁿ = 2
- **洛必达法则直接对 n 求导**: n 是整数不能求导，必须先把 a_n 嵌入函数 f(x) 再对 x 用洛必达
- **比式/根式判别法 L = 1 时下结论**: L = 1 无任何信息；Σ1/n^p 对所有 p 都有 L = 1，但 p > 1 收敛、p ≤ 1 发散
- **用积分判别法不验证条件**: f 必须为正且递减（非增）；p < 0 时 f(x) = 1/x^p 递增，不能用积分判别法
- **从 Σ|a_n| 发散推出原级数发散**: 绝对值级数发散只说明"不绝对收敛"；原级数可能条件收敛（Σ(−1)ⁿ/n 收敛）
- **纠结级数起始项**: 前有限项不影响敛散性；但起点必须使所有项有定义（如 Σ1/n² 不能从 n = 0 开始，首项无定义）
- **几何级数只记收敛不记条件**: 收敛要求 |r| < 1（即 −1 < r < 1）；r = −1 时振荡发散而非发散到无穷

## 公式与参考表

| 判别法 | 对象/条件 | 收敛 | 发散 | 无结论 |
|---|---|---|---|---|
| 第n项判别法 | lim a_n | — | lim a_n ≠ 0 或不存在 | lim a_n = 0 |
| 比较判别法 | 正项 | a_n ≤ b_n, Σb_n 收敛 | a_n ≥ b_n ≥ 0, Σb_n 发散 | — |
| 极限比较判别法 | a_n ~ b_n | 与 Σb_n 同敛散 | 同 | — |
| p判别法 | Σ1/n^p | p > 1 | p ≤ 1 | — |
| 绝对收敛判别法 | Σ|a_n| 收敛 | 原级数收敛（绝对） | — | Σ\|a_n\| 发散 |
| 比式判别法 | L = lim\|a_{n+1}/a_n\| | L < 1（绝对收敛） | L > 1 | L = 1 或极限不存在 |
| 根式判别法 | L = lim\|a_n\|^{1/n} | L < 1（绝对收敛） | L > 1 | L = 1 |
| 积分判别法 | f 正、递减、f(n)=a_n | ∫₁^∞ f 收敛 | ∫₁^∞ f 发散 | — |
| 交错级数判别法 | 交错 + \|a_n\| 递减 → 0 | 收敛 | — | 条件不满足时另法 |

关键结论：
- 等比数列极限: lim rⁿ = 0（−1 < r < 1）；= 1（r = 1）；= ∞（r > 1）；不存在（r ≤ −1）
- 重要极限: lim (1 + k/n)ⁿ = e^k
- 几何级数: Σ_{n=0}^∞ ar^n = a/(1−r)（−1 < r < 1），否则发散
- 部分和公式: 1 + r + ... + r^N = (1 − r^{N+1})/(1 − r)（r ≠ 1，伸缩级数证明）
- p 级数: Σ1/n^p 收敛 ⇔ p > 1；调和级数 Σ1/n 发散；Σ1/n² 收敛

## 精讲例题
判定 Σ_{n=0}^∞ sin(1/2ⁿ) 的敛散性。

解：当 n 很大时 1/2ⁿ → 0。由 x → 0 时 sin x ~ x，代换得
当 n → ∞ 时, sin(1/2ⁿ) ~ (1/2)ⁿ。
由极限比较判别法，Σsin(1/2ⁿ) 与 Σ(1/2)ⁿ 同敛散。后者是公比 r = 1/2 ∈ (−1,1) 的几何级数，收敛（和为 1/(1−1/2) = 2）。故原级数收敛。
注意：极限比较只给出敛散性，原级数的收敛值**不是** 2，具体值未知。

## 要点速记
1. 判别级数先跑第n项判别法：通项不趋于 0 直接判发散，零成本
2. 级数 = 部分和数列的极限；讨论时区分清楚三个对象：{a_n}、Σa_n、{A_N}
3. 前有限项与敛散性无关，大胆删项换起点（保证各项有定义即可）
4. 含阶乘/指数首选比式，含整体 n 次幂用根式，L = 1 立即换方法
5. 正负不规则先加绝对值：绝对收敛即收敛；不绝对收敛再试交错级数判别法
6. p 级数和几何级数是所有比较/极限比较的基准库，记牢 Σ1/n^p (p>1 收敛) 与 Σar^n (|r|<1 收敛于 a/(1−r))
7. 条件收敛不是发散：Σ(−1)ⁿ/n 收敛但 Σ1/n 发散
