# 第28章：复数

## 核心思想
引入 i² = −1 后，一切 n 次多项式恰有 n 个复根（代数基本定理）；把复数写成极坐标形式 z = re^(iθ)，乘法、乘幂、开方、解 zⁿ = w 与 eᶻ = w 全部化归为模与辐角的实数运算。

## 本节框架与方法
- **复数四则运算与除法（共轭有理化）**
  - 何时使用：加减乘任何复数，或化简形如 (a+bi)/(c+di) 的商、求商的实部/虚部。
  - 怎么做：加减按实部、虚部分别运算；乘法展开后凡见 i² 一律换成 −1；除法分子分母同乘分母的共轭，分母变为 |分母|²（实数），再展开分子。
- **笛卡儿形式 ↔ 极坐标形式互换**
  - 何时使用：要做乘法、高次幂、开方、解方程时先转极坐标；要报最终答案时常需转回笛卡儿形式。
  - 怎么做：极→直用欧拉恒等式 re^(iθ) = r(cosθ + i·sinθ)；直→极用 r = √(x²+y²)，tanθ = y/x，**必须画图确定 θ 所在象限**（tanθ 单独不够）。
- **高次幂法（极坐标 + 周期化简）**
  - 何时使用：计算如 (1−i)^99 之类的大指数幂。
  - 怎么做：转极坐标 (re^(iθ))ⁿ = rⁿe^(inθ)；对辐角 nθ 减去"小于它的 π 的最大偶数倍"（即去掉 2π 的整数倍）；再用欧拉恒等式转回笛卡儿形式。
- **解 zⁿ = w 的九步法（棣莫弗思想）**
  - 何时使用：求复数的 n 次方根、复系数二次方程求根（先配方/求根公式再开复数平方根）、复数域因式分解。
  - 怎么做：(1) 设 z = re^(iθ)；(2) 把 w 写成 Re^(iφ)；(3) 方程化为 rⁿe^(inθ) = Re^(iφ)；(4) 拆成 rⁿ = R 与 e^(inθ) = e^(iφ)；(5) r = R^(1/n)；(6) 用重要原理得 nθ = φ + 2πk；(7) 只取 k = 0,1,…,n−1（再多会重复）；(8) 代回 z = re^(iθ) 得 n 个解；(9) 必要时转笛卡儿形式。
- **解 eᶻ = w**
  - 何时使用：对给定复数 w ≠ 0 求 z（即复对数）。
  - 怎么做：z 保持笛卡儿形式 x + iy，则 eᶻ = eˣe^(iy) 自动是极坐标形式（模 eˣ，辐角 y）；与 w = Re^(iφ) 比较得 x = ln R，y = φ + 2πk（k 为任意整数）——**有无穷多解**，形成等差数列。
- **三角级数求和（欧拉配对技巧）**
  - 何时使用：求 Σcos(nθ)·aₙ 或 Σsin(nθ)·aₙ 型级数（如 /n! 或 /3ⁿ）。
  - 怎么做：把目标级数与互补级数按"实部 + i·虚部"组合成 Σe^(inθ)·aₙ = Σ(e^(iθ))ⁿaₙ，识别为 e^(e^(iθ)) 或几何级数等已知和式，求出后再转回笛卡儿形式，令实部、虚部分别相等，一次得到两个级数的和。
- **复因式分解 → 实因式分解（共轭配对）**
  - 何时使用：在实数域上分解实系数多项式。
  - 怎么做：先求出所有复根做复因式分解，再把共轭根配对：(z−w)(z−w̄) = z² − 2Re(w)z + |w|²，系数必为实数。

## 关键概念
- **虚数单位 i**: i² = −1；i 的幂按 i, −1, −i, 1 循环（周期 4），故 i¹⁰¹ = i。
- **复数**: 形如 z = x + iy（x, y 实数）的数，全体记作 C；实数与虚数都是复数的特例。
- **实部与虚部**: Re(z) = x，Im(z) = y——注意 Im(z) 是实数 y，不是 iy。
- **共轭复数**: z = x + iy 的共轭为 z̄ = x − iy，满足 zz̄ = |z|²（实数）。
- **模**: |z| = √(x²+y²)，即复平面上 z 到原点的距离，是绝对值的推广。
- **辐角**: arg(z) = θ，即 z 的极角；常约定 0 ≤ θ < 2π（或 −π < θ ≤ π）以避免歧义。
- **复平面**: 用点 (x, y) 表示 x + iy 的平面，横轴实轴、纵轴虚轴。
- **极坐标形式（模–辐角式）**: z = re^(iθ)，其中 r = |z| ≥ 0，θ = arg(z)。
- **欧拉恒等式**: e^(iθ) = cosθ + i·sinθ（对所有实 θ 成立）；特例 e^(iπ) = −1。
- **重要原理**: 若 e^(iA) = e^(iB)（A, B 实数），则 A = B + 2πk（k 为整数）——解方程时分角的核心工具。
- **代数基本定理**: 任何 n 次多项式恰有 n 个复根（重根按重数计）。

## 心智模型
- 当要做复数乘法、乘幂、开方时，用极坐标形式——模相乘、角相加，把复数运算降维成实数运算；当要做加减或报答案时，用笛卡儿形式。
- 当两个含 e^(i·) 的量相等时，不要直接让指数相等——用重要原理补上 +2πk，否则会丢掉 n−1 个根（zⁿ = w）或无穷多个解（eᶻ = w）。
- 当 tanθ = y/x 给出多个候选角（或 x = 0 无法相除）时，画图标出点的象限来定 θ。
- 当遇到含 cos(nθ)/sin(nθ) 的级数时，把它们想成某个复级数的实部与虚部——配上 i 倍互补级数，一次算出两个和。

## 常见错误与陷阱
- **由 e^(inθ) = e^(iφ) 直接得 nθ = φ**: 丢掉周期项 2πk，只剩 1 个根而非 n 个；必须写 nθ = φ + 2πk。
- **k 取所有整数**: k = 0,…,n−1 之外会产生重复解（k 加 n 后 z 值相同）；zⁿ = w 恰有 n 个不同的解（w ≠ 0）。
- **由 tanθ = y/x 定辐角不看象限**: tan 周期为 π，会差 π；x = 0 时连 tan 都无定义（θ = π/2 或 3π/2），必须画图。
- **误以为 Im(2 − 3i) = −3i**: 虚部是不带 i 的实数 −3。
- **除法时找错共轭**: 如分母写作 i − 1 时应先整理为 −1 + i，共轭是 −1 − i；只对虚部变号。
- **展开高次幂硬算**: (1−i)^99 直接展开是死路，必须走"极坐标 → 乘幂 → 减 2π 倍数 → 转回"的流程。
- **解 eᶻ = w 只写一个解**: 它有无穷多解 z = ln R + i(φ + 2πk)；而 w = 0 时无解（eᶻ 永不为 0）。

## 公式与参考表
- i 的幂循环：i¹ = i, i² = −1, i³ = −i, i⁴ = 1
- 共轭与模：zz̄ = |z|² = x² + y²；(z−w)(z−w̄) = z² − 2Re(w)z + |w|²
- 欧拉恒等式：e^(iθ) = cosθ + i·sinθ；特例 e^(iπ) = −1, i = e^(iπ/2), −i = e^(i3π/2)
- 形式互换：x + iy = re^(iθ)，r = √(x²+y²)，tanθ = y/x（由图定象限）
- 周期性：e^(iθ) 关于 θ 以 2π 为周期；e^(iA) = e^(iB) ⟺ A = B + 2πk
- 乘幂：(re^(iθ))ⁿ = rⁿe^(inθ)
- zⁿ = w 的 n 个解（w = Re^(iφ) ≠ 0）：
  z = R^(1/n) · e^(i(φ + 2πk)/n)，k = 0, 1, …, n−1；n 个解在半径 R^(1/n) 的圆上均匀分布，构成正 n 边形。
- eᶻ = w（w = Re^(iφ) ≠ 0）的全部解：
  z = ln R + i(φ + 2πk)，k ∈ Z；解分布在竖直直线 x = ln R 上，构成等差数列。
- 复指数定义：eᶻ = Σ zⁿ/n!（对所有复数 z 收敛），且 eᶻeʷ = e^(z+w)；若 z = x + iy，则 eᶻ = eˣe^(iy)（模 eˣ，辐角 y）。
- 二次公式对复系数仍适用，可能需求复数的平方根（即解 Z² = w）。

## 精讲例题
**解 z⁵ = −√3 + i（九步法全流程）**

1. 设 z = re^(iθ)，则 z⁵ = r⁵e^(i5θ)。
2. 把 w = −√3 + i 写极坐标：R = √(3+1) = 2；tanφ = −1/√3，点在第二象限，故 φ = 5π/6，即 w = 2e^(i5π/6)。
3. 方程化为 r⁵e^(i5θ) = 2e^(i5π/6)。
4. 拆分：r⁵ = 2 且 e^(i5θ) = e^(i5π/6)。
5. r = 2^(1/5)。
6. 由重要原理：5θ = 5π/6 + 2πk，即 θ = π/6 + 2πk/5。
7. 取 k = 0,1,2,3,4：θ = π/6, 17π/30, 29π/30, 41π/30, 53π/30。
8. 五个解：z = 2^(1/5)e^(iπ/6), 2^(1/5)e^(i17π/30), …, 2^(1/5)e^(i53π/30)。
9. 转笛卡儿形式（能化简的化简）：第一个解 2^(1/5)e^(iπ/6) = 2^(1/5)(√3/2 + i/2) = 2^(−4/5)(√3 + i)；其余如 2^(1/5)(cos(17π/30) + i·sin(17π/30)) 保留即可。
几何验证：5 个解都在半径 2^(1/5) 的圆上，相邻辐角差 2π/5，构成正五边形。

## 要点速记
1. 复数运算分工：加减用笛卡儿形式，乘除乘幂开方用极坐标形式；除法 = 同乘分母共轭，分母变 |分母|²。
2. 欧拉恒等式 e^(iθ) = cosθ + i·sinθ 是全章枢纽：定义在单位圆上，周期 2π，特例 e^(iπ) = −1。
3. 一切"e 的复指数相等"问题都靠重要原理 A = B + 2πk 分角——漏掉它就是漏解。
4. zⁿ = w 恰有 n 个解（k = 0,…,n−1），几何上是正 n 边形；eᶻ = w 有无穷多解，几何上是直线上的等差数列。
5. 求高次幂的固定流程：转极坐标 → 乘幂 → 辐角减去 π 的最大偶数倍（去 2π 整数倍）→ 转回笛卡儿。
6. 三角级数 Σcos/sin(nθ)·aₙ 的杀招：配成 Σe^(inθ)aₙ，识别成 e^(e^(iθ)) 或几何级数，求实虚部一箭双雕。
7. 实系数多项式的复根成共轭对出现，配对相乘 (z−w)(z−w̄) 即得实系数二次因式。
