# 第17章：微积分基本定理

## 核心思想
微分和积分是互逆运算：变上限积分函数的导数就是被积函数（第一基本定理），而任何定积分都可以用任一反导数在上下限的差来计算（第二基本定理），从而彻底摆脱黎曼和。

## 本节框架与方法
- **变上限积分函数 F(x) = ∫ₐˣ f(t)dt**: 以上限 x 为变量的函数，几何意义是曲线 y=f(t)、t 轴、t=a 与 t=x 围成的有向面积
  - 何时使用: 需要把"积分"当作函数来研究（求导、分析性质）时
  - 怎么做: 虚拟变量必须换成 t（绝不能写 ∫₀ˣ x²dx）；下限 a 的选择只让 F 相差一个常数（分解积分证明 F(x) = H(x) + C）
- **微积分第一基本定理 (FTC1)**: 若 f 在 [a,b] 连续，F(x)=∫ₐˣ f(t)dt，则 F 在 (a,b) 可导且 **d/dx ∫ₐˣ f(t)dt = f(x)**
  - 何时使用: 求"积分的导数"，无论被积函数是否有初等反导数（如 sin(t²)、e^(−t²)）
  - 怎么做: 直接把被积函数中的虚拟变量 t 换成上限变量 x 即可；下限常数不影响结果
- **微积分第二基本定理 (FTC2)**: 若 f 在 [a,b] 连续，F 是 f 的任一反导数，则 **∫ₐᵇ f(x)dx = F(b) − F(a) = F(x)|ₐᵇ**
  - 何时使用: 计算一切（有初等反导数的）定积分和面积
  - 怎么做: (1) 求不定积分；(2) 代入上、下限；(3) 求差。定积分中常数 C 会抵消，取 C=0 即可
- **不定积分 ∫f(x)dx**: 表示 f 的全体反导数（函数的集合），写成 F(x) + C
  - 何时使用: 需要反导数本身（而非数值）时
  - 怎么做: 把导数公式倒着用：若 d/dx F(x) = f(x)，则 ∫f(x)dx = F(x) + C
- **FTC1 的四种变形**（详见公式表）
  - 变形1 变量在下限: 交换上下限加负号
  - 变形2 上限是 x 的函数: 设 u=上限，用链式法则 dy/dx = (dy/du)(du/dx)
  - 变形3 上下限都是函数: 用定义域内任一常数把积分拆成两段，分别按变形1、2 处理
  - 变形4 极限伪装成导数: lim(h→0) (1/h)∫ₓ^(x+h) f(t)dt 就是 F′(x)，直接用 FTC1

## 关键概念
- **反导数 (antiderivative)**: 导数等于 f 的函数 F；同一函数有无穷多个反导数，彼此只差一个常数
- **不定积分**: f 的所有反导数的集合，记作 ∫f(x)dx = F(x) + C，结果是函数族
- **定积分**: ∫ₐᵇ f(x)dx 是一个数，表示有向面积；有上下限是它区别于不定积分的标志
- **虚拟变量 (dummy variable)**: 积分号内的变量（如 t），用什么字母无所谓，结果与它无关
- **有向面积**: 位于 x 轴下方计为负的面积；定积分给出有向面积，实际面积需加绝对值
- **ln|x| 公式**: ∫(1/x)dx = ln|x| + C，绝对值使公式对 x<0 也成立（技术上两分支各需一个常数 C₁、C₂，但单次计算只涉及一支）
- **常数倍替换规则**: 积分中 x 被 ax 替换时，相应公式要**除以** a（对比：求导时是**乘以** a）

## 心智模型
- 当要求 d/dx ∫ₐˣ f(t)dt 时：别想先积分再求导——积分与求导直接抵消，答案就是 f(x)（类比 (√54756)² = 54756，无需先开方）
- 当积分限不是简单的"a 到 x"时：先通过交换限、拆分段、设 u 代换，把问题归约到标准形 ∫ₐˣ，再用 FTC1
- 当计算定积分时：FTC2 是唯一通道——找任一反导数，代入上下限求差；常数 C 自动抵消，放心忽略
- 当求实际面积（非有向面积）或两曲线间面积时：先找被积函数变号的点（与 x 轴交点/两曲线交点），分段积分后各段取绝对值再相加

## 常见错误与陷阱
- **忘记 +C**: 不定积分漏掉 C 只得到一个反导数而非全体，结果错误（但定积分中 C 会抵消，可省略）
- **用 FTC1 求导后加 +C**: 严重错误——你在求导，不是在反导
- **虚拟变量与上限同名**: 写 ∫₀ˣ x²dx 造成混乱；必须先把积分变量改为 t
- **面积不加绝对值**: ∫₋π^π sin(x)dx = 0（有向面积），但实际面积是 ∫₋π^π |sin(x)|dx = 4；求"面积"而非"定积分"时必须先分段取绝对值
- **两曲线面积不判断谁在上**: y=x 与 y=1/x 在 x=1 处交叉，[1/2,1] 上 1/x 更大；直接积分 x−1/x 会得到错误甚至为负的"面积"
- **∫xᵃdx 公式用于 a=−1**: a=−1 时分母为 0，此时 ∫(1/x)dx = ln|x| + C
- **∫(1/x)dx 跨越 x=0**: 上下限异号时被积函数在 0 处无界，属反常积分（第20章），不能直接用 ln|b|−ln|a|
- **常数倍规则用反**: 积分中 x→ax 要除以 a（如 ∫sec²(7x)dx = (1/7)tan(7x)+C），不要和链式法则的乘以 a 混淆
- **代入上下限时丢负号**: 用括号写成 (F(b)) − (F(a))，避免符号错误

## 公式与参考表

**FTC1**: f 在 [a,b] 连续 ⟹ d/dx ∫ₐˣ f(t)dt = f(x)

**FTC2**: f 连续，F 为任一反导数 ⟹ ∫ₐᵇ f(x)dx = F(x)|ₐᵇ = F(b) − F(a)

**FTC1 四种变形**:
| 情形 | 公式 |
|---|---|
| 标准形 | d/dx ∫ₐˣ f(t)dt = f(x) |
| 变形1 变量在下限 | d/dx ∫ₓᵇ f(t)dt = −f(x) |
| 变形2 上限是函数 | d/dx ∫ₐ^(u(x)) f(t)dt = f(u(x))·u′(x) |
| 变形3 上下限都是函数 | d/dx ∫_(v(x))^(u(x)) f(t)dt = f(u(x))·u′(x) − f(v(x))·v′(x) |
| 变形4 极限伪装成导数 | lim(h→0) (1/h) ∫ₓ^(x+h) f(t)dt = f(x) |

**不定积分性质**: ∫(f+g)dx = ∫f dx + ∫g dx；∫cf(x)dx = c∫f(x)dx（和与差只需写一个 C）

**基本积分表**（导数公式逆用）:
- ∫xᵃdx = x^(a+1)/(a+1) + C (a ≠ −1)
- ∫(1/x)dx = ln|x| + C
- ∫eˣdx = eˣ + C；∫bˣdx = bˣ/ln(b) + C
- ∫cos x dx = sin x + C；∫sin x dx = −cos x + C
- ∫sec²x dx = tan x + C；∫sec x tan x dx = sec x + C
- ∫csc²x dx = −cot x + C；∫csc x cot x dx = −csc x + C
- ∫dx/√(1−x²) = sin⁻¹x + C；∫dx/(1+x²) = tan⁻¹x + C；∫dx/(|x|√(x²−1)) = sec⁻¹x + C
- ∫cosh x dx = sinh x + C；∫sinh x dx = cosh x + C
- **ax 替换**: x 换成 ax ⟹ 公式除以 a，如 ∫e^(−x/3)dx = −3e^(−x/3) + C

## 精讲例题
求 d/dx ∫_(x⁵)^(x⁶) ln(t² − sin(t) + 7)dt（变形3：上下限都是函数）。

1. 在被积函数定义域内任选常数（取 0）拆分：
   原式 = d/dx [ ∫_(x⁵)⁰ ln(...)dt + ∫₀^(x⁶) ln(...)dt ]
2. 第一段属变形1+2：先交换限加负号 = −d/dx ∫₀^(x⁵) ln(...)dt，再设 u = x⁵ 用链式法则：
   = −ln((x⁵)² − sin(x⁵) + 7)·5x⁴ = −5x⁴ ln(x¹⁰ − sin(x⁵) + 7)
3. 第二段设 v = x⁶ 直接用变形2：
   = ln((x⁶)² − sin(x⁶) + 7)·6x⁵ = 6x⁵ ln(x¹² − sin(x⁶) + 7)
4. 合并：原式 = 6x⁵ ln(x¹² − sin(x⁶) + 7) − 5x⁴ ln(x¹⁰ − sin(x⁵) + 7)

关键：全程无需真的求出 ln(t² − sin(t) + 7) 的反导数（它很可能没有初等形式）——FTC1 让积分与求导直接抵消。

## 要点速记
1. 求"变上限积分的导数"永远不要去算积分——把 t 换成 x 就完了（FTC1），下限常数无关紧要
2. 求定积分只走一条路：找反导数 → 代入上下限 → 求差（FTC2）；取 C=0 的反导数最省事
3. 不定积分答案是函数族，+C 不可省；定积分答案是数，C 自动抵消
4. 见到上下限含函数：下限的交换加负号、上限的设 u 链式法则、双边就拆成两段——所有变形都归约到标准形
5. 见到 lim(h→0) (1/h)∫ₓ^(x+h)：立刻认出这是伪装的 F′(x)，答案 = f(x)
6. 求面积先问"要的是有向面积还是实际面积"；实际面积必须在每个变号点分段、取绝对值再相加
7. 积分常数倍规则与求导相反：x→ax 时积分结果除以 a
