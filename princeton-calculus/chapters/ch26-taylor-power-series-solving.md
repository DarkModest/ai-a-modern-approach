# 第26章：泰勒级数和幂级数：如何解题

## 核心思想
幂级数 ∑aₙ(x−a)ⁿ 的收敛行为只有三种模式：收敛半径为正（区间收敛）、处处收敛（R=∞）、仅在中心点收敛（R=0）；而合成新泰勒级数、求导、求极限都只需对五个基本麦克劳林级数做代换、求导、积分、加减、乘除等操作，无需直接计算高阶导数。

## 本节框架与方法
- **求收敛半径和收敛区域**: 对幂级数通项用比式判别法（首选）或根式判别法，令极限 L|x−a| 与 1 比较
  - 何时使用: 任何给定幂级数，要求收敛区间时
  - 怎么做:
    1. 写出 lim(n→∞) |aₙ₊₁(x−a)ⁿ⁺¹ / (aₙ(x−a)ⁿ)| = lim |aₙ₊₁/aₙ|·|x−a|（根式法为 lim |aₙ|¹ᐟⁿ·|x−a|）；含 n!、ln n 之类用比式，含 n² 之类的幂指数因子（如 2ⁿ²）用根式更方便
    2. 取 n→∞ 的极限（不是 x→∞），结果必形如 L|x−a|
    3. L 为正有限值：|x−a| < 1/L 绝对收敛，> 1/L 发散，收敛半径 R = 1/L；端点 |x−a| = 1/L 比式/根式法无效，必须逐点代入单独判别
    4. L = 0：对所有 x 绝对收敛，R = ∞
    5. L = ∞：仅在 x = a 收敛，R = 0
    6. 端点判别：把 x = a±R 代回成数项级数，用积分判别法、交错级数判别法、p 判别法等判定绝对收敛/条件收敛/发散。两端点收敛性有四种可能组合：都收敛、都发散、只左收敛、只右收敛
- **代换法合成泰勒级数**: 将基本麦克劳林级数中的 x 换成 xⁿ 的倍数或 (x−a)
  - 何时使用: 求如 eˣ²、1/(1+2x²)、ln(x) 关于 x=1 的级数等
  - 怎么做: 在级数与"成立范围"不等式中同时做代换（如把 x 换成 −x² 时，成立条件 −1<x<1 换成 −1<−x²<1，再化简）；换成 (x−a) 会得到关于 x=a 的泰勒级数，但函数本身也变了（如 sin(x) 换元得 sin(x−18) 关于 18 的级数，不是 sin(x) 的级数）
- **逐项求导**: 对收敛幂级数逐项求导得到 f′ 的级数，收敛区间内部不变
  - 何时使用: 由 cos(x) 级数求 sin(x)，由 1/(1+x) 求 1/(1+x)² 等
  - 怎么做: 两边逐项求导后化简（如 4/4! = 1/3!）；泰勒多项式求导后阶数减 1；端点处求导后的级数可能发散，需单独讨论
- **逐项积分**: 对收敛幂级数逐项积分得到反导数的级数，收敛区间（端点除外）不变
  - 何时使用: 求 ln(1−x)、arctan(x)、∫₀ˣ sin(t³)dt 之类的级数（直接求导太痛苦时）
  - 怎么做: 用不定积分时写常数 C（放前面，作为零次项），代入 x=0（或中心点）求 C；定积分则逐项积分后代入上下限；泰勒多项式积分后阶数加 1
- **级数加减**: 两个泰勒级数相加/减得和/差的级数
  - 何时使用: 求 sin(x) − eˣ 等的级数
  - 怎么做: 合并同类项，收敛区间取两者交集；泰勒多项式相加时取两阶数中的较小者（先把高阶多项式截断到低阶，再相加）
- **级数相乘**: 展开相乘，只保留所需阶数以下的项
  - 何时使用: 求 eˣ sin(x) 的低阶麦克劳林级数
  - 怎么做: 写出两因子到所需阶，逐项相乘并预先略去必然超出目标阶的乘积项；从 N 阶多项式出发相乘，结果只有 N 阶可信，更高阶的项必须丢弃
- **级数相除（长除法）**: 按升幂排列做多项式长除法
  - 何时使用: 求 sec(x) = 1/cos(x)、tan(x) = sin(x)/cos(x) 的级数
  - 怎么做: 与通常长除法相反，各项按次数递增的顺序书写，除到目标阶为止
- **由泰勒级数反求导数**: f⁽ⁿ⁾(a) = n! × (级数中 (x−a)ⁿ 的系数)
  - 何时使用: 求 f⁽¹⁰⁰⁾(0) 之类的高阶导数在某点的值
  - 怎么做: 先用合成方法求出泰勒级数（求和号形式便于解方程确定系数），令幂次方程解出 n；若幂次不出现（如只有偶次幂而求奇数阶导数），系数为 0，导数即为 0。只需 n 阶或更高的泰勒多项式即可，不需要整个级数；此方法只给 x=a 处的导数信息
- **用麦克劳林级数求极限**: 用级数前几项替换函数，化简 0/0 型极限
  - 何时使用: lim(x→0) f(x)/g(x) 的 0/0 型，且洛必达法则需多次求导太繁琐时
  - 怎么做: 将分子分母展开到足够阶（首项不再完全相消为止），上下同除以最低次项后代入 x=0；理论基础是 f(x) ∼ a_Nxᴺ（最低非零项），等价关系可乘除但不可加减

## 关键概念
- **收敛半径 R**: 使幂级数在 |x−a|<R 内收敛、|x−a|>R 内发散的非负数；R=0 表示仅在中心收敛，R=∞ 表示处处收敛
- **端点**: 满足 |x−a|=R 的两个点 x=a±R，此处级数可能绝对收敛、条件收敛或发散，必须单独判定
- **收敛区域（收敛区间）**: 使幂级数收敛的所有 x 的集合，由收敛半径加端点判定结果共同确定
- **绝对收敛 vs 条件收敛**: 各项取绝对值后收敛为绝对收敛；交错端点常由交错级数判别法得条件收敛
- **麦克劳林级数**: 关于 x=0 的泰勒级数
- **泰勒多项式的阶（order）**: 多项式保留的最高次数，不要与实际次数混淆（如 eˣ² 的 P₃ = 1+x² 同时也是 P₂）
- **泰勒系数公式**: aₙ = f⁽ⁿ⁾(a)/n!，即 f⁽ⁿ⁾(a) = n!·aₙ
- **最低次项决定渐近行为**: 若麦克劳林级数最低非零项为 a_Nxᴺ，则 x→0 时 f(x) ∼ a_Nxᴺ（即使级数在 0 之外不收敛也成立，条件是 f⁽ᴺ⁺¹⁾ 在 0 附近有界）

## 心智模型
- 当看到"求幂级数收敛区间"时，用比式判别法得出 L|x−a|，再"分三步"：内部绝对收敛、外部发散、端点单独代入判别
- 当要展开复合函数（如 eˣ²、sin(t³)）时，不要逐次求导，用代换法——把已知基本级数里的 x 换掉
- 当目标是形如 arctan、ln、积分定义的函数时，反过来想"它是谁的积分"，从导数的级数逐项积分上去
- 当遇到 0/0 极限且洛必达要算很多次时，用麦克劳林级数替换——只保留到首项不再相消的那阶，其余全部丢进 "···"

## 常见错误与陷阱
- **忘记检查端点**: 比式/根式判别法在 |x−a|=R 处无结论；端点必须逐点代入，用交错级数判别法、积分判别法等单独判定，否则收敛区间会答错
- **求导/积分后直接沿用端点结论**: 逐项求导后的级数在端点可能发散；逐项积分不给出端点信息（如 arctan、ln(1−x) 的级数在端点其实收敛，但需另行证明）
- **代换泰勒多项式时数错阶数**: 把 x 换成 x² 后多项式阶数翻倍——eˣ² 的 "1+x²+x⁴/2!+x⁶/3!" 是六阶而非三阶；要三阶须截掉所有高于三次的项
- **乘法保留超出输入阶数的项**: 两个二阶多项式相乘得 1+x⁴/4，x⁴/4 项并不可信，必须丢弃；输出阶数不可能超过输入阶数
- **加减时阶数取错**: 和的泰勒多项式阶数取两因子阶数的较小者，须先把高阶多项式截断再相加
- **积分忘写常数或放错位置**: 常数 C 是幂级数的零次项，代入 x=0（或中心点）求值
- **极限中级数项取得太少**: 全部项相消得到 0/0 说明展开不足，须加阶；多写无害（可后略），少写则解不出
- **滥用等价关系的加减**: f(x) ∼ a_Nxᴺ 可乘除但不可加减（如 eˣ−1−sin(x) 不能由各自等价式相减得出）
- **阶乘化简错误**: 如 100!/50! 不能化为 2!；正确技巧是 n!/(n·(n−1)!) 之类逐步消项（如 52!/52 = 51!）
- **长除法按降幂排**: 级数相除必须按升幂排列各项

## 公式与参考表

### 五个基本麦克劳林级数
| 函数 | 展开式 | 求和号形式 | 成立范围 |
|---|---|---|---|
| eˣ | 1 + x + x²/2! + x³/3! + ··· | ∑ xⁿ/n! | 所有 x |
| sin(x) | x − x³/3! + x⁵/5! − x⁷/7! + ··· | ∑ (−1)ⁿx²ⁿ⁺¹/(2n+1)! | 所有 x |
| cos(x) | 1 − x²/2! + x⁴/4! − x⁶/6! + ··· | ∑ (−1)ⁿx²ⁿ/(2n)! | 所有 x |
| 1/(1−x) | 1 + x + x² + x³ + ··· | ∑ xⁿ | −1 < x < 1 |
| ln(1+x) / ln(1−x) | x − x²/2 + x³/3 − ··· / −x − x²/2 − x³/3 − ··· | ∑ −(−1)ⁿxⁿ/n / ∑ −xⁿ/n | −1 < x < 1（ln(1+x) 对 x=1 也成立；ln(1−x) 对 x=−1 也成立）|

### 收敛半径求解流程
1. 通项用比式法：lim |aₙ₊₁/aₙ|·|x−a|（或根式法 lim |aₙ|¹ᐟⁿ·|x−a|），极限取 n→∞
2. 得 L|x−a|：
   - 0 < L < ∞ → R = 1/L，端点 x = a ± 1/L 单独判定
   - L = 0 → R = ∞，处处绝对收敛
   - L = ∞ → R = 0，仅在 x = a 收敛
3. 端点代入后用积分判别法 / 交错级数判别法 / p 判别法判定绝对或条件收敛

### 常用派生级数（本章得到）
- 1/(1+x)² = ∑ (−1)ⁿ(n+1)xⁿ，−1 < x < 1（1/(1+x) 求导取负）
- arctan(x) = ∑ (−1)ⁿx²ⁿ⁺¹/(2n+1)，−1 < x < 1（且 x=±1 时由交错级数判别法收敛，得 1−1/3+1/5−··· = π/4）
- sec(x) = 1 + x²/2 + 5x⁴/24 + ···；tan(x) = x + x³/3 + ···（长除法）

## 精讲例题
求幂级数 ∑(n=1→∞) (−2)ⁿ(x−7)ⁿ/√n 的收敛区域。

1. 中心 a = 7。比式判别法：
   lim | (−2)ⁿ⁺¹(x−7)ⁿ⁺¹/√(n+1) | / | (−2)ⁿ(x−7)ⁿ/√n | = lim 2|x−7|·√(n/(n+1)) = 2|x−7|
2. 2|x−7| < 1 时绝对收敛，> 1 时发散 → |x−7| < 1/2，R = 1/2
3. 右端点 x = 7.5：级数变为 ∑ (−2)ⁿ(1/2)ⁿ/√n = ∑ (−1)ⁿ/√n，由交错级数判别法收敛，但取绝对值后 ∑ 1/√n 发散（p 判别法，p=1/2）→ 条件收敛
4. 左端点 x = 6.5：级数变为 ∑ (−2)ⁿ(−1/2)ⁿ/√n = ∑ 1/√n → 发散
5. 结论：在 6.5 < x < 7.5 时绝对收敛，x = 7.5 时条件收敛，其余发散。收敛区域为 (6.5, 7.5]

## 要点速记
1. 幂级数收敛性只有三种模式：R > 0、R = ∞、R = 0；不会出现在任意点集上零散收敛的情况
2. 求收敛半径的标准动作是比式判别法（含 n² 型指数因子改用根式法），答案总是 L|x−a| 形式，R = 1/L
3. 端点是比式/根式判别法的盲区，必须逐点代回做数项级数判别；两端点收敛性的四种组合都可能发生
4. 合成新级数优先用五个基本麦克劳林级数：代换、逐项求导（阶减 1）、逐项积分（阶加 1，勿忘常数）、加减（阶取小）、乘法（结果阶不超过输入阶）、长除法（升幂排列）
5. 求高阶导数 f⁽ⁿ⁾(a) = n! × 级数中 (x−a)ⁿ 的系数；级数缺该幂次则导数为 0
6. 0/0 极限用麦克劳林级数替换：展开到首项不再相消，同除最低次项；宁多勿少
7. 理论基础：x→0 时 f(x) ∼ 最低非零项 a_Nxᴺ，该等价关系可乘除不可加减
