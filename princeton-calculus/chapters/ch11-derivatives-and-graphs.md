# 第11章：导数和图像

## 核心思想
导数不只是斜率工具：一阶导数的符号决定函数在哪里增减、在哪里达到极值，二阶导数的符号决定图像的凹性；借助罗尔定理与中值定理，这些"显然"的几何事实被严格化为可论证的工具，从而把求极值、分类临界点、绘制图像变成机械流程。

## 本节框架与方法

- **极值定理（Extreme Value Theorem）**: 若 c 为开区间 (a,b) 内的局部极值点，则 c 必为临界点，即 f'(c)=0 或 f'(c) 不存在。
  - 何时使用: 缩小全局/局部极值的候选范围（注意逆命题不成立）。
  - 怎么做: 闭区间 [a,b] 上求全局最值的五步法：(1) 求 f'(x)，列出 (a,b) 内 f'=0 或 f' 不存在的临界点；(2) 加入端点 a、b；(3) 逐点代入求函数值；(4) 最大者即全局最大值；(5) 最小者即全局最小值。定义域为 [a,+∞) 时，把 lim_{x→∞} f(x) 当作"伪端点"值参与比较（但极限取到处不算真正的最值点）。

- **罗尔定理**: f 在 [a,b] 连续、(a,b) 可导，且 f(a)=f(b)，则存在 c∈(a,b) 使 f'(c)=0。
  - 何时使用: 证明某点处导数必为零；配合反证法证明"至多 N 个交点/根"。
  - 怎么做: 三个条件缺一不可——闭区间连续、开区间可导（哪怕一个尖点也会失效）、f(a)=f(b)。进阶用法：对 f 用一次罗尔得 f'(p)=f'(q)=0，再对 f' 用罗尔得 f''(r)=0。

- **中值定理 (MVT)**: f 在 [a,b] 连续、(a,b) 可导，则存在 c∈(a,b) 使 f'(c) = [f(b)−f(a)]/(b−a)。
  - 何时使用: 把"平均速度=某瞬时速度"的几何直觉变成代数等式；证明导数性质的三个推论。
  - 怎么做: 罗尔定理是 MVT 的特例（f(a)=f(b) 时右端为 0）。三个推论：(1) f'≡0 ⇒ f 为常数；(2) f'=g' ⇒ f=g+C（积分理论的基础）；(3) f'>0 ⇒ f 增函数，f'<0 ⇒ f 减函数。

- **一阶导数判别法**: 设 f'(c)=0，观察 f' 过 c 时的符号变化。
  - 何时使用: 任何临界点都适用（比二阶判别法更通用），尤其当 f''(c)=0 使二阶法失效时。
  - 怎么做: f' 由正变负 ⇒ 局部最大；由负变正 ⇒ 局部最小；符号不变 ⇒ 水平拐点。技巧：画出 y=f'(x) 的草图看符号变化（如 f(x)=x ln x 时画 y=ln(x)+1）。

- **二阶导数判别法**: 设 f'(c)=0。
  - 何时使用: 能很快算出 f''(c) 且其非零时，一步定乾坤。
  - 怎么做: f''(c)<0（凹向下，倒扣的碗）⇒ 局部最大；f''(c)>0（凹向上，碗形）⇒ 局部最小；f''(c)=0 ⇒ **无法判断**，四种情况皆可能（对比 x³ 的拐点与 x⁴ 的极小值），必须回到一阶导数法。

## 关键概念
- **全局（绝对）最大/最小值**: f(a) 在整个定义域上不小于/不大于任何 f(x)。可有多个（如 cos x 在 2π 整数倍处都取最大值 1）。
- **局部（相对）最大/最小值**: 在包含 a 的某一小区间内 f(a) 是最值。每个全局极值也是局部极值。
- **临界点**: f'(c)=0 或 f'(c) 不存在的点 x=c。开区间内局部极值 ⇒ 临界点；闭区间内局部极值 ⇒ 临界点或端点。
- **凹向上（concave up）**: 区间内 f''(x)>0，即 f' 递增、图像越来越陡，形如碗（cup）。与 f' 的正负无关。
- **凹向下（concave down）**: 区间内 f''(x)<0，即 f' 递减，形如倒扣的碗（frown）。
- **拐点（inflection point）**: 图像改变凹性的点 c，两侧 f'' 符号相反（若 f'' 存在则 f''(c)=0）。拐点处切线穿
过曲线。
- **水平拐点**: 既是拐点又有水平切线（f'(c)=0）的点，如 x³ 在 0 处。

## 心智模型
- 当需要"限制搜索范围"时，用极值定理：极值候选 = 临界点 ∪ 端点，查表代值即完事——把连续优化变成有限点比较。
- 当遇到"证明至多 N 个交点/根"时，用罗尔定理 + 反证法：多假设一个交点，就多挤出一次 f'(c)=0（甚至 f''(r)=0），与已知导数符号矛盾。n 个根 ⇒ f' 至少 n−1 个零点。
- 当看到"导数恒正/恒负/恒零"的全局假设时，用 MVT 把它翻译成函数本身的全局性质（增/减/常数）——MVT 是从局部（导数）到整体（函数）的桥。
- 当判断临界点类型时，把它想成登山：f' 符号由正到负是登顶（最大），由负到正是谷底（最小），符号不变只是歇脚的平台（水平拐点）。f'' 的口诀："Like a cup, concave up; like a frown, concave down."

## 常见错误与陷阱
- **"f'(c)=0 ⇒ c 是极值点"**: 错。f(x)=x³ 在 0 处 f'(0)=0 却是水平拐点。f'=0 只说明切线水平，类型必须另行判别。
- **"f''(c)=0 ⇒ c 是拐点"**: 错。f(x)=x⁴ 有 f''(0)=0 但处处凹向上，无拐点。反之拐点 ⇒ f''(c)=0（存在时），方向不可逆。
- **二阶判别法当 f''(c)=0 时给结论**: 此时完全失明——x³（拐点）与 x⁴（极小）的二阶导数都是 0，必须退回一阶导数符号法。
- **罗尔定理少验一个条件**: 闭区间不连续（哪怕端点 a 处有跳跃）、开区间有尖点（如 |x| 在 0）、或 f(a)≠f(b)，任一缺失结论即失效。
- **忘记端点**: 闭区间上的全局最值常在端点取得（如例中 f(2)=305），只查临界点会漏解。
- **混淆"极限值"与"函数值"**: 定义域为 [0,∞) 时 lim_{x→∞} g(x)=1 若比其他值都小，也只能说 g 没有全局最小值——∞ 不是数，取不到的最值不叫最值。
- **由 f''(c)>0 推断 f'(c) 的符号**: 二阶导数正只说明图像凹向上，一阶导数可正可负（碗形图像两侧斜率反号）。

## 公式与参考表

**极值定理**：c 为开区间内局部极值 ⇒ f'(c)=0 或 f'(c) 不存在。

**罗尔定理**：连续[a,b] + 可导(a,b) + f(a)=f(b) ⇒ ∃c: f'(c)=0。

**中值定理**：连续[a,b] + 可导(a,b) ⇒ ∃c: f'(c) = (f(b)−f(a))/(b−a)。

**MVT 三推论**：
1. f'(x)=0 ∀x∈(a,b) ⇒ f 在该区间为常数（应用：sin⁻¹x + cos⁻¹x = π/2，因其导数为 0 且在 x=0 处取 π/2）。
2. f'(x)=g'(x) ∀x ⇒ f(x)=g(x)+C。
3. f'(x)>0 ∀x ⇒ f 增函数；f'(x)<0 ∀x ⇒ f 减函数。

**临界点分类表（设 f'(c)=0）**：

| 方法 | 条件 | 结论 |
|---|---|---|
| 一阶导数 | f' 由正变负 | 局部最大值 |
| 一阶导数 | f' 由负变正 | 局部最小值 |
| 一阶导数 | f' 符号不变 | 水平拐点 |
| 二阶导数 | f''(c)<0 | 局部最大值 |
| 二阶导数 | f''(c)>0 | 局部最小值 |
| 二阶导数 | f''(c)=0 | 无法判断，退回一阶法 |

**凹性与拐点**：f''>0 ⇒ 凹向上；f''<0 ⇒ 凹向下；拐点 ⇒ f''(c)=0（且两侧变号才是充分条件）。闭区间全局最值候选 = {临界点} ∪ {端点 a, b}（∪ 无穷端点极限）。

## 精讲例题

**例：求 f(x) = 12x⁵ + 15x⁴ − 40x³ + 1 在 [−1, 2] 上的全局最值，并分析临界点 x=0 的类型。**

解：
1. f'(x) = 60x⁴ + 60x³ − 120x² = 60x²(x−1)(x+2)，在 (−1,2) 内处处存在。
2. f'=0 ⇒ x = 0, 1, −2；−2 不在定义域，弃去。候选列表：{−1, 0, 1, 2}（含端点）。
3. 代值：f(−1)=44, f(0)=1, f(1)=−12, f(2)=305。
4. 全局最大值 305 在 x=2（端点！），全局最小值 −12 在 x=1。
5. x=0 的类型：f'(x)=60x²(x−1)(x+2)，在 0 附近 x²>0、(x−1)<0、(x+2)>0，故 f' 在 0 两侧均为负——符号不变，x=0 是**水平拐点**而非极值。（也可用图论证：若 x=0 是局部最大，则 (−1,0) 内必有一个低谷即另一临界点，与候选列表矛盾。）

**例（罗尔定理应用）：若 f''(x)>0 对所有 x 成立，证明 f 的图像与 x 轴至多有两个交点。**

反证：假设有三个交点 a<b<c，f(a)=f(b)=f(c)=0。在 [a,b]、[b,c] 分别用罗尔定理得 f'(p)=f'(q)=0；再对 f' 在 [p,q] 上用罗尔定理得 f''(r)=0，与 f''>0 矛盾。故交点至多两个。（构造实例：f(x)=x²+C，C 正/零/负分别对应 0/1/2 个交点。）

## 要点速记
1. 求闭区间全局最值 = 机械五步法：求导 → 列临界点 → 加端点 → 代值 → 比大小。最值经常藏在端点。
2. f'(c)=0 只是"水平切线"，三种可能：局部最大、局部最小、水平拐点——必须做符号判别。
3. 一阶导数法永远有效，二阶导数法快但有 f''(c)=0 的死穴；先算 f''(c)，为零立即切回一阶法。
4. 罗尔定理和中值定理是"反证法证明交点/根个数上界"的标准武器：每多一个交点就逼出一个导数零点。
5. f''>0（凹向上）与 f'>0（递增）毫无关系；凹性看二阶，增减看一阶，分开判断。
6. 找拐点：先解 f''(x)=0 得候选，再逐一检查两侧 f'' 是否变号；x⁴ 型是"不变号"的陷阱范例。
7. 定义域含 ∞ 时，把极限值纳入比较，但极限取到才算数；取不到就没有全局最值。
