# 第12章：绘制函数图像

## 核心思想
绘制 y = f(x) 的图像不求完美精确，而是要展现函数的主要特征：用极限找渐近线、用一阶导数找增减与极值、用二阶导数找凹性与拐点，所有信息通过**符号表格**汇总后应严丝合缝地拼成一张草图。

## 本节框架与方法
- **符号表格（Sign Table）**: 判断 f(x)、f′(x) 或 f″(x) 在各区间的正负
  - 何时使用: 每次画图都要用——函数正负、f′ 正负、f″ 正负各做一张
  - 怎么做:
    1. 按递增顺序列出所有零点与不连续点；
    2. 建三行表格：首行标 x，填入特殊点并在每两点之间（及两端之外）任选一个测试点；第二行标 f(x)（或 f′/f″），零点填 0，不连续点填 ⋆；
    3. 对每个测试点，**只需逐因式判断正负再相乘**，不必算出精确值（如 f(−3) 的 (−)(+)/(−)(−) = −）；
    4. 测试点的符号代表整个区间的符号；
    5. 第三行画图导引：f′ 表——正画斜向上斜线 /、负画斜向下 \、零画水平线 —；f″ 表——正画开口向上小抛物线 ⌣、负画开口向下 ⌢、零画点 ·。

- **绘制函数图像的全面方法（11 步清单）**:
  1. **对称性**: 以 −x 替换 x 检验奇偶性；奇/偶函数只需画 x ⩾ 0 半边，另一半由对称性得到，省时省力。
  2. **y 轴截距**: 设 x = 0 求之（若存在）。
  3. **x 轴截距**: 设 y = 0 解 x；高次多项式先试根（有理根必为常数项因子），再用多项式除法降次。
  4. **定义域**: 剔除使分母为 0、偶次根号下为负、对数内为负或 0 的点；记住反三角函数的定义域（如 arcsin 只在 [−1, 1]）。
  5. **垂直渐近线**: 分母为 0 处（**但若分子也为 0，则是可去不连续点而非渐近线**）；对数因子也可引入；用垂直虚线标出。
  6. **函数的正负**: 建立 f(x) 符号表格（零点来自第 3 步，不连续点来自第 4、5 步）——告诉你图像在 x 轴上方还是下方，以及在渐近线两侧的走势。
  7. **水平渐近线**: 算 lim_{x→±∞} f(x)；即使极限为 ±∞ 也给出端点走势（可暗示"倾斜"渐近线或主导项行为，如 f(x) ~ x²）；在渐近线附近取样判断图像位于其哪一侧。
  8. **导数的正负**: 求 f′，找全部临界点（f′ = 0 或不存在处），做 f′ 符号表格，第三行给出增/减/水平。
  9. **最大值和最小值**: 从 f′ 表读出局部极值（只出现在临界点）；代回 f(x) 求 y 坐标并标注。（也可用二阶导数检验，但 f″=0 时失效，故首选一阶导数符号表格。）
  10. **二阶导数的正负**: 求 f″，找 f″=0 或不存在处，做 f″ 符号表格，第三行给出凹向。
  11. **拐点**: f″=0 **且**两侧凹性相反的点才是拐点；代回 f(x) 求坐标并标注。

## 关键概念
- **符号表格**: 用零点与不连续点分割数轴，逐区间测试函数/导数正负的三行表格。
- **临界点**: f′(x) = 0 或 f′(x) 不存在的点；所有局部极值必出现在临界点处。
- **局部最大值/最小值**: 由 f′ 符号表格中 +→− / −→+ 的转变读出。
- **水平拐点**: f′(x) = 0 但两侧导数同号的点（如 x²(x−5)³ 在 x=5）。
- **拐点**: 凹性发生改变的点——f″ 在该点为 0 且两侧符号相反（**f″(x)=0 不是充分条件**，见 g(x)=x⁹−9x⁸ 在 x=0 处两侧均凹向下，非拐点）。
- **凹向上/凹向下**: f″ > 0 时图像凹向上（⌣），f″ < 0 时凹向下（⌢）。
- **垂直渐近线**: 分母趋于 0 而分子非零（或对数因子趋于 −∞）处的 x = a。
- **水平渐近线**: lim_{x→±∞} f(x) = L 时的直线 y = L。
- **可去不连续点**: 分母分子同时为 0、可约去因子的点（如 (x²−3x+2)/(x−2) 在 x=2）。
- **主导项行为**: x 很大时多项式表现得像其最高次项（x²(x−5)³ ~ x⁵，(x³−…)/x ~ x²）。

## 心智模型
- 当判断某点函数值的正负时，**不要算精确值，逐因式定号再相乘**。
- 当 f″(c) = 0 时，**不要急着宣布拐点或极值**——回到 f′ 符号表格看两侧符号是否变（拐点是凹性变，极值是增减变）。
- 当解三次方程求截距/临界点时，**先试常数项的因子（±1, ±2, ±4, ±8…）**，中一个就用长除法降次。
- 当对结果存疑时，**检查各步信息是否互相咬合**——不一致说明哪里算错了。
- 当函数含指数或对称结构时，**先查奇偶性**，可能直接省掉一半工作。

## 常见错误与陷阱
- **把分母为 0 一律当垂直渐近线**: 若该点分子也为 0 且可约去因子，实际是可去不连续点（仅图像上有个洞）。
- **以为 f″(x)=0 必是拐点**: x=0 处 g(x)=x⁹−9x⁸ 有 g″=0 但两侧都凹向下，不是拐点；必须两侧符号相反。
- **把第三行的导引线当成图像本身**: 斜线/抛物线只表示增减与凹向，连起来并不构成函数图像。
- **试图用二阶导数检验判定一切极值**: 临界点处 f″=0 时二阶导数检验失效（如 x=2 是 f(x)=(x³−6x²+13x−8)/x 的水平拐点），此时必须回到 f′ 符号表格看两侧符号。
- **过度依赖图形计算器**: 描点作图会让极值与拐点的细节丢失；示意图虽比例不准，却能突出所有特征点的位置。
- **强行求无理数拐点的精确 y 值**: 代回原式得一团糟时，可记 α、β 或用计算器取近似（明确标注是近似值），不必纠缠。
- **忘记定义域导致虚构渐近线**: 如 x ln(x) 只在 x>0 有定义，x→−∞ 的极限无从谈起；x→0⁺ 极限为 0，原点只是右侧可去不连续点而非渐近线。

## 公式与参考表
符号表格示例（f(x) = (x−3)(x−1)²/[x³(x+2)]）：

| x | −3 | −2 | −1 | 0 | 1/2 | 1 | 2 | 3 | 4 |
|---|---|----|----|---|-----|---|---|---|---|
| f(x) | − | ⋆ | + | ⋆ | − | 0 | − | 0 | + |

f′(x) 表第三行：`+ → /`，`− → \`，`0 → —`；f″(x) 表第三行：`+ → ⌣`，`− → ⌢`，`0 → ·`（凹性改变时该点为拐点）。

**11 步画图清单**（压缩版）：
1. 对称性（−x 代换）→ 2. y 截距（x=0）→ 3. x 截距（y=0，试根+长除法）→ 4. 定义域 → 5. 垂直渐近线（分母=0 且分子≠0，或对数）→ 6. f(x) 符号表 → 7. 水平渐近线（x→±∞ 极限）→ 8. f′ 符号表（临界点）→ 9. 极值（代回求坐标）→ 10. f″ 符号表 → 11. 拐点（f″=0 且两侧凹性变）。

## 精讲例题
**例四：f(x) = (x³ − 6x² + 13x − 8)/x**

1. **对称性**: 非奇非偶。
2. **y 截距**: x=0 无定义，无。
3. **x 截距**: 试根 x=1 成功（1−6+13−8=0）；长除法得分子 = (x−1)(x²−5x+8)，二次因子判别式 −7 < 0 恒正，故唯一截距 x=1。
4. **定义域**: R\{0}。
5. **垂直渐近线**: x=0（分母 0 而分子 −8≠0）。
6. **f 符号表**: x=−1 为 +，0 为 ⋆，1/2 为 −，1 为 0，2 为 + → 渐近线左侧曲线趋于 +∞，右侧趋于 −∞。
7. **水平渐近线**: lim_{x→±∞} (x²−6x+13−8/x) = ∞，无；端点行为 f(x) ~ x²（图像远看像抛物线 y=x²）。
8. **f′**: 用展开式 f(x)=x²−6x+13−8/x 求导最省事：f′(x) = 2x−6+8/x² = 2(x+1)(x−2)²/x²。临界点 x=−1, 0, 2。符号：x<−1 为 −，x>−1 为 +（含 x=2 两侧均为 +）。
9. **极值**: x=−1 局部最小值，f(−1)=28；x=2 水平拐点，f(2)=1。
10. **f″**: f″(x) = 2−16/x³ = 2(x³−8)/x³，仅在 x=2 为 0、x=0 不存在；x<0 与 x>2 凹向上，0<x<2 凹向下。
11. **拐点**: 仅 (2, 1)（f″(2)=0 且两侧凹性改变；f′ 表两侧同为 + 进一步确认是水平拐点而非极值）。

最终图像：左端随 y=x² 上升，下降到 (−1, 28) 最小值后回升；x=0 左侧冲向 +∞、右侧从 −∞ 升起；穿过 (1, 0)，在 (2, 1) 处水平拐折，之后随 y=x² 上扬。

## 要点速记
1. 三张符号表格（f、f′、f″）是画图的全部骨架——先做表，再画图。
2. 测试点任取区间内方便值；判断符号只逐因式定号，不算精确值。
3. 分母为 0 先看分子：同 0 且可约 → 可去不连续；分子非 0 → 垂直渐近线。
4. 拐点 = f″=0 **且** 凹性改变；水平拐点 = f′=0 且两侧同号；两者都靠符号表格确认而非单凭导数为 0。
5. 高次多项式求根：先试常数项因子，中即长除法降次。
6. x→±∞ 时极限即使为 ∞，也用主导项描述端点行为（如 ~ x²、~ x⁵）。
7. 各步信息必须相互咬合；出现矛盾就是某处算错——把一致性检查当成免费纠错器。
