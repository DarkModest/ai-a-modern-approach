# 第5章：连续性和可导性

## 核心思想
连续性和可导性是函数图像的两种"光滑性"要求：连续意味着图像可以一笔画成（极限值等于函数值），可导意味着图像没有尖角（差商极限存在）；可导必连续，但连续不一定可导。

## 本节框架与方法

- **在一点处连续的三条判据**: f 在 x = a 处连续 ⟺ (1) 双侧极限 lim_{x→a} f(x) 存在且有限; (2) f(a) 存在且有限; (3) 两者相等，即 lim_{x→a} f(x) = f(a)
  - 何时使用: 检验分段函数衔接点、可疑点处的连续性
  - 怎么做: 分别验证三条，任一条失败即不连续（左/右极限不等→极限不存在；函数无定义→有"洞"；极限≠函数值→跳跃）

- **在区间 [a, b] 上连续**: (1) 在 (a, b) 内每点连续; (2) 在 x = a 处右连续（用右极限）; (3) 在 x = b 处左连续（用左极限）
  - 何时使用: 端点处双侧极限不存在时，必须用单侧极限修正定义

- **构造连续函数的结论**: 连续函数的常数倍、和、差、积、复合仍连续；商在分母非零处连续
  - 何时使用: 快速判定多项式、指数、对数、三角函数（除渐近线外）处处连续
  - 推论: 若 f 在 a 连续，则 lim_{x→a} f(x) = f(a)，即可以"直接代入"求极限——这把"附近的"极限与"在 a 处的"函数值联系起来

- **介值定理 (IVT)**: 若 f 在 [a, b] 上连续，且 f(a) < 0 且 f(b) > 0（或反过来），则在 (a, b) 内至少存在一点 c 使 f(c) = 0。变体：将 0 换成任意数 M，若 f(a) < M < f(b)，则存在 c 使 f(c) = M
  - 何时使用: 证明方程有解 / 函数有根 / 有 x 轴截距（不求出解，只证存在性）
  - 怎么做: 把方程全部移到左边构造 f(x) = 0；找 a、b 使 f(a) 与 f(b) 异号；确认 f 在 [a, b] 上连续；应用定理。注意：定理不给解的位置，也不给解的个数

- **最大值与最小值定理**: 若 f 在闭区间 [a, b] 上连续，则 f 在 [a, b] 上至少有一个最大值和一个最小值
  - 何时使用: 需要保证闭区间上连续函数有界、能达到最高/最低点
  - 陷阱: 区间必须是闭的——开区间 (a, b) 上函数可能在趋近端点时无限逼近却永远达不到"最大值"

- **导数（瞬时速度 / 切线斜率）**: f'(x) = lim_{h→0} [f(x+h) − f(x)] / h
  - 何时使用: 求瞬时变化率、切线斜率、速度
  - 怎么做: 写出差商 → 展开化简 → 消去分母的 h → 代入 h = 0。绝不能直接把 h = 0 代入原始差商（得 0/0 不定式）

- **可导 ⇒ 连续**: 若 f 在 x 可导，则 f 在 x 连续（证明技巧：把 [f(x+h)−f(x)]/h × h 的极限拆成两个极限之积 f'(x) × 0 = 0）
  - 何时使用: 已知可导性时免费获得连续性（如 sin、exp、log 可导故连续）；反之不可导必用于判定不连续之外的情形

## 关键概念
- **连续（在一点）**: lim_{x→a} f(x) = f(a)，即极限值与函数值都存在且相等。
- **右连续 / 左连续**: 在端点处用单侧极限代替双侧极限来满足连续性条件。
- **位移**: 终点位置 − 初始位置；可正可负可为零，与中间过程无关（区别于永远非负的距离）。
- **平均速度**: 位移 / 时间，即位置-时间图像上两点连线的斜率；单向行驶时平均速率 = |平均速度|。
- **瞬时速度**: v(t) = lim_{h→0} [f(t+h) − f(t)] / h = f'(t)，即位置关于时间的导数。
- **切线**: 通过点 (x, f(x)) 且斜率为 lim_{z→x} [f(z)−f(x)]/(z−x) 的直线；允许与曲线有其他交点。
- **导函数 f′**: 切线斜率作为 x 的函数；f 在 x 可导 ⟺ 差商极限存在；不可导的点不在 f′ 的定义域内。
- **左导数 / 右导数**: 用 h→0⁻ / h→0⁺ 的单侧极限定义的导数；两者都存在且相等 ⟺ 导数存在。
- **二阶导及高阶导**: f″ = (f′)′，记作 f″(x)、f⁽ⁿ⁾(x) 或 d²y/dx²；高阶用 f⁽ⁿ⁾(x) 避免一堆撇号。

## 心智模型
- 当要证"方程有解"而无需解出时，用介值定理：移项造 f，找异号两端点。
- 把导数看作"放大倍数"：x 的微小变化 Δx 产生约 f′(x) 倍的 y 变化，即 Δy ≈ f′(x)·Δx（第13章线性化的前身）。
- 把平均速度看作割线斜率，把瞬时速度看作割线取极限后的切线斜率——同一个极限过程的两副面孔。
- 当 h 出现在分母造成 0/0 时，先代数化简约掉 h，再令 h→0，而不是直接代入。

## 常见错误与陷阱
- **直接代入 h = 0 求差商极限**: 得到 0/0 不定式；必须先化简（展开、消因子）再取极限。
- **把连续当可导**: 连续函数不一定可导——f(x) = |x| 在 x = 0 连续但左右导数分别为 −1 和 1，尖点处导数不存在。反向才对：可导必连续。
- **在开区间或无连续性的区间上用最大值最小值定理**: 渐近线处函数无限上升无最大值；开区间端点附近"最大值"永远可以更接近端点而不存在。
- **误以为介值定理给出解的位置或个数**: 它只保证 (a, b) 内至少有一个 c，不知道在哪、有几个（如 x = cos x 的解不在 π/4）。
- **切线只能与曲线相交一次**: 错误；切线可与曲线多次相交，只要在切点处"刚好掠过"。
- **把 dy/dx 当普通分数**: 它是 Δy/Δx 在 Δx→0 时的极限记号，dx、dy 单独没有意义。
- **位移与距离混淆**: 往返运动位移可为 0 而距离很大；平均速度为 0 时平均速率可能很高。
- **偶数次多项式套用"必有根"**: 只有奇数次多项式保证至少一个根（x² + 1 无根）。

## 公式与参考表

- 连续性定义: lim_{x→a} f(x) = f(a)（双侧极限存在 + f(a) 存在 + 两者相等）
- 平均速度: v_{t↔u} = [f(u) − f(t)] / (u − t)
- 瞬时速度: lim_{u→t} [f(u) − f(t)] / (u − t) = lim_{h→0} [f(t+h) − f(t)] / h（h = u − t）
- 导数: f′(x) = lim_{h→0} [f(x+h) − f(x)] / h = lim_{Δx→0} Δy/Δx = dy/dx
- 左导数: lim_{h→0⁻} [f(x+h) − f(x)] / h；右导数: lim_{h→0⁺} [f(x+h) − f(x)] / h
- 导数记号等价: f′(x) = dy/dx = d/dx (f(x))；二阶: f″(x) = d²y/dx²
- 线性函数: f(x) = mx + b ⟹ f′(x) = m；常数函数 ⟹ f′(x) = 0
- 位移 = 终点 − 起点；位移 < 0 ⟺ 终点在起点左侧；平均速度 = 位移/时间
- 介值定理: f 在 [a,b] 连续 + f(a)、f(b) 异号 ⟹ ∃c ∈ (a,b), f(c) = 0
- 最大值最小值定理: f 在 [a,b] 连续 ⟹ 至少一个最大值与一个最小值

## 精讲例题

**例：求 f(x) = x² 的导数（并连接瞬时速度语境）**

套用定义并化简：

f′(x) = lim_{h→0} [f(x+h) − f(x)] / h = lim_{h→0} [(x+h)² − x²] / h

展开 (x+h)² = x² + 2xh + h²：

= lim_{h→0} [2xh + h²] / h = lim_{h→0} (2x + h) = 2x

结论：f′(x) = 2x。验证图像：抛物线 y = x² 在 x = −1 处切线斜率为 −2 = 2×(−1)，一致。

同法用于运动问题：若汽车位置 f(t) = 15t² + 7，则瞬时速度 v(t) = f′(t) = 30t。t = 0 时速度 0（静止起步），t = 1/2 时 15 英里/小时，每小时速度增加 30 英里/小时（即加速度 30 英里/小时²）。关键步骤始终如一：展开 → 消去分母的 h → 令 h→0。

**（IVT 应用范式：证 x = cos x 有解）** 移项设 f(x) = x − cos x（连续）。取 a = 0, b = π/2：f(0) = −1 < 0，f(π/2) = π/2 > 0。由介值定理，∃c ∈ (0, π/2) 使 f(c) = 0，即 c = cos c。解存在但位置与个数未知。

## 要点速记
1. 连续性 = 三个条件齐备：极限存在、函数值存在、二者相等；缺一条即不连续。
2. 用"连续函数的运算封闭性"（和差积商复合）快速断言多项式、三角、指数、对数函数的连续域。
3. 证方程有解的标准动作：移项构造 f → 找异号端点 → 介值定理；奇数次多项式必有根也靠它（x→±∞ 时 p(x) 与首项 aₙxⁿ 同号，而奇次幂两端异号）。
4. 最大值最小值定理只在**闭区间 + 连续**时才可依赖；开区间上的"最值"可能只是运气好。
5. 求导三板斧：写差商 → 代数化简约掉 h → 取极限；y = x² ⟹ y′ = 2x 是模板。
6. 可导 ⇒ 连续（乘 h 拆极限证明）；连续 ⇏ 可导（|x| 在 0 处的尖点，左导 −1 ≠ 右导 1）。
7. 速度 = 位置的导数，切线斜率 = 导数；Δy ≈ f′(x)Δx 是导数的实用读法（线性化思想萌芽）。
