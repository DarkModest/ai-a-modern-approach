# 第9章：指数函数和对数函数

## 核心思想
e 是使指数/对数函数的微积分运算最简洁的特殊底数（(e^x)' = e^x，(ln x)' = 1/x）；围绕它可系统解决求导、含 e 的极限、取对数求导法、指数增长/衰变与双曲函数问题。

## 本节框架与方法
- **e 的定义（复利极限）**: e = lim(n→∞)(1 + 1/n)^n = lim(h→0)(1 + h)^(1/h)；更一般地 lim(n→∞)(1 + x/n)^n = e^x 且 lim(h→0)(1 + xh)^(1/h) = e^x
  - 何时使用: 遇到 (1 + 小量)^(1/小量) 型的 1^∞ 极限
  - 怎么做: 凑出"匹配"——底数中趋于 0 的量必须与指数的倒数是同一个量；系数不匹配时把指数拆因子（如 1/3h² = (1/h²)·(1/3)），外层幂次落到 e 的指数上
- **取对数求导法**: 对 y = f(x)^g(x)（底数与指数都含 x），或分子分母含大量幂/指数乘积商的函数
  - 何时使用: 无法用幂函数或指数函数求导公式直接处理时（如 x^sin(x)）
  - 怎么做: (1) 两边取 ln，把指数拉下来：ln y = g(x) ln f(x)；(2) 两边对 x 隐函数求导，左边恒为 (1/y)(dy/dx)，右边用乘积/链式法则；(3) 两边乘 y 并用原式代回 y。等价写法：f^g = e^{g ln f} 再求导
- **伪装导数的极限**: lim(h→0)(e^h − 1)/h = 1，lim(h→0) ln(1 + h)/h = 1
  - 何时使用: 分子是 e^小量 − 1 或 ln(1 + 小量) 且除以同阶小量的 0/0 极限
  - 怎么做: 识别为 f(x) = e^x 或 ln x 在 x = 0 或 1 处的导数定义；系数不匹配时同乘同除凑出匹配因子
- **增长速率比较原则**: 指数增长迅速、对数增长缓慢
  - 何时使用: x→∞ 时多项式/e^多项式 或 ln/x^a 型极限
  - 怎么做: 直接套 lim x^n/e^x = 0（n 任意大）与 lim ln(x)/x^a = 0（a 任意小正数）；x→0+ 时用替换 x = 1/t 转化为 ∞ 情形
- **指数增长/衰变模型**: dy/dt = ky ⇔ y = Ae^(kt)；衰变时 P(t) = P₀e^(−kt)，k = ln(2)/t₁/₂
  - 何时使用: 种群增长、放射性衰变（半衰期）问题
  - 怎么做: 由 P₀ 定 A，由第二个数据点取对数解 k；求时间时取对数解 t，善用 ln(2)≈0.7、ln(5)≈1.6 手算
- **换底法则**: log_b(x) = log_c(x)/log_c(b)
  - 何时使用: 需要统一底数、对任意底数 b 求导，或比较不同底数对数图像时
  - 怎么做: 一切化为 ln：log_b(x) = ln(x)/ln(b)；由此不同底对数互为常数倍

## 关键概念
- **自然对数 ln(x)**: 以 e 为底的对数，满足 e^ln(x) = x（x>0）与 ln(e^x) = x（一切实数 x）。
- **e**: lim(h→0)(1+h)^(1/h) ≈ 2.71828 的无理数，ln(e)=1 使其导数公式最简。
- **增长常数 k**: 微分方程 dP/dt = kP 中控制增长速率的常数；衰变时取 −k。
- **半衰期 t₁/₂**: 任何样本衰变一半所需的时间，与初始量无关，k = ln(2)/t₁/₂。
- **双曲函数**: cosh(x) = (e^x + e^(−x))/2（偶函数，cosh 0 = 1），sinh(x) = (e^x − e^(−x))/2（奇函数，sinh 0 = 0）；伪装的指数函数，性质类似三角函数。
- **反函数关系**: y = b^x 与 y = log_b(x) 互为反函数，图像关于 y = x 对称；定义域要求 b > 1 且真数 > 0。
- **连续复利**: 年利率 r 连续计息，t 年后财富 = Ae^(rt)，为复利频率趋于 ∞ 时的"财富增长极限"。

## 心智模型
- 当指数里藏着变量时用**取对数**：对数法则 5（ln(x^y) = y ln x）是把指数"拉下马"的唯一通用工具。
- 当看到 0/0 且含 e^h−1 或 ln(1+h) 时想**导数定义**：极限常是 e^x 或 ln x 在某点的伪装导数，答案直接读出。
- 当极限形如 (1+…)^(1/…) 时做**匹配检查**：底数里的小量与指数分母必须是同一个趋于 0 的量；不匹配就先拆指数系数，答案形如 e^(剩余系数)。
- 当比较"谁增长快"时记住层级：对数（任意正幂）≪ 多项式 ≪ 指数（指数为大的正多项式型）；做商取极限时直接写 0 或 ∞。

## 常见错误与陷阱
- **对负数或 0 取对数**: b^x 恒正，故 log_b(y) 只在 y > 0 有定义；ln(0) 无定义，只有 lim(x→0+) ln x = −∞（右极限）。
- **底数 b = 1 或负底数**: 1 的任何幂都是 1，log₁ 不存在；b < 0 时 b^x 对非整数 x 可能无定义。永远设 b > 1（0<b<1 时 log_b(y) = −log_{1/b}(y)）。
- **(1+cos h)^(1/cos h) 误套 e 的极限**: cos h → 1 而非 0，不满足"小量"条件，极限其实是 2。只有底数中那项随 h→0 而趋于 0 才能用 e 的公式。
- **b^x 求导漏 ln(b)**: (b^x)' = b^x ln(b)，只有 b = e 时因子为 1；同理 (log_b x)' = 1/(x ln b)。
- **ln(x) 在 0 附近直接代入**: x ln(x) 是 0·∞ 型，须用 x = 1/t 转化为 −ln(t)/t 再由"对数增长缓慢"得 0。
- **过度依赖图形计算器**: e^x 和 ln x 的图像看似触碰坐标轴，实则 e^x 无 x 截距、ln x 无 y 截距。
- **双曲函数符号混淆**: (cosh x)' = sinh x（无负号！），且恒等式是 cosh²x − sinh²x = 1（减号），与三角恒等式不同。

## 公式与参考表

**指数法则**（b > 0）: b⁰=1；b¹=b；b^x b^y = b^(x+y)；b^x/b^y = b^(x−y)；(b^x)^y = b^(xy)

**对数法则**（b > 1，x, y > 0）:
| 法则 | 公式 |
|---|---|
| 基本 | log_b(1) = 0，log_b(b) = 1 |
| 乘积 | log_b(xy) = log_b x + log_b y |
| 商 | log_b(x/y) = log_b x − log_b y |
| 幂 | log_b(x^y) = y log_b x（y 任意实数） |
| 换底 | log_b(x) = log_c(x)/log_c(b) |
| 互反 | b^(log_b x) = x；log_b(b^x) = x |

**求导公式**:
| f(x) | f′(x) |
|---|---|
| e^x | e^x |
| e^(ax) | a e^(ax) |
| b^x | b^x ln(b) |
| ln(x) | 1/x |
| log_b(x) | 1/(x ln b) |
| x^a（a 任意实数） | a x^(a−1) |
| sinh(x) | cosh(x) |
| cosh(x) | sinh(x) |
| tanh(x) | sech²(x) |
| sech(x) | −sech(x)tanh(x) |
| csch(x) | −csch(x)coth(x) |
| coth(x) | −csch²(x) |

**关键极限**:
| 极限 | 值 |
|---|---|
| lim(h→0)(1+h)^(1/h) 、lim(n→∞)(1+1/n)^n | e |
| lim(1+xh)^(1/h)、lim(1+x/n)^n | e^x |
| lim(h→0)(e^h − 1)/h | 1 |
| lim(h→0) ln(1+h)/h | 1 |
| lim(x→∞) x^n/e^x | 0（指数增长迅速） |
| lim(x→∞) ln(x)/x^a (a>0) | 0（对数增长缓慢） |
| lim(x→0+) x^a ln(x) (a>0) | 0 |
| lim(x→∞) e^x = ∞；lim(x→−∞) e^x = 0 | |
| lim(x→0+) ln(x) | −∞ |
| lim(x→∞) r^x | ∞ (r>1)；1 (r=1)；0 (0≤r<1) |

**双曲函数**: cosh x = (e^x+e^(−x))/2，sinh x = (e^x−e^(−x))/2，tanh = sinh/cosh，sech = 1/cosh 等；恒等式 cosh²x − sinh²x = 1，1 − tanh²x = sech²x。除 cosh、sech 为偶函数外其余均为奇函数；tanh、coth 有水平渐近线 y = ±1，sech、csch 有 y = 0。

**增长/衰变**: 增长 P(t) = P₀e^(kt)；衰变 P(t) = P₀e^(−kt)，k = ln(2)/t₁/₂；连续复利 财富 = Ae^(rt)。

## 精讲例题
**例：用取对数求导法求 d/dx [x^sin(x)]**

设 y = x^sin(x)。底数和指数都含 x，幂/指数公式都不适用，取对数：
1. ln y = sin(x) ln(x)（对数法则 5 把指数拉下）。
2. 两边隐函数求导：左边 = (1/y)(dy/dx)；右边用乘积法则 = cos(x) ln(x) + sin(x)/x。
3. 乘 y 并代回：
   dy/dx = [cos(x) ln(x) + sin(x)/x] · x^sin(x)。

验证：另一法写 x^sin(x) = e^(sin x · ln x)，链式+乘积法则求导得同一结果。

**例（指数衰变）**: 半衰期 7 年的原料 50 磅，多久剩 1 磅？
k = ln 2/7，P(t) = 50e^(−t ln2/7)。令 P = 1：ln(1/50) = −t ln2/7，t = 7 ln 50/ln 2 = 7(ln2 + 2ln5)/ln2 ≈ 7 + 14(1.6)/0.7 = 39 年（略多于 5.5 个半衰期）。

## 要点速记
1. 一切非 e 底的运算先换底：log_b(x) = ln x/ln b，b^x = e^(x ln b)，然后只记 e 的公式。
2. 1^∞ 型极限 = e^(系数)：把底数小量与指数配成互倒，剩余因子提到 e 的指数上。
3. f^g 型或巨型乘除式求导，第一反应取 ln——左边永远是 y′/y，别忘了最后乘回 y。
4. lim (e^h−1)/h = 1 与 lim ln(1+h)/h = 1 是导数定义的伪装；用"同乘同除"凑匹配。
5. 增长竞赛口诀：ln 最慢、幂居中、e 最快；涉及 x→0+ 的对数极限就换 t = 1/x。
6. 半衰期问题先算 k = ln2/t₁/₂；手算估值记 ln 2 ≈ 0.7，ln 5 ≈ 1.6。
7. 双曲函数定义纯指数、性质似三角，但记两处反号：cosh′ = sinh（无负号）、cosh²−sinh² = 1（是减号）。
