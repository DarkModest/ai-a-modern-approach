# 第18章：积分的方法I

## 核心思想
求反导数没有万能算法，但有一套核心技巧：换元法（逆用链式法则）、分部积分法（逆用乘积法则）、部分分式法（把有理函数拆成易积的简单分式之和）。本章的关键判断力在于"选哪个方法"以及"换元/分部选哪一部分"。

## 本节框架与方法

- **换元法 (变量替换)**: ∫f(g(x))g′(x)dx = ∫f(t)dt = F(g(x)) + C，其中 t = g(x)
  - 何时使用: 被积函数中存在"某一项的导数恰好是另一个因子"的结构（链式求导的逆运算痕迹），例如 x²cos(x³)、e²ˣsec²(e²ˣ)、1/(x ln x)
  - 怎么做: (1) 选 t = g(x)，使其导数 g′(x) 也出现在被积函数中; (2) 写出 dt = g′(x)dx，凑出 dx 的替换; (3) 把被积函数中所有 x 项换成 t; (4) 不定积分算完后**必须换回 x**; (5) 定积分则可**不换回 x**，而是把上下限也换成 t 的值——共三处替换：dx、被积函数、上下限。定积分若先按不定积分做再代入原上下限也可以
  - 特殊类型 ∫ⁿ√(ax+b): 设 t = ⁿ√(ax+b)，先两边 n 次方得 tⁿ = ax+b 再求微分（如 5t⁴dt = 3dx），此时可直接写出 dx = (5/3)t⁴dt，并能反解出 x 的表达式用于替换被积函数中剩余的 x
  - 理论依据: 链式法则。也可反向换元 x = g(t)，dx = g′(t)dt（19.3 节三角换元的基础）

- **分部积分法**: ∫u dv = uv − ∫v du
  - 何时使用: 被积函数是乘积且换元法无效；或反三角函数、ln(x) 及其幂（此时设 dv = dx）
  - 怎么做: (1) 把积分拆成 ∫u dv; (2) 对 u 求导得 du，对 dv 积分得 v(**不需要 +C**); (3) 代入公式，剩余积分应更简单; (4) 选 u 的经验规则：见 eˣ 就让 dv = eˣdx（它的积分是自己）；多项式乘三角/指数时令 u = 多项式（每分部一次降一次幂）; (5) ln(x)、sin⁻¹(x)、tan⁻¹(x) 型令 u 为该函数、dv = dx; (6) 定积分建议先算不定积分再代上下限

- **循环型分部积分**: 两次分部后等式两边出现同一个原始积分
  - 何时使用: 如 ∫cos(x)e²ˣdx 这类指数×三角积分，分部后难度不降
  - 怎么做: 坚持同一种拆分方向再做一次分部，把原始积分项移到等式左边合并（如 (5/4)∫cos(x)e²ˣdx = ...），解出原积分，最后加 C。若两次分部后积分被正好约掉（系数为 1 相消），说明方向选错，重来

- **部分分式法**: ∫p(x)/q(x)dx，把有理函数拆成简单分式之和再逐项积分
  - 何时使用: 被积函数是多项式之比
  - 六步法: (1) 检查次数：分子次数 ≥ 分母次数时先做多项式除法; (2) 分母因式分解（二次式查判别式 b²−4ac < 0 则不可分解）; (3) 写"分部"（分解形式，仅由分母决定，与分子无关）; (4) 两边乘分母，用代入特殊 x 值法和/或系数相等法求常数，两法可混用; (5) 线性幂分式积分 → 对数或线性负幂; (6) 不可分解二次分式积分 → 配方 + 换元，拆成两个积分：一个给对数，一个给 tan⁻¹

## 关键概念
- **换元法 (substitution)**: 链式法则的逆用，设 t = g(x) 并用 dt = g′(x)dx 把积分化为关于 t 的更简单形式
- **f′/f 型积分**: ∫f′(x)/f(x)dx = ln|f(x)| + C——分子恰为分母导数时，答案是分母绝对值的对数；分子是导数的常数倍时先乘除常数凑配
- **分部 (partial fractions 分解项)**: 由分母每个因式决定的待定分式形式，与分子无关
- **判别式**: b²−4ac，为负时二次分母不可因式分解，须走配方路线
- **配方 (completing the square)**: 把 ax²+bx+c 写成 (x+h)²+k 形式，为 tan⁻¹ 型积分做准备
- **循环积分**: 分部两次后回到原积分，通过移项解方程求得结果的技巧
- **多项式除法**: 分子次数不低于分母时必先做除法，分离出多项式部分和真分式
- **微分替换 dt = g′(x)dx**: 不能只换函数不换 dx；dt 与 dx 的关系由链式法则严格决定

## 心智模型
- 当被积函数里藏着"复合函数 × 内层导数"时用**换元法**——找那个"导数也在场"的部分设为 t
- 当被积函数是乘积且换元失败时用**分部积分**——让求导后变简单的那个当 u，让积分后不变复杂的当 dv
- 当看到有理函数 p(x)/q(x) 时用**部分分式**——先除法、再分解、再待定系数，把难题拆成对数与反正切
- 当积分越分部越复杂时，检查：要么 u/dv 选反了，要么它其实是循环型，需要"移项解方程"而不是继续降幂

## 常见错误与陷阱
- **只换被积函数不换 dx**: dt 必须等于 g′(x)dx，不能随便把 dx 改成 dt
- **定积分换元后忘换上下限**: 对 t 积分却保留 x 的上下限是"大错特错"；要么三处都换，要么先求不定积分换回 x 再代原上下限
- **不定积分换元后忘换回 x**: 从 x 出发的答案必须回到 x
- **分部积分给 v 加 +C**: 只需任一满足 dv 的 v 即可，加 C 徒增混乱
- **分部方向选错**: 如 ∫xeˣdx 设 u=eˣ, dv=xdx，得到的 (1/2)∫x²eˣdx 比原积分更糟——见 eˣ 应让 dv = eˣdx
- **部分分式字母复用**: 不同分部的常数必须用不同字母（A、B、C…）；用 C₁、C₂ 这类下标极易笔误
- **忘做多项式除法**: 分子次数 ≥ 分母次数时直接写分部，结果必错
- **判别式为负还强行分解**: 不可分解的二次分母应配方，而非分解
- **分部形式与分子挂钩**: 分部只由分母因式决定，与分子无关
- **二次分母最高次系数非 1 时直接配方**: 应先把系数提出积分外再配方

## 公式与参考表

**分部积分公式**

∫u dv = uv − ∫v du

**常用积分公式**

∫f′(x)/f(x)dx = ln|f(x)| + C

∫1/(t²+a²) dt = (1/a)·tan⁻¹(t/a) + C

**部分分式分解形式表**（分部仅由分母决定）

| 分母因式 | 对应分部 |
|---|---|
| (x + a) | A/(x + a) |
| (x + a)² | A/(x + a)² + B/(x + a) |
| (x + a)³ | A/(x + a)³ + B/(x + a)² + C/(x + a) |
| (x + a)⁴ | A/(x+a)⁴ + B/(x+a)³ + C/(x+a)² + D/(x+a) |
| 不可分解二次式 x² + ax + b | (Ax + B)/(x² + ax + b) |

**求常数的两种方法**: (a) 代入使某些因子为 0 的特殊 x 值（如 x=1, x=−1）; (b) 展开后令两边同次幂系数相等。可混用，有几个常数就需要几个条件。

**各部分积分结果速查**

∫1/(ax+b)dx = (1/a)ln|ax+b| + C；∫1/(ax+b)²dx = −1/(a(ax+b)) + C；不可分解二次分式 → 配方后一半给 ln、一半给 tan⁻¹

## 精讲例题

求 ∫(x + 8)/(x² + 6x + 13)dx。

**判断**: 分母判别式 6² − 4×13 = −16 < 0，不可因式分解 → 不走分部拆分，走配方路线。

**步骤**:
1. 配方: x² + 6x + 13 = (x + 3)² + 4
2. 换元 t = x + 3，则 x = t − 3, dx = dt:
   ∫(t + 5)/(t² + 4)dt
3. 拆成两个积分: ∫t/(t²+4)dt + 5∫1/(t²+4)dt
4. 第一个：分子分母同乘 2，分子成 2t（分母的导数）→ (1/2)ln(t² + 4)（t²+4 恒正，可去绝对值）
5. 第二个：套公式 a = 2 → 5 × (1/2)tan⁻¹(t/2)
6. 换回 t = x + 3（对数部分直接用未展开的配方形式即可化回原分母）:

**(1/2)ln(x² + 6x + 13) + (5/2)tan⁻¹((x + 3)/2) + C**

## 要点速记
1. 换元法口诀：找"导数也在场"的部分设 t；不定积分必须换回 x，定积分换元则三处齐换（dx、被积函数、上下限）
2. 分子是分母导数 → 答案直接是 ln|分母|；差个常数倍就乘除凑
3. 分部积分选 dv 的黄金规则：有 eˣ 就让 dv = eˣdx；多项式乘别的函数时多项式当 u 逐次降幂
4. ln(x)、反三角函数单独出现时也能分部：设 dv = dx
5. 两次分部后回到原积分不是失败——移项合并就是答案（eˣ×三角型）
6. 部分分式六步：查次数→分解分母→写分部→定常数→积线性幂→配方积二次式；不必每题走满六步
7. 任何积分结果都可以**求导验证**——这是最便宜的正确性检查
