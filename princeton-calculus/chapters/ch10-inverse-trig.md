# 第10章：反函数和反三角函数

## 核心思想
单调性由导数符号判定，故可导函数"恒增或恒减"即满足水平线检验、必有反函数；反三角/反双曲函数都是先限制定义域取单值分支，再用隐函数求导得到导数公式，关键在于**用图像斜率符号或值域范围来选定 ± 号**。

## 本节框架与方法
- **导数判别可逆性**: f 在区间 (a,b) 上可导且满足下列任一条件：(1) f′(x) > 0；(2) f′(x) < 0；(3) f′(x) ≥ 0 且仅在有限个点取 0；(4) f′(x) ≤ 0 且仅在有限个点取 0，则 f 有反函数。定义域为闭/半闭区间时还需 f 在其上连续。
  - 何时使用: 判断形如三次多项式、cos x 在 (0,π)、x³ 等函数是否有反函数，当直接解 y=f(x) 太繁琐时
  - 怎么做: 求 f′；二次型 f′ 用判别式或配方定号（如 x²−2x+5=(x−1)²+4>0）；检查 f′=0 的点是否有限；端点处用连续性延伸
- **反函数求导公式**: 若 y = f⁻¹(x)，则 dy/dx = 1/f′(y)，即 d/dx f⁻¹(x) = 1/f′(f⁻¹(x))
  - 何时使用: 求反三角/反双曲函数导数，或在无法显式解出 f⁻¹ 时求特定点处的 (f⁻¹)′
  - 怎么做: 由 f(y)=x 隐函数求导得公式；求特定点值时先用 f(y)=x 解出 y（解唯一，因反函数存在），再代入分母 f′(y)
- **反三角/反双曲函数求导通法**: 写 x = trig(y)，两边关于 x 隐函数求导得 dy/dx = 1/(trig 的导数)；用三角恒等式（cos²+sin²=1、sec²=1+tan²、cosh²−sinh²=1）把分母化成 x 的式子
  - 何时使用: 推导或记忆验证全部六个反三角函数、反双曲函数导数
  - 怎么做: **± 号判定**：看反函数图像斜率恒正还是恒负（sin⁻¹、tan⁻¹、sec⁻¹、cosh⁻¹、sinh⁻¹ 取正；cos⁻¹、csc⁻¹、cot⁻¹ 取负）；sec⁻¹/csch⁻¹ 用 |x| 保证结果恒正
- **反双曲函数的对数表示**: 由 x = (eʸ+e⁻ʸ)/2 令 u = eʸ 得二次方程 u²−2xu+1=0，解出 u 再取对数
  - 何时使用: 需要 cosh⁻¹、sinh⁻¹ 的显式表达式
  - 怎么做: cosh⁻¹(x) = ln(x+√(x²−1))（取 + 号，因 x−√(x²−1)<1 对数为负）；sinh⁻¹(x) = ln(x+√(x²+1))
- **化简 trig⁻¹(trig(θ)) 型表达式**: 不能消去！按反函数值域重找角
  - 怎么做: 判 θ 所在象限和三角函数值符号；求参照角；在反函数值域区间内找参照角相同、符号一致的角

## 关键概念
- **arcsin / sin⁻¹**: sin x 限制定义域到 [−π/2, π/2] 后的反函数；定义域 [−1,1]，值域 [−π/2, π/2]，奇函数；sin⁻¹(x) ≠ (sin x)⁻¹
- **arccos / cos⁻¹**: cos x 限制到 [0, π]（不是 [−π/2,π/2]，那里通不过水平线检验）；定义域 [−1,1]，值域 [0, π]，非奇非偶
- **arctan / tan⁻¹**: tan x 限制到 (−π/2, π/2)；定义域 R，值域 (−π/2, π/2)，奇函数；有双侧水平渐近线 y=±π/2
- **arcsec / sec⁻¹**: sec x 限制到 [0, π]\{π/2}；定义域 (−∞,−1]∪[1,∞)，值域 [0, π]\{π/2}；有双侧水平渐近线 y=π/2
- **arccsc / arccot**: csc⁻¹ 奇函数，定义域 (−∞,−1]∪[1,∞)，值域 [−π/2,π/2]\{0}；cot⁻¹ 非奇非偶，定义域 R，值域 (0,π)
- **cosh⁻¹**: cosh 舍弃左半支（限制到 [0,∞)）的反函数；定义域 [1,∞)，值域 [0,∞)，非奇非偶
- **sinh⁻¹**: sinh 本身过水平线检验，无需限制；定义域、值域均为 R，奇函数
- **水平线检验**: 函数有反函数 ⟺ 每条水平线与其图像至多交一次（对应单调）
- **反函数图像**: y=f⁻¹(x) 的图像是 y=f(x)（受限部分）关于直线 y=x 的反射
- **f⁻¹ 的定义域与值域**: f⁻¹ 的定义域 = f 的值域，f⁻¹ 的值域 = f 的（受限）定义域

## 心智模型
- 当要证明"某函数有反函数"时，不要硬解 y=f(x) 求逆，用 **求导看符号**：f′ 恒正/恒负（或仅有限个零点）⇒ 单调 ⇒ 过水平线检验。
- 当对反函数求导遇到 ±√ 号时，**看图说话**：斜率恒正取正，恒负取负；两侧单调性不同（sec⁻¹、csch⁻¹）时改用 |x| 统一取正。
- 当看到 trig⁻¹(trig(θ)) 且 θ 超出值域时，把它当成**换角题**：结果 ≠ θ，而是值域内同值的那个角；trig(trig⁻¹(A)) = A 却总是安全的（A 在定义域内时）。
- 当原函数在某点斜率为 0 时，警觉**反函数在对应点斜率无穷大、不可导**（如 h(x)=x³ 的反函数 x^(1/3) 在 x=0 处导数不存在）——原函数处处可导 ≠ 反函数处处可导。
- 当反函数定义域是两个不连通区间的并（tan、sec⁻¹ 的定义域）时，意识到**单调判别法失效**：f′ 恒正也可能不过水平线检验（tan x 就是反例）。

## 常见错误与陷阱
- **f′=0 的零点太多**：f′ 在整段区间上为 0（如分段函数在 [0,1] 上取常数 1）⇒ 水平线 y=1 与图像交于无穷多点，反函数不存在。"有限个零点"限制不可省
- **定义域非区间时滥用单调判别**：f(x)=tan x 时 f′(x)=sec²x>0，但 tan 不过水平线检验——有垂直渐近线/间断点时该法失效
- **sin⁻¹(sin(x)) = x 的误用**：仅当 x∈[−π/2,π/2] 才成立；sin⁻¹(sin(13π/10)) = −3π/10 而非 13π/10
- **误记 sin⁻¹(x) 为 1/sin(x)**：sin⁻¹ 是反函数记号，不是倒数；但 sin²x=(sin x)² 的记号又成立，两者并存需区分
- **cos x 的受限定义域选错**：限制到 [−π/2,π/2] 不行，必须 [0,π]
- **sec⁻¹ 导数丢绝对值**：写成 1/(x√(x²−1)) 在 x<−1 时给出负值，但 sec⁻¹ 斜率恒正；正确是 1/(|x|√(x²−1))
- **端点处可导性**：sin⁻¹、cos⁻¹ 在 x=±1 处不可导（分母 √(1−x²)=0），导数公式只在开区间 (−1,1) 成立
- **tanh⁻¹ 与 coth⁻¹ 导数相同 ≠ 函数相同**：两公式都是 1/(1−x²)，但定义域 (−1,1) 与 |x|>1 互不重叠，故无矛盾
- **x→−∞ 时 tan⁻¹(3x²) 的极限**：随 3x²→+∞，tan⁻¹(3x²)→π/2 而非 −π/2；判断极限看内层函数趋近方向，不是外层 x 的

## 公式与参考表

### 反三角函数定义域/值域
| 函数 | 定义域 | 值域 | 奇偶性 | 渐近线 |
|---|---|---|---|---|
| sin⁻¹ | [−1, 1] | [−π/2, π/2] | 奇 | 无 |
| cos⁻¹ | [−1, 1] | [0, π] | 无 | 无 |
| tan⁻¹ | R | (−π/2, π/2) | 奇 | y = ±π/2（水平） |
| sec⁻¹ | (−∞,−1]∪[1,∞) | [0, π]\{π/2} | 无 | y = π/2（双侧） |
| csc⁻¹ | (−∞,−1]∪[1,∞) | [−π/2, π/2]\{0} | 奇 | y = 0（双侧） |
| cot⁻¹ | R | (0, π) | 无 | y=0（右侧），y=π（左侧） |

### 反三角函数导数
| 公式 | 成立范围 |
|---|---|
| d/dx sin⁻¹(x) = 1/√(1−x²) | −1 < x < 1 |
| d/dx cos⁻¹(x) = −1/√(1−x²) | −1 < x < 1 |
| d/dx tan⁻¹(x) = 1/(1+x²) | 所有实数 x |
| d/dx cot⁻¹(x) = −1/(1+x²) | 所有实数 x |
| d/dx sec⁻¹(x) = 1/(\|x\|√(x²−1)) | x > 1 或 x < −1 |
| d/dx csc⁻¹(x) = −1/(\|x\|√(x²−1)) | x > 1 或 x < −1 |

配套关系：sin⁻¹ 与 cos⁻¹ 的导数互为相反数 ⇒ 恒等式 **sin⁻¹(x)+cos⁻¹(x) = π/2**（可用导数之和为 0 证明，也可由直角三角形 α+β=π/2 几何看出）；tan⁻¹ 与 cot⁻¹、sec⁻¹ 与 csc⁻¹ 同理。

重要极限：lim(x→∞) tan⁻¹(x) = π/2；lim(x→−∞) tan⁻¹(x) = −π/2；lim(x→±∞) sec⁻¹(x) = π/2；lim(x→±∞) csc⁻¹(x) = 0；lim(x→∞) cot⁻¹(x) = 0；lim(x→−∞) cot⁻¹(x) = π。

### 反双曲函数
| 函数 | 定义域 | 值域 | 奇偶性 | 导数（定义域内） |
|---|---|---|---|---|
| cosh⁻¹ | [1, ∞) | [0, ∞) | 无 | 1/√(x²−1), x>1 |
| sinh⁻¹ | R | R | 奇 | 1/√(x²+1) |
| tanh⁻¹ | (−1, 1) | R | 奇 | 1/(1−x²) |
| sech⁻¹ | (0, 1] | [0, ∞) | 无 | −1/(x√(1−x²)) |
| csch⁻¹ | R\{0} | R\{0} | 奇 | −1/(\|x\|√(1+x²)) |
| coth⁻¹ | (−∞,−1)∪(1,∞) | R\{0} | 奇 | 1/(1−x²) |

对数形式：cosh⁻¹(x) = ln(x+√(x²−1))（x≥1）；sinh⁻¹(x) = ln(x+√(x²+1))（所有 x）。

## 精讲例题
**例**（10.1.4 综合题）：f(x) = x²(x−5)³，定义域 [2, ∞)。(1) 证明 f 可逆；(2) 求 f⁻¹ 的定义域和值域；(3) 验证 f(4)=−16；(4) 计算 (f⁻¹)′(−16)。

**解**：
1. **可逆性**：乘积法则得 f′(x) = 2x(x−5)³ + 3x²(x−5)²，提取公因子 x(x−5)² 化简为 f′(x) = 5x(x−5)²(x−2)。当 x>2 时三个因子均非负，且仅 x=5 一点使 f′=0；f 在 [2,∞) 上连续，由判别条件 (3) 得 f 可逆。
2. **f⁻¹ 的值域** = f 的定义域 = [2, ∞)。**f⁻¹ 的定义域** = f 的值域：f 递增，最低点 f(2) = 4·(−3)³ = −108，向上无界，故值域为 [−108, ∞)。
3. f(4) = 16·(−1)³ = −16 ✓，故 f⁻¹(−16) = 4。
4. 由反函数求导公式：dy/dx = 1/f′(y) = 1/(5y(y−5)²(y−2))，代入 y=4：(f⁻¹)′(−16) = 1/(5·4·1·2) = **1/40**。

**例**（trig(trig⁻¹) 化简）：求 sin(cos⁻¹(−√15/4))。设 x = cos⁻¹(−√15/4)，则 cos x = −√15/4，sin x = ±√(1−15/16) = ±1/4。因 −√15/4 < 0，其反余弦落在 [π/2, π]（第二象限），而**正弦在第二象限仍为正**，故答案为 1/4（不是 −1/4）。一般结论：sin(cos⁻¹(A)) 恒非负，因 cos⁻¹(A)∈[0,π] 上 sin ≥ 0。

## 要点速记
1. 证明可逆先求导：f′ 恒正/恒负（允许有限个零点）⇒ 有反函数；遇到二次 f′ 用判别式 < 0 或配方定号。
2. 反函数求导两步走：(f⁻¹)′(x) = 1/f′(f⁻¹(x))；给定 x 先解 f(y)=x 求 y（试简单值），再代入 f′(y)。
3. 六个反三角导数分三组背：sin⁻¹/cos⁻¹ = ±1/√(1−x²)，tan⁻¹/cot⁻¹ = ±1/(1+x²)，sec⁻¹/csc⁻¹ = ±1/(|x|√(x²−1))；每对内只差一个负号。
4. ± 号永远靠图像定，不靠猜；sec⁻¹、csch⁻¹ 类用 |x| 保证斜率恒正。
5. trig(trig⁻¹(A)) = A 总是对（A 在定义域内）；trig⁻¹(trig(θ)) ≠ θ 除非 θ 已在反函数值域内——超出时用"象限 + 参照角 + 符号"重找角。
6. tan⁻¹、sec⁻¹、csc⁻¹、cot⁻¹ 的水平渐近线来自原三角函数的垂直渐近线，极限值直接读图像，不要死记。
7. cosh⁻¹、sinh⁻¹ 有对数表达式 ln(x+√(x²∓1))，推导技巧是令 u = eʸ 化成二次方程。
