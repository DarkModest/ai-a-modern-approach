# 第29章：体积、弧长和表面积

## 核心思想
把立体或曲线切成无穷薄的片/小段，写出单片（圆盘、壳、截面、割线段、圆柱环）的"原型公式"，再用定积分做求和取极限——一个公式族即可覆盖体积、弧长与表面积。

## 本节框架与方法

- **圆盘法（切片法）**: 小条绕**平行于其短边**的轴旋转，得到薄圆柱片，体积 π(半径)²dx
  - 何时使用: 小条的短边平行于旋转轴时（典型：y=f(x) 下方区域绕 x 轴）
  - 怎么做: 半径=小条到轴的距离（y、y−h、x 等），体积 V=∫π(半径)²d(切片方向变量)
- **壳法（柱壳法）**: 小条绕**垂直于其短边**的轴旋转，得到薄柱壳；剪开摊平成长方体，体积 = 周长×高×厚 = 2π(半径)(高)dx
  - 何时使用: 小条短边垂直于旋转轴时（典型：y=f(x) 下方区域绕 y 轴），可避免反解 x=g(y)
  - 怎么做: 半径=到轴的距离（x、x−h、h−x），高=小条长度 y，V=∫2π(半径)(高)dx
- **三大变式**:
  - 变式1（区域在曲线与 y 轴之间）: 交换 x 和 y，积分限取 y 轴上的范围 [A,B]
  - 变式2（区域在两曲线之间）: 大旋转体体积 − 小旋转体体积，分别积分后取差
  - 变式3（绕平行轴 x=h 或 y=h）: 做代换——轴是 x=h 用 (x−h)（若 x<h 用 h−x）代换 x；轴是 y=h 用 (y−h)（若 y<h 用 h−y）代换 y
- **一般立体体积（截面法）**: 选定一个轴（不必穿过立体），求点 x 处垂直切片的横截面面积 A(x)，则 V=∫_a^b A(x)dx；选轴标准是使横截面尽量简单、彼此相似
- **弧长**: 小段弦长 √((dx)²+(dy)²) 为原型，按变量形式提出 (dx)²/(dy)²/(dt)² 化为可积分公式
- **参数化与速率**: 参数曲线的弧长被积函数即质点瞬时速率 √((dx/dt)²+(dy/dt)²)，总路程=速率的积分
- **表面积**: 弧段旋转得圆柱环，面积 = 周长×弧长元 = 2π(半径)√((dx)²+(dy)²)，再按变量形式展开

## 关键概念
- **旋转体**: 平面区域绕某轴旋转一周所得的立体（本章假设轴平行于 x 轴或 y 轴）
- **圆盘法**: 将垂直于旋转轴的薄片视为圆柱（半径=曲线到轴的距离，厚 dx/dy）求体积的方法
- **壳法**: 将平行于旋转轴的小条旋转成薄柱壳，用 2π×半径×高×厚 求体积的方法
- **广义锥体**: 平面上面积为 A 的底与平面上方距离 h 的顶点 P 连成的立体，体积 V=(1/3)Ah，与底形状无关（正圆锥、四棱锥均为特例）
- **横截面面积 A(x)**: 过轴上点 x 且垂直于轴的切片面积；相似图形的面积比等于对应线段长度比的平方
- **弧长**: 沿曲线拉直的细绳长度，原型为 ∫√((dx)²+(dy)²)，需化为单一变量积分
- **速率（参数情形）**: 质点在 t 时刻的速率 √((dx/dt)²+(dy/dt)²)，恰是弧长公式的被积函数
- **表面积原型**: 半径 r、宽 ds 的圆柱环面积为 2πr·ds，ds=√((dx)²+(dy)²)

## 心智模型
- 当不确定用圆盘法还是壳法时：画一个小条看其**短边与旋转轴的关系**——短边平行于轴用圆盘法，垂直于轴用壳法
- 当轴不是坐标轴时：不要背新公式，做**平移代换**（x→x−h 或 y→y−h），把整个图像平移回标准情形
- 当区域在 y 轴一侧时：想象把纸转过来看——**交换 x 和 y**，但积分限必须换成 y 的范围
- 当推导公式卡住时：回到原型——圆盘 πr²h、柱壳 2πrh·厚、弦长 √(dx²+dy²)、环面积 2πr·ds，各自积分即可重建任何变式

## 常见错误与陷阱
- **变式1中积分限不换轴**: 对 dy 积分时仍用 x 的范围 [a,b]——必须改用 y 的范围 [A,B]（书中例子是 0 到 2，不是 0 到 4）
- **直接对 ∫√((dx)²+(dy)²) 积分**: 这个"积分"没有意义，必须把 (dx)²、(dy)² 或 (dt)² 提出根号，化为关于单一变量的积分
- **壳法/表面积中半径取错符号**: 轴在区域右侧时半径是 h−x（或 h−y），不是 x−h；取错会得到负的表面积/体积
- **变式3中圆盘法过虑而壳法不过虑**: 绕 y=h 旋转且曲线在轴下方时，圆盘法因高度平方故 (y−h)²=(h−y)² 无影响，但壳法/表面积必须写成 h−y
- **两曲线区域只积一个函数**: 旋转两曲线间区域必须取两个旋转体体积之差（立体−洞），漏掉减法等于多算了空心部分
- **忘记相似比平方**: 求广义锥体横截面时，面积比是线度比的**平方**，A(x)=A·x²/h² 而非 A·x/h

## 公式与参考表

### 体积公式对照（区域：y=f(x) 下方，x∈[a,b]）

| 情形 | 方法 | 公式 |
|---|---|---|
| 绕 x 轴 | 圆盘法 | V = ∫_a^b πy²dx |
| 绕 y 轴 | 壳法 | V = ∫_a^b 2πxydx |
| 曲线与 y 轴间区域绕 y 轴（变式1） | 圆盘法 | V = ∫_A^B πx²dy |
| 曲线与 y 轴间区域绕 x 轴（变式1） | 壳法 | V = ∫_A^B 2πyxdy |
| 两曲线 y₁>y₂ 之间绕 x 轴（变式2） | 圆盘法 | V = ∫_a^b πy₁²dx − ∫_a^b πy₂²dx |
| 绕 y=h（变式3） | 圆盘法 | V = ∫_a^b π(y−h)²dx |
| 绕 x=h（区域在轴右侧）（变式3） | 壳法 | V = ∫_a^b 2π(x−h)ydx |
| 绕 x=h（区域在轴左侧）（变式3） | 壳法 | V = ∫_a^b 2π(h−x)ydx |
| 一般立体（截面法） | 切片 | V = ∫_a^b A(x)dx |
| 广义锥体（底面积 A，高 h） | 截面法 | V = (1/3)Ah |

### 弧长公式

| 形式 | 公式 |
|---|---|
| 原型 | ∫√((dx)²+(dy)²)（不可直接用，需变形） |
| 标准形式 y=f(x) | ∫_a^b √(1+(dy/dx)²)dx = ∫_a^b √(1+(f′(x))²)dx |
| 关于 y：x=g(y) | ∫_A^B √(1+(dx/dy)²)dy |
| 参数形式 | ∫_{t₀}^{t₁} √((dx/dt)²+(dy/dt)²)dt |
| 极坐标 r=f(θ) | ∫_{θ₀}^{θ₁} √((f(θ))²+(f′(θ))²)dθ |
| 速率（参数） | v(t) = √((dx/dt)²+(dy/dt)²)，路程=∫v dt |

### 表面积公式

| 情形 | 公式 |
|---|---|
| 绕 x 轴原型 | ∫2πy√((dx)²+(dy)²) |
| 绕 y 轴原型 | ∫2πx√((dx)²+(dy)²) |
| y=f(x) 绕 x 轴 | ∫_a^b 2πf(x)√(1+(f′(x))²)dx |
| y=f(x) 绕 y 轴 | ∫_a^b 2πx√(1+(f′(x))²)dx |
| 参数版绕 x 轴 | ∫_{t₀}^{t₁} 2πy√((dx/dt)²+(dy/dt)²)dt |
| 参数版绕 y 轴 | ∫_{t₀}^{t₁} 2πx√((dx/dt)²+(dy/dt)²)dt |
| 绕 y=h（变式） | ∫_a^b 2π(y−h)√(1+(dy/dx)²)dx（曲线在轴下方时改 h−y） |

辅助公式：圆台侧面积 π(R+r)√((R−r)²+h²)；圆柱体体积 πr²h。

## 精讲例题

**例（壳法，29.1.2 节）**：求上半圆 y=√(1−(x−3)²)（x∈[2,4]，即圆心 (3,0)、半径 1）下方区域绕 **y 轴**旋转所得半个面包圈的体积。

1. 选法：竖直小条短边垂直于 y 轴 → 壳法。壳半径 x，高 y，厚 dx，壳体积 ≈ 2πxydx。
2. 列式：V = 2π∫₂⁴ x√(1−(x−3)²)dx。
3. 代换 t = x−3：V = 2π∫_{−1}^{1} (t+3)√(1−t²)dt = 2π[∫_{−1}^{1} t√(1−t²)dt + 3∫_{−1}^{1} √(1−t²)dt]。
4. 用对称性取巧：第一个积分的被积函数是**奇函数**且区间关于 0 对称 → 为 0；第二个积分是单位半圆的面积 → π/2。
5. 结果：V = 2π·3·(π/2) = **3π²** 立方单位。

要点：壳法把"绕 y 轴"问题留在 x 变量里，避免反解 x=g(y)；积分时优先检查奇偶对称性和几何意义（半圆面积），可省掉三角换元。

## 要点速记
1. 圆盘法 vs 壳法只看一件事：小条短边与旋转轴平行→圆盘，垂直→壳
2. 三大变式通吃口诀：贴 y 轴→交换 x,y；两曲线→体积相减；平行轴→平移代换 x±h / y±h
3. 弧长、表面积、参数速率共享同一个"弧长元" ds=√((dx)²+(dy)²)，背一个原型即可推出全部公式
4. 截面法关键在选轴：让横截面彼此相似（如广义锥体），用相似比平方得 A(x)=A·x²/h²，积分即得 V=Ah/3
5. 对 dy 积分时积分限必须换成 y 的范围——这是变式1最高频错误
6. 轴在区域外侧时半径写 h−x 或 h−y，否则表面积/壳体积会为负
7. 计算积分前先看奇偶对称与几何意义（圆面积、圆柱体积），往往无需硬算（如 3π²、52π/3 等例题）
