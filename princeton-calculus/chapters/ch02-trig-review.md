# 第2章：三角学回顾

## 核心思想
本章为微积分扫清三角学障碍：掌握弧度制、用"参考角 + ASTC 定号"把任意角的三角函数值化归到第一象限查表，并熟记三组恒等式（毕达哥拉斯、互余、和角/倍角）——这些公式在求导、积分中会反复出现。

## 本节框架与方法

- **度与弧度的转换**: 用弧度度量的角 = (π/180) × 用度度量的角
  - 何时使用: 任何角度单位不统一时；微积分中一律使用弧度
  - 怎么做: 把 π 弧度 = 180° 当作单位转换因数，像英里换公里一样换算。基准锚点：90°=π/2，180°=π，270°=3π/2，360°=2π

- **直角三角形定义**: sin(θ)=对边/斜边, cos(θ)=邻边/斜边, tan(θ)=对边/邻边
  - 何时使用: 0 到 π/2 之间的角
  - 怎么做: 注意斜边永远是最长边、对着直角；换角则对边邻边互换

- **坐标定义（扩展定义域）**: 在角 θ 终边射线上取点 (x, y)，r=√(x²+y²)，则 sin(θ)=y/r, cos(θ)=x/r, tan(θ)=y/x
  - 何时使用: 任意角（含负角、大于 2π 的角）；常取 r=1 即单位圆
  - 怎么做: x、y 可正可负，r 恒正（平方消去负号）

- **ASTC 方法（求 0 到 2π 角的三角函数值的完整流程）**:
  1. 画象限图，确定角落在哪个象限（把系数与 0, 1/2, 1, 3/2, 2 比较定位）
  2. 若角在坐标轴上（0, π/2, π, 3π/2），ASTC 失效——改画函数图像直接读值
  3. 否则求参考角：终边射线与 x 轴之间最小的角（必在 0 到 π/2）
  4. 查常用角表得参考角的函数值
  5. 用 ASTC 图决定是否添负号：Ⅰ全部为正(A)、Ⅱ仅正弦(S)、Ⅲ仅正切(T)、Ⅳ仅余弦(C)
  - 核心原理: 任意角的三角函数值 = ±其参考角的同名函数值，符号由象限决定

- **超出 [0, 2π] 的角**: 加减 2π 的整数倍化归到 [0, 2π]
  - 何时使用: 角大于 2π 或为负
  - 怎么做: 与 π/2 等价的角的完整集合写作 {π/2 + 2πn}, n 取所有整数；等价角函数值完全相同

## 关键概念
- **弧度**: 半径为 1 的圆上扇形弧长等于其圆心角的弧度数；一周 = 2π 弧度
- **参考角**: 表示角 θ 的射线与 x 轴之间最小的角，必定介于 0 到 π/2
- **倒数函数**: csc(x)=1/sin(x), sec(x)=1/cos(x), cot(x)=1/tan(x)
- **象限**: 坐标轴将平面分为Ⅰ—Ⅳ象限，逆时针编号；ASTC 标记各象限为正的函数
- **奇偶性**: sin, tan, cot, csc 是奇函数；cos, sec 是偶函数。即 sin(−x)=−sin(x), tan(−x)=−tan(x), cos(−x)=cos(x)
- **周期性**: sin 与 cos 周期为 2π；tan 周期为 π，且在 π/2 的奇数倍处有垂直渐近线（无定义）
- **互余角**: 两角之和为 π/2；"co-"前缀（cos, cot, csc）即"互余"之意

## 心智模型
- 把三角函数值求值看作**两步走**：先求大小（参考角查表），再定符号（ASTC）——把二维问题拆成两个一维问题
- 把弧度/度转换看作**单位换算**：π 弧度 = 180° 就是转换因数，不是新数学
- 当角大于 2π 或为负时，把它看作**原地转圈**：整数周旋转是"徒劳的旋转"，扔掉即可（加减 2π 的倍数）
- 当坐标轴上的角（π/2 的倍数）出现时，**忘掉 ASTC**，改用函数图像读值
- 把倍角公式看作**推导引擎**：sin(4x)、cos(4x) 等不必记，要用时把 4x 看作两倍的 2x 现场推导

## 常见错误与陷阱
- **忘记判断符号**: 参考角只给出绝对值；如 sin(7π/6) 的参考角是 π/6，但 y 为负，答案是 −1/2 而非 1/2
- **参考角找错基准边**: 第四象限的角要向上走到 2π（不是到 0）；第二象限走到 π。参考角永远是与 x 轴（不是 y 轴）的最小夹角
- **对坐标轴上的角套 ASTC**: 0, π/2, π, 3π/2 不在任何象限，ASTC 无答案，须从图像读值
- **把计算器近似值当作精确答案**: −tan(4π/13) = −0.768 438 861 是错的写法；精确形式就是 −tan(4π/13)。除非题目要求，否则写精确值，近似时用约等号并合理化整：−tan(4π/13) ≈ −0.768
- **没背常用角表**: 考场上画三角形推 sin(π/3) 浪费时间，不化简答案则丢分；此表必须双向熟练（给角求值、给值求角）
- **误认为 tan 周期是 2π**: tan(x) 周期为 π，且有垂直渐近线
- **死记 sin(4x)、cos(4x) 展开式**: 应记倍角公式本身并会推导，展开式现推现用

## 公式与参考表

### 常用角三角函数值表（必须背熟，双向掌握）

| | 0 | π/6 | π/4 | π/3 | π/2 |
|---|---|---|---|---|---|
| sin | 0 | 1/2 | 1/√2 | √3/2 | 1 |
| cos | 1 | √3/2 | 1/√2 | 1/2 | 0 |
| tan | 0 | 1/√3 | 1 | √3 | ★(无定义) |

★ tan(π/2) 无定义（垂直渐近线）。

### ASTC 象限符号表

| 象限 | 为正的函数 |
|---|---|
| Ⅰ (A) | sin, cos, tan 全部为正 |
| Ⅱ (S) | 仅 sin 为正 |
| Ⅲ (T) | 仅 tan 为正 |
| Ⅳ (C) | 仅 cos 为正 |

### 基本恒等式
- tan(x) = sin(x)/cos(x), cot(x) = cos(x)/sin(x)
- **毕达哥拉斯恒等式**: cos²(x) + sin²(x) = 1
- 同除 cos²(x): 1 + tan²(x) = sec²(x)（微积分中极常用）
- 同除 sin²(x): cot²(x) + 1 = csc²(x)

### 互余公式
三角函数(x) = co-三角函数(π/2 − x)，即：
- sin(x) = cos(π/2 − x), tan(x) = cot(π/2 − x), sec(x) = csc(π/2 − x)
- cos(x) = sin(π/2 − x), cot(x) = tan(π/2 − x), csc(x) = sec(π/2 − x)
（co-co-sin 就是 sin：余角的余角是原角）

### 和角与倍角公式
- sin(A + B) = sin(A)cos(B) + cos(A)sin(B)
- cos(A + B) = cos(A)cos(B) − sin(A)sin(B)
- sin(A − B) = sin(A)cos(B) − cos(A)sin(B)
- cos(A − B) = cos(A)cos(B) + sin(A)sin(B)
- **倍角**: sin(2x) = 2 sin(x)cos(x)；cos(2x) = 2cos²(x) − 1 = 1 − 2sin²(x)（令 A=B=x 并用毕达哥拉斯恒等式变形）

## 精讲例题

**求 sin(7π/6) 与 sec(15π/4)**

(1) sin(7π/6)：
- 定位：7/6 介于 1 与 3/2 之间，故 7π/6 在第三象限
- 参考角：射线与 x 轴负半轴（即 π）的差 = 7π/6 − π = π/6
- 查表：sin(π/6) = 1/2
- 定号：第三象限仅 tan 为正（ASTC 的 T），sin 为负
- 结论：sin(7π/6) = −1/2（同理 cos(7π/6) = −√3/2）

(2) sec(15π/4)：
- 化归：15π/4 − 2π = 7π/4，故 cos(15π/4) = cos(7π/4)
- 定位：7/4 介于 3/2 与 2 之间，第四象限
- 参考角：2π − 7π/4 = π/4（注意走到 2π，不是 0）
- 查表：cos(π/4) = 1/√2；第四象限 cos 为正（ASTC 的 C）
- 取倒数：sec(15π/4) = √2

## 要点速记
1. 微积分中一律用弧度；90°=π/2、180°=π、270°=3π/2 是转换锚点
2. 求任意角三角函数值 = 参考角（定大小）+ ASTC（定符号）
3. 常用角表（0, π/6, π/4, π/3, π/2）必须双向背熟：给角求值，给值求角
4. 角在坐标轴上时，ASTC 失效，改从函数图像读值
5. 大于 2π 或负角：加减 2π 整数倍化归，等价角集合记作 {θ + 2πn}
6. 三个毕达哥拉斯恒等式（尤其 1+tan²=sec²）与和角、倍角公式是后续微积分的常客
7. sin(4x)、cos(4x) 不背，用倍角公式现推；理解推导优于记忆结论
