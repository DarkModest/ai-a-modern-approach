# 第14章：洛必达法则及极限问题总结

## 核心思想
用导数反过来求极限：当直接代入得到不定式（0/0、±∞/±∞、∞−∞、0×±∞、1^±∞、0^0、∞^0）时，把表达式化归为分式（类型A），对分子分母**分别**求导再取极限。本章同时把全书所有求极限的方法汇总成一套决策流程。

## 本节框架与方法
- **类型A（0/0 或 ±∞/±∞）**: 若 f(a)=g(a)=0（或两者同趋于±∞），则 lim f(x)/g(x) = lim f′(x)/g′(x)，前提是右端极限存在且 x≠a 时 g′(x)≠0。
  - 何时使用: 极限本身就是分式，且代入 a 后是不定式 0/0 或 ±∞/±∞。
  - 怎么做: 分子分母**分别**求导（绝不用商的求导法则！），再代入；若仍是不定式可重复使用洛必达法则。记号上在等号上方标 "l'H"。
- **类型B1（±(∞−∞)）**: 两个同趋于无穷大的函数之差的极限。
  - 何时使用: lim (f(x) − g(x)) 且 f, g → ±∞。
  - 怎么做: **通分**化为一个分式（如 1/sin x − 1/x → (x−sin x)/(x sin x)）；没有分母时**乘除共轭表达式**（如 √(x+ln x)−√x 乘除 √(x+ln x)+√x，用平方差公式）造出分母，转化为类型A。
- **类型B2（0×±∞）**: lim f(x)g(x)，一因子→0，另一因子→±∞。
  - 何时使用: 乘积形式的不定式，如 x ln(x)（x→0⁺）。
  - 怎么做: 把**较简单**的因子取倒数移到分母：lim f·g = lim g/(1/f)，转化为类型A。关键原则：把对数留在分子（移动 ln 会得到 (ln x)² 这类更复杂的极限）；移动指数项通常是糟糕的选择。
- **类型C（1^±∞、0^0、∞^0）**: 底与指数都含变量的 f(x)^g(x)。
  - 何时使用: 幂指函数型极限，如 x^(sin x)、(1+3 tan x)^(1/x)、x^(−1/x)。
  - 怎么做: (1) 先取对数：lim ln(f^g) = lim g·ln(f)，转化为类型B2或A；(2) 用洛必达求出新极限 L；(3) 两边取指数，原极限 = e^L。特例：L=+∞ 时结果为 ∞；L=−∞ 时结果为 0。

## 关键概念
- **不定式（indeterminate form）**: 代入后无法直接定值的代数形式，仅 0/0、±∞/±∞、∞−∞、0×±∞、1^±∞、0^0、∞^0 七种；洛必达法则只适用于其中的不定式。
- **洛必达法则**: 对 0/0 或 ±∞/±∞ 型分式，lim f/g = lim f′/g′（右端极限存在时成立）。
- **类型A**: 分式型不定式，可直接用洛必达。
- **类型B1**: 差型不定式 ±(∞−∞)，通分或乘共轭转化为A。
- **类型B2**: 积型不定式 0×±∞，把简单因子移入分母转化为A。
- **类型C**: 幂指型不定式，取对数化为B2/A，最后取指数还原。
- **垂直渐近线**: 代入得 b/0（b≠0）时的情形，极限为 ∞、−∞ 或不存在。
- **线性化依据**: 洛必达法则的直观来源是 f(x)≈f′(a)(x−a)、g(x)≈g′(a)(x−a)（因 f(a)=g(a)=0），比值为 f′(a)/g′(a)。
- **共轭表达式**: 对 √A − √B 乘除 √A + √B，用 (a−b)(a+b)=a²−b² 消去根号。
- **导数定义型极限**: lim_{h→0} [f(x+h)−f(x)]/h 本身是 0/0 型，既可用导数定义反解，也可直接洛必达。

## 心智模型
- 当代入得到分式时，先问"是 0/0 或 ∞/∞ 吗？"——是才洛必达，否则直接代数化简。
- 当见到 ∞−∞ 时，想"造分母"：有分式就通分，有根号就乘共轭。
- 当见到 0×∞ 时，问"哪个因子移下去更简单？"——永远把 ln 留在分子。
- 当底和指数都含 x 时，条件反射："取对数 → 求 L → 答 e^L"。

## 常见错误与陷阱
- **对非不定式用洛必达**: lim_{x→0} x²/cos(x) 是 0/1 型，正确答案是 0；误用洛必达会得到 −2 的错误结果。每次使用前必须验证是 0/0 或 ±∞/±∞。
- **用商的求导法则**: 洛必达是对分子、分母**分别**求导，不是对 f/g 整体求导。
- **B2 中移错因子**: 把 ln(x) 移到分母会得到 −x(ln x)² 这类比原题更复杂的极限；应移动简单因子（如 x），保留对数在分子。
- **类型C 忘记最后取指数**: 求出 lim ln(原式)=L 后，原极限是 e^L 而不是 L（如 x^(sin x) 的答案是 e⁰=1，不是 0）。
- **该停不停**: 某次洛必达后若代入已得确定值（如 0/2），就不要再用，直接代入即可。
- **混用其他不定式**: ∞−∞、0×∞、幂指型不能直接用洛必达，必须先化归为类型A。
- **"无穷大"误区**: x→∞ 不意味着极限是∞（如 sin(1/x)→0）；x→0 时函数值也可能非常大。

## 公式与参考表

### 洛必达法则类型转换总表

| 类型 | 不定式 | 原始形式 | 转化方法 | 化为 |
|------|--------|----------|----------|------|
| A | 0/0 或 ±∞/±∞ | lim f/g | 直接洛必达：lim f′/g′ | — |
| B1 | ±(∞−∞) | lim (f−g) | 通分，或乘除共轭表达式 | A |
| B2 | 0×±∞ | lim f·g | 简单因子移分母：lim g/(1/f)（对数留分子） | A |
| C | 1^±∞、0^0、∞^0 | lim f^g | 取对数 lim g·ln f = L，答案 e^L | B2 或 A |

### 极限求解总决策流程（lim_{x→a} F(x)）
1. **先试直接代入**——能算即得。
2. 代入得 **b/∞** → 极限为 0。
3. 代入得 **b/0 (b≠0)** → 垂直渐近线：用符号表（4.1节）求左右极限，得 ∞、−∞ 或不存在。
4. **0/0 型**：先看能否写成导数定义形式（极限 = f′(x)）；再考虑洛必达。
5. **有根号** → 分子/分母有理化（4.2节）。
6. **有绝对值** → 化分段函数 |A| = A（A≥0）或 −A（A<0）（4.6节）。
7. 按函数类型用特性（见下）。
8. 以上皆败 → 洛必达法则（14.1.6），得到新极限后回到本流程。

### 分函数类型的技巧
- **多项式**：小 x 时因式分解约公因式；x→∞ 时最高次项决定极限，同除该项（4.3节）。
- **三角函数（小讨论）**：A 很小时 sin(A)≈A、tan(A)≈A，可乘除 A 凑形；cos(A)→1 不可这样处理；仅对乘积/商有效，和差形式失效（7.1.2节）。
- **三角函数（大讨论）**：|sin|≤1、|cos|≤1 配合三明治定理；tan⁻¹(∞)=π/2、tan⁻¹(−∞)=−π/2。
- **指数函数**：lim(1+hx)^(1/h) = e^x；lim(1+x/n)^n = e^x；e⁰=1（乘积中可替换）；x→∞ 时 e^x→∞ 且比任何多项式快：lim 多项式/e^x = 0；x→−∞ 时 e^x→0。
- **对数函数**：lim_{x→0⁺} ln x = −∞，但对任意 a>0 有 lim x^a ln x = 0（趋 −∞ 很慢）；lim_{x→∞} ln x = ∞，但 lim ln x/多项式 = 0（增长很慢）；x=1 附近 ln(1)=0，用洛必达或导数定义。

## 精讲例题
**求 lim_{x→0} (1/sin(x) − 1/x)**（类型B1 → A，两次洛必达）

1. 判定类型：x→0⁺ 时两项都→+∞，x→0⁻ 时都→−∞，属 ±(∞−∞)。
2. 通分转化为A：lim (x − sin x)/(x sin x)，代入 x=0 得 0/0。
3. 第一次洛必达（分母用乘法法则）：lim (1 − cos x)/(sin x + x cos x)，代入仍为 0/0。
4. 第二次洛必达：lim sin x/(cos x + cos x − x sin x)。
5. 此时代入 x=0：分子 0，分母 1+1−0=2，**不再是不定式，停止洛必达**，直接代入。
6. 结果 = 0/2 = **0**。

## 要点速记
1. 洛必达只对 0/0 与 ±∞/±∞ 分式成立；其余不定式必须先变形为分式。
2. 分子分母分别求导，绝不用商法则；结果仍是不定式可连用多次。
3. ∞−∞：通分或乘共轭造分母；0×∞：移动简单因子、留住对数。
4. 幂指型 f^g：取对数求 L，答案是 e^L（L=±∞ 时对应 ∞ 或 0）。
5. 每次洛必达前先验证不定式——0/1、b/0 等确定形式直接代入。
6. 求极限先代入，再按 b/∞、b/0、0/0 分支，最后才动用洛必达。
7. 导数定义型极限 lim [f(x+h)−f(x)]/h 可直接洛必达，省去配凑技巧。
