# 第4章：求解多项式的极限问题

## 核心思想
求多项式/有理函数极限的第一步永远是先看极限在哪里取：x→a（有限点）与 x→∞/x→−∞ 用的是完全不同的技巧——前者靠代入、因式分解、共轭化简，后者靠"首项决定一切"的乘除方法。

## 本节框架与方法

- **代入法（x→a 的有理函数）**: 对 lim(x→a) p(x)/q(x)，总是先直接代入 x=a
  - 何时使用: 任何 x→a（a 为有限数）的有理函数极限
  - 怎么做: 分母代入后不为 0 → 代入值就是极限；得 0/0 → 不定式，转用因式分解消公因子；分子非 0、分母为 0 → 涉及垂直渐近线，转用符号分析

- **因式分解消公因子（0/0 不定式）**: 将分子分母分解后消去公共因子 (x−a)，再代入
  - 何时使用: 代入得到 0/0 时
  - 怎么做: 分解所有多项式（掌握立方差公式 a³−b³=(a−b)(a²+ab+b²)），消去 (x−a)，再代入 a。原理：极限只看 x 在 a 附近的值，f 在 a 点本身无定义不要紧

- **符号分析法（非零/0 型，垂直渐近线四情形）**: 当分子→非零数、分母→0 时，极限为 ±∞ 或不存在
  - 何时使用: 代入得 C/0（C≠0）时
  - 怎么做: 分别考察 x→a⁺ 和 x→a⁻ 时各因子的正负号（用 (+)/(−) 记号做符号乘法），判断两侧是 +∞ 还是 −∞。两侧同号 → 双侧极限为该无穷；异号 → 双侧极限不存在（两个单侧极限各为无穷）。分母零因子的奇偶次幂是关键：(x−1)³ 两侧异号，(x−1)² 两侧同号

- **共轭表达式法（含平方根，x→a）**: 分子分母同乘以 √A−B 的共轭 √A+B
  - 何时使用: 出现平方根加/减一个量且代入得 0/0 时
  - 怎么做: 用 (a−b)(a+b)=a²−b² 去掉根号，再因式分解、消公因子、代入

- **首项乘除法（x→∞ 的有理函数/多项式型函数）**: 当 x 很大时，首项决定一切：lim(x→∞) p(x)/p_L(x) = 1
  - 何时使用: x→∞ 或 x→−∞ 的多项式或多项式型函数之比
  - 怎么做: 把每个多项式 p(x) 代以 [p(x)/首项 × 首项]；化简后每个分式趋于 1，只留下首项之比；再对该简单比取极限。基础事实：对任意常数 C 和 n>0，lim(x→±∞) C/xⁿ = 0

- **次数判别规则（检验用）**: 对 lim(x→∞) p(x)/q(x)
  - (1) deg p = deg q → 极限有限且非零（等于首项系数之比）
  - (2) deg p > deg q → 极限为 ∞ 或 −∞（由首项之比的符号/次数决定）
  - (3) deg p < deg q → 极限为 0
  - 应用：应先用乘除法求解，再用此规则检验答案合理性

- **多项式型函数的处理**: 含分数次幂或 n 次根的函数，原理同上，但首项可能藏在根号内
  - 怎么做: 把首项（如 4x²）"拖进"根号（变为 16x⁴）再化简根号内分式；若根号外首项与根号化简后首项同级相消，则先用共轭表达式法再造出差项

- **x→−∞ 的符号陷阱处理**: 方法不变，但把因子拖进/拖出偶次根号时必须注意 x<0
  - 规则：若 x<0 且要写 ⁿ√(x的某次幂) = xᵐ，只有当 n 为偶、m 为奇时才需在 xᵐ 前加负号。例如 x<0 时 √x²=−x，⁴√x⁴=−x；但 ³√x³=x 对所有 x 成立，且 √x⁴=x² 对所有 x 成立（结果定义上非负）

- **绝对值函数的分段法**: 按绝对值内部表达式的符号分区间讨论
  - 何时使用: 极限中含 |g(x)|
  - 怎么做: 找出 g(x)=0 的分界点，在各区间上把 |g(x)| 换成 g(x) 或 −g(x)，分别求单侧极限。例如 |x|/x 在 x>0 时为 1、x<0 时为 −1，故 lim(x→0)|x|/x 不存在

## 关键概念
- **不定式**: 代入后得到 0/0 的情形；此时极限可能有限、±∞ 或不存在，"什么都可能发生"，必须用技巧化简
- **首项**: 多项式中次数最高的项（不一定写在最前面）；x→∞ 时多项式的行为由首项完全决定
- **多项式型函数**: 含分数次幂或 n 次根、但行为类似多项式的函数（如 x³+4x²−5x^{2/3}+1、√(x⁹−7x²+2)），可用首项法处理
- **共轭表达式**: a−b 的共轭是 a+b（反之亦然）；用于经 (a−b)(a+b)=a²−b² 消去平方根
- **立方差公式**: a³−b³ = (a−b)(a²+ab+b²)，分解含立方之差的分子时必备
- **垂直渐近线四情形**: 有理函数在分母为 0（分子非 0）的点 x=a 处，双侧极限的四种可能：+∞、−∞、两侧异号（不存在）的两种镜像情形；靠两侧符号分辨
- **常数提出极限**: lim(x→∞) C·f(x) = C·lim(x→∞) f(x)，常数可拖到极限符号之外
- **极限的加减拆分**: "和的极限等于极限的和" 仅当各极限都有限时成立；∞+(−∞) 无意义

## 心智模型
- 当 x→a 代入得 0/0 时，把它看作"分子分母藏着公因子 (x−a)"——分解、消去、再代入。
- 当 x→∞ 时，把每个多项式看作"只有首项存在"：低次项是噪声，x 越大越微不足道。
- 当分子分母中每个多项式都"乘除首项"时，把分式部分看作趋于 1 的包装纸，真正的果汁是首项之比。
- 当 x→−∞ 且涉及偶次根号时，把 √(偶次幂) 看作"结果必须为正"——x 为负时开出来要加负号。

## 常见错误与陷阱
- **0/0 时直接下结论**: 代入得 0/0 什么都不说明——极限可能有限、无穷或不存在，必须化简后再判断
- **把消去公因子前后的函数当作同一函数**: f(x)=(x²−3x+2)/(x−2) 与 g(x)=x−1 不是同一函数（x=2 不在 f 的定义域内）；但它们的 x→2 极限相等，因为极限只关心附近的值
- **误以为 lim p(x) = lim p_L(x)**: 两边都是 ∞ 时这种写法毫无意义；正确表达是 lim p(x)/p_L(x) = 1
- **滥用"和的极限等于极限的和"**: 仅当各极限有限时成立；lim(x→∞)[x+(1−x)]=1，但拆成 ∞+(−∞) 是无意义的
- **首项识别错误**: 首项是次数最高的项，不是写在最前面的项（如 x−8x⁴ 的首项是 −8x⁴）；含根号时根号内外的项要比较化简后的次数（如 √(16x⁴+8) ~ 4x² 与 3x³ 比较，3x³ 胜出）
- **首项相消时束手无策**: 如 √(4x⁶−5x⁵)−2x³，首项法看似"什么都不剩"，此时须先乘共轭表达式造出低次主项（−5x⁵）
- **x→−∞ 时 √x²=x 的错误**: x 为负时 √x²=−x；更一般地 ⁿ√(xᵐ)=xᵐ 前加负号当且仅当 n 偶、m 奇、x<0
- **忽视绝对值的分段性**: 不分 x 的区间直接处理 |g(x)| 会漏掉单侧极限不同的情况

## 公式与参考表

**基础极限（x→±∞）**
- 对任意常数 C、n>0：lim(x→±∞) C/xⁿ = 0
- 首项逼近：lim(x→∞) p(x)/p_L(x) = 1（p_L 为 p 的首项）

**x→a 决策表（代入 p(a)/q(a)）**

| 代入结果 | 含义 | 对策 |
|---|---|---|
| 正常数（分母≠0） | 极限即该值 | 完成 |
| 0/0 | 不定式 | 因式分解消 (x−a)，含根号则乘共轭式 |
| C/0（C≠0） | 垂直渐近线 | 两侧符号分析 → +∞ / −∞ / 不存在 |

**x→∞ 有理函数次数规则（检验用）**

| deg p vs deg q | 极限 |
|---|---|
| 相等 | 首项系数之比（有限非零） |
| p > q | ±∞（看首项之比） |
| p < q | 0 |

**x<0 开根号规则**
- √x² = −x，⁴√x⁴ = −x（n 偶、m 奇 → 加负号）
- ³√x³ = x（n 奇 → 不加）
- √x⁴ = x²（m 偶 → 结果本来非负，不加）

**绝对值原型**
- x>0: |x|/x = 1；x<0: |x|/x = −1 → lim(x→0)|x|/x 不存在
- |x+2|/(x+2) 是上图左移 2 个单位：lim(x→−2⁻) = −1

## 精讲例题

求 lim(x→3) (x³−27)/(x⁴−5x³+6x²)。

1. **代入检验**: x=3 代入得 0/0 → 不定式，需因式分解。
2. **分解分子**: x³−27 = x³−3³，用立方差公式得 (x−3)(x²+3x+9)。
3. **分解分母**: x⁴−5x³+6x² = x²(x²−5x+6) = x²(x−3)(x−2)。
4. **消公因子**: 因取极限只看 x 在 3 附近（x≠3），消去 (x−3)：
   lim(x→3) (x²+3x+9)/[x²(x−2)]。
5. **再代入**: (9+9+9)/(9·1) = 27/9 = **3**。

对比变式：若代入得 C/0（如 lim(x→1) (2x²−x−6)/[x(x−1)³] 得 −5/0），则用符号法：分子≈−5 为 (−)，x≈1 为 (+)，(x−1)³ 在 x>1 为 (+)、x<1 为 (−)，故右极限 = −∞、左极限 = +∞，双侧极限不存在。

## 要点速记
1. 求解前先分类：x→a（代入/分解/共轭/符号）与 x→±∞（首项法）是两套完全不同的工具箱。
2. 0/0 不定式的标准解法：分解出并消去公因子 (x−a)，再代入；立方差公式 a³−b³=(a−b)(a²+ab+b²) 要熟。
3. 见到"平方根 ± 量"的 0/0，先乘共轭表达式，(a−b)(a+b)=a²−b² 能化掉根号。
4. x→∞ 时首项决定一切：对每个多项式（包括根号内的）乘除其首项，分式趋于 1，只留首项之比。
5. 用次数规则（等次→系数比；分子高→±∞；分母高→0）快速检验答案，但不要用它替代乘除法求解。
6. x→−∞ 时方法与 x→∞ 相同，但偶次根号开出来必须取正值：x<0 时 ⁿ√(xᵐ) 仅当 n 偶 m 奇时加负号。
7. 含绝对值一律分段：按内部表达式符号确定区间，左右极限不等则双侧极限不存在。
