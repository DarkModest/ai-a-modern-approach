# 第24章：泰勒多项式、泰勒级数和幂级数导论

## 核心思想
任何光滑函数 f 在 x = a 附近都可以用多项式来逼近：取 f 在 a 处的各阶导数，就能构造 N 阶泰勒多项式 P_N(x)；而令 N → ∞ 且余项趋于 0，便得到精确等于 f(x) 的无穷级数——泰勒级数。

## 本节框架与方法
- **泰勒近似定理**: 若 f 在 x = a 光滑，则在所有次数 ≤ N 的多项式中，当 x 在 a 附近时最近似于 f(x) 的是
  P_N(x) = Σ_{n=0}^{N} [f^(n)(a)/n!] (x−a)^n
  - 何时使用: 需要在某点 a 附近用低次多项式逼近光滑函数（手算近似值、计算器原理）。
  - 怎么做: 求 f 在 a 处的 0 到 N 阶导数，逐项除以 n! 乘以 (x−a)^n 求和。每增加一项就是加一个"n 阶修正项"，近似更好。
- **泰勒定理（含误差项/拉格朗日余项）**: R_N(x) = f^(N+1)(c)/(N+1)! · (x−a)^(N+1)，其中 c 介于 x 与 a 之间（一般无法确定）
  - 何时使用: 需要量化近似的精确度（误差上界），而非只知道"很接近"。
  - 怎么做: 写出 f(x) = P_N(x) + R_N(x)；利用 c 的范围对 f^(N+1)(c) 取上界 M，得 |误差| ≤ M|x−a|^(N+1)/(N+1)!。N = 0 时即中值定理 f(x) = f(a) + f'(c)(x−a)。
- **泰勒级数收敛判别法**: 若 lim_{N→∞} R_N(x) = 0，则 f(x) 等于其泰勒级数
  - 何时使用: 证明某函数在某 x 处真的等于其泰勒级数（而非仅是形式上写出级数）。
  - 怎么做: 写出 R_N(x) 公式，对 f^(N+1)(c) 取与 N 无关的上界，再用三明治定理配合关键极限 lim_{N→∞} x^N/N! = 0 证明 R_N → 0。
- **关键极限证明（比式判别法技巧）**: 证明 lim_{n→∞} x^n/n! = 0（对任意实数 x）
  - 何时使用: 一切泰勒级数余项估计的基石。
  - 怎么做: 固定 x，对级数 Σx^n/n! 用比式判别法：|a_{n+1}/a_n| = |x|/(n+1) → 0 < 1，级数收敛；由第 n 项判别法，通项必趋于 0。注意"级数收敛 ⇒ 通项趋于 0"的逆向运用。

## 关键概念
- **泰勒多项式 P_N(x)**: f 在 x = a 处的 N 阶多项式 Σ_{n=0}^N f^(n)(a)/n! · (x−a)^n，满足 P_N^(n)(a) = f^(n)(a)（n = 0,...,N），提取了 f 在 a 处直到 N 阶导数的全部信息。
- **N 阶 vs N 次**: P_N 的次数可能小于 N（若 f^(N)(a) = 0），故称"N 阶泰勒多项式"而非"N 次"。如 cos(x) 的 P_4 = P_5（无 5 次项）。
- **余项/误差项 R_N(x)**: R_N(x) = f(x) − P_N(x)，真实值与近似值之差。
- **线性化**: 一阶泰勒多项式 P_1(x) = f(a) + f'(a)(x−a)，即切线；二次项 ½f″(a)(x−a)² 是"二阶修正项"。
- **幂级数**: 形如 Σ_{n=0}^∞ a_n(x−a)^n 的式子，a_n 为系数，a 称为中心；在中心 x = a 处自动收敛（只剩 a_0）。
- **泰勒级数**: 由光滑函数 f 生成的幂级数 Σ f^(n)(a)/n! · (x−a)^n；泰勒多项式是其 N 项部分和。
- **麦克劳林级数**: a = 0 的泰勒级数，即 Σ f^(n)(0)/n! · x^n。看到"麦克劳林"就想"a = 0"。
- **几何级数作为幂级数**: 1/(1−x) = Σx^n 仅当 −1 < x < 1 成立；区间外左边有意义而右边发散。

## 心智模型
- 当需要"在一点附近近似函数"时，用泰勒多项式——线性化（第13章）只是一阶泰勒近似，泰勒多项式是它的自然升级。
- 当问"近似有多好"时，用泰勒定理的余项公式——误差 ≈ 下一阶导数 × (x−a)^(N+1)/(N+1)!，离中心越近、阶数越高，误差越小。
- 当问"无穷级数是否等于原函数"时，转化为"余项是否趋于 0"——级数 = 部分和的极限，而部分和 = f − 余项。
- 阶乘 n! 增长快于任何幂 x^n：这是所有泰勒余项估计背后的引擎，也是幂级数大范围收敛的根本原因。

## 常见错误与陷阱
- **认为泰勒级数必收敛到 f(x)**: 级数可能对某些 x 发散，甚至收敛却收敛到别的值。经典反例：f(x) = e^(−1/x²)（x≠0），f(0)=0，其在 0 处所有导数为 0，麦克劳林级数恒为 0 却 ≠ f(x)。必须验证 R_N → 0。
- **忽视收敛区间**: 幂级数等式（如 1/(1−x) = Σx^n）只在收敛区间内成立；|x| ≥ 1 时左边有定义而右边发散，不能混用。
- **忘记余项中 c 依赖于 x 和 N**: c 无法确定，但估计误差时必须用 c 的取值范围（介于 a 与 x 之间）对 f^(N+1)(c) 取一致上界，且该上界要与 N 无关（如 e^x 情形取 e^c ≤ max(1, e^x)）。
- **混淆"阶"与"次"**: 高阶导数为 0 时 P_N 次数低于 N，数项数或次数会出错（cos(x) 的 P_4 = P_5）。
- **以为 0 是唯一自然的中心**: 函数在 0 处无定义时（如 ln x）应选别的中心（ln x 选 a = 1，收敛区间 0 < x ≤ 2）。

## 公式与参考表
**N 阶泰勒多项式（中心 a）**

P_N(x) = Σ_{n=0}^{N} f^(n)(a)/n! · (x−a)^n = f(a) + f′(a)(x−a) + f″(a)/2! · (x−a)² + ⋯ + f^(N)(a)/N! · (x−a)^N

约定 0! = 1，f^(0) = f。

**泰勒定理（拉格朗日余项）**

f(x) = P_N(x) + R_N(x),  R_N(x) = f^(N+1)(c)/(N+1)! · (x−a)^(N+1)，c 介于 a 与 x 之间。

**麦克劳林级数（a = 0）**

Σ_{n=0}^∞ f^(n)(0)/n! · x^n

**重要展开（本章证明对所有实数 x 成立）**

| 函数 | 级数 | 收敛范围 |
|---|---|---|
| e^x | Σ x^n/n! = 1 + x + x²/2! + x³/3! + ⋯ | 所有 x |
| cos(x) | Σ (−1)^n x^(2n)/(2n)! = 1 − x²/2! + x⁴/4! − ⋯ | 所有 x |
| 1/(1−x) | Σ x^n | −1 < x < 1 |
| ln(x)（中心 1） | Σ_{n≥1} (−1)^(n−1)/n · (x−1)^n | 0 < x ≤ 2 |

**关键极限**：对任意实数 x，lim_{n→∞} x^n/n! = 0。

## 精讲例题
**例：估计 e^(−1/10) 并给出误差上界（a = 0，N = 3）。**

1. f(x) = e^x 的各阶导数都是 e^x，故 f^(n)(0) = 1，三阶泰勒多项式
   P_3(x) = 1 + x + x²/2 + x³/6。
2. 代入 x = −1/10：e^(−1/10) ≈ 1 − 1/10 + 1/200 − 1/6000 = 5429/6000 ≈ 0.904 833 3。
3. 误差项：R_3(x) = e^c/4! · x⁴，其中 −1/10 < c < 0。
4. e^c 关于 c 递增，故 e^c ≤ e⁰ = 1，得
   |R_3| ≤ 1/24 · (1/10)⁴ = 1/240 000 ≈ 0.000 004 17。
5. 结论：近似值 5429/6000 精确到 1/240 000 以内（实际误差约 0.000 004 08，吻合）。

**例：证明 cos(x) 等于其麦克劳林级数（收敛性证明模板）。**

1. 连续求导得循环 cos, −sin, −cos, sin, …；代入 x = 0 得序列 1, 0, −1, 0, 1, 0, …
2. 麦克劳林级数：1 − x²/2! + x⁴/4! − x⁶/6! + ⋯ = Σ (−1)^n x^(2n)/(2n)!（只有偶次项，需插入 (−1)^n 因子）。
3. 余项：|R_N(x)| = |f^(N+1)(c)|/(N+1)! · |x|^(N+1)，而 |f^(N+1)(c)| 为 |cos c| 或 |sin c|，均 ≤ 1。
4. 故 0 ≤ |R_N(x)| ≤ |x|^(N+1)/(N+1)! → 0（关键极限），由三明治定理 R_N → 0，等式对所有实数 x 成立。

## 要点速记
1. 泰勒多项式是唯一在 a 处与 f 的 0 到 N 阶导数全部相等的 ≤ N 次多项式——"导数匹配"即"最佳逼近"。
2. 误差估计三部曲：写 R_N 公式 → 对 f^(N+1)(c) 在 c 范围内取与 N 无关的上界 → 用 x^N/N! → 0 收尾。
3. 证明 f 等于其泰勒级数 ⇔ 证明 lim_{N→∞} R_N(x) = 0；永远不要跳过这一步。
4. 幂级数在其中心必收敛；离开中心后收不收敛要逐点检验（第26章的比式判别法）。
5. "麦克劳林" = a = 0 的泰勒级数；中心选取要配合函数定义域（ln x 用 a = 1）。
6. 只有偶次/奇次项的级数用 2n（或 2n+1）替换 n，并记得补交错因子 (−1)^n。
7. 泰勒定理是中值定理的推广：N = 0 时恰为 MVT，N = 1 时误差项与第13章线性化误差一致。
