# 第19章：积分的方法II

## 核心思想
处理含三角函数的积分主要靠两类工具：用三角恒等式（倍角、毕达哥拉斯、积化和差）改写被积函数，用幂次处理策略和约化公式逐级降幂；处理二次式平方根的奇次幂则用三角换元法（三种类型），换元后问题又转化为三角函数幂的积分。

## 本节框架与方法
- **倍角公式降幂法**: cos²x = ½(1+cos 2x)，sin²x = ½(1−cos 2x)
  - 何时使用: 被积函数含 sin²x、cos²x，或 √(1±cos x) 形式（√(1+cos x) 时把 x 换成 2·(x/2) 得 2cos²(x/2)）
  - 怎么做: 代入公式化平方根为 2|sin| 或 2|cos|，按区间符号去掉绝对值再积分
- **毕达哥拉斯恒等式 + 共轭法**: sin²+cos²=1，tan²+1=sec²，1+cot²=csc²
  - 何时使用: 分母出现 1±trig(x)（如 sec x − 1）
  - 怎么做: 分子分母同乘分母的共轭式 → 分母变为平方差 → 用恒等式化为单一三角函数的平方 → 拆成两个积分分别处理
- **积化和差**: cos A·cos B = ½[cos(A−B)+cos(A+B)]；sin A·sin B = ½[cos(A−B)−cos(A+B)]；sin A·cos B = ½[sin(A−B)+sin(A+B)]
  - 何时使用: cos(mx)cos(nx)、sin(mx)sin(nx)、sin(mx)cos(nx)（m≠n）型乘积
  - 怎么做: 直接代入公式把乘积化为和，逐项积分
- **sin/cos 幂的黄金法则**: 奇次幂是"朋友"——抓出它的一项与 dx 配对做换元
  - 何时使用: ∫cosᵐx·sinⁿx dx，m 或 n 为奇数（都奇取幂低者）
  - 怎么做: 移出一个奇次项（如 cos x dx = dt，t=sin x），剩余偶次幂用 cos²=1−sin² 或 sin²=1−cos² 全部改写，化为 t 的多项式
- **偶次幂的倍角降幂**: 当 sin、cos 的幂全为偶数
  - 怎么做: 用 ½(1±cos 2x) 代入并展开，对每项再判断奇偶，反复用倍角或奇次幂法，直到全部可积
- **tan/cot 幂的降幂法**: tan²x = sec²x − 1（cot²x = csc²x − 1）
  - 怎么做: 提出 tan² 改写为 (sec²−1)，拆成两个积分：第一个设 t=tan x（dt=sec²x dx）直接积出；第二个是低 2 次的同型积分，重复此过程直至 n=0 或 1。注意 cot 换元 dt = −csc²x dx 带负号
- **sec/csc 幂的分部积分法**: 提出 sec²（或 csc²），设 dv=sec²x dx（v=tan x），u 为其余 sec 幂
  - 怎么做: 分部积分后新积分含 sec 低次幂·tan²，用 tan²=sec²−1 拆开，其中一项是原积分的倍数——把它移到左边合并（这是关键一步！），另一项继续降幂，直到只剩 ∫sec x 或 ∫sec²x。csc 时 v=−cot x 且 du 也有负号
- **约化公式法**: 令 Iₙ = ∫tanⁿx dx，则 Iₙ = (1/(n−1))·tanⁿ⁻¹x − Iₙ₋₂；定积分 Iₙ = ∫₀^{π/2} cosⁿx dx 满足 Iₙ = ((n−1)/n)·Iₙ₋₂（分部积分提出一个 cos x 证得）；还有非三角的 Iₙ = ∫xⁿeˣdx = xⁿeˣ − nIₙ₋₁
  - 怎么做: 反复套用，终止于 I₀ 或 I₁ 的已知值
- **三角换元法三种类型**: 见下方对照表
  - 何时使用: 被积函数含 √(a²−x²)、√(x²+a²)、√(x²−a²) 的奇次幂（但先校验有无更明显的换元）
  - 怎么做: 换元后积分化为三角函数幂的积分；带一次项的二次式先配方（x²−4x+19=(x−2)²+15）再换 t=x−2；最后用直角三角形换回 x
- **绝对值与符号判定（类型3陷阱）**: 类型1：θ=sin⁻¹(x/a)∈[−π/2,π/2]，cos θ≥0，无需绝对值；类型2：θ=tan⁻¹(x/a)，sec θ>0，无需绝对值；类型3：θ=sec⁻¹(x/a)∈[0,π]\{π/2}，tan θ 符号随 x 变化——x>0 时 √(a²tan²θ)=a tan θ，x<0 时为 −a tan θ，两段定义域上积分常数也不同（C₁≠C₂）

## 关键概念
- **约化公式（reduction formula）**: 把含整数参数 n 的积分 Iₙ 表示为低阶积分（如 Iₙ₋₂）的递推关系，反复套用直至已知的基础情形
- **倍角公式降幂**: cos²x=½(1+cos 2x)、sin²x=½(1−cos 2x)，把偶次幂线性化的核心工具
- **积化和差**: 把不同频率三角函数乘积化为和差的公式组，由 cos(A±B)、sin(A±B) 公式推出
- **共轭乘除技巧**: 分母为 1±trig(x) 时，分子分母同乘共轭式以利用 (a−b)(a+b)=a²−b² 与毕达哥拉斯恒等式
- **三角换元**: 用 x=a sin θ / a tan θ / a sec θ 消除二次式平方根的换元法
- **辅助三角形**: 换元后画直角三角形（由 sin θ=x/a 等确定两边），据此读出 cos、tan 等值以换回 x
- **奇次幂是"朋友"**: sin/cos 幂积分中，奇次幂可移出一项与 dx 凑成换元微分
- **移项合并（sec 幂）**: 分部积分后原积分在等式右侧再次出现，将其移到左边合并系数求解
- **分部定义域**: 如 1/(x³√(x²−4)) 定义域为 (−∞,−2)∪(2,∞)，反导数在两段上可有不同常数

## 心智模型
- 看到 √(1±cos x)，想"倍角公式把平方根变成 |sin| 或 |cos|"——并立刻检查区间符号
- 看到三角函数幂，先问"有没有奇次幂？"有就抓它做换元；全偶就倍角降幂；tan/sec 类就"降 2 次、重复"
- 看到 √（二次式）的奇次幂，先按 ±x²±a² 的三种符号选换元，有一次项先配方
- 看到高次幂积分想偷懒，想"能不能建立约化公式？"——尤其是定积分 ∫₀^{π/2} cosⁿ 用 Iₙ=((n−1)/n)Iₙ₋₂ 远快于倍角展开

## 常见错误与陷阱
- **√(A²)=A 而不是 |A|**: 如 √(2sin²x) 直接写成 √2 sin x 是鲁莽的；正确是 √2|sin x|，必须按积分区间判定符号（∫π^2π √(1+cos x) 错取 cos(x/2) 会得 −2√2，但被积函数恒正，答案必须为正——可用符号做合理性检验）
- **类型3换元忽略绝对值**: √(4tan²θ) 仅在 x>0 时等于 2tan θ；x<0 时需 −2tan θ，sec⁻¹ 项符号不同且两段常数独立
- **忘记 dx 也要换元**: x=a sin θ 必须配套 dx=a cos θ dθ，积分内所有 x 都要换成 θ
- **tan⁶ 降幂时丢负号**: tan²=sec²−1 拆出的第二个积分带负号，逐层递归时负号要传递
- **cot/csc 的换元负号**: t=cot x 时 dt=−csc²x dx；csc 分部积分 v=−cot x
- **(cos²θ)^{3/2}≠cos³θ 一般成立**: 等于 |cos³θ|，只有 cos θ≥0 时才能去绝对值（类型1、2 恰好满足）
- **cos(3x)sin(19x) 的顺序迷惑**: 乘法可交换，直接套 sin A·cos B 公式，A=19x、B=3x

|---|---|---|---|
| 换元 | x = a sin θ | x = a tan θ | x = a sec θ |
| dx | a cos θ dθ | a sec²θ dθ | a sec θ tan θ dθ |
| 化简结果 | a²−x² = a²cos²θ | x²+a² = a²sec²θ | x²−a² = a²tan²θ |
| 开根号 | a cos θ（cos θ≥0，无绝对值问题） | a sec θ（sec θ>0，无绝对值问题） | x>0: a tan θ；x<0: −a tan θ |

### sin/cos/tan/sec 幂次处理决策表
| 被积函数 | 策略 | 关键步骤 |
|---|---|---|
| sinᵐx·cosⁿx，有奇次幂 | 奇次幂移出一项换元 | cos x dx→t=sin x，余下用 cos²=1−sin² |
| sinᵐx·cosⁿx，全偶 | 倍角公式 | ½(1±cos 2x) 代入展开，逐项再判奇偶 |
| tanⁿx (n≥2) | 提 tan²→(sec²−1) | t=tan x 积第一项，递归降 2 次 |
| secⁿx (n≥3) | 提 sec² 分部积分 | dv=sec²x dx，移项合并，降至 ∫sec 或 ∫sec² |
| cotⁿx / cscⁿx | 同 tan/sec，注意负号 | cot²=csc²−1；dt=−csc²x dx |
| ∫sec x | 乘 (sec+tan)/(sec+tan) | = ln\|sec x + tan x\| + C |
| ∫tan x | t=cos x | = −ln\|cos x\| + C = ln\|sec x\| + C |

### 约化公式汇总
- tan: Iₙ = (1/(n−1))tanⁿ⁻¹x − Iₙ₋₂；I₀=x，I₁=−ln|cos x|
- 定积分 cos: Iₙ = ∫₀^{π/2}cosⁿx dx = ((n−1)/n)Iₙ₋₂；I₀=π/2，I₁=1
- 非三角例: ∫xⁿeˣdx: Iₙ = xⁿeˣ − nIₙ₋₁，I₀=eˣ

### 积分技巧决策清单（19.4）
1. 有显而易见的换元（一部分是另一部分的导数）→ 先试 t 换元
2. 含 ⁿ√(ax+b) → 设 t=ⁿ√(ax+b)
3. 有理函数：分子是分母导数的倍数 → t=分母；否则部分分式（18.3节）
4. √(1±cos x) → 倍角公式；1−sin²、1+tan² 等 → 毕达哥拉斯恒等式
5. 分母含 1±sin x 之类 → 乘共轭式
6. cos(mx)cos(nx) 等 → 积化和差
7. 二次式平方根奇次幂 → 三角换元（有一次项先配方）
8. 乘积形式且无换元 → 分部积分（18.2节）；商可改写为乘积（如 ln(1+x²)/x² = ln(1+x²)·(1/x²)）
9. ln x 的幂或反三角函数 → 分部积分，u 取 ln/反三角部分

## 精讲例题
**求 ∫x²/(9−x²)^{3/2} dx**（类型1三角换元）

1. 识别 √(9−x²) 奇次幂 → 设 x = 3sin θ，dx = 3cos θ dθ
2. 化简：9−x² = 9cos²θ，故 (9cos²θ)^{3/2} = 27cos³θ（θ∈[−π/2,π/2]，cos θ≥0，无需绝对值）
3. 积分变为 ∫(9sin²θ)/(27cos³θ)·3cos θ dθ = ∫tan²θ dθ
4. tan²θ = sec²θ − 1 → ∫tan²θ dθ = tan θ − θ + C
5. 换回 x：画三角形，sin θ = x/3 → 对边 x、斜边 3、邻边 √(9−x²)，故 tan θ = x/√(9−x²)，θ = sin⁻¹(x/3)
6. 答案：x/√(9−x²) − sin⁻¹(x/3) + C

**对照（约化公式的威力）**：∫₀^{π/2} cos⁸x dx 若用倍角公式极繁琐；用 Iₙ=((n−1)/n)Iₙ₋₂ 得 I₈ = (7/8)(5/6)(3/4)(1/2)·I₀ = (7·5·3·1)/(8·6·4·2)·π/2 = 35π/256。

## 要点速记
1. 三角函数幂积分先分类：sin/cos 看奇偶，tan/cot 提平方降 2 次，sec/csc 提平方分部积分并移项合并
2. 开平方永远先想 |A|，再用反函数值域或积分区间判定符号：类型1、2 天然安全，类型3 按 x 正负分段
3. secⁿ 分部积分后原积分在右侧重现——移到左边除以系数，这是通法不是巧合
4. 约化公式 Iₙ → Iₙ₋₂ 能把"复杂展开"变成"套递推"，定积分 ∫₀^{π/2} cosⁿ 和 sinⁿ 尤其受益
5. 二次式带一次项先配方再换元（x²−4x+19=(x−2)²+15）
6. 换回 x 用辅助三角形，不要写 tan(sin⁻¹(x/3)) 这种繁琐形式
7. 选方法顺序：明显换元 → 恒等式 → 幂次策略/三角换元 → 分部积分；商的形式别忘了可改写成乘积再分部
