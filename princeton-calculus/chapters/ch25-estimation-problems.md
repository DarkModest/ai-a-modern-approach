# 第25章：求解估算问题

## 核心思想
用泰勒多项式 P_N(x) 估算一个量的真值，再用余项 R_N(x) = f^(N+1)(c)/(N+1)! · (x−a)^(N+1) 来界定误差上限——通过分析区间内的 c 把误差放大成一个可计算的数，从而**保证**估算的精确度。问题分两类：给定 N 估算误差，或给定误差反求 N。

## 本节框架与方法
- **用误差项估算的一般方法（25.3 节的九步法）**: 给定要估算的量，选择 f、x、a，建立导数表，写出余项并极大化 |R_N|，最后写出 P_N 代入求值
  - 何时使用: 需要用泰勒多项式估算某数（如 e^(1/3)、√27、cos(π/3−0.01)）并保证误差不超过给定界限时
  - 怎么做:
    1. 选相关函数 f 与使目标成立的 x（要估算 e^(1/3)，令 f(x)=e^x, x=1/3）
    2. 选靠近 x 且 f(a)、f'(a) 等易算的 a（如 0、25、π/3）
    3. 做三列导数表 n / f^(n)(x) / f^(n)(a)，至少算到 N+1 阶（误差项需要 N+1 阶导数）
    4. 写出 R_N(x)，注明 "c 在 a 与 x 之间"，并用 a 的实际值替换
    5. 已知 N 就用它；否则按误差要求猜 N（多数问题 N=2 或 3 够了），错了就增大 N 重来
    6. 代入 x，用不等式写下 c 的范围
    7. 在 c 的区间上极大化 |R_N(x)|，这就是误差上界；不够小就回到第 5 步增大 N
    8. 写 P_N 公式代入 x 得近似值
    9. R_N 正则低估，R_N 负则高估（由 f(x)=P_N(x)+R_N(x) 可知）
- **极大化 |f^(N+1)(c)| 的对策（25.3.6 节）**:
  - 何时使用: 第 7 步中需要在 c 的区间上找误差项的最大值
  - 怎么做: (1) |sin c|≤1、|cos c|≤1 总能直接用；(2) f^(N+1) 递增 → 右端点取最大；(3) 递减 → 左端点取最大；(4) 都不适用时求临界点（见 11.1.1 节）
- **交错级数法（25.4 节）**: 若 f(x) 的泰勒级数在某 x 处是各项绝对值递减趋于 0 的交错级数，则 |R_N(x)| ≤ 下一项的绝对值
  - 何时使用: 泰勒级数恰好是交错级数时（典型：估算 ∫₀¹ (1−cos t)/t² dt 这类积分）
  - 怎么做: 写出级数展开（积分时对级数逐项积分），逐项累加直到下一项的绝对值小于容许误差。**优点：公式里没有 c**，即 |R_N(x)| ≤ |f^(N+1)(a)/(N+1)! · (x−a)^(N+1)|。必须验证交错级数三条件：交错、绝对值递减、趋于 0
- **用导数表求泰勒级数（25.2 节）**: 对不易用已知级数变形得到的函数，直接求导填表
  - 何时使用: 求某函数关于 x=a 的泰勒级数/多项式且不能从已知级数直接变形时
  - 怎么做: 建三列表 n / f^(n)(x) / f^(n)(a)，先逐行求导填中间列，再把 x=a 代入填右列，最后代入标准公式 Σ f^(n)(a)/n! (x−a)^n。幸运时可用已知级数运算代替（见 26.2 节）

## 关键概念
- **N 阶泰勒多项式 P_N(x)**: 关于 x=a 与 f 直到 N 阶导数都相同的唯一 ≤N 次多项式，即 P_N(x) = Σ_{n=0}^{N} f^(n)(a)/n! (x−a)^n
- **匹配性质**: P_N(a)=f(a), P'_N(a)=f'(a), …, P_N^(N)(a)=f^(N)(a)；在 a 以外或高于 N 阶处一般不成立
- **N 阶余项（误差项）R_N(x)**: f(x) − P_N(x) = f^(N+1)(c)/(N+1)! (x−a)^(N+1)，其中 c 介于 x 与 a 之间且一般求不出来
- **泰勒级数**: 无穷级数 Σ f^(n)(a)/n! (x−a)^n；对某 x，当 N→∞ 时 R_N(x)→0，则该点处 f(x) 等于其泰勒级数
- **麦克劳林级数**: a=0 的泰勒级数，即 Σ f^(n)(0)/n! x^n
- **二项式级数**: (1+x)^a = 1 + ax + a(a−1)/2! x² + a(a−1)(a−2)/3! x³ + …，对 −1<x<1 成立；a 非负整数时级数退化为多项式（高阶导数最终为 0）
- **估算方向**: R_N(x)>0 时 P_N 低估真值，R_N(x)<0 时高估

## 心智模型
- 当要求"误差不超过某值"时，用试错法递增 N：先算 |R_N| 的上界，不满足就换 N+1，直到上界小于容许值为止
- 当余项中出现未知量（如 e^c 但 e^(1/3) 未知）时，用一个**好算的粗糙上界**换掉它：例如 c<1/3 时 e^c < e^(1/3) < 8^(1/3) = 2，选 8 是因为能心算开三次方
- 当余项含 c^(−k) 这类递减函数且区间含难算的端点（如 23^(−5/2)）时，找区间内/附近一个幂好算的更小值放大：23^(−5/2) < 16^(−5/2) = 1/1024
- 当级数是交错级数时，丢掉余项公式里的 c——误差直接小于第一个被丢掉的项，这是最省力的误差界

## 常见错误与陷阱
- **导数表少算一行**: 余项 R_N 需要 f^(N+1)，只算到 N 阶导数就无法写误差项
- **把 f^(N+1)(a) 当作 f^(N+1)(c)**: 误差项里的导数必须在 c 处取值（c 未知，只能估范围），例五中表的第 4 行标 "不需要" 就是因为只需 |cos c|≤1
- **对递增/递减函数选错区间端点**: 递增取右端点、递减取左端点；选反了会得到过小的假误差界
- **假设泰勒级数处处等于 f(x)**: 只有 R_N(x)→0 时 f(x) 才等于其泰勒级数；如 (1+x)^(1/2) 的级数只在 −1<x<1 收敛
- **滥用交错级数法**: 三个条件（交错、递减、趋于 0）有一条不满足，"误差小于下一项" 就不成立
- **误判瑕点**: ∫₀¹ (1−cos t)/t² dt 看似反常，但由洛必达 lim_{t→0}(1−cos t)/t² = 1/2，被积函数有界，是正常积分

## 公式与参考表
泰勒多项式与余项（核心公式）:

```
P_N(x) = f(a) + f'(a)(x−a) + f''(a)/2! (x−a)² + … + f^(N)(a)/N! (x−a)^N
f(x)   = P_N(x) + R_N(x)
R_N(x) = f^(N+1)(c)/(N+1)! · (x−a)^(N+1),   c 介于 a 与 x 之间
交错级数情形: |R_N(x)| ≤ |f^(N+1)(a)/(N+1)! · (x−a)^(N+1)|（无 c）
```

常用麦克劳林展开（本章用到的）:

```
e^x       = 1 + x + x²/2! + x³/3! + x⁴/4! + …            (所有 x)
cos(x)    = 1 − x²/2! + x⁴/4! − x⁶/6! + …                (所有 x)
sin(x)    = x − x³/3! + x⁵/5! − …                        (所有 x)
(1+x)^1/2 = 1 + x/2 − x²/8 + x³/16 − 5x⁴/128 + …         (−1<x<1)
(1+x)^a   = 1 + ax + a(a−1)/2! x² + a(a−1)(a−2)/3! x³ + … (−1<x<1)
```

常用放大不等式: |sin c|≤1，|cos c|≤1；e^c < e^(1/3) < 2（当 0<c<1/3）；递减幂用左端点。

## 精讲例题
**例：估算 √27，误差不大于 1/250（25.3.3 节）**

1. 选 f(x)=x^(1/2)，x=27；选 a=25（靠近 27 且平方根易算）。
2. 导数表：f(25)=5，f'(x)=½x^(−1/2) → f'(25)=1/10，f''(x)=−¼x^(−3/2) → f''(25)=−1/500。
3. 试 N=0：|R_0(27)| = |f'(c)|·2 = c^(−1/2)，25≤c≤27，递减故 c=25 处最大 = 1/5，太大。
4. 试 N=1：|R_1(27)| = |f''(c)/2! · 2²| = c^(−3/2)/2 ≤ 25^(−3/2)/2 = 1/125 × 1/2 = **1/250**，达标。
5. 写 P_1(x) = f(25) + f'(25)(x−25) = 5 + (1/10)(x−25)，代入 x=27：P_1(27) = 5 + 2/10 = **26/5 = 5.2**。
6. 方向：R_1(27)<0（f'' 为负），故 26/5 是**高估**。验证：√27 ≈ 5.19615，与 5.2 之差确在 1/250 内。

## 要点速记
1. 估算问题的完整闭环：选 f、x、a → 导数表 → 余项定界 → 必要时调 N → 写 P_N 求值 → 由 R_N 符号判断高估/低估
2. 误差界永远是对 |f^(N+1)(c)| 在区间上取**最大值**得到的；递增看右端点，递减看左端点，sin/cos 直接用 1
3. 导数表必须比多项式阶数多算一行（N+1 阶），否则写不出余项
4. 遇到算不了的 e^c、c^(−5/2) 之类，用邻近好算的数（8、16 这类完全幂）做粗糙但安全的放大
5. 交错级数是捷径：误差 ≤ 下一项绝对值，公式无 c；但必须先验证三个条件
6. 估算定积分时，可先将被积函数展开为麦克劳林级数再逐项积分（如 ∫(1−cos t)/t² dt ≈ 1/2! − 1/(3·4!) = 35/72，误差 < 1/(5·6!) = 1/3600）
7. 选 a 的黄金标准：离 x 近，且 f(a) 及各阶导数在 a 处都能精确写出（0、25、π/3 这类特殊点）
