# 第1章：函数、图像和直线

## 核心思想
函数是微积分的"营养成分表"之首：它把每个输入唯一地变为一个输出。本章用两个几何检验（垂线检验判断"是不是函数"、水平线检验判断"有没有反函数"）把函数的全部代数性质翻译成图像语言，并盘点后续微积分反复用到的基本函数族（多项式、有理、指数、对数、绝对值）。

## 本节框架与方法
- **垂线检验**: 若任何一条垂线与图像相交多于一次，该图像就不是函数的图像；否则它就是函数的图像。
  - 何时使用: 判断一个坐标平面上的图形是否定义了一个函数。
  - 怎么做: 想象沿 x 轴滑动一条竖直线，检查它与图形的交点数；函数的本质是"每个 x 只有一个 f(x)"，所以同一 x 上不能有两个点。
- **水平线检验**: 若每条水平线与函数图像至多相交一次，则函数有反函数；只要有一条水平线相交多于一次，就没有反函数。
  - 何时使用: 判断 f 是否存在反函数 f⁻¹。
  - 怎么做: 画水平线 y = y₀，看方程 f(x) = y₀ 是否对每个 y₀ 至多一个解。失败时唯一补救办法是**限制定义域**——删掉图像的一部分使剩余部分通过检验。
- **用图像求值域（影子法）**: 画出函数图像，想象从图像左、右两侧远处朝 y 轴水平打光，曲线在 y 轴上投下的两侧影子的并集就是值域。
  - 何时使用: 已知图像（或容易作图）时求值域。
  - 怎么做: 画图 → 找 y 轴上被"照亮"的区域 → 取左、右影子的并。
- **求定义域的三条禁令**:
  - 何时使用: 题目未给定义域，按惯例取实数集的尽可能大部分。
  - 怎么做: (1) 分母 ≠ 0；(2) 负数不能取偶次根（平方根、四次根……）；(3) 负数和 0 不能取对数。注意 0 可以开方但不能取对数。把各条件化为不等式求交集，再挖掉孤立禁止点，用区间记号（如 (−8, 13] \ {2}）写出答案。
- **求反函数的两步法**: 写下 y = f(x)，解出 x = f⁻¹(y)；不喜欢变量 y 就改写成 x。几何上，f⁻¹ 的图像是 f 关于直线 y = x 的镜面反射（把 y = x 当双面镜）。
- **配方（配完全平方）**: 先提出二次项系数化为首一多项式；再把 x 系数除以 2 并平方，"加一次再减一次"塞进表达式；前三项即成平方。如 2x²−3x+10 = 2(x−3/4)² + 71/8。
  - 何时使用: 处理二次函数，第 18、19 章积分时会大量使用。
- **判别式判根**: 对 ax²+bx+c，令 Δ = b²−4ac：Δ>0 两个不同实根；Δ=0 一个（重）根；Δ<0 无实根。根为 (−b±√Δ)/(2a)。
- **奇偶性判定法**: 把每个 x 替换为 (−x)（务必加小括号）计算 f(−x) 并化简：等于 f(x) 则为偶函数；等于 −f(x) 则为奇函数；两者都不是则非奇非偶（多数函数如此）。
- **直线方程的点斜式**: 直线过点 (x₀, y₀)、斜率为 m ⟺ y − y₀ = m(x − x₀)。斜率未知但知两点时，先用 m = (y₂−y₁)/(x₂−x₁) 求斜率再套点斜式；用哪个点结果都一样。

## 关键概念
- **函数**: 将一个对象（输入）变为另一个对象（输出）的规则；每个有效输入必须对应唯一输出。f 是函数（变换规则），f(x) 是规则作用于 x 的结果，说"f(x) 是函数"是不严谨的。
- **定义域**: 所有合法输入的集合；未说明时取实数集中尽可能大的部分。
- **上域与值域**: 上域是"可能输出"的集合，值域是"实际输出"的集合；值域是上域的子集。本书约定上域恒为 R。
- **区间表示法**: [a,b] 闭（含端点），(a,b) 开（不含端点），[a,b)、(a,b] 半开；(a,∞) 表示 x>a。反斜杠 A\{2} 表示"除去 2"。
- **反函数 f⁻¹**: 当每个输出 y 对应唯一输入 x 时定义，满足 f(x)=y ⟺ f⁻¹(y)=x；f⁻¹ 的定义域 = f 的值域，f⁻¹ 的值域 = f 的定义域。f⁻¹ 是 f 的"撤销按钮"。
- **复合函数**: f = h ∘ g 表示 f(x) = h(g(x))：书写时 h 在左，计算时却从 g 开始（先内后外）。
- **奇函数/偶函数**: 对定义域内所有 x，f(−x) = −f(x) 为奇函数（图像关于原点 180° 点对称）；f(−x) = f(x) 为偶函数（图像关于 y 轴镜面对称）。等式必须对所有 x 成立。
- **线性函数**: f(x) = mx + b，图像是直线；m 是斜率（正=上山，负=下山，0=水平），b 是 y 轴截距。
- **多项式**: p(x) = aₙxⁿ + … + a₁x + a₀；最高次幂 n 为次数，aₙ 为首项系数。
- **有理函数**: 两个多项式之比 p(x)/q(x)；多项式本身是 q=1 的特例。
- **绝对值**: |x| 分段定义为 x（x≥0）与 −x（x<0）；|x−y| 是数轴上 x 与 y 的距离；|x| = √(x²)。

## 心智模型
- 当想判断"这是不是函数"时，用垂线检验；当想判断"能不能反着走回去"时，用水平线检验。两者通过镜子 y = x 相连：水平线经镜面反射变垂线——所以水平线检验失败的函数，其"反射像"必通不过垂线检验（不是函数）。
- 把反函数看作"撤销按钮"：f 把 x 变成 y，f⁻¹ 把 y 变回 x；两次撤销恢复原状。
- 把 |x−a| 看作"x 到 a 的距离"，绝对值不等式立刻变成数轴上的区间问题（如 |x−1|≤3 即 [−2,4]）。
- 把 y = f(x−a) 的图像看作 y = f(x) 整体向右平移 a 个单位（a 为负则向左）："向右移 −3 = 向左移 3"。
- 把多项式两端走势看作只由首项决定：只需看次数 n 的奇偶和首项系数 aₙ 的正负（四种组合），中间部分由其余项决定。

## 常见错误与陷阱
- **复合时忘加小括号**: 写 g(x+5) = x+5² 是错的，必须是 (x+5)²。替换时把每个 x 换成 (表达式) 并加括号；唯一例外是指数函数（已写成上标）。
- **混淆复合与乘积**: f = g∘h 与 f = gh 完全不同，且复合与顺序有关（g∘h ≠ h∘g），乘积与顺序无关。例：x²sin x 是乘积，sin²x 与 sin(x²) 是两个不同方向的复合。
- **误认为 f⁻¹(f(x)) = x 恒成立**: 限制定义域后，f(f⁻¹(y)) = y 对值域中所有 y 成立，但 f⁻¹(f(x)) = x 仅当 x 落在限制后的定义域内才成立。例：g(x)=x² 限制到 [0,∞) 后，g⁻¹(g(−2)) = √4 = 2 ≠ −2（而且 −2 根本不在定义域里）。数学家限制定义域时常不换字母，要格外小心。
- **认为奇偶性只需对某些 x 成立**: f(−x) = ±f(x) 必须对定义域内所有 x 成立才谈得上奇偶；大多数函数非奇非偶。
- **既奇又偶的函数不止一个？错**: 唯一既奇又偶的是零函数 f(x)=0（由 f(−x)=f(x) 与 f(−x)=−f(x) 相减得 2f(x)=0）。
- **对数与根号条件混用**: √0 合法而 log(0) 非法；tan(90°) 无定义的本质是隐藏分母 cos(90°)=0，归入"分母不为零"。
- **指数函数图像触轴错觉**: y = bˣ (b>1) 以 x 轴为水平渐近线，无限接近但永不接触，计算器上再像也不算。

## 公式与参考表

### 反函数要点
| 项目 | 内容 |
|---|---|
| 定义关系 | f(x)=y ⟺ f⁻¹(y)=x |
| 定义域/值域 | f⁻¹ 定义域 = f 值域；f⁻¹ 值域 = f 定义域 |
| 图像 | f⁻¹ 是 f 关于 y = x 的镜面反射 |
| 撤销性 | f(f⁻¹(y))=y 恒成立；f⁻¹(f(x))=x 仅当 x 在（限制后的）定义域内 |

### 奇偶函数运算规则
- 奇 × 奇 = 偶；偶 × 偶 = 偶；奇 × 偶 = 奇
- 奇函数若 0 在定义域内，则 f(0)=0（证明：f(−0)=−f(0) ⟹ 2f(0)=0）
- 图像对称性：偶函数关于 y 轴镜面对称；奇函数关于原点 180° 点对称（画半边即可得另半边）

### 直线
- 斜率：m = (y₂−y₁)/(x₂−x₁)
- 点斜式：y − y₀ = m(x − x₀)
- y = mx + b：y 截距 (0,b)；b=0 时过原点与 (1,m)；m=0 时是水平线 y=b

### 多项式两端走势（四种情况）
| 次数 n | 首项系数 aₙ | 左端 | 右端 |
|---|---|---|---|
| 偶 | + | 上 | 上 |
| 偶 | − | 下 | 下 |
| 奇 | + | 下 | 上 |
| 奇 | − | 上 | 下 |

### 二次函数
- Δ = b²−4ac：Δ>0 两根；Δ=0 一根；Δ<0 无实根
- 求根公式：x = (−b ± √(b²−4ac)) / (2a)

### 基本函数图像要点
| 函数 | 定义域 | 值域 | 关键特征 |
|---|---|---|---|
| y = xⁿ (n偶) | R | [0,∞) | 偶函数，过 (0,0),(±1,1)，U 形 |
| y = xⁿ (n奇) | R | R | 奇函数，过原点，S 形 |
| y = 1/xⁿ (n奇) | x≠0 | y≠0 | 两象限双曲线（如 1/x） |
| y = 1/xⁿ (n偶) | x≠0 | y>0 | 一三象限对称双曲线（如 1/x²） |
| y = bˣ (b>1) | R | (0,∞) | 过 (0,1)，x 轴为左端水平渐近线 |
| y = bˣ (0<b<1) | R | (0,∞) | 即 y=(1/b)⁻ˣ，为 y=bˣ 关于 y 轴的镜像（如 (1/2)ˣ = 2⁻ˣ） |
| y = log_b(x) (b>1) | (0,∞) | R | y 轴为垂直渐近线，是 y=bˣ 的反函数 |
| y = \|x\| | R | [0,∞) | V 形；y=\|f(x)\| 由 y=f(x) 把 x 轴下方部分以 x 轴为镜翻上来得到 |

### 绝对值
- |x| = √(x²)（注意：x<0 时 √x² = −x，不是 x）
- |x−y| = 数轴上 x 与 y 的距离

## 精讲例题
**求 f(x) = log₁₀(x+8)√(26−2x) / ((x−2)(x+19)) 的定义域。**

解：逐一施加三条禁令。
1. 根号：26−2x ≥ 0 ⟹ x ≤ 13。
2. 对数：x+8 > 0（注意是严格大于）⟹ x > −8。合并得 (−8, 13]。
3. 分母：(x−2)≠0 且 (x+19)≠0 ⟹ x≠2，x≠−19。−19 已在 (−8,13] 之外，自动排除；2 必须挖掉。

答案：定义域为 (−8, 13] \ {2}（反斜杠表示"不包括"）。

**求过 (−3,4) 和 (2,−6) 的直线方程。**

解：斜率 m = (−6−4)/(2−(−3)) = −10/5 = −2。用点斜式取点 (−3,4)：y−4 = −2(x−(−3))，化简得 y = −2x−2。（用另一点 (2,−6)：y+6 = −2(x−2)，结果相同。）

## 要点速记
1. 函数 = 每输入唯一输出；垂线检验查"是不是函数"，水平线检验查"有没有反函数"，镜子 y = x 把两者连起来。
2. 求定义域先查三件事：分母≠0、偶次根号内≥0、对数真数>0；再取交集、挖孤点。
3. 没有反函数就限制定义域，但记住 f⁻¹(f(x))=x 只在限制后的定义域内成立。
4. 复合先内后外、替换必带括号；复合≠乘积，且顺序不可交换。
5. 判奇偶：代入 (−x)（带括号）化简，比对 f(x) 与 −f(x)；奇×奇=偶，奇函数过原点（若 0 在定义域内）。
6. 两点定直线：先算斜率 m=(y₂−y₁)/(x₂−x₁)，再套点斜式 y−y₀=m(x−x₀)。
7. 把 |x−a| 翻译成"距离"，把 √(x²) 翻译成 |x|；配方是二次函数的常备技术。
