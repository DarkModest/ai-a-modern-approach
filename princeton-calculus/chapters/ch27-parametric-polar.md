# 第27章：参数方程和极坐标

## 核心思想
当 x 和 y 不直接相关、而是通过一个公共参数 t 相联系时，参数方程不仅给出曲线本身，还记录了"画线的方式"（方向与速度）；极坐标则是另一套定位系统（距离 r + 转角 θ），其核心计算（切线、面积）都归结为"把 θ 当参数"的参数方程问题。

## 本节框架与方法
- **参数方程求导（一阶导）**: dy/dx = (dy/dt)/(dx/dt) = y′(t)/x′(t)
  - 何时使用: 求参数曲线 x = x(t), y = y(t) 上某点（给定 t 值）的切线斜率
  - 怎么做: ① 分别求 dx/dt 与 dy/dt；② 相除得斜率；③ 把该 t 代入原方程求出该点的 (x, y)；④ 写点斜式直线方程
- **参数方程求导（二阶导）**: d²y/dx² = d(y′)/dx = (dy′/dt)/(dx/dt)
  - 何时使用: 判断参数曲线的凹性
  - 怎么做: 先求出 y′ = dy/dx（它是 t 的函数，此时**不要**代入具体 t 值），再对 t 求导并除以 dx/dt，最后才代入 t
- **寻找曲线的参数化**
  - 何时使用: 曲线形如 x² + y² = 常数、椭圆、或 xⁿ + yⁿ = 常数等
  - 怎么做: 圆 x² + y² = 9 → x = 3cos t, y = 3sin t；椭圆 x² + 4y² = 9 → 令 Y = 2y 化为圆再参数化（x = 3cos t, y = (3/2)sin t）；x⁶ + y⁶ = 64 → 用分数次幂 x = 2cos^(1/3)(t), y = 2sin^(1/3)(t)（使 6 次方后变成 cos²、sin²）
- **极坐标 → 笛卡儿坐标**: x = r cos θ, y = r sin θ
  - 何时使用: 已知 (r, θ) 求 (x, y)（这总是容易的方向）
- **笛卡儿坐标 → 极坐标**: r² = x² + y², tan θ = y/x（x ≠ 0），**必须检验象限**
  - 何时使用: 已知 (x, y) 求 (r, θ)
  - 怎么做: 先求 r；tan θ = y/x 给出两个相差 π 的候选角，画图确定正确象限；习惯取 r ≥ 0 且 0 ≤ θ < 2π；当 x = 0 时 tan 公式失效，直接看图（如 (0,1) → (1, π/2)）
- **极坐标曲线作图 r = f(θ)**
  - 何时使用: 画 r = f(θ) 的图像
  - 怎么做: ① 先在 θ–r 笛卡儿平面上画 r = f(θ)，看清 r 随 θ 的增减；② 找出 r = 0 的 θ（图像过原点的角度，即切线方向）；③ 描点（选含 π 的整齐的 θ 值列表）；④ 注意 r < 0 时图像翻转到相反方向（对侧象限）；⑤ 利用对称性补全
- **极坐标曲线切线**: dy/dx = (dy/dθ)/(dx/dθ)，其中 x = f(θ)cos θ, y = f(θ)sin θ
  - 何时使用: 求 r = f(θ) 上极坐标点为 (r₀, θ₀) 处的切线
  - 怎么做: ① 验证点确实在曲线上（代入 θ₀ 看 r 是否等于 r₀）；② 用乘积法则求 dx/dθ、dy/dθ；③ 相除代入 θ₀ 得斜率；④ 用 x = r cos θ, y = r sin θ 把点化为笛卡儿坐标写点斜式。在原点处（r = 0）：对每个使 r = 0 的 θ 分别求 dy/dx，每个值给出一条切线
- **极坐标面积**: 曲线 r = f(θ) 内、介于 θ = θ₀ 与 θ = θ₁ 之间的面积 = ∫(θ₀→θ₁) (1/2) r² dθ
  - 何时使用: 求极坐标曲线围成的扇形面积（小楔形 ≈ 半径 r、角 dθ 的扇形，面积 (1/2)r²dθ）
  - 怎么做: 直接积分；常配合二倍角公式处理 sin²、cos²。**若 r 在某段为负，必须格外小心**（见陷阱）

## 关键概念
- **参数**: 联系 x 与 y 的公共变量 t，x = x(t), y = y(t) 称为参数方程
- **参数化**: 用参数方程描述一条曲线；同一曲线有无穷多种参数化（不同起点、方向、速度）
- **极坐标 (r, θ)**: 从原点出发，逆时针转角 θ、沿该方向行进 r 到达的点；r 为负表示向相反方向走
- **极坐标的多值性**: 同一点有无穷多极坐标表示：(r, θ + 2πn) 与 (−r, θ + π + 2πn) 都是同一点
- **极坐标网格**: r = 常数是以原点为圆心的圆，θ = 常数是从原点发出的射线（雷达屏）
- **心形线**: r = 1 + cos θ，是蜗牛形曲线 r = 1 + a cos θ 的特例
- **蜗牛形曲线**: r = 1 + a cos θ 一类曲线；当 |a| > 1 时 r 会变负，形成内环
- **阿基米德螺旋线**: r = θ/π 型曲线，非周期，随 θ 增大螺旋越来越大
- **二阶导公式**: d²y/dx² = (dy′/dt)/(dx/dt)，即"把 y′ 当作新的因变量再套一次链式法则"

## 心智模型
- 当需要描述"曲线是怎么被画出来的"（方向、速度、重复经过）时，用参数化——笛卡儿图像只显示蜗牛的粘液轨迹，参数化才知道蜗牛每时每刻的位置
- 当曲线绕原点展开、含旋转结构（圆、螺线、花瓣）时，换到极坐标，让 θ 扮演参数 t 的角色
- 当求极坐标曲线的任何"斜率/切线"问题时，先写成 x = f(θ)cos θ, y = f(θ)sin θ，就退化为普通的参数方程求导
- 当从笛卡儿转极坐标时，tan θ = y/x 只给出"方向线"不给出"方向"——永远画图检验象限

## 常见错误与陷阱
- **漏掉同一曲线的多个 t 值**: 求"曲线上某点的切线"时，同一个 (x, y) 可能对应多个 t（如 x = 4t²−4, y = 2t−2t³ 在原点对应 t = ±1），每个 t 给出一条不同的切线——问"任意切线"就要全部找出
- **对 y′ 代值太早**: 求二阶导时若在求 d(y′)/dt 之前就把 t 的具体值代入 y′，会得到常数的导数 0；必须先对 t 求导、除 dx/dt，最后再代值
- **tan θ = y/x 的象限错误**: 由 tan θ = 1 直接得 θ = π/4 可能错（如点 (−1,−1) 的正确答案是 5π/4）；tan 值在相差 π 的两个角上相同，必须画图确认象限
- **x = 0 时硬套 tan 公式**: tan θ = y/0 无定义；轴上的点直接看图定角（π/2, π, 3π/2）
- **r 为负时的面积陷阱**: 面积公式含 r²，无法区分 r 的正负。若 r = f(θ) 在积分区间某段为负（如 r = 1 + 2cos θ 在 θ ∈ (2π/3, 4π/3)），直接对 [0, 2π] 积分会把内环面积多算进去。修正方法：单独算出 r < 0 段围成的小环面积，从总面积中减去**两次**（一次去掉重复计算，一次真正挖掉小环）
- **误以为参数化唯一**: 同一圆可由 x = 3cos t, y = 3sin t（0 ≤ t ≤ 2π，逆时针），或 x = 3cos 2t（速度翻倍），或 x = 3sin t, y = 3cos t（顺时针、起点 (0,3)）描述——解题时要明确参数范围与方向

## 公式与参考表

参数方程：
```
dy/dx = (dy/dt)/(dx/dt) = y′(t)/x′(t)
d²y/dx² = (dy′/dt)/(dx/dt)   （先对 t 求导，再除 dx/dt，最后代值）
```

坐标互换：
```
极 → 直:  x = r cos θ,  y = r sin θ
直 → 极:  r² = x² + y²,  tan θ = y/x (x ≠ 0)，检验象限！
同一性的全部表示: (r, θ + 2πn) 和 (−r, θ + π + 2πn)，n 为整数
```

极坐标切线（把 θ 当参数）：
```
x = f(θ)cos θ,  y = f(θ)sin θ
dy/dx = (dy/dθ)/(dx/dθ)
dy/dθ = f′(θ)sin θ + f(θ)cos θ
dx/dθ = f′(θ)cos θ − f(θ)sin θ
```

极坐标面积：
```
A = ∫[θ₀,θ₁] (1/2) r² dθ = ∫[θ₀,θ₁] (1/2)(f(θ))² dθ
```
（楔形 ≈ 扇形：半径 r、弧度角 dθ，面积 = (1/2)r²dθ）

常用参数化：
```
圆 x² + y² = 9:        x = 3cos t, y = 3sin t, 0 ≤ t < 2π
椭圆 x² + 4y² = 9:     x = 3cos t, y = (3/2)sin t
x⁶ + y⁶ = 64:          x = 2cos^(1/3)(t), y = 2sin^(1/3)(t)
r = 3sin θ ⇔ x² + (y − 3/2)² = (3/2)² （圆）
r = 2/(1 + sin θ) ⇔ x² = 4 − 4y （抛物线）
```

## 精讲例题

**例：求曲线 x = 4t² − 4, y = 2t − 2t³（t 为全体实数）在原点处的任意切线方程。**

1. **找原点对应的 t**：解 x = 4(t² − 1) = 0 得 t = ±1；代入 y = 2(t − t³)，t = 1 与 t = −1 都使 y = 0。所以曲线在 **t = 1 和 t = −1 两次经过原点**——这是"任意"而非"某个"的原因。
2. **求斜率**：
   dy/dx = (dy/dt)/(dx/dt) = (2 − 6t²)/(8t) = 1/(4t) − 3t/4
3. **分别代值**：
   - t = 1: dy/dx = 1/4 − 3/4 = −1/2 → 切线 y = −x/2
   - t = −1: dy/dx = −1/4 + 3/4 = 1/2 → 切线 y = x/2
4. **结论**：原点处有两条切线 y = x/2 与 y = −x/2（曲线自交于原点，描点作图可验证）。

**附（二阶导检验凹性）**：y′ = 1/(4t) − 3t/4，则
d²y/dx² = (dy′/dt)/(dx/dt) = (−1/(4t²) − 3/4)/(8t) = −1/(32t³) − 3/(32t)
代入 t = 1 得 d²y/dx² = −1/32 − 3/32 = −1/8 < 0，与图像上该段下凹一致。

## 要点速记
1. 参数曲线切线三步走：求 dx/dt、dy/dt → 相除得斜率 → 代 t 得点、写点斜式
2. 二阶导 = d(y′)/dx = (dy′/dt)/(dx/dt)；**代值永远在最后一步**
3. 极坐标求切线不必背新公式：x = f(θ)cos θ, y = f(θ)sin θ 就是参数化，直接套 dy/dx = (dy/dθ)/(dx/dθ)
4. 笛卡儿转极坐标时，tan θ = y/x 之后必须画图检验象限；x = 0 时点退化，直接看图
5. 极坐标面积 = ∫(1/2)r²dθ；若 r 在某段为负，先算该段小环面积，再从总面积中减两次
6. 画 r = f(θ) 先在 θ–r 平面上画辅助图，标出 r = 0 的角度（曲线过原点的方向），r < 0 时图像翻到对侧
7. 同一条曲线有无穷多参数化与无穷多极坐标表示——答案不唯一时按约定取 r ≥ 0, 0 ≤ θ < 2π
