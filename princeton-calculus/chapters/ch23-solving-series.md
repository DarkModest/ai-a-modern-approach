# 第23章：求解级数问题

## 核心思想
给定级数 Σaₙ，按一套固定的决策流程挑选判别法：先看是不是几何级数，再用第n项判别法排除发散，然后按通项特征（阶乘、n次幂、1/n与对数、负项）路由到比式/根式/积分/比较类判别法，含负项的走绝对收敛与交错级数路线。

## 本节框架与方法

本章开宗明义给出一张七步判别布图（按顺序执行）：
1. 是几何级数吗？（只含 2ⁿ、e³ⁿ 这类指数）
2. 各项趋于0吗？→ 第n项判别法
3. 有负项吗？→ 绝对收敛判别法 / 交错级数判别法（23.7）
4. 有阶乘吗？→ 比式判别法
5. 底和指数都含n吗？→ 根式判别法
6. 含因子 1/n 或对数吗？→ 积分判别法
7. 都不行？→ 比较判别法 + 极限比较判别法 + p判别法（重温第21章函数渐近表现）

- **几何级数求值**: Σₙ₌ₘ^∞ arⁿ 当 −1 < r < 1 时收敛，和 = 首项 / (1 − 公比)；|r| ≥ 1 时发散。
  - 何时使用: 通项可写成单个（或多个）rⁿ 的形式。
  - 怎么做: 把通项化为 a·rⁿ，读出 r 和首项（注意起始下标 m），套公式。分子含两项指数之差（如 2²ⁿ − (−7)ⁿ）时拆成两个几何级数分别求值；若拆开有一个发散，则整体发散（收敛+发散必发散）。

- **第n项判别法**: 若 lim aₙ ≠ 0 或极限不存在，则级数发散。
  - 何时使用: 永远最先做快速检验。
  - 怎么做: 求通项极限；不为0即发散（如 lim (n²−3n+7)/(4n²+2n+1)=1/4 → 发散）。注意：趋于0不能推出收敛，只是通行证。

- **比式判别法**: L = lim |aₙ₊₁/aₙ|。L<1 绝对收敛；L>1 发散；L=1 或极限不存在则无效。
  - 何时使用: 通项含阶乘（n!、(2n+5)!），或含指数但非几何级数。
  - 怎么做: aₙ 中 n 换成 n+1 做商，颠倒相乘并分组同类项取极限。阶乘商要展开相消：n!/(n+1)! = 1/(n+1)；(2n+2)!/(2n)! = (2n+1)(2n+2)。含 (n+k)ⁿ 型因子时拆出 ((n+a)/(n+b))ⁿ → eᵃ⁻ᵇ（可用洛必达/对数法）。

- **根式判别法**: L = lim |aₙ|^(1/n)。结论与比式判别法同（L<1 收敛，L>1 发散，L=1 无效）。
  - 何时使用: 通项为 A^B 且 A、B 都是 n 的函数；或容易对 aₙ 开 n 次方。
  - 怎么做: 开 n 次方化简指数（如 (1−2/n)^(n²) 开n次方 → (1−2/n)ⁿ → e⁻² < 1，收敛），常用重要极限 lim (1+k/n)ⁿ = eᵏ。

- **积分判别法**: 若 aₙ = f(n)，f 连续且递减，则 Σₙ₌ₙ^∞ aₙ 与 ∫ₙ^∞ f(x)dx 同敛散。
  - 何时使用: 通项同时含因子 1/n 和 ln(n)。
  - 怎么做: ①n换x、Σ换∫、加dx；②验证被积函数递减（导数为负或直接观察）；③求反常积分，最常用换元 t = ln(x)；④积分敛则级数敛，散则散。

- **比较 / 极限比较 / p判别法**（仅正项级数）:
  - 比较判别法: 猜发散就找一个发散的更小的级数（aₙ ≥ bₙ，Σbₙ 发散 ⇒ Σaₙ 发散）；猜收敛就找收敛的更大的级数（aₙ ≤ bₙ，Σbₙ 收敛 ⇒ Σaₙ 收敛）。
  - 极限比较判别法: 找简单 bₙ 使 n→∞ 时 aₙ ∼ bₙ（即 lim aₙ/bₙ = 1），则同敛散。
  - p判别法: Σ 1/nᵖ 当 p>1 收敛，p≤1 发散（a≥1 时起点无关）。
  - 何时使用: 前面所有判别法都失效的正项级数，尤其多项式/根式比、含 ln 或 sin 的通项。
  - 怎么做: 只保留最高次项找渐近等价（多项式、根式）；对数增长慢——用 ln(n) ≤ Cnᵅ（α 取得足够小，使 p−α 仍 >1）；指数增长快——用 2⁻ⁿ ≤ C/n^(k+2) 之类；|sin(n)| ≤ 1 直接压；x→0 时 sin x ∼ x、tan x ∼ x 用于 sin(1/n) 类。

- **含负项级数**（23.7）:
  - 全负：提负号化成正项级数判别；收敛于 L 则原级数收敛于 −L。
  - 正负混合：先第n项判别法（通项不趋0即发散）。
  - 绝对收敛判别法: Σ|aₙ| 收敛 ⇒ Σaₙ 收敛。优先尝试，成立就结束。
  - 交错级数判别法: 需验证三条——①符号交错；②lim |aₙ| = 0；③|aₙ| 关于 n 递减。三条全满足则收敛（常与"不绝对收敛"配合得到条件收敛）。

## 关键概念
- **几何级数**: 通项为 arⁿ 的级数，收敛当且仅当 |r|<1，和为首项/(1−r)。
- **第n项判别法**: 通项不趋于0即发散的单向发散判据（不能用来证收敛）。
- **绝对收敛**: Σ|aₙ| 收敛，蕴含原级数收敛。
- **条件收敛**: 级数收敛但不绝对收敛（如 Σ(−1)ⁿ/n）。
- **交错级数**: 符号正负交替的级数，通常含 (−1)ⁿ 因子。
- **渐近等价 (aₙ ∼ bₙ)**: lim aₙ/bₙ = 1，极限比较判别法的核心工具。
- **p级数**: Σ1/nᵖ，p>1 收敛、p≤1 发散，是比较的标准尺。
- **比式判别法临界失效**: L=1 时无任何信息（如 Σ1/(n ln n) 的比值极限为1），须换方法。

## 心智模型
- 判别法选择是"按特征路由"，不是碰运气：阶乘→比式；A^B 双含n→根式；1/n 配 ln(n)→积分；多项式比→最高次项渐近+极限比较；指数混杂→拆分或比较。
- 永远先花五秒钟问两个问题：是几何级数吗？通项趋0吗？这两步成本最低、排除最多。
- 对数与指数是一对"微调旋钮"：ln(n) 比任何 nᵅ（α>0）都慢，2⁻ⁿ 比任何多项式衰减都快——比较判别法中用一个足够小的 Cnᵅ 吸收对数、用 C/nᵏ 压制指数。
- 含负项时的优先级：第n项判别法 → 绝对收敛（一票定收敛）→ 交错级数判别法（兜底，给条件收敛）。绝不要跳过绝对收敛直接用交错判别法。

## 常见错误与陷阱
- **用第n项判别法证收敛**: 通项趋0只是必要条件（调和级数通项趋0却发散）；该判别法只能判发散。
- **把 (2n)! 当成 2×n!**: 正确展开是 (2n+2)!/(2n)! = (2n+1)(2n+2)，阶乘商必须展开相消。
- **拆分发散的几何级数**: 拆成两级数时若其一 |r|≥1，整体必发散，不能只对收敛那半求和。
- **从 n=0 开始的级数直接套极限比较**: 比较对象 2/n² 在 n=0 无定义；应改变起始下标或把首项提出来（加有限数不改变敛散性）。
- **比式/根式得 L=1 时误下结论**: L=1 表示判别法无效，须换积分或比较法（如 Σ1/(n ln n) 实际发散）。
- **交错级数陷阱**: Σ(−1)ⁿ(1+1/n)ⁿ 的通项在 ±e 间振荡，极限不存在，由第n项判别法发散——若只机械检查交错判别法的三条会误判。
- **忽视 ln(n) 的作用**: 对数"通常不起作用"是错觉——Σ1/(n ln n) 发散而 Σ1/(n(ln n)²) 收敛，分母上 ln 的幂次微小增加即可翻转敛散性。

## 公式与参考表

几何级数：

$$\sum_{n=m}^{\infty} ar^n = \frac{\text{首项 } ar^m}{1-r}, \quad -1 < r < 1$$

判别法选择速查表：

| 通项特征 | 首选判别法 |
|---|---|
| 纯指数 arⁿ | 几何级数公式（|r|<1 求和） |
| 通项不趋0 | 第n项判别法 → 发散 |
| 含 n!、(2n)! 或指数非几何 | 比式判别法 L=lim\|aₙ₊₁/aₙ\| |
| 底与指数都含 n（A^B 型） | 根式判别法 L=lim\|aₙ\|^{1/n} |
| 含 1/n 与 ln(n) | 积分判别法（换元 t=ln x） |
| 多项式/根式之比 | 最高次项渐近 + 极限比较 + p判别法 |
| 含 ln(n) 的分子 | 比较判别法，ln(n) ≤ Cnᵅ（α 任意小） |
| 含 (−1)ⁿ 或正负混合 | 第n项 → 绝对收敛 → 交错级数 |
| Σ1/nᵖ | p>1 收敛，p≤1 发散 |

常用渐近与极限（配合第21章）：lim(1+k/n)ⁿ = eᵏ；x→0 时 sin x ∼ x、tan x ∼ x；ln(n) 慢于任意 nᵅ (α>0)；指数 2ⁿ 快于任意多项式。

## 精讲例题

判别 Σₙ₌₁^∞ (2n)!/(n!)² 的敛散性。

1. 特征路由：含阶乘 → 比式判别法。
2. 写比值并化简：

$$\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right| = \lim_{n\to\infty}\frac{(2n+2)!}{(2n)!}\left(\frac{n!}{(n+1)!}\right)^2$$

3. 阶乘展开相消：(2n+2)!/(2n)! = (2n+1)(2n+2)，n!/(n+1)! = 1/(n+1)。
4. 代入得

$$\lim_{n\to\infty}\frac{(2n+2)(2n+1)}{(n+1)^2} = \lim_{n\to\infty}\frac{4n^2+6n+2}{n^2+2n+1} = 4.$$

5. L = 4 > 1 → 级数发散。

敏感性观察：若通项改为 (2n)!/(5ⁿ(n!)²)，比值极限多一个因子 1/5，得 4/5 < 1，级数变为收敛——单个指数因子即可翻转结论。

## 要点速记
1. 按七步布图顺序排查：几何级数 → 第n项 → 负项 → 阶乘（比式）→ 双n幂（根式）→ 1/n与对数（积分）→ 比较类。
2. 几何级数唯一可直接求值的情形：和 = 首项/(1−公比)，首项取决于起始下标。
3. 第n项判别法只做发散排除；通项趋0后必须另选判别法。
4. 阶乘商一律展开相消：n!/(n+1)! = 1/(n+1)，(2n+2)!/(2n)! = (2n+1)(2n+2)。
5. 比式/根式 L=1 是"无结论"，转积分或比较法。
6. 处理对数：ln(n) ≤ Cnᵅ 且 α 取得足够小，保住分母 p 幂大于1；处理指数：指数衰减压制任意多项式。
7. 含负项先查绝对收敛（Σ|aₙ| 收敛即收敛），失败再上交错级数判别法（验证交错、趋0、递减三条），得条件收敛。
