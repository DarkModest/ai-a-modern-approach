# 速查与决策指南 (Cheatsheet)

按"遇到 X → 做 Y"组织的决策规则，来自 AIMA 4e。

## 1. 搜索算法选择

| 情境 | 用法 | 理由 |
|---|---|---|
| 需要最优解路径、空间可承受 | A\*（可采纳 h） | 最优+利用 h 剪枝 |
| 内存受限、深度未知 | 迭代加深 / IDA\* | 线性内存+完备 |
| 只要好状态不要路径 | 局部搜索/退火 | O(1) 内存，适合连续 |
| 有对手 | α-β 剪枝（+评价函数） | 博弈树最优近似 |
| 有随机事件 | 期望极小化极大 | 机会节点取期望 |
| 动作结果不确定 | AND-OR 搜索 → 条件规划 | 解是策略不是序列 |
| 看不到全部状态 | 信念状态搜索/过滤 | 在信念空间规划 |
| 天生是"变量+约束" | CSP 回溯+传播 | 领域无关推断剪枝 |

**启发式三判据**：① h 可采纳 ⇒ A\* 最优；② h(n) 一致 ⇒ 图搜索无需重开节点；③ h1≥h2（均 dominating ⇒ 展开节点更少；max(h1,h2) 保持可采纳。

**何时放弃精确推断**：网络结构好（链、树、单连通）→ 变量消元线性；一般结构 NP 难 → 似然加权/吉布斯采样换近似。

## 2. 表示与推理路线

- 确定性、可枚举世界 → 逻辑（KB+推断）
- 事实有例外/默认 → 非单调推理（限定、缺省逻辑）
- 不确定 → 概率，不要用规则/置信度（违反概率公理会 Dutch book）
- 判断"加这条边有没有必要" → 先查 D-分离/条件独立
- 规划问题 → PDDL 因子化 + 领域无关启发式（松弛问题），规模大再上 SAT/HTN

## 3. 决策路线

| 问题形态 | 工具 |
|---|---|
| 一次性决策、结果有概率 | MEU + 决策网络 (Ch 16) |
| 要不要先获取信息 | 算 VPI，> 成本才收集 (Ch 16) |
| 序贯、模型已知 | MDP：值迭代/策略迭代 (Ch 17) |
| 序贯、模型未知 | 强化学习：TD/Q 学习 (Ch 22) |
| 环境含其他理性者 | 博弈论：零和→极小化极大；一般和→纳什均衡 (Ch 5, 18) |
| 需要多人协作/资源分配 | 机制设计：VCG、Shapley 值、合同网 (Ch 18) |

## 4. 学习路线

- 有标签 → 监督：可解释/小数据→决策树/线性；高维→SVM/核；大样本→深度网络；不稳定模型→集成
- 模型选择铁律：训练误差不算数；交叉验证 + 正则化/MDL 才是裁判
- 有隐变量 → EM（多初始化重启防局部最优）
- 只有奖励 → RL：能采样转移用 ADP（快）；不能就 TD/Q 学习（稳）；状态大 → 函数近似
- 探索：ε-greedy 递减（GLIE）保证既探索够又收敛；多臂赌博机用 UCB/基廷斯指数
- 序列/语言 → 词向量 + RNN/LSTM 或 Transformer + 预训练-微调

## 5. 常见坑（tells & smells）

- 状态空间爆炸 → 检查能否因子化（CSP/贝叶斯网络）或上抽象/启发式
- 负代价环 → Dijkstra/A\* 失效，先检测或换 Bellman-Ford 思路
- 训练好测试差 → 过拟合：正则化、更多数据、早停；先怀疑数据泄漏
- 梯度消失 → ReLU/残差连接/LSTM；梯度爆炸 → 梯度裁剪
- 粒子滤波全崩到一个粒子 → 重采样多样性丢失，加粗粒子数或重采样扰动
- 用 min-conflicts 解 CSP 大实例时震荡 → 加随机重启/权重约束
- "给 AI 写死目标就安全" → 标准模型谬误：价值对齐问题（Ch 1, 27）
