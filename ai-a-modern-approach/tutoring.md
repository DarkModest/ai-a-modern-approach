# 辅导与讲解笔记 (Tutoring Notes)

面向聊天式辅导场景的教学资产：已验证有效的讲解风格、类比与组织框架。内容源自实际辅导课的打磨沉淀，讲授对应主题时优先复用。

## 教学风格约定（已验证有效）

- **对话式中文**，少术语堆砌；每个概念落到一个具体例子上。
- **贯穿示例**：吸尘器世界（智能体/搜索/信念状态）、带不带伞（概率/效用）。同一例子跨章复用，减少认知负担。
- **表格保持小**（≤5 行），一表只对比一个维度。
- **每课结尾 1–2 道理解检查题**，学习者答完再"继续"推进。
- **每章可产出复习卡**：逐节大纲 + 优先级星标 + 5 句话记忆卡。
- **两种讲解档位**，按学习者信号切换：
  - "**详解**"（选中课文提问）→ 完整深潜：定义、常见误区、与前后章的联系、练习。
  - "**简要介绍 / 都是啥**" → 一句话 + 一个例子点到为止，"混个脸熟"即可，不展开。
- **记忆口诀**配合对比表使用（见下）。

## 已验证的类比与讲解框架

### 1. 两种"有限理性"（Ch 1–2, 16–17）
区分两条常被混为一谈的线，统一为一句口诀：
- **计算成本** → 有界理性 → 满意化、启发式、元推理（Ch 1, 27）
- **信息成本** → 信息收集理性 → VPI、POMDP、探索-利用（Ch 16, 17, 22）
- 口诀：**把所有成本都记进期望值账本**（思考的时间与传感器的钱都是成本）。

### 2. 智能体四层级 vs 表示三层级（Ch 2）
- 两条**独立**的轴：智能体表 = "决策机制"；表示 = "状态语言"。
- 四层级记忆口诀：**一级看一眼就动，二级心里有谱，三级眼里有目标，四级手里有标尺**（简单反射 → 基于模型 → 基于目标 → 基于效用）。
- h(n) 的另一种讲法：启发式是把结构"**走私**"回原子表示——原子表示本来看不见内部结构，h 函数手工塞回一点领域知识。
- 表示学习（深度学习）= **自动爬表示阶梯**（原子 → 因子化 → 结构化）。

### 3. 期望值：贝尔曼方程的数学前奏（Ch 12 前置 → Ch 17, 22）
- 讲期望时埋伏笔：**期望的线性性 + 全期望定律** E[X] = E[E[X|Y]] 正是贝尔曼方程 / Q 学习更新式的数学骨架。
- 配套内容：大数定律与蒙特卡洛、常见误区（期望≠最可能值）、圣彼得堡悖论 → 引出效用函数（Ch 16 铺垫）、条件期望。

### 4. 性能度量与奖励黑客（Ch 1, 27）
- **Goodhart / Campbell 定律**：度量一旦成为目标就不再是好度量。
- 实例：赛艇游戏 CoastRunners绕圈刷分、Tetris 暂停永不输。
- **变换链**讲法：性能度量 → 效用 → 奖励 → 信号 → 价值对齐，每一环都有失真风险；wireheading（自改度量）与外部批评者（学习元素放在系统外）作为解法。
- 设计练习载体：扫地机器人 / 配送无人机的性能度量设计。

### 5. P/NP/NP-难：组合锁类比（全书通用）
- **组合锁类比**：难解、易验（开锁难，试钥匙快）——NP 的本质一句话讲透。
- 配套表：各章计算难点——CSP（Ch 6）、SAT/归结推断（Ch 7）、规划（Ch 11）、贝叶斯网精确推断 NP 难（Ch 13）、MDP 策略判定 PSPACE 难（Ch 17）。
- **四条聪明退路**：近似算法 / 启发式 / 平均情形分析 / 有界理性——AI 全书的应对策略就这四条。

### 6. 四大形式化 2×2（全书地图，"混个脸熟"档位）
静态/动态 × 确定/不确定：
| | 确定 | 不确定 |
|---|---|---|
| 静态 | CSP（Ch 6，赋值） | 贝叶斯网络（Ch 13，推断） |
| 动态 | PDDL 规划（Ch 11，动作序列） | HMM/时序模型（Ch 14，滤波） |

### 7. 启发式函数 h(n)（Ch 3）
- 定义三件套：**便宜**（远比展开子树省力）、**乐观**（不高估=可采纳）、**估剩余代价**。
- 光谱讲法：h=0 退化回一致代价搜索；h=完美则沿直线走到目标；好 h 在两者之间买性价比。
- 可采纳 h 的 **max(h1,h2) 仍可采纳且更强**；经典对比：八数码错位棋子数 vs 曼哈顿距离。

### 8. 学科史收尾框架（Ch 1）
- 物理符号系统假设（PSSH）→ **逻辑主义 vs 联接主义**两条路线之争。
- 弱方法（领域无关搜索）vs 知识密集型（Dendral/Mycin）：口诀"**智能 = 搜索 + 知识**"。
- **可计算性 ≠ 易处理性**（tractability）：前者问"能不能"，后者问"来不来得及"。
