# 第21章 深度学习 (Deep Learning)

## 核心思想
深度学习把假设表示为多层、可调权重的计算图（电路），用梯度下降拟合数据：长计算路径使所有输入变量以复杂方式相互作用，这是其表达力超越线性模型与决策树的根本原因。

## 框架
- **前馈网络 / 计算图（feedforward network / computation graph）**
  - 何时使用：任何可微的监督学习任务，尤其高维输入（图像、语音、文本）
  - 如何做：把网络看作数据流电路，每个节点是一个基本运算（加、乘、sigmoid）；权重如"音量旋钮"，调整它使输出逼近真值 y
- **反向传播（back-propagation）**
  - 何时使用：计算任何前馈计算图的损失对全部权重的梯度
  - 如何做：从输出层沿每条连接回传偏导数消息；节点汇总传入消息（对多个后继求和），乘以自身局部导数后发给前驱；本质是反向模式自动微分，代价与前向计算同阶
- **卷积网络（convolutional network, CNN）**
  - 何时使用：数据具有网格邻接结构（图像），需注入局部性与空间不变性先验
  - 如何做：每个隐藏单元只连接局部区域，同一核（kernel）权重在所有位置共享；配池化层下采样，末端 softmax 分类
- **残差网络（residual network）**
  - 何时使用：训练数十至数百层的深网络，避免梯度消失
  - 如何做：每层学习对前层表示的扰动而非替换：a⁽ⁱ⁾ = g_r(a⁽ⁱ⁻¹⁾ + f(a⁽ⁱ⁻¹⁾))；某层权重为零时退化为恒等映射，信息天然可传递
- **循环网络 / LSTM（recurrent network / long short-term memory）**
  - 何时使用：时序数据（语音、文本、手写）
  - 如何做：隐藏状态跨时间步循环、权重共享，按时间展开后用基于时间的反向传播（BPTT）训练；LSTM 用记忆单元加遗忘/输入/输出三门控制信息流，梯度不做乘法累积
- **生成模型家族：自编码器 / VAE / GAN（autoencoder / variational autoencoder / generative adversarial network）**
  - 何时使用：无标签数据上的表示学习与生成
  - 如何做：编码器–解码器重建输入（线性版≈PCA）；VAE 最大化变分下界（ELBO）；GAN 让生成器与判别器对抗训练至均衡

## 关键概念
- **激活函数（activation function）** — 单元对输入加和施加的非线性 g；没有它，任意多层网络仍只表示线性函数
- **万能近似（universal approximation）** — 两层网络（首层非线性、末层线性）能以任意精度逼近任何连续函数
- **梯度消失（vanishing gradient）** — 误差信号回传时因局部导数接近或等于 0 而衰减殆尽；深网络与简单 RNN 的核心困难
- **softmax 层** — 把 d 个输出指数归一化为概率分布，多分类标准输出层（d=2 时退化为 sigmoid）
- **交叉熵（cross-entropy）** — 两分布差异的度量，最小化它等价于最小化 KL 散度；最常用损失函数
- **核 / 步长 / 填充（kernel / stride / padding）** — 共享的权重模式；核每次滑动的像素数；边缘补值使输出保持尺寸
- **感受野（receptive field）** — 能影响某单元激活的输入区域；步长为 1 时随深度线性增长，步长大于 1 或池化时指数增长
- **特征映射 / 通道（feature map / channel）** — 一个核扫过整幅图像的输出数组；d 个通道各携带一种特征
- **批量归一化（batch normalization）** — 对每个小批量在内部层做均值方差归一化（带可学习缩放平移），大幅加速 SGD 收敛
- **权重衰减（weight decay）** — 损失加惩罚项 λΣ_{i,j} W²_{i,j}（λ≈10⁻⁴）；等价于零均值高斯先验下的 MAP 学习；sigmoid 网中使激活保持在线性区附近
- **暂退法（dropout）** — 训练时每步以概率 p 随机停用单元（存活输出乘 1/p），隐藏层常用 p=0.5、输入单元 p=0.8，测试时不用；近似大规模集成网络
- **对抗样例（adversarial example）** — 对输入的微小扰动令输出剧变（狗→鸵鸟），暴露深度模型决策边界的脆弱
- **词嵌入（word embedding）** — 单词的高维向量表示，语义相近的词向量靠近，支撑跨单词类别泛化

## 思维模型
- 把权重当音量旋钮、网络当电路：学习 = 调旋钮使输出拟合数据
- 当数据有空间邻接结构时用局部连接+权重共享（CNN），时间结构同理（RNN）——把先验写进架构，参数少、学习快、泛化好
- 把每层看作一次表示变换：深网络 = 许多简单变换的串接，层间自动涌现"边→角→眼→脸"的抽象层级
- 把生成模型看作学到的隐空间 z：不同方向编码语义维度（性别、眼镜），可在 z 空间做算术（"戴眼镜的男人"−"男人"+"女人"）

## 反模式
- **全连接处理图像**：n² 量级权重（百万像素 RGB 约 9 万亿个），且邻接信息在完全连通中失去意义
- **类别属性编码为整数**：网络是连续函数，会注意虚假的数值邻接（Thai=3 与 Burger=4 相邻无意义）——应使用独热编码
- **梯度消失**：sigmoid/tanh 饱和区导数近 0、简单 RNN 权重谱半径小于 1 时误差信号指数衰减——用 ReLU、残差连接、批量归一化、LSTM 缓解
- **以为拟合训练集即可**：目标在测试集泛化——需架构先验、权重衰减、dropout 三管齐下
- **认为深度学习万能**：它相当于"短并行程序"（10–10³ 计算步），缺乏一阶逻辑式的组合与量化能力；输入-输出映射不连续，对抗样例可欺骗

## 算法要点

前向传播（逐层）：
```
in_j = Σ_i w_i,j·a_i + w_0,j              # 含固定 +1 虚拟输入（偏置）
a_j  = g(in_j)                             # g 必须非线性
整体：h_w(x) = g⁽²⁾(W⁽²⁾ g⁽¹⁾(W⁽¹⁾x))      # 权重矩阵链式组合
```

反向传播（任意计算图，图21-6）：
```
输出节点：发出消息 ∂L/∂ŷ（由损失函数直接算出）
中间节点 h（后继为 j, k）：
  汇总  ∂L/∂h = ∂L/∂h_j + ∂L/∂h_k                    # 式21-11
  发出  ∂L/∂f_h = (∂L/∂h)·(∂h/∂f_h)（对 g_h 同理）    # 式21-12
权重节点：累加的传入消息之和 = ∂L/∂w，即更新所需梯度
共享权重（卷积/RNN）：梯度 = 所有共享位置贡献之和
# 消息可为张量，可部署到 GPU/TPU；需存储前向中间值（内存 ∝ 单元数）
```

链式法则实例（图21-3 网络：x₁,x₂ → 隐单元 3,4 → 输出单元 5）：
```
∂L/∂w₃,₅ = −2(y−ŷ)·g'₅(in₅)·a₃                        # 式21-4：直连输出的权重
∂L/∂w₁,₃ = −2(y−ŷ)·g'₅(in₅)·w₃,₅·g'₃(in₃)·x₁          # 式21-5：多应用一次链式法则
# 记 Δ₅ = −2(y−ŷ)g'₅(in₅)（输出单元的"感知误差"），两式呈统一的 Δ·前驱激活 模式
```

输出层与损失（21.2.2）：
```
softmax(in)_k = e^{in_k} / Σ_{k'=1..d} e^{in_{k'}}   # 和为 1；d=2 时退化为 sigmoid
  例：in = ⟨5, 2, 0, −2⟩ → 输出 ⟨0.946, 0.047, 0.006, 0.001⟩（指数放大差异但光滑可微）
负对数似然(式21-6)：w* = argmin_w −Σ_{j=1..N} log P_w(y_j | x_j)
交叉熵：H(P,Q) = H(P) + D_KL(P‖Q)，D_KL ≥ 0；固定 P 时最小化交叉熵 = 最小化 KL 散度
```

卷积与池化（一维，图21-4/21-5）：
```
z_i = Σ_{j=1..l} k_j · x_{j+i−(l+1)/2}     # 式21-8：核 k 与以 x_i 为中心、宽 l 的片段内积
步长 s → 输出尺寸 ≈ n/s（边缘可填充使输出与输入同尺寸）
卷积=线性矩阵运算(式21-9)：核 [+1,−1,+1]、步长 2 作用于 [5,6,6,2,5,6,5]，
  即 3×7 矩阵（每行核相对前行移动 s）乘输入向量 → [5, 9, 4]ᵀ
平均池化：l 个输入取均值 → 粗化分辨率、多尺度识别
最大池化：l 个输入取最大 → 逻辑析取"感受野内存在该特征"（[5,9,4]→9）
d 个核 → 输出尺寸 × d，第三维为通道（特征映射）
```

残差连接：
```
a⁽ⁱ⁾ = g_r( a⁽ⁱ⁻¹⁾ + f(a⁽ⁱ⁻¹⁾) ),  f = V·g(W·a⁽ⁱ⁻¹⁾)（小网络）
V=0 ⇒ f=0 ⇒ a⁽ⁱ⁾ = ReLU(ReLU(a⁽ⁱ⁻¹⁾)) = a⁽ⁱ⁻¹⁾   # 失效层退化为恒等，深网络默认安全
```

LSTM 门控更新（⊙ 为逐元素乘，W 下标=连接起点与终点）：
```
f_t = σ(W_x,f·x_t + W_z,f·z_{t−1})     # 遗忘门：记忆单元元素保留还是置 0
i_t = σ(W_x,i·x_t + W_z,i·z_{t−1})     # 输入门：是否写入新信息
o_t = σ(W_x,o·x_t + W_z,o·z_{t−1})     # 输出门：记忆是否转移到短期记忆 z
c_t = c_{t−1} ⊙ f_t + i_t ⊙ tanh(W_x,c·x_t + W_z,c·z_{t−1})   # 记忆单元：加性更新，梯度不随时间乘法累积
z_t = tanh(c_t) ⊙ o_t                  # 短期记忆，作用同基本 RNN 的隐藏状态
```

基本 RNN 与 BPTT（图21-8：z 循环连接，展开 T 步后权重共享）：
```
模型(式21-13)：z_t = g_z(W_z,z·z_{t−1} + W_x,z·x_t)；ŷ_t = g_y(W_z,y·z_t)
梯度(式21-15)：∂z_t/∂w_z,z = g'_z(in_z,t)·(z_{t−1} + w_z,z·∂z_{t−1}/∂w_z,z)
  # 递归式：t 步贡献依赖 t−1 步；按序计算则总时间与网络规模呈线性（BPTT）
```

VAE 的变分下界（式21-17）：
```
L(x, Q) = log P(x) − D_KL(Q(z) ‖ P(z|x)) = H(Q) + E_{z~Q}[log P(z, x)]
# KL ≥ 0 ⟹ L 是 log P(x) 的下界；高斯 Q 的熵 H(Q) 有解析式，
# 期望项对 z~Q 采样无偏估计；编码器 f(x) 给出 Q 的参数，解码器 g(z) 定义 P(x|z)
```

（注：Transformer 与注意力机制不在本章原文范围内，见第24章。）

## 参考表

| 激活函数 | 形式 | 特点 |
|---|---|---|
| sigmoid | 1/(1+e⁻ˣ) | 输出 (0,1) 可解释为概率；饱和区梯度趋 0 |
| ReLU | max(0,x) | 计算廉价、缓解梯度消失；平坦区梯度恰为 0 |
| softplus | log(1+eˣ) | ReLU 的光滑版，导数恰为 sigmoid |
| tanh | — | 值域 (−1,1)，是 sigmoid 的伸缩平移版 |

| 任务 | 输出层 | 损失 |
|---|---|---|
| 布尔分类 | sigmoid | 负对数似然 / 交叉熵 |
| 多分类（d 类） | softmax | 交叉熵 |
| 回归 | 线性（无激活） | 平方误差（= 固定方差高斯的 NLL） |
| 混合连续输出 | 混合密度层 | 混合高斯 NLL |

## 完整示例
书中一维 CNN 例子（核 [+1, −1, +1] 检测暗点）：
1. 输入为 n 像素一维图像，核 [+1,−1,+1]、步长 2（图21-4）：[5,6,6,2,5,6,5] → [5,9,4]，响应峰值集中在暗（低光强）像素处，输出尺寸约 n/2
2. 第二层核大小 3、步长 1、边缘填充（图21-5）：第二层单元感受野为 5 像素；第 m 层感受野随深度线性增长（步长大于 1 时指数增长）
3. 对隐藏层输出 [5, 9, 4] 做最大池化得 9 —— "该区域内存在暗点"的析取
4. 张量视角（21.3.2）：批量 64 张 256×256×3 图像即 256×256×3×64 的四维张量；用 96 个 5×5×3 核、双向步长 2 处理 → 特征映射 128×128×96×64；96 个通道各携带一种特征，原颜色通道被学习到的特征通道吸收

计算图最小实例（图21-3）：2 输入 x₁,x₂、隐藏单元 3,4、输出单元 5；拆成计算图后每个权重（含连到固定 +1 虚拟输入的偏置 w₀,₃、w₀,₄、w₀,₅）都是独立节点，基本运算只有 ×、+ 与激活 g——式21-4/21-5 的链式求导就在此图上进行。

深度 vs 宽度（图21-7，谷歌街景门牌转录数据）：固定权重总量（横轴至 7×10⁷），3 层网络测试误差 0.07–0.085 且呈 U 形，11 层网络从 ~0.063 随加宽单调降至 ~0.040——同预算下深而窄始终更优。

规模实例 AlexNet（2012 ImageNet，深度学习的转折点）：ImageNet 含 120 万幅图像、1000 个类别，按 Top-5 评分；AlexNet 5 个卷积层（穿插最大池化）+ 3 个全连接层，ReLU 激活，GPU 加速训练 6000 万权重；Top-5 错误率 15.3%，远优于第二名（超过 25%）。此后 ImageNet Top-5 错误率降至 2% 以下（受训人类约 5%）。

## 要点
1. 非线性激活是表达力之源：没有非线性，任意多层叠加仍只是线性函数
2. 反向传播 = 反向模式自动微分：一次反向遍历得全部梯度，代价与前向同阶；主流框架自动完成，催生端到端学习
3. 参数量相近时，深而窄胜过浅而宽（门牌识别：11 层误差始终低于 3 层）
4. 泛化三手段：结构先验（CNN/RNN）、权重衰减（高斯先验 MAP）、dropout（廉价集成）
5. 监督深度学习依赖海量标注；无监督（VAE/GAN/自回归）与迁移学习（预训练 + 冻结浅层 + 微调）是减少标注依赖的出路——COCO 预训练的 ResNet-50 加少量独轮车图片即可建分类器
6. 深度强化学习（DQN、AlphaGo）证明计算图表示复杂函数的能力可迁移到从奖励学习决策
7. 迁移学习也含 sim-to-real：自动驾驶控制器先在模拟中训练数十亿公里再迁移到真实汽车
