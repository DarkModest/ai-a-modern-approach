# 第25章 计算机视觉 (Computer Vision)

## 核心思想
视觉是"从图像中重建世界模型并识别其中物体"的逆图形学问题：成像过程（透视投影、光照、反射）是良定义的正问题，而视觉作为其逆问题本质上有歧义，必须靠先验概率和任务相关性消解歧义；现代实践用 CNN 从数据中学习分层特征来完成分类、检测与三维恢复。

## 框架
- **特征提取（Feature Extraction）**：对传感器响应做简单直接的计算，得到可解释的数字
  - 何时使用：需要快速、低级信息直接驱动控制时（如飞行动物估计碰撞时间）
  - 如何做：对像素邻域做局部运算（梯度、直方图），不依赖图像内容理解
- **透视投影 / 针孔照相机（Perspective Projection / Pinhole Camera）**：x = fX/Z, y = fY/Z
  - 何时使用：建模任意成像几何的基准模型；解释平行线汇聚于消失点（vanishing point）
  - 如何做：焦距 f、相似三角形；物体越远图像越小；深度近似不变时退化为缩放正交投影（scaled orthographic projection）
- **边缘检测（Edge Detection，高斯导数法）**
  - 何时使用：需要紧凑抽象表示、后续匹配或分割的前端
  - 如何做：平滑与微分合并为"图像 ∗ 高斯导数核"；梯度模长沿梯度方向取局部极大值且超阈值的点为边缘点；再按方向一致性连接成曲线
- **基于 CNN 的分类与检测（CNN Classification / Fast R-CNN Detection）**
  - 何时使用：大规模图像分类与多物体定位（ImageNet：2012 年起 Top-5 从 <70% 升至 98%）
  - 如何做：卷积+ReLU 层构成"局部模式检测器"，逐层堆叠得到"模式的模式"；检测用 RPN 打分锚框 → ROI 池化 → 分类 → 非极大值抑制 → 边框回归
- **双目立体视觉（Binocular Stereopsis）**：视差（disparity）与深度成反比
  - 何时使用：有同一场景两个视点（双相机或移动相机），需恢复深度
  - 如何做：SSD 匹配左右像素块建立对应 → 测视差 → 由基线 b 与视差得深度；移动相机时光流场同理，延伸焦点（focus of expansion）给出方向，光流模长比给出深度比，距离/速度给出接触时间
- **图像生成与变换（Image Transformation / GAN / 风格迁移）**
  - 何时使用：成对/非成对图像翻译、图像合成、隐私保护数据集生成
  - 如何做：成对监督 + GAN 损失；无配对时用循环一致性约束（X→Y→X）；风格迁移最小化 ‖L(x)−L(内容)‖+‖E(x)−E(风格)‖（早期层≈风格，晚期层≈内容）

## 关键概念
- **重建（Reconstruction）** — 从一幅或多幅图像建立世界模型（几何模型或纹理地图）。
- **识别（Recognition）** — 将视觉信息与其他信息结合，辨识所见物体及其属性。
- **物体模型 vs 绘制模型（Object Model / Rendering Model）** — 前者描述物体性质，后者描述产生刺激的物理与统计过程。
- **消失点（Vanishing Point）** — 空间中同方向平行直线族在图像中的共同汇聚点。
- **漫反射 / 镜面反射（Diffuse / Specular Reflection）** — 前者向各方向均匀散射（亮度不依赖观察方向），后者按入射方向窄波瓣反射形成亮斑（specularity）。
- **兰伯特余弦定律（Lambert's Cosine Law）** — 漫反射亮度 = I₀·ρ·cosθ（ρ 为漫反射系数 albedo，θ 为光照方向与法线夹角）。
- **三原色原理与颜色恒常性（Trichromacy / Color Constancy）** — 3 种感受器（RGB）可匹配任意光谱；人能忽略光照色偏估计表面真实颜色。
- **纹理（Texture）与纹元（Texel）** — 表面上可视觉感知的大致规则图案；基本构造为图像块内梯度方向直方图（对照明不变）。
- **光流（Optical Flow）** — 观察者与场景相对运动引起的图像特征运动方向与速度。
- **分割（Segmentation）与超像素（Superpixel）** — 把图像分成相似像素组；过分割策略保证不漏真边界，把百万像素降为数百超像素。
- **归一化切割（Normalized Cuts）** — Shi & Malik 将分割表述为图划分：组间边权最小、组内边权最大。
- **视差（Disparity）** — 同一场景点在左右视图中位置的变化；水平视差 = 基线/深度。
- **数据集增强（Dataset Augmentation）** — 复制训练样本并随机平移/旋转/拉伸/调色以扩大数据。
- **环境（Context）** — 物体周围的区分性模式（猫粮盆、项圈）可帮助也可误导分类。

## 思维模型
- 把视觉看作**图形学的逆问题**：正问题（场景→图像）易，逆问题需额外证据或先验。
- 当外观变化（照明、视向、遮挡、变形）难以建模时，**交给数据**：让 CNN 在大训练集中见过每种效应。
- 把 CNN 的一层看作**"局部模式检测器"，深层是"模式的模式"**：感受野逐层扩大，层级化构建表示。
- 当多视图可用时，**把对应问题当核心**：点匹配（纹理特征/SSD）一旦解决，几何重建是成熟理论。
- 当只有单视图时，**把几何线索当作学习任务的输入**：深度图、位姿、地平线均可由网络从单图回归。

## 反模式
- **对含噪图像直接求导找边缘**：噪声产生伪峰值（如 x=75 处），必须先高斯平滑或直接卷积高斯导数。
- **只用边缘做分割**：老虎的每条条纹和每棵草都产生边缘，会淹没真实轮廓；需区域聚类或高级知识。
- **假设单像素携带信息**：MNIST 数字可平移缩放，暗像素位置每个实例都不同；信息在局部模式及其空间关系中。
- **报告所有超阈值窗口**：相邻高度重叠的窗口对应同一物体；需非极大值抑制去重。
- **认为分类器高分等于理解**：训练/测试分布不一致（游泳池检测器≠游泳检测器）、环境线索可导致性别等猜测性错误；VQA 暴露这类空洞。

## 算法要点
**边缘检测（二维）**
1. 计算图像梯度 ∇I = (∂I/∂x, ∂I/∂y)（实现为与高斯偏导核卷积）。
2. 判据：像素为边缘点 ⟺ 梯度模长沿梯度方向是局部极大值（非极大值抑制）且超过阈值。
3. 连接相邻、梯度方向一致的边缘像素成曲线；输出有间隙和伪边缘，留待后续修正。

**纹理表示（方向直方图）**
1. 对切片内每像素算梯度方向；2. 在（多尺度的）单元上统计方向直方图；3. 聚合各单元直方图为切片描述子；垂直条纹呈双峰，豹斑近均匀。

**光流 / 立体对应（SSD）**
以 (x₀,y₀) 为中心的像素块与下一帧（或另一视图）各候选块比较，取使差值平方和 SSD(Dx,Dy) 最小的位移；光流 = (Dx/Dt, Dy/Dt)。无纹理（白墙）时退化为盲猜。

**物体检测（Fast R-CNN 流程）**
1. RPN 在 16 像素步长网格上为每个中心打分 9 个锚框（3 尺寸×3 纵横比），输出"是否含物体"。
2. 高分 ROI 经 ROI 池化采样为固定尺寸特征图。
3. CNN 分类器判定类别。
4. 非极大值抑制：按分数排序，取最高者并删除与其大量重叠的其余窗口。
5. 边框回归微调窗口位置到精确边框。

**从运动恢复结构（SfM，定性）**
匹配多视图点 → 推广到图像组得粗解 → 打磨（最小化预测点与观测特征的误差）；应用：城市建模、影视合成、机器人路径重建、施工管理。

## 参考表
图像四类基础特征对比：

| 特征 | 覆盖范围 | 对什么不变 | 主要用途 |
|---|---|---|---|
| 边缘 | 局部（低级） | — | 紧凑表示、匹配前端 |
| 纹理 | 中级（像素块） | 照明（方向直方图） | 物体识别、立体匹配 |
| 光流 | 中级（大区域序列） | — | 运动结构、深度比、接触时间 |
| 分割 | 整幅（区域级） | — | 超像素降维、物体边界 |

边缘成因：①深度不连续 ②表面法线不连续 ③反射率不连续 ④照明不连续（阴影）——检测器无法区分成因。

自动驾驶视觉任务分解：横向控制（车道位置/方向）｜纵向控制（前车距离）｜避障（邻车、行人）｜遵守交通信号（灯、标志、手势）。

## 完整示例
**单视图三维线索定位行人（地平线推理）**：假设所有行人身高相近且站在地面。给定图像中地平线位置，行人脚离地平线越近则越远、看起来越小。由此可**剔除检测器错误响应**——"脚接近地平线却显得很大"的行人不可能存在。反过来，多个可信行人检测的相对比例又可**估计地平线位置**，再用它去过滤更多检测错误：检测与几何线索互相校验的闭环。

## 要点
1. 视觉两大核心问题：重建与识别；歧义靠"先验可能性"与"任务相关性无关紧要"两种策略消解。
2. 成像物理（针孔、透镜、兰伯特定律、三原色）提供正模型；所有三维线索（视差、光流、纹理梯度、明暗、遮挡、位姿、空间关系）都是其逆推论。
3. 平滑与微分的卷积可交换性（(f∗g)′ = f∗g′）让边缘检测一次卷积完成。
4. CNN 成功的关键是特征从数据学得而非手工设计；ImageNet 竞赛 + 开源获胜模型加速了整个领域。
5. 检测 = 分类器 + 区域候选 + 抑制 + 回归，每一步都是对"窗口在哪里、报哪些"的工程化回答。
6. 生成方向（图像插入、pix2pix、CycleGAN、风格迁移、deepfake、合成医学数据）表明视觉与图形学正在合流。
7. 视觉导航的标准分解：SLAM 建图（26.4 节）+ 路径规划（26.6 节），端到端变体（认知映射与规划）正在兴起。
