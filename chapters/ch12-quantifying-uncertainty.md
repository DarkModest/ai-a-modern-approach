# 第12章 不确定性的量化 (Quantifying Uncertainty)

## 核心思想
当逻辑因惰性与无知无法穷举例外（资格问题）时，用概率表示对语句的信念度；决策论＝概率论＋效用理论，理性＝选择最大期望效用（MEU）的动作；而条件独立性是把指数规模的联合分布压缩到可计算规模的关键分解手段。

## 框架
- **决策论（decision theory）＝ 概率论 ＋ 效用理论**
  - 何时使用：无规划能保证达成目标、但智能体必须行动并比较规划优劣时
  - 如何做：对每个动作，用概率加权平均各结果的效用，选期望效用最高者（MEU 原则）
- **枚举推断（inference by full joint distribution）**
  - 何时使用：变量少、完全联合分布可用时（理论基座，如同第7章真值表之于 DPLL）
  - 如何做：P(X|e) = α Σ_y P(X, e, y)，对未观测变量 Y 的所有取值组合求和后归一化
- **贝叶斯法则（Bayes's rule）**
  - 何时使用：已知因果方向条件概率 P(效果|原因)，需诊断方向 P(原因|效果) 时
  - 如何做：P(b|a) = P(a|b)P(b)/P(a)；带归一化形式 P(X|e) = α·P(e|X)P(X)，可免去估计证据先验 P(e)
- **条件独立性（conditional independence）**
  - 何时使用：直接原因"分隔"两个效果（如 Cavity 分隔 Toothache 与 Catch）时
  - 如何做：P(X,Y|z) = P(X|z)P(Y|z) ⇒ 联合分布分解为小表乘积，规模从 O(2^n) 降到 O(n)
- **朴素贝叶斯模型（naive Bayes model）**
  - 何时使用：单一原因直接影响多个结果、给定原因时结果近似条件独立（文本分类、垃圾邮件过滤、医学初筛）
  - 如何做：P(Cause, E₁…Eₙ) = P(Cause)·Πᵢ P(Eᵢ|Cause)；推断：对每个原因，先验×各已观测结果条件概率，再归一化；运行时间线性于已观测结果数，未观测变量从计算中完全消失

## 关键概念
- **不确定性（uncertainty）** — 由部分可观测性、非确定性与对抗者导致，智能体无法确知所处状态或动作结局。
- **资格问题（qualification problem）** — 逻辑结论须列举近乎无限的前提条件（车不抛锚、无陨石砸中……），无真正解决方案。
- **惰性／理论无知／实践无知（laziness / theoretical ignorance / practical ignorance）** — 逻辑方法在诊断等领域失败的三个原因。
- **信念度（degree of belief）** — 智能体对语句的数值置信，取值 0（必假）到 1（必真）；概率陈述是关于知识状态而非真实世界的断言。
- **样本空间（sample space）** — 所有可能世界的集合，互斥且穷举；每个世界 ω 有概率 P(ω)∈[0,1]，总和为 1。
- **先验／后验概率（prior / posterior probability）** — 无其他信息下命题的信念度 vs 给定证据 e 后的条件概率 P(a|e)＝P(a∧e)/P(e)。
- **乘积法则（product rule）** — P(a∧b) = P(a|b)P(b)。
- **随机变量（random variable）与联合分布（joint distribution）** — 可能世界到值域的函数；所有变量的完全联合分布 P(X₁,…,Xₙ) 完全确定概率模型（可能世界＝所有随机变量的一种赋值）。
- **柯尔莫哥洛夫公理（Kolmogorov's axioms）** — 0≤P(ω)≤1、ΣP(ω)=1 及由此导出的 P(¬a)=1−P(a)、容斥原理 P(a∨b)=P(a)+P(b)−P(a∧b)。
- **德菲内蒂定理（de Finetti's theorem）** — 违反概率公理的信念集合，对手可构造一组赌注使你无论结果如何必输（Dutch book）。
- **边缘化／求和消元（marginalization / summing out）** — P(Y) = Σ_z P(Y,z)，对无关变量的所有取值求和以消去它们；配套的条件化规则 P(Y) = Σ_z P(Y|z)P(z)。
- **独立性（independence）** — P(a∧b)=P(a)P(b)（亦称绝对／边缘独立）：牙科与气象独立，使联合表分解为小表之积。
- **因果／诊断方向（causal / diagnostic direction）** — P(effect|cause) vs P(cause|effect)；因果知识不随环境先验（如流行病）漂移，更稳健。

## 思维模型
- 把概率断言看作对知识状态的陈述：同一病人"牙痛⇒蛀牙 0.6"与"牙痛且无蛀洞证据⇒蛀牙≈0"并不矛盾——它们条件于不同证据。
- 当知道 P(效果|原因) 而需要 P(原因|效果) 时，用贝叶斯法则做方向翻转。
- 把独立性／条件独立性断言看作联合分布的因子化：32 条目的大表＝8 条目表×4 条目表；n 次独立抛硬币的 2^n 表＝n 个单变量分布之积。
- 把直接原因看作分隔器：Cavity 分隔 Toothache 和 Catch——给定原因，效果彼此无关。
- 把归一化 α 当捷径：先算各假设的相对权重，再除以总和，可跳过难求的证据先验 P(toothache)。

## 反模式
- **用命题逻辑写诊断规则（Toothache ⇒ Cavity）**：三种无知使正确规则的前提列表近乎无限长；且逻辑无法在"保证成功的规划不存在"时比较规划优劣。
- **持有违反概率公理的信念**（如 P(a)=0.4, P(b)=0.3, P(a∨b)=0.8）：Dutch book——对手下注 4/3/2 美元即保证你每场必输；de Finetti/Cox/Carnap/Jaynes 证明概率是满足一致性公理的唯一信念演算。
- **把朴素贝叶斯的独立假设当真**："first quarter"等短语使词间独立明显不成立，后验会比真实更接近 0 或 1（过度自信）；排序常仍可用，但概率值要紧时（是否做阑尾切除）应改用更强模型。
- **直接使用诊断方向统计**：脑膜炎爆发时 P(s) 上升而 P(s|m)=0.7 不变——只有用因果知识＋贝叶斯重算的系统才能正确更新。
- **给未见过的单词赋概率 0**：一次乘法即抹去式 (12-21) 中的全部其他证据；应保留小份额给"未见"事件。
- **指望完全联合分布做实用推断**：n=100 布尔变量需 2^100 条目表，估计每个概率所需样本量更是天文数字。

## 算法要点
- **枚举推断（由完全联合分布）**：
  ```
  给定查询变量 X、证据 E=e、其余未观测变量 Y：
  对 X 的每个取值 xᵢ：
      Q(xᵢ) ← Σ_y P(X=xᵢ, e, y)     // 对 Y 所有取值组合求和
  return α·Q                         // α = 1/ΣᵢQ(xᵢ)，归一化
  ```
  复杂度：O(2^n) 空间的表＋O(2^n) 时间——不可扩展，仅作理论基础。
- **贝叶斯＋归一化（脑膜炎例）**：P(m|s) = 0.7×(1/50000)/0.01 = 0.0014；或 P(M|s) = α·〈0.7×(1/50000), P(s|¬m)P(¬m)〉，无须估计 P(s)。
- **合并证据（条件独立化简）**：
  P(Cavity | toothache ∧ catch) = α · P(Cavity)·P(toothache|Cavity)·P(catch|Cavity)
  ——信息需求降为：查询变量先验＋每条证据的因果条件概率（O(n) 而非 O(2^n)）。
- **wumpus 世界化简求和**：把未知方格分为 frontier（与已访问方格相邻者，[2,2]、[3,1]）与 other（其余 10 个）；给定 known、query、frontier，微风观测条件独立于 other ⇒ 对 other 求和恒为 1，求和项从 2¹²=4096 降到 4；再对与已知一致的逻辑模型枚举加权。

## 参考表
概率公理与推理规则：

| 名称 | 公式 |
|---|---|
| 概率公理 | 0 ≤ P(ω) ≤ 1；Σ_ω P(ω) = 1 |
| 命题概率 | P(φ) = Σ_{ω⊨φ} P(ω) |
| 否定规则 | P(¬a) = 1 − P(a) |
| 容斥原理 | P(a∨b) = P(a) + P(b) − P(a∧b) |
| 条件概率定义 | P(a\|b) = P(a∧b)/P(b)（P(b)>0） |
| 乘积法则 | P(a∧b) = P(a\|b)P(b) |
| 边缘化 | P(Y) = Σ_z P(Y, z) |
| 条件化 | P(Y) = Σ_z P(Y\|z)P(z) |
| 贝叶斯法则 | P(b\|a) = P(a\|b)P(b)/P(a) |
| （绝对）独立 | P(a\|b) = P(a) ⟺ P(a∧b) = P(a)P(b) |
| 条件独立 | P(X,Y\|z) = P(X\|z)P(Y\|z) |

独立性对复杂度的效果：牙科+气象 32 条目 → 8+4 条目；n 个独立硬币 2^n 条目 → n 条目；给定单原因的 n 个条件独立症状 O(2^n) → O(n)。

## 完整示例
牙痛—蛀洞—探针世界（Toothache、Cavity、Catch；数值与书中式 (12-9) 的计算一致）：

| toothache | catch | cavity | P |
|---|---|---|---|
| T | T | T | 0.108 |
| T | F | T | 0.012 |
| F | T | T | 0.072 |
| F | F | T | 0.008 |
| T | T | F | 0.016 |
| T | F | F | 0.064 |
| F | T | F | 0.144 |
| F | F | F | 0.576 |

- 边缘化：P(cavity) = 0.108+0.012+0.072+0.008 = 0.2（与文中先验一致）。
- 条件查询＋归一化：P(Cavity|toothache) = α〈0.108+0.012, 0.016+0.064〉 = α〈0.12, 0.08〉 = 〈0.6, 0.4〉。
- 合并证据（用条件独立）：P(cavity|toothache∧catch) ≈ 0.108/(0.108+0.016) ≈ 0.87。
- 贝叶斯方向翻转（脑膜炎）：P(s|m)=0.7，P(m)=1/50000，P(s)=0.01 ⇒ P(m|s)=0.0014——强因果迹象≠高后验，因为颈部僵硬的先验远高于脑膜炎的先验。
- wumpus 世界（图 12-5）：每方格布尔变量 Pᵢⱼ（含无底洞，先验 0.2）、已访问方格 Bᵢⱼ（微风）；联合分解 P(b|p)·Π P(pᵢⱼ)；在 [1,2]、[2,1] 察觉微风后：P(P₁,₃|已知) ≈ 0.31，而 P(P₂,₂|已知) ≈ 0.86——逻辑只说"[2,2] 未知"，概率说"避开 [2,2]"。

## 要点
1. 概率是关于知识状态的断言：诊断中真实世界并无不确定性（病人或有或无蛀洞），变的是证据条件。
2. 逻辑与概率本体论承诺相同（世界由事实构成），认识论承诺不同（真/假/不评价 vs 0–1 信念度）。
3. 理性＝MEU：效用可解释任意（含利他）偏好集合；选动作既看目标重要性也看实现概率。
4. 违反公理必被 Dutch book 剥削——概率公理不是约定而是理性的必然。
5. 枚举推断 O(2^n)，不可扩展；完全联合分布是理论基座，实用系统靠独立性分解。
6. 存因果方向 P(effect|cause)：诊断统计在先验漂移（流行病）时失效，因果知识稳健——这是概率系统在真实世界可行的关键。
7. 朴素贝叶斯线性于证据数、未观测变量自动"消失"；文本分类中先验取类频、P(HasWord|class) 取词频，排序可靠但概率值过自信。
