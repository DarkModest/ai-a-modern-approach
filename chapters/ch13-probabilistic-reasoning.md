# 第13章 概率推理 (Probabilistic Reasoning)

## 核心思想
贝叶斯网络用"每个变量只直接依赖少数父节点"的局部结构，把指数规模的联合分布压缩为条件概率的乘积，并在其上做精确推断（变量消元）或近似推断（采样）；因果方向的箭头还进一步区分了"观察到"与"干预"。

## 框架
- **贝叶斯网络 (Bayesian network)**
  - 何时使用：域是局部结构化（稀疏）的，即每个变量只被少量变量直接影响
  - 如何做：有向无环图 + 每节点条件概率表（CPT）；语义为 P(x₁,…,xₙ) = Πᵢ P(xᵢ | Parents(Xᵢ))。按拓扑序逐个添加节点，每个节点只选"直接因果影响"它的前驱作父节点
- **变量消元 (variable elimination)**
  - 何时使用：精确计算后验 P(X|e)，网络树宽较小时
  - 如何做：把联合分布写成因子（以变量为索引的矩阵）乘积；按消元顺序反复执行"取所有含变量 Z 的因子→逐点相乘→对 Z 求和→存为新因子"；贪心排序：每次消去使新因子最小的变量；先删除与查询无关的叶变量
- **D-分离 (d-separation)**
  - 何时使用：判定给定 Z 时 X 是否条件独立于 Y
  - 如何做：① 取 X、Y、Z 及其祖先的祖先子图；② 连接共享子节点而无连边的节点对（道德化）；③ 去掉箭头方向；④ 若 Z 阻塞所有 X–Y 无向路径，则 X ⊥ Y | Z
- **似然加权 (likelihood weighting)**
  - 何时使用：证据多在采样顺序"上游"时的近似推断
  - 如何做：固定证据值，按拓扑序采样非证据变量；每个样本权重 = Π P(eᵢ | Parents(Eᵢ))（证据似然之积），按权重归一化计数
- **吉布斯采样 / 马尔可夫链蒙特卡罗 (Gibbs sampling / MCMC)**
  - 何时使用：证据多在"下游"、或精确推断不可行
  - 如何做：状态 = 全变量赋值（证据固定）；每步选一个非证据变量，按其马尔可夫毯分布 P(Xᵢ|mb(Xᵢ)) ∝ P(Xᵢ|Parents(Xᵢ))·Π_child P(child | Parents(child)) 重采样；链的平稳分布即真实后验
- **因果网络与 do 演算 (causal network & do-operator)**
  - 何时使用：要预测干预（动作）的效果而非观察的效果
  - 如何做：do(Xⱼ=x) = 从图中删除指向 Xⱼ 的所有箭头（"残缺图"）再条件化；调整公式对 Xⱼ 父节点加权求和；后门准则用可观测集 Z（d-分离后门路径）替代不可观测的父节点

## 关键概念
- **条件概率表 (conditional probability table, CPT)** — 每个条件事件（父节点值组合）下一行条件概率；k 个布尔父节点需 2ᵏ 个独立参数
- **链式法则 (chain rule)** — 联合分布恒可写成条件概率连乘；贝叶斯网络是它的最简形式
- **马尔可夫毯 (Markov blanket)** — 变量的父节点+子节点+子节点的其他父节点；给定它，变量条件独立于网络中所有其他节点
- **多重树 (polytree)** — 任意两节点间至多一条无向路径（单连通）；精确推断时间空间均线性于网络规模
- **噪声或 (noisy-OR)** — 各原因的抑制相互独立时，子为假的概率 = 为真父节点抑制概率之积；用 O(k) 参数代替 O(2ᵏ)
- **混合贝叶斯网络 (hybrid Bayesian network)** — 同时含离散与连续变量；用线性高斯 (linear-Gaussian)、条件高斯 (CG)、probit/expit 软阈值等正则分布
- **逐点乘积 (pointwise product)** — 两因子的公共变量取值一致时元素相乘，得到变量并集上的新因子；其规模是消元复杂度的来源
- **细致平衡 (detailed balance)** — π(x)k(x,x′)=π(x′)k(x′,x)；蕴涵平稳性，是吉布斯与 Metropolis-Hastings 正确性的证明核心
- **遍历 (ergodic)** — 每个状态从其他状态可达且无周期；CPT 无 0/1 概率时吉布斯链遍历
- **结构方程 (structural equation)** — xᵢ = fᵢ(父变量, 扰动 Uᵢ)；描述对局部干预不变的机制，是 do 演算的基础
- **后门准则 (back-door criterion)** — 找集合 Z 阻塞 Xⱼ 到 Xᵢ 的后门路径，使干预效果可用观察数据估计（反驳"只有随机对照试验才能给因果信息"）

## 思维模型
- 当变量有因果方向时，把箭头从原因画向结果：因果序的网络最紧凑、参数最易从专家获取（诊断方向的判断不自然）
- 把贝叶斯网络看作"条件独立性声明 + 局部条件概率"的集合，而不是一张巨型联合表
- 看到重复子表达式就动态规划存中间因子——枚举与变量消元的全部差别仅此而已
- 把 MCMC 想象成在状态空间随机游走：走得够久，访问状态的频率即后验概率
- 把 do 看作外科手术：观察不改变图，干预切掉箭头

## 反模式
- **逐项枚举联合分布 / 忽略条件独立性**：n=30 布尔变量需 2³⁰≈10 亿个数值；每节点 5 个父节点的贝叶斯网络只需 960 个
- **按诊断方向（果→因）排序节点**：入室盗窃网络因果序需 10 参数，M,J,A,B,E 序需 13，M,J,E,B,A 序需 31（等于完全联合分布），且部分链路关系脆弱难评估
- **对多证据问题用拒绝采样**：接受率 = P(e)，随证据数指数下降（保险网络仅 1/1000–1/10000）；连续证据的接受概率为 0
- **似然加权用于下游证据**：非证据变量的祖先中无证据时，样本与证据几乎无关，权重全面坍缩
- **对（近似）确定性依赖用吉布斯采样**：Cloudy↔Rain 确定相关时遍历性破坏，链困在两个状态之一，永远报〈1.0, 0.0〉或〈0.0, 1.0〉；需块采样或 MH 重启
- **用"以证据为条件"回答干预问题**：观测 Sprinkler=true 会提高对 ¬Cloudy 的信念，而 do(Sprinkler=true) 不影响天气

## 算法要点

枚举推理（ENUMERATION-ASK，深度优先计算嵌套求和）：
```
ENUMERATE-ALL(vars, e):
  若 vars 空: 返回 1.0
  Y ← vars 首变量
  若 Y 为证据 (=y): 返回 P(y|Parents(Y)) × ENUMERATE-ALL(rest, e)
  否则: 返回 Σ_y P(y|Parents(Y)) × ENUMERATE-ALL(rest, e ∪ Y=y)
对 X 每个值调用上式得 Q(x)，返回 NORMALIZE(Q)
```
时间 O(2ⁿ)、空间 O(n)；关键改进：求和尽量内移（利用因子只依赖少数变量）。

变量消元（VE）：
```
F ← 所有变量的 CPT 因子（证据值代入）
删除与查询无关的变量（反复剪非查询/非证据叶节点）
for 每个隐变量 Z（按消元顺序）:
    F_Z ← F 中含 Z 的因子
    F ← F \ F_Z ∪ { Σ_Z Π F_Z }
返回 F 剩余因子逐点相乘后归一化
```

吉布斯采样（GIBBS-ASK）：
```
随机初始化状态 x（证据固定）
重复 N 次:
    均匀选非证据变量 Zᵢ
    按 P(Zᵢ|mb) ∝ P(Zᵢ|Parents(Zᵢ)) × Π_{c∈children(Zᵢ)} P(c|Parents(c)) 重采样
    计数当前状态的 X 值
返回 NORMALIZE(计数)
```
每步代价只与 Zᵢ 的子节点数和值域大小成比例，与网络规模无关。

D-分离判定：祖先子图 → 道德化 → 无向化 → 检查 Z 是否阻塞所有路径（见框架节）。

Metropolis-Hastings：从提议分布 q(x′|x) 采样新状态，以概率 min(1, [π(x′)q(x|x′)]/[π(x)q(x′|x)]) 接受否则保持；任意遍历提议均保证收敛；吉布斯是接受率为 1 的 MH 特例。π 只以比率出现 → 用联合概率（CPT 乘积）之比计算，未变变量各项自动消去。

## 参考表

| 算法 | 类型 | 时间 | 主要限制 |
|---|---|---|---|
| 枚举 | 精确 | O(2ⁿ) | 保险网络单查询约 2.27 亿次运算 |
| 变量消元 | 精确 | 多重树线性；一般网络由最大中间因子决定（最坏指数） | 消元顺序难优化（贪心启发式） |
| 聚类/连接树 | 精确 | 全部节点 O(n) | 大节点（meganode）CPT 指数规模 |
| 拒绝采样 | 近似 | 误差 ∝ 1/√N | 受接受率 P(e) 限制，多证据失效 |
| 似然加权 | 近似 | 误差 ∝ 1/√N | 下游证据导致权重坍缩 |
| 吉布斯/MCMC | 近似 | 每步与网络规模无关 | 混合速率依赖 CPT；确定性依赖破坏遍历性 |

复杂度根基：贝叶斯网络推断含 3-SAT 为特例，NP 困难；由可满足赋值计数可归约，进而 #P 困难。反向归约到加权模型计数（WMC）可借用 SAT 求解器，在大树宽网络上常胜过专用精确算法。树宽（tree width）同时支配 CSP 与贝叶斯网络的推断难度。

## 完整示例

入室盗窃网络：Burglary B → Alarm A ← Earthquake E；A → JohnCalls J；A → MaryCalls M。
CPT：P(B)=⟨0.001, 0.999⟩，P(E)=⟨0.002, 0.998⟩；P(a|b,e)=0.95，P(a|b,¬e)=0.94，P(a|¬b,e)=0.29，P(a|¬b,¬e)=0.001；P(j|a)=0.90，P(j|¬a)=0.05；P(m|a)=0.70，P(m|¬a)=0.01。

联合条目示例：
P(j, m, a, ¬b, ¬e) = 0.999 × 0.998 × 0.001 × 0.90 × 0.70 ≈ 0.000628。

查询 P(B | j, m)（两邻居都来电话，求盗窃概率）：
- 枚举法：将求和内移为嵌套表达式（对 E、A 求和的树），自底向上计算得 P(B|j,m) = α⟨0.00059224, 0.0014919⟩ ≈ **⟨0.284, 0.716⟩**——即使两人都打电话，盗窃概率也只有约 28%。
- 变量消元同一查询：f₁(B)=P(B)，f₂(E)=P(E)，f₃(A,B,E)=P(A|B,E)，f₄(A)=⟨0.90, 0.05⟩（J=true 代入），f₅(A)=⟨0.70, 0.01⟩（M=true 代入）。
  ① 消 A：f₆(B,E) = Σ_A f₃·f₄·f₅（2×2 因子）；② 消 E：f₇(B) = Σ_E f₂·f₆；③ 答案 = α f₁·f₇。

节点顺序实验（同一联合分布的三种表示）：因果序 B,E,A,J,M → 10 个参数；M,J,A,B,E → 13 个；M,J,E,B,A → 31 个（与完全联合分布相同）。

## 要点
1. 构建网络的顺序：先定变量集并按因果序排列，再为每个节点选最小父节点集——保证无环、无冗余、最紧凑。
2. k 个布尔父节点的 CPT 需 2ᵏ 参数；噪声或、确定性节点、CSI 可压到 O(k)（CPCS 网络：448 节点 906 链路，8254 参数 vs 完整 CPT 的 1.34 亿）。
3. 精确推断看结构：多重树线性；多连通网络最坏指数且 #P 困难。保险网络上变量消元（逆拓扑序）比枚举快约 1000 倍。
4. 采样方法选型看证据位置：证据在上游用似然加权，在下游用吉布斯/MCMC（信息可从证据向各方向传播）。
5. 马尔可夫毯是局部采样的全部所需：重采样一个变量只用到它自己及其子节点的 CPT 行。
6. 干预 ≠ 观察：do(Xⱼ=x) 删除 Xⱼ 的入弧，效果只沿后代传播；调整公式 P(Xᵢ|do(Xⱼ=xₖ)) = Σ_parents P(Xᵢ|xₖ, parents) P(parents) 可由标准推断算法算出。
7. 把网络编译成模型特定采样代码，比通用图操作快 2–3 个数量级（每秒数千万采样步）。
