# 第20章 概率模型学习 (Learning Probabilistic Models)

## 核心思想
把学习本身表述为概率推断：数据是证据，假设（或参数）有先验分布；对全部假设按后验概率加权预测的贝叶斯学习是最优的，实践中退化为 MAP 或最大似然；当模型含隐变量时，用期望最大化（EM）算法求局部最大似然解。

## 框架
- **贝叶斯学习（Bayesian learning）**
  - 何时使用：需要最优预测、假设空间不大或求和/积分可算时
  - 如何做：P(h_i|d) ∝ P(d|h_i)P(h_i)（式20-1）；预测 P(X|d)=Σ_i P(X|h_i)P(h_i|d)（式20-2）——对所有假设加权平均，只要真实假设先验不为 0，其后验终将胜出
- **最大后验/最大似然学习（MAP / Maximum Likelihood）**
  - 何时使用：贝叶斯求和不可行时的标准近似
  - 如何做：MAP 取 argmax P(d|h)P(h)，对数形式 −log P(d|h)−log P(h) 即"描述数据的位数+描述假设的位数"（MDL），天然体现奥卡姆剃刀；先验均匀时退化为最大似然 argmax P(d|h)。数据量大时三者趋同，小数据时先验（正则化）至关重要
- **完全数据最大似然参数学习（ML Parameter Learning, complete data）**
  - 何时使用：每个数据点含模型全部变量的观测值（密度估计的无监督形式）
  - 如何做：三步法——写似然→取对数、对每个参数求导→解零点。对表格 CPT 的贝叶斯网络：学习分解为每参数一个独立问题，解即"给定父节点取值下该变量取值的观测频率"
- **贝叶斯参数学习（Bayesian Parameter Learning，共轭先验）**
  - 何时使用：小数据集、要避免"未观测事件概率=0"、需要参数的不确定度
  - 如何做：布尔参数 θ 用 Beta(a,b) 先验；观测到一次成功只需 a←a+1（失败 b←b+1），后验仍是 Beta（封闭性=共轭）。把 a、b 当作"虚拟计数"；参数间假设先验独立，学习变为派生贝叶斯网络上的推断（可用 MCMC 近似）
- **EM 算法（Expectation-Maximization）**
  - 何时使用：模型含隐变量（隐疾病、混合分量、HMM 状态）且数据不完整
  - 如何做：E 步用当前参数推断每个隐变量的后验（期望计数）；M 步把期望计数当作真实观测重估参数（同完全数据公式）。每轮迭代似然不减，收敛到局部极大
- **结构学习与非参数密度估计（Structure Learning / Nonparametric Density Estimation）**
  - 何时使用：网络结构未知 / 不愿假设任何参数化形式
  - 如何做：结构=离散搜索（爬山/模拟退火，加/删/反转边）+ 复杂度惩罚（纯最大似然必得全连接网络）；或用 MCMC 采样结构。非参数密度用 k 近邻（固定 k 变球体积）或核函数（固定带宽叠高斯丘），k/w 由交叉验证定

## 关键概念
- **似然（likelihood）** — P(d|h_i)：在假设 h_i 下观测到数据 d 的概率，连接数据与假设的核心量。
- **最大后验假设（MAP hypothesis）** — 使后验 P(h|d) 最大的单个假设，用它替代全假设加权平均做预测。
- **最大似然假设（ML hypothesis）** — 使 P(d|h) 最大的假设，等价于均匀先验的 MAP。
- **密度估计（density estimation）** — 从数据学习生成它们的概率模型的一般任务，属无监督学习。
- **完全数据（complete data）** — 每个数据点都含模型所有变量的值，使最大似然有闭式条件频率解。
- **生成式 vs 判别式模型（generative vs discriminative model）** — 前者建模联合分布 P(y,x)（朴素贝叶斯）可采样可"生成"；后者只学 P(y|x) 或决策边界（逻辑斯谛回归、决策树、SVM）。小数据生成式常占优，大数据判别式占优（Ng & Jordan：15 个小数据集中 14 个生成式更好）。
- **共轭先验（conjugate prior）** — 与似然结合后后验仍属同族 的先验族；类似的还有狄利克雷（离散多元）、正态-威沙特（高斯）。
- **虚拟计数（virtual count）** — Beta(a,b) 超参数的解读：等价于已"虚拟"观测 a−1 次成功、b−1 次失败。
- **无信息先验（uninformative prior）** — 对参数无想法时取均匀 Beta(1,1) 或大方差高斯。
- **隐变量（hidden / latent variable）** — 数据中未观测但影响观测的变量（如 HeartDisease）；能大幅减少参数（心脏病网：78 vs 708）。
- **混合高斯（mixture of Gaussians）** — P(x)=Σ_i P(C=i)·N(x;μ_i,Σ_i)，无监督聚类假设的分布族。
- **可辨识性（identifiability）** — 能否从观测分布唯一复原模型：两属性糖果混合不可辨识；三属性可辨识但两袋互换仍等价。
- **非参数密度估计（nonparametric density estimation）** — 不假设参数化形式，用 k 近邻球或核叠加直接从数据估密度。

## 思维模型
- 把学习看作推断：构造"派生贝叶斯网络"——把参数 θ 当作节点、把每条数据当作证据，学习就只剩一种算法——贝叶斯网络推断。
- 把先验看作虚拟数据：Beta(a,b) 等价于"开局先假装见过 a−1 次樱桃、b−1 次酸橙"，因此小样本不会被单次观测带偏。
- 把最小二乘看作高斯最大似然：y=wx+ε(方差固定) 时，最大化似然 ⇔ 最小化 Σ(y−wx)²；第19章的 L2 回归由此获得概率解释。
- 把 EM 看作"鸡生蛋"循环：知道分量归属就能估参数（M），知道参数就能算归属概率（E）；两边都不知道时，从任意初始化出发交替"补全数据—重估参数"。
- 把贝叶斯线性回归的预测方差看作"杠杆"：数据离原点越远对斜率约束越强，外推预测的不确定度随 |x| 线性增长。

## 反模式
- **小数据 + 纯最大似然**：观测到 1 颗樱桃糖就断言袋中 100% 是樱桃（θ̂=1）；未出现的事件概率被置 0——用先验/虚拟计数（计数初始化为 1）修正。
- **结构学习只用最大似然评分**：加父节点似然只增不减，必得全连接网络；必须加 MAP/MDL 复杂度惩罚或用 MCMC。
- **EM 退化解**：某分量收缩到单点使方差→0、似然→∞；两分量均值重合"合并"；对称初始化落入坏的局部极大——对策：随机初始化、参数先验（MAP 版 EM）、重置过小/过近分量。
- **不可辨识还硬学**：隐变量模型参数可能本质不唯一（两袋互换等价），别指望 EM 恢复"真"标签。
- **非参数密度估计的 k/核宽拍脑袋**：k 太小过尖、太大过平；核宽同理——必须交叉验证。
- **HMM 的 EM 用滤波而非平滑计数**：转移计数的期望需要给定全部证据（含转移之后的事件）的后验，即前向-后向平滑。

## 算法要点
**最大似然参数学习三步法（以糖果比例 θ 为例）**
```
似然:  P(d|θ) = θ^c·(1−θ)^ℓ              # c 颗樱桃、ℓ 颗酸橙
对数:  L = c·log θ + ℓ·log(1−θ)
求导置零: ∂L/∂θ = c/θ − ℓ/(1−θ) = 0  ⟹  θ_ML = c/N
推广: 带包装的模型 P(W|R)̂= 对应条件观测频率；表格 CPT 的每个参数独立求解
```

**贝叶斯参数更新（Beta 共轭）**
```
先验 θ ~ Beta(a,b)；观测一颗樱桃: 后验 ~ Beta(a+1,b)（酸橙则 b+1）
大样本极限收敛到与 ML 相同的值；均值为 a/(a+b)，a+b 越大峰越尖（越确定）
```

**EM 一般形式**
```
repeat:
  E步: θ^(t+1) ← argmax_θ E_{Z~P(Z|x,θ^(t))} [log P(x,Z|θ)]   # 隐变量后验下的"完整数据"对数似然期望
  M步: 用期望计数当作真实计数，按完全数据公式重估 θ
until 收敛（每轮对数似然不减；收敛到局部极大/鞍点）
E步可近似：MCMC 采样状态当完整观测、变分法、循环信念传播 → 仍有效的学习算法
```

**EM 用于混合高斯（无监督聚类）**
```
初始化 π_i, μ_i, Σ_i（任意/随机，注意对称陷阱）
E步: p_ij = π_i·N(x_j; μ_i,Σ_i) / Σ_k π_k·N(x_j; μ_k,Σ_k)    # x_j 属于分量 i 的后验
     N_i^eff = Σ_j p_ij                                        # 分量 i 的有效点数
M步: μ_i ← Σ_j p_ij x_j / N_i^eff；π_i ← N_i^eff/N；
     Σ_i ← Σ_j p_ij (x_j−μ_i)(x_j−μ_i)^T / N_i^eff
分量个数 k 未知时尝试多个 k 比较；退化分量重置或加先验
```

**EM 用于带隐变量的贝叶斯网络 / HMM**
```
贝叶斯网络: CPT 参数 θ_ijk ← E[计数(x_i=k, Pa=i)] / E[计数(Pa=i)]，期望由任意推断算法给出，且只需局部后验（仅涉及 X_i 及其父节点）
HMM: 转移概率 θ_ij ← E[状态 i→j 转移次数] / E[处于状态 i 次数]；计数期望由前向-后向算法（平滑）计算
```

## 参考表
贝叶斯 / MAP / 最大似然三种准则：

| 准则 | 选择/预测 | 先验作用 | 计算代价 | 小数据行为 |
|---|---|---|---|---|
| 贝叶斯学习 | 预测=Σ_h P(X\|h)P(h\|d)（全假设加权） | 全程使用，最优预测 | 大求和/积分，常不可行 | 最优，天然抗噪声/过拟合 |
| MAP | 单个 argmax P(d\|h)P(h) | 正则化：惩罚复杂假设 | 一个优化问题 | 近似贝叶斯；体现奥卡姆剃刀（一致假设中最简者） |
| 最大似然 | 单个 argmax P(d\|h) | 无（均匀先验） | 通常最易 | 危险：未观测事件概率→0 |

完全数据 vs 隐变量学习：

| | 完全数据 | 隐变量（EM） |
|---|---|---|
| 参数解 | 条件频率，闭式、可分解 | 迭代，E/M 交替，局部极大 |
| 结构学习 | 独立性检验或 MDL 惩罚 | 结构 EM：用当前结构算期望计数再评新结构 |
| 推断需求 | 无 | 每轮需后验推断（可 MCMC/变分近似） |

## 完整示例
**糖果袋贯穿例（贝叶斯→ML→贝叶斯参数→EM）**：5 种袋子 h1…h5（樱桃占比 100/75/50/25/0%），先验 ⟨0.1,0.2,0.4,0.2,0.1⟩。逐颗打开糖果观测口味，i.i.d. 下似然 P(d|h_i)=∏ P(D_k|h_i)。连续观测 10 颗酸橙糖：后验从 h3 最大→2 颗后 h4 最大→3 颗后 h5 最大→10 颗后近乎确定；对下一颗的贝叶斯预测 P(lime|d) 单调升并渐近 1，而 MAP 学习器在 3 颗后即给出激进的 1.0（贝叶斯为 0.8），数据增多两者趋同。

比例完全未知时改用连续参数 θ（樱桃占比）：ML 解 θ̂=c/N。加 Beta(a,b) 先验后，观测只是递增虚拟计数，后验峰随数据变窄、收敛到真值。再引入包装变量（红/绿依概率依赖口味），ML 解为各条件频率，问题自动分解。

EM 版本：两袋糖果混合（隐变量=袋子），观测口味/包装/夹心 3 属性的 8 类计数（如 cherry·red·holes=273，lime·green·无夹心=167，共 1000 颗）。初始 π=θ_F1=θ_W1=θ_H1=0.6（余 0.4）。E 步对每类计数算归属袋 1 的后验，如 P(bag1|cherry,red,holes) = 0.6⁴/(0.6⁴+0.4⁴) ≈ 0.83；据此累加得袋 1 的期望糖果数与各属性期望计数。M 步按频率重估全部 7 个参数。对数似然从 −2044 →（1 轮）−2021 →（10 轮）−1982，超过真模型的拟合度；10 轮后进展放缓，实践常在末段换牛顿法等基于梯度的方法加速。两属性版本只有 3 个自由计数对 5 个参数，不可辨识。

## 要点
1. 学习=概率推断：贝叶斯预测对所有假设加权，是给定先验下的最优预测；MAP/ML 是可处理的近似，数据充分时三者等价。
2. 完全数据 + 表格 CPT ⟹ 最大似然=条件频率，且按参数完全分解——这是朴素贝叶斯高效训练的基础（n 个布尔属性仅需 2n+1 个参数、零搜索，但条件独立假设在属性多时会给出过度自信的 0/1 概率）。
3. 最小二乘回归 = 固定方差高斯噪声的最大似然；贝叶斯线性回归额外给出斜率后验与随外推距离增长的预测方差——点估计给不了的不确定度。
4. MAP 的对数形式 −log P(d|h)−log P(h) 就是 MDL：先验以位数计价，奥卡姆剃刀由概率自动兑现。
5. EM 的通用配方：明确定义隐变量（混合指示 Z_ij / 网络缺失变量 / HMM 状态），E 步算期望计数，M 步按完全数据公式重估；似然单调不减。
6. 生成式与判别式之别是建模选择而非对错：小数据要生成式啃数据效率，大数据要判别式直击决策边界。
7. 隐变量能压缩参数（78 vs 708），但引入可辨识性与局部极大问题；结构学习离不开复杂度惩罚。
