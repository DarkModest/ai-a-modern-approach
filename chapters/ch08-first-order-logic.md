# 第8章 一阶逻辑 (First-Order Logic)

## 核心思想
一阶逻辑（FOL，亦称一阶谓词演算）在命题逻辑之上引入**对象、关系与量词**，使"所有国王都是人""与无底洞相邻的方格有微风"这类一般规律可以用一条而非一百万条语句简洁表达。它的表达能力来自本体论约定——世界由对象及对象间关系组成。

## 框架
- **一阶逻辑语法（FOL syntax：项—原子—复合—量化语句）**
  - 何时使用：需要指代对象、表达对象间关系或对全体/部分对象做断言时
  - 如何做：常量符号命名对象；函数符号构成复合项（仍是对象的名称，不是子程序调用）；谓词符号 + 参数构成原子语句；再用命题联结词与量词 ∀/∃ 组合
- **一阶逻辑语义（model / domain / interpretation）**
  - 何时使用：判定语句在模型中的真值、理解蕴含为何不可枚举检验时
  - 如何做：模型 = 非空对象集（域）+ 解释（把常量映射到对象、谓词映射到关系（元组集）、函数映射到全函数）；原子为真当且仅当参数所指对象组成的元组落在谓词所指关系中；量化语句用**扩展解释（extended interpretation）**逐对象验证
- **数据库语义（database semantics）**
  - 何时使用：已知全部对象与事实、要让"列出的事实即全部事实"直白成立时（数据库、逻辑编程）
  - 如何做：叠加三个假设——唯一名称假设（每个常量指代唯一对象）、封闭世界假设（未知原子为假）、域闭包（域元素不多于常量所指）；模型数从天文数字降为有限
- **知识工程过程（knowledge engineering，7 步法）**
  - 何时使用：为特定论域（电路、wumpus、亲属关系）构建专用知识库
  - 如何做：①确定问题范围 ②收集相关知识 ③确定谓词/函数/常量词汇表（形成本体论 ontology）④编码通用公理 ⑤编码问题实例 ⑥提出查询取答案 ⑦调试评估（缺失公理表现为推理链意外中断）

## 关键概念
- **合成性（compositionality）** — 语句含义是其各部分含义的函数；这是好的表示语言的必要性质。
- **本体论约定（ontological commitment）** — 逻辑对真实世界性质的假设：命题逻辑只假设事实存在；一阶逻辑假设对象与关系存在；模糊逻辑假设真实度（degree of truth）在 0 与 1 之间。
- **认识论约定（epistemological commitment）** — 每个事实允许的知识状态：命题/一阶逻辑只有真、假、未知三态；概率论允许 0–1 的信任度（degree of belief）——与模糊逻辑的真实度不可混淆。
- **项（term）** — 指代对象的逻辑表达式：常量、变量或函数符号作用于项；不含变量的项称基本项（ground term）。
- **原子语句（atomic sentence）** — 谓词符号后接括号内一列项；或用等词 t₁=t₂ 表示两项指代同一对象。
- **全称量词（∀）/存在量词（∃）** — ∀x P 在 P 对域中每个对象的扩展解释均为真时为真；∃x P 在至少一个扩展解释下为真时为真；∃! 表示"恰好存在一个"。
- **解释（interpretation）与预期解释（intended interpretation）** — 模型中固定所有符号指代物的映射；排除与预期不符的模型是知识库的职责（如同命题逻辑允许 Cloudy 与 Sunny 同真）。
- **语法糖（syntactic sugar）** — 中缀记法（m+0）、量词折叠（∀x,y 代替 ∀x∀y）、列表记法 [A,B,C] 等；可"脱糖"为标准一阶逻辑而不改语义。
- **公理与定理（axiom / theorem）** — 公理是直接给出的语句（可以是定义、部分刻画或直白事实）；定理是被公理蕴含的语句，存入 KB 只为省去重复推导。
- **置换/绑定表（substitution / binding list）** — AskVars 对量化查询返回的变量赋值集合，如 {x/John}。

## 思维模型
- **∀ 配 ⇒，∃ 配 ∧**：全称量词用蕴涵只对满足前提的对象断言结论（非国王的对象自动为真）；存在量词用合取确保各分句谈同一对象。反过来 ∀x(King(x)∧Person(x)) 断言万物皆为国王（过强），∃x(Krown(x)⇒…) 被任何不满足前提的对象弄真（过弱、等于什么都没说）。
- **把模型看作"对象集 + 一张解释表"**：理查/约翰模型的 5 个对象、兄弟关系元组集 {〈理查,约翰〉,〈约翰,理查〉}、左腿函数——一阶模型比命题真值赋值丰富得多，因此蕴含无法靠枚举模型检验（≤6 个对象就有 1375 亿个模型）。
- **量词顺序就是语义**：∀x∃y Loves(x,y)（每个人都有所爱）≠ ∃y∀x Loves(x,y)（有人被所有人爱）；嵌套时始终用不同变量名——变量属于提及它的最内层量词。
- **谓词还是函数看"输出个数"**：每人恰有一条左腿 → 用函数 LeftLeg(x)；可能没有或多个 → 用谓词。对象需要指名（wumpus 唯一）用常量，无需区分个体（每个无底洞）用谓词。

## 反模式
- **量词配错联结词**：∀x(King(x)∧Person(x)) 会断言理查的左腿也是国王；∃x(Crown(x)⇒OnHead(x,John)) 只要存在一个非王冠对象即为真——最常见的翻译错误。
- **用 ∃x∃y 分开表达"至少两个"却忘了不等**：∃x,y Brother(x,Richard)∧Brother(y,Richard) 在 x、y 绑定同一对象时也为真；必须加 x≠y。同理"理查的兄弟恰是约翰和杰弗里"需要否定其余并逐一列举，或改用数据库语义。
- **在嵌套量词中复用变量名**：∀x∃x Brother(Richard,x) 中外层 ∀x 是无效装饰，内层量词独占该变量。
- **以为存在"正确的"语义**：标准语义与数据库语义各有适用面；对象身份与全部事实已知时数据库语义直白，否则会把未知误当为假。
- **谓词无完整定义就放弃**：Person 无法被完整定义，但一阶逻辑允许只写部分公理（∀x Person(x)⇒…）；强求定义是没必要的。

## 算法要点
**语法构成（BNF 意义下）**：
```
语句 ::= 原子 | 复合
原子 ::= Predicate(项,...) | 项 = 项
复合 ::= (语句) | ¬语句 | 语句∧语句 | ∨ | ⇒ | ⇔
        | ∀变量 语句 | ∃变量 语句
项 ::= 常量 | 变量 | Function(项,...)
```
运算符优先级从高到低：¬、∧、∨、⇒、⇔；量词优先级高于其右侧一切。

**语义求值**：
- 项 f(t₁,…,tₙ)：在解释下各项指代对象 d₁,…,dₙ，项的指代物 = 函数 F 的值 F(d₁,…,dₙ)
- 原子 P(t₁,…,tₙ)：真 ⇔ 〈d₁,…,dₙ〉 ∈ 谓词所指的关系元组集
- ∀x P：对每个域元素 d 的扩展解释（x→d）下 P 均真；∃x P：至少一个为真
- 函数须为全函数（无左腿之物用"不可见对象"补齐——技术细节，不影响无断言时的推理）

**量词等价式与常规转换（德摩根式的对偶）**：
- ¬∀x P ≡ ∃x ¬P；¬∃x P ≡ ∀x ¬P
- ∀ 与 ∃ 只需保留其一（如 ∧∨ 之于德摩根律），但为了可读性两者都保留
- 连续同类量词可折叠：∀x∀y → ∀x,y

**数据库语义三假设**：唯一名称假设 + 封闭世界假设 + 域闭包 ⇒ "列出的兄弟就是全部兄弟"，模型数从 1375 亿级降到有限组合数（两常量、一个二元关系仅 16 个模型）。

**知识工程 7 步**：见上文框架；调试技巧——推理链意外中断处即缺失/过弱公理；错误公理可独立于 KB 判真伪（如 ∀x,y Brother(x,y)⇒Opposite(x,y) 对桌子不成立）。

## 参考表
形式化语言的两类约定（据图 8-1）：

| 语言 | 本体论约定（世界由什么组成） | 认识论约定（知识状态） |
|---|---|---|
| 命题逻辑 | 事实 | 真 / 假 / 未知 |
| 一阶逻辑 | 对象、关系、函数 | 真 / 假 / 未知 |
| 时态逻辑 | 事实 + 有序时间 | 真 / 假 / 未知 |
| 高阶逻辑 | 关系与函数亦为对象 | 真 / 假 / 未知 |
| 模糊逻辑 | 有真实度的事实 | [0,1] 真实度 |
| 概率论 | 事实 | [0,1] 信任度 |

自然语句到一阶逻辑的标准译法：

| 自然语言 | 一阶逻辑 |
|---|---|
| 所有国王都是人 | ∀x King(x) ⇒ Person(x) |
| 约翰头顶有王冠 | ∃x Crown(x) ∧ OnHead(x, John) |
| 每个人都喜爱一些人 | ∀x∃y Loves(x, y) |
| 有人被所有人喜爱 | ∃y∀x Loves(x, y) |
| 理查至少有两个兄弟 | ∃x,y Brother(x,Richard) ∧ Brother(y,Richard) ∧ x≠y |
| 兄弟关系是对称的（定理） | ∀x,y Sibling(x,y) ⇔ Sibling(y,x) |

## 完整示例
**逐句形式化 + 两大论域公理化**。

亲属关系论域（定义即公理，形如"⇔"）：
- 母亲：∀m,c Mother(c)=m ⇔ Female(m) ∧ Parent(m,c)
- 丈夫：∀h,w Husband(h,w) ⇔ Male(h) ∧ Spouse(h,w)
- 父母-孩子互反：∀p,c Parent(p,c) ⇔ Child(c,p)
- 祖父母：∀g,c Grandparent(g,c) ⇔ ∃p Parent(g,p) ∧ Parent(p,c)
- 兄弟姐妹：∀x,y Sibling(x,y) ⇔ x≠y ∧ ∃p Parent(p,x) ∧ Parent(p,y)

数的论域（皮亚诺公理 Peano axioms）：NatNum(0)；∀n NatNum(n) ⇒ NatNum(S(n))；∀m,n m=n ⇔ S(m)=S(n)；加法由后继定义：∀m NatNum(m) ⇒ +(m,0)=m；∀m,n NatNum(m)∧NatNum(n) ⇒ +(m,S(n))=S(+(m,n))。一个常量、一个函数、一个谓词、四条公理即可长出整个数论。

wumpus 世界（对比第 7 章的百万条命题公理）：
- 感知语句：Percept([Stench,Breeze,None,None,None], 5)（谓词含时间参数）
- 动作查询：AskVars(KB, ∃a BestAction(a,5)) 返回 {a/Grab}
- 相邻不必逐对列举，用复合项定义：∀s₁,s₂ Adjacent(s₁,s₂) ⇔ …（行列为整数）
- 微风公理（命题版 R2/R3 的每方格展开，压缩为一条）：
  ∀s Breezy(s) ⇔ ∃r Adjacent(r,s) ∧ Pit(r)
- 箭的后继状态公理（一个谓词只需一条，而非每时间步一份）：
  ∀t HaveArrow(t+1) ⇔ HaveArrow(t) ∧ ¬Shoot(t)

电子电路论域（7 步法的示范）：词汇表含 Circuit/Gate/Terminal 谓词、Type/In/Out/Signal 函数、Connected 谓词；12 条通用公理刻画连通端子信号相同（∀t₁,t₂ Connected(t₁,t₂) ⇒ Signal(t₁)=Signal(t₂)）、信号只能取 1 或 0、四类门的输入输出行为（如与门输出为 0 ⇔ 任一输入为 0）；实例编码全加器 C₁ 的门与连线；查询"哪些输入使和位为 0、进位为 1"得到三种置换——即**电路验证（circuit verification）**；调试案例：忘写 1≠0 时异或门公理在输入 1、0 下无法化简，系统对输入 10、01 推不出输出。

## 要点
1. FOL 的简洁力来自对象+关系+量词：任意大小、任意时长的 wumpus 世界约 10 条一阶语句，命题逻辑需上亿条。
2. 选语言先看两类约定：本体论约定决定能谈什么（对象？时间？真实度？），认识论约定决定能信什么（三值？概率？）。
3. ∀x(P⇒Q) 的"前提为假即为真"不是缺陷而是特性——它使全称规则只约束满足前提的对象。
4. 标准语义下蕴含不可枚举（模型无穷），推断须走语法证明路线（第 9 章：合一、归结、前向/反向链接）。
5. 数据库语义用三个假设换直白性：适合事实齐全的封闭世界，不适合部分信息推理。
6. 公理分三类：定义（⇔ 形式）、部分刻画（只有 ⇒ 方向）、直白事实；定理可选缓存以省推导成本。
7. 知识工程的核心是第 3 步本体论决策：无底洞是对象还是谓词、朝向是函数还是谓词、位置是否依赖时间——这些风格决定后续公理的成败。
