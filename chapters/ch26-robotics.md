# 第26章 机器人学 (Robotics)

## 核心思想
机器人是运行在连续、高维、部分可观测、随机且不可逆的真实世界中的实体智能体；由于一次性端到端求解 MDP/POMDP 不可行，机器人学的中心方法论是**分层分解**——感知（滤波估计）与运动生成（规划+控制）分离、任务/运动/控制三级分层、人机交互中预测与动作分离——并在每一层用概率推断、图搜索、优化和反馈控制各自击破。

## 框架
- **构形空间（Configuration Space, C-Space）**：所有能确定机器人每个机身点位置的参数构成的空间（二连杆臂即 (θ₁,θ₂)）
  - 何时使用：一切运动规划的统一表述；把"形状各异的刚体避障"化归为"点在 C 空间中避障"
  - 如何做：C_obs = {q : R(q)∩O ≠ ∅}，C_free = C∖C_obs；实践中不显式构建 C_obs，而用碰撞检查器 COLTEST(q) 探测
- **蒙特卡罗定位（Monte Carlo Localization, MCL）**：粒子滤波实现的定位
  - 何时使用：地图已知、信念可能多峰（对称走廊）时
  - 如何做：粒子按运动模型 P(x_t+1|x_t,a_t) 传播，按传感器模型（距离扫描或地标距离+方位）加权重采样
- **概率路线图 / 快速探索随机树（PRM / RRT）**
  - 何时使用：高维 C 空间；PRM 适合多查询规划，RRT（双向）适合单查询
  - 如何做：拒绝采样取无碰撞里程碑，用简单规划器连 k 近邻成图再搜索；RRT 树向未探索区生长，RRT* 按到达代价选父并重连、渐近最优
- **轨迹优化（Trajectory Optimization）**：从不可行的直线路径出发迭代推向可行
  - 何时使用：需要平滑、代价最优的路径（抓瓶子、类人行走）
  - 如何做：J = J_obs + J_eff，J_eff 用 q̇ 平方积分，J_obs 用有符号距离场（signed distance field）构造路径积分；欧拉-拉格朗日方程求梯度后梯度下降；仅有 J_eff 时最优解是直线
- **PID 控制（PID Control）与计算扭矩控制（Computed Torque Control）**
  - 何时使用：跟踪参考轨迹、补偿模型误差
  - 如何做：u = K_P·e + K_D·ė + K_I·∫e（比例回轨、微分阻尼、积分消稳态偏差）；计算扭矩 = 前馈（逆动力学）+ 反馈（构形相关惯性矩阵 m(q) 加权的 PD）
- **同时定位与地图构建（SLAM）**
  - 何时使用：无先验地图，定位与建图互为鸡生蛋问题
  - 如何做：EKF-SLAM 把地标位置扩入状态向量（更新二次增长，适合数百地标）；大地图用图松弛、EM
- **人机协调：预测+动作分解（Prediction + Action）**
  - 何时使用：机器人在人类周围行动（并线、过走廊）
  - 如何做：假设人类带噪声地优化未知目标 J_H（softmax 概率 ∝ exp(−Q/J_H)），用其动作作贝叶斯证据更新对 J_H 的信念，再在预测的人类行为上求解机器人 MDP；进阶版考虑机器人动作影响人类反应

## 关键概念
- **效应器 / 传感器 / 执行器（Effector / Sensor / Actuator）** — 效应器对环境施力（腿、轮、夹具），执行器是驱动效应器的机械装置（电动/液压/气动），传感器测量环境与自身状态。
- **主动 vs 被动传感器（Active / Passive Sensor）** — 主动传感器（声呐、激光雷达、雷达）发射能量测反射，信息多但耗能且可能互相干扰。
- **计程（Odometry）与本体感受（Proprioception）** — 轴编码器测轮转推算行程，短程精确但打滑漂移；陀螺仪等惯性传感器减小不确定性。
- **自由度（Degree of Freedom, DOF）** — 独立驱动的关节数；C 空间维数由它决定。
- **正向 / 逆向运动学（Forward / Inverse Kinematics）** — 前者构形→机身点位置，后者目标点位姿→所需构形（抓取前先解 IK 得目标构形）。
- **运动模型 / 传感器模型（Motion Model / Sensor Model）** — 递归滤波方程（积分形式）P(x_t+1|z_t+1,a_t) ∝ P(z_t+1|x_t+1)∫P(x_t+1|x_t,a_t)P(x_t|…)dx_t 的两个成分。
- **扩展卡尔曼滤波器（EKF）** — 用一阶泰勒展开线性化非线性的运动/传感器模型，使高斯信念保持闭合。
- **保护移动（Guarded Movement）** — 显式的信息收集动作：运动指令+断言传感器数值的终止条件（如"移动手直到接触表面"）。
- **模型预测控制（Model Predictive Control, MPC）** — 短时域规划、每步重规划，把规划变成策略，天然处理人类偏离联合规划的情况。
- **域随机化（Domain Randomization）** — 在模拟中随机化物理与视觉参数训练策略，实现从模拟到现实（sim-to-real）迁移。
- **偏好学习（Preference Learning）/ 逆强化学习式代价推断** — 把人类演示当作其带噪声优化某代价函数的证据，推断该代价作为机器人自己的目标。
- **模仿学习 / 行为克隆（Imitation Learning / Behavioral Cloning）** — 直接监督拟合策略 π(s)；泛化（ALVINN 误差滚雪球）是核心难题，DAgger 靠数据聚合、对抗训练靠判别器缓解。
- **包容架构（Subsumption Architecture）** — Brooks 用增强有限状态机（AFSM=FSM+时钟）自底向上组装反应式控制器，无环境模型、无规划。

## 思维模型
- 把**运动规划看作连续状态的搜索问题**：离散化（网格/能见度图/沃罗诺伊图）后即可复用第3章图搜索；或随机采样（PRM/RRT）绕开维度诅咒。
- 把**控制器当作策略而非规划**：PD/PID/LQR 告诉机器人在任意偏离位置该做什么，这正是"规划→策略"的降维替换。
- 当分解（估计∥控制、预测∥动作、规划∥跟踪）带来误差时，用**反馈闭环缝合**：MPC 重规划、计算扭矩的前馈+反馈、意图感知的协调交互都是重新整合的形态。
- 把**人类当作近似理性的智能体**：softmax 噪声最优性既是预测模型，也是偏好学习的推断模型。
- 当 C 空间障碍形状不可直观想象时，**只探不建**：碰撞检查器 + 采样即足够。

## 反模式
- **能见度图贴障路径**：最短路径贴着障碍边缘，运动/感知稍有误差就碰撞；应改用沃罗诺伊图（最大间隙）或代价场中离障碍衰减的项。
- **均匀网格分解用于高维**：网格数随维数指数增长（维度诅咒）；且混合单元使规划器不可靠（解可能穿障）或不完备（只用自由单元则漏解）。
- **纯开环逆动力学跟踪**：质量、惯性、静摩擦建模不准导致误差累积越偏越远；必须加反馈项。
- **只用 P 控制器**：无摩擦时等价于弹簧定律，围绕参考路径永久震荡；调低增益仍震荡。缺微分阻尼。
- **PD 遇到系统性外力（斜坡、磨损）**：误差无法归零；需积分项。
- **从动作中剥离感知**：只按当前信念解 MDP，等于放弃信息的价值——机器人永远不会主动绕去看地标。
- **行为克隆不处理分布漂移**：小误差把机器人带入演示外的状态，误差滚雪球。
- **包容架构硬编码复杂策略**：条件数爆炸（并线协商例子）、无法换目标、难以融合跨时间的传感器信息。

## 算法要点
**运动规划方法谱系**（问题即"搬钢琴问题"：在 C_free 中找连续路径 τ: [0,1]→C_free）
- 能见度图（visibility graph）：C_obs 顶点互连（线段无碰撞即可见），图搜索得最短路径；完备且最优，但贴障。
- 沃罗诺伊图（Voronoi diagram）：取与多障碍等距的点集，路径离障碍最远；走廊场景好，室外绕弯。
- 单元分解（cell decomposition）：网格+A*；混合单元递归细分可恢复完备性；混合 A* 在网格中存连续状态、用运动模型扩展邻域，保证轨迹平滑可执行（DARPA 挑战赛车辆所用）。
- PRM：采样 M 个里程碑（拒绝采样）→ 简单规划器连 k 近邻 → 图搜索；失败则加样。概率完备。
- 双向 RRT：从 q_s、q_g 各建一棵树，随机采样并连到树最近点（步长 ε），两树相遇即得解；后处理"走捷径"平滑；RRT* 渐近最优。

**蒙特卡罗定位（MCL）**
1. 初始化粒子（无先验则均匀撒 = 全局不确定性）。
2. 每步：按运动模型移动粒子（v、ω 加高斯噪声）。
3. 按传感器模型为每粒子打权重：距离扫描模型比较各波束预测距离与实测（独立高斯），或地标模型比较距离+方位。
4. 按权重重采样。办公楼层示例：均匀 → 走廊中双峰 → 进入特定房间后单峰。

**PID / 计算扭矩控制**
- u(t) = K_P e(t) + K_D ė(t) + K_I ∫e dt：P 回轨、D 抑震（误差快变时导数项反作用）、I 消长期偏差（可能引入震荡）。
- 计算扭矩：u = f⁻¹(q, v, a_ref) + m(q)(K_P e + K_D ė)，前馈用逆动力学算期望加速度所需扭矩，反馈补模型误差，增益随构形自适应。

**最优控制 / LQR**
最小化 ∫(xᵀQx + uᵀRu)dt 受线性动力学约束：最优 cost-to-go 是二次型，最优策略是线性 u = −Kx，K 由代数 Riccati 方程直接解出——无值迭代、无策略迭代、无局部最优。ILQR：迭代地在当前轨迹附近线性化动力学、二次近似代价，逐步逼近似最优；实用上让类人机器人行走、汽车行驶（多重打靶、直接配置法同理）。

**不确定性下的规划**
- 在线重规划 / MPC：短时域规划→执行第一动作→用新信念重规划。
- 信息收集动作：保护移动（peg-in-hole：先故意触壁确定在孔的哪一侧，再贴壁滑入——速度不确定锥内所有速度同向，则结果确定）；海岸导航启发式、预期信息增益（信念熵下降）作代价项。

**从演示学习**
偏好学习：P(u_H|x, J_H) ∝ exp(−Q(x,u_H)/J_H)，演示更新 P(J_H|…)，取 J_H 为机器人代价。模仿学习：监督拟合 π；DAgger 迭代用当前策略采集状态、询问专家标签、重训练。对应问题（人类五指→机器二指）可用动觉教学（kinesthetic teaching）、关键帧演示、可视化编程规避。

|---|---|---|---|

| | MCL（粒子滤波） | EKF |
|---|---|---|
| 信念表示 | 粒子集合 | 单高斯（均值+协方差） |

## 完整示例
**带速度不确定性的插孔（保护移动两步策略）**：C 空间含窄竖孔（钥匙点火）。指令速度 v 有锥形 C_v 不确定性，直接下压可能落在孔两侧任一位置且不知在哪侧。策略：①运动指令"向左下"，终止条件"接触任何表面"——无论锥内实际速度如何，终止构形必在孔左侧（信息收集）；②指令"向右"沿水平表面滑行——锥内所有速度都向右，遇到孔口即滑入，碰右侧竖壁则顺壁下滑，终止条件"接触孔底"。所有可能轨迹终结于孔底：用几何确定性驯服控制不确定性。

**MPC 华夫饼协作**：人+机器人做华夫饼，联合规划让人取牛奶鸡蛋、机器人取面粉；人却走向面粉柜。机器人不固执执行原规划（自己转身去冰箱），而是重规划：人已近面粉，机器人改拿华夫饼铛——MPC 使协作对人偏离最优性保持鲁棒。

## 要点
1. 机器人学 = MDP（随机）+ POMDP（部分可观测）+ 博弈（有他智能体）在连续高维空间与不可逆真实世界中的实例化。
2. 递归滤波（积分形式的式 26-1）统一感知：运动模型+传感器模型驱动信念更新，MCL 与 EKF 是两种信念表示的取舍。
3. C 空间是运动规划的通用语言；碰撞检查器让我们"探查"而非"构建"障碍空间。
4. 规划+控制分离（运动学路径 → 重计时 → 控制律跟踪）引入两次次优性；LQR/ILQR/轨迹优化代表重新整合的方向。
5. 忽略未来信息 = 放弃信息的价值；保护移动、海岸导航、信息增益代价是补回它的三种手段，强度递增。
6. 真实世界样本昂贵且危险：基于模型 RL、域随机化、运动基元、迁移/元学习、安全探索都在降"危险状态下的真实样本数"。
7. 审慎式 vs 反应式不是二选一：六足 Genghis 的 AFSM 证明简单规则能做复杂地形行走，但其不可扩展性恰恰论证了学习与规划的必要性。
