# 第17章 做复杂决策 (Making Complex Decisions)

## 核心思想
当今天的动作影响明天的处境时，解不再是一个动作序列而是一个**策略**（每个状态给一个动作）：完全可观测随机环境下的序贯决策 = 马尔可夫决策过程（MDP），用动态规划（值迭代/策略迭代）求解；部分可观测环境（POMDP）化为**信念状态空间上的连续 MDP**，最优行为内在地包含信息收集。

## 框架
- **马尔可夫决策过程（Markov Decision Process, MDP）**
  - 何时使用：完全可观测、转移马尔可夫、奖励加性（可折扣）的序贯决策
  - 如何做：⟨S, s₀, A(s), P(s′|s,a), R(s,a,s′)⟩；求最优策略 π*(s) = argmax_π E[Σ γᵗR(Sₜ,Aₜ,Sₜ₊₁)]；无限期 + 折扣 ⟹ 最优策略平稳且与初始状态无关
- **贝尔曼方程（Bellman equation）与 Q 函数**
  - 何时使用：一切 MDP 求解与在线决策的基础
  - 如何做：U^π(s)=E[Σ_t γᵗR(Sₜ,π(Sₜ),Sₜ₊₁)]（式17-2）；π*(s)=argmax_{a∈A(s)} Σ_{s′}P(s′|s,a)[R(s,a,s′)+γU(s′)]（式17-4）；贝尔曼方程 U(s)=max_a Σ_{s′}P(s′|s,a)[R(s,a,s′)+γU(s′)]（式17-5，唯一解）；Q(s,a)=Σ_{s′}P(s′|s,a)[R+γU(s′)]，U(s)=max_a Q(s,a)（17-6），π*(s)=argmax_a Q(s,a)（17-7），Q 的贝尔曼方程 Q(s,a)=Σ_{s′}P(s′|s,a)[R+γ max_{a′}Q(s′,a′)]（17-8）
- **值迭代（Value Iteration）**
  - 何时使用：离线求精确效用；状态数中等
  - 如何做：反复贝尔曼更新 U_{i+1}(s)=max_a Σ P[R+γU_i(s′)]；贝尔曼更新是最大范数下因子 γ 的**压缩** ⟹ 指数收敛到唯一解；终止条件 ‖Uᵢ−Uᵢ₋₁‖∞ < ε(1−γ)/γ
- **策略迭代（Policy Iteration）**
  - 何时使用：效用估计不必精确时更快得到最优策略
  - 如何做：交替策略评估（固定 π 的**线性**方程组，O(n³) 精确解，或修正策略迭代=几次简化值迭代）与策略改进（对 Uᵢ 一步前瞻取 MEU）；有限策略数 + 每轮严格改进 ⟹ 必终止；异步版本可对任意状态子集做任意更新
- **基廷斯指数（Gittins index）与老虎机策略**
  - 何时使用：n 个独立臂、一次只能拉一个、折扣奖励的探索-利用权衡（疗法选择、广告投放、投资）
  - 如何做：每臂独立计算指数 λ = max_{T>0} E[Σ_{t=0}^{T−1}γᵗRₜ]/E[Σ_{t=0}^{T−1}γᵗ]（式17-15，最优停止的折扣效用/折扣时间），总拉指数最高的臂；近似替代：UCB（置信上界）、汤普森采样（按后验是最优的概率随机选臂）
- **POMDP 价值迭代（分段线性凸）与在线算法**
  - 何时使用：环境部分可观测（真实世界默认情形）
  - 如何做：信念空间上效用 U(b)=max_p α_p·b 是条件规划超平面的最大值 ⟹ 分段线性凸；按深度递归生成条件规划并剔除**劣势规划**；在线用信念状态 maxim-expectimax 树 + 粒子滤波 + UCT（POMCP）

## 关键概念
- **策略（policy）/ 最优策略（optimal policy）** — 状态到动作的映射；质量由所产生环境历史的期望效用衡量；无限期折扣下最优策略平稳，有限期则依赖剩余时间（非平稳）。
- **折扣因子（discount factor γ）** — 0<γ<1；偏好当前奖励的四种理由（经验/利率等价/意外终止概率/偏好平稳性）；式17-1：U_h([s₀,a₀,s₁,…])=Σ_t γᵗR(sₜ,aₜ,sₜ₊₁) ≤ ΣγᵗR_max = R_max/(1−γ)，消除无穷。
- **适当策略（proper policy）** — 保证到达终止状态的策略；是使用纯加性无折扣奖励（γ=1）的前提，否则非适当策略可获无限奖励使算法失效。
- **平均奖励（average reward）** — 比较无限序列的第三种准则（另两种见"折扣因子"与"适当策略"），分析较复杂。
- **压缩（contraction）与最大范数** — 贝尔曼更新把任意两个效用向量的距离至少缩小到 γ 倍 ⟹ 唯一不动点 + 指数收敛 + 实用误差/终止界（式17-11/17-12）。
- **策略损失（policy loss）** — 执行由不精确效用 Uᵢ 导出的 MEU 策略相对最优的最大损失 ‖U^πᵢ−U‖；式17-13：‖Uᵢ−U‖<ε ⟹ 策略损失 <2ε——策略常在效用收敛前已最优。
- **奖励塑形定理（shaping theorem）/ 势（potential）** — 奖励加任意 Φ 的"梯度"γΦ(s′)−Φ(s) 不改变最优策略；取 Φ=U 时对修正奖励的贪心策略即最优——训练动物式逐步塑形的理论基础。推导链（据行内公式图转录）：π_G(s) = argmax_a Σ P(s′|s,a)R′(s,a,s′) = argmax_a Σ P[R(s,a,s′)+γΦ(s′)−Φ(s)] = argmax_a Σ P[R(s,a,s′)+γU(s′)−U(s)] = argmax_a Σ P[R(s,a,s′)+γU(s′)] = π*(s)［依式17-4］。
- **动态决策网络（Dynamic Decision Network, DDN）** — DBN + 决策/奖励/效用节点的因子化 MDP 表示（移动机器人见图17-4；俄罗斯方块图17-5：状态变量 CurrentPiece/NextPiece + 10×20 位向量 Filled，状态空间 7×7×2²⁰⁰ ≈ 10⁶²，其每个策略都是适当策略）。
- **expectimax 树与期限（horizon）** — 在线 MDP 决策树（max 节点+机会节点）；深度 H 后奖励折扣和 < ε 即可截断（γ 小时 H 很小）。
- **实时动态规划（RTDP）** — 把已探索状态构成子 MDP 就地求解，类似 LRTA*。
- **遗憾（regret）** — 相对"预知未来总拉最佳臂"的平均奖励损失；无折扣下任何算法遗憾增长不低于对数级（Lai–Robbins），UCB/汤普森采样可达该阶。
- **重启 MDP（restart MDP）** — 在每个状态加"返回初始状态"动作后求解，其最优价值/γ 即基廷斯指数。
- **选择问题（selection problem）与老虎机超过程（bandit superprocess, BSP）** — 前者只要选出最佳选项（不存在索引函数）；后者每臂是完整 MDP，全局最优可能要求各臂局部次优（机会成本）。
- **信念状态（belief state）与传感器模型** — POMDP 在状态分布 b(s) 上"可观测"；b′=Forward(b,a,e) 为滤波更新；最优动作只依赖信念状态 ⟹ POMDP = 信念空间上的 MDP（转移/奖励见算法要点式17-16/17-17）。
- **条件规划（conditional plan）/ 劣势规划（dominated plan）** — POMDP 策略在固定 b 下的展开形式；在整个信念空间都被超过者可剔除。

## 思维模型
- 把序贯决策的解看作"为每个可能到达的状态准备好动作"的查表函数，而非固定动作序列。
- 把值迭代看作信息在状态空间中**传播**：奖励从终止状态逐层外溢，效用随迭代逐格浮现。
- 把贝尔曼更新看作 γ-压缩：任何初始臆测反复压缩后都被挤到唯一不动点。
- 把 POMDP 看作信念空间上的 MDP：动作同时改变物理状态与（通过产生的感知）信念状态——信息价值内生于决策。
- 把老虎机指数看作"每单位折扣时间的最大效用"，臂与臂之间因此解耦、O(1) 决策。
- 中间信念的价值低于两端（不知身在何处本身就是损失）——所以 POMDP 最优策略自然包含信息收集动作。

## 反模式
- **γ→1 时忽略收敛代价**：初始误差最大 R_max/(1−γ)，要把误差压到 ε=c·R_max 需 N = ⌈log(R_max/(c(1−γ)))/log(1/γ)⌉ 次迭代（图17-7b，c=0.0001～0.1 四曲线）；N 随 γ→1 剧增；γ 变小收敛快但让智能体"短视"。
- **无终止状态 + γ=1 + 加性奖励**：效用无穷、非适当策略作祟，标准算法失效。
- **以为最优老虎机策略最终会停在最佳臂上**：经典错误——最优策略以有限概率持续选次优臂。
- **对 BSP 逐臂求最优再调度**：全局最优可能要求某臂执行局部次优计划（施工队例子：局部第 5 周 vs 第 15 周出店租，四个mall串行时差 40 周）；只有 γ=1 时全局与局部最优才必然一致。
- **对选择问题套用老虎机索引**：选择问题不存在索引函数（加第三臂可翻转前两臂的偏好）。
- **在"混乱"小 MDP 上用 UCT**：建树不建图、不回头，4×3 世界平均 160 次模拟才得 0.4 奖励（最优 0.7453）；UCT 的用武之地是长视野、奖励靠远期才显现的域（俄罗斯方块）。
- **有限期下寻找平稳策略**：有限期最优动作依赖剩余时间，策略必须非平稳。

## 算法要点
**值迭代（图17-6 Value-Iteration，逐行转录）**
```
function Value-Iteration(mdp, ε) returns 一个效用函数 U
inputs: mdp = 状态 S、动作 A(s)、转移模型 P(s′|s,a)、奖励 R(s,a,s′)、折扣 γ
        ε   = 任意状态效用允许的最大误差
local:  U, U′ = S 上效用向量, 初始为 0; δ = 单步最大效用变化
repeat
    U ← U′; δ ← 0
    for each 状态 s in S do
        U′[s] ← max_{a∈A(s)} Q-Value(mdp, s, a, U)
        if |U′[s]−U[s]| > δ then δ ← |U′[s]−U[s]|
until δ ≤ ε(1−γ)/γ
return U
其中 Q-Value(mdp, s, a, U) = Σ_s′ P(s′|s,a)·[R(s,a,s′) + γ·U[s′]]
```
误差链：贝尔曼更新（式17-10）是最大范数下因子 γ 的压缩 ‖BUᵢ−BU′ᵢ‖ ≤ γ‖Uᵢ−U′ᵢ‖（式17-11）⟹ 唯一不动点、指数收敛；终止条件（式17-12）‖U_{i+1}−U_i‖ < ε(1−γ)/γ ⟹ ‖U_{i+1}−U‖ < ε；策略损失（式17-13）‖U_i−U‖ < ε ⟹ ‖U^πᵢ−U‖ < 2ε。
**策略迭代（图17-9 Policy-Iteration，逐行转录）**
```
function Policy-Iteration(mdp) returns 一个策略 π
inputs: mdp = 状态 S、动作 A(s)、转移模型 P(s′|s,a) 的 MDP
local:  U = S 上效用向量, 初始为 0; π = 按状态索引的策略向量, 初始随机
repeat
    U ← Policy-Evaluation(π, U, mdp)
    unchanged? ← true
    for each 状态 s in S do
        a* ← argmax_{a∈A(s)} Q-Value(mdp, s, a, U)
        if Q-Value(mdp, s, a*, U) > Q-Value(mdp, s, π[s], U) then
            π[s] ← a*; unchanged? ← false
until unchanged?
return π
```
策略评估解线性方程组（式17-14，无 max，O(n³)，大空间用 k 次简化值迭代=修正策略迭代）。例（图17-2a 策略，γ=1）：U(1,1)=0.8[−0.04+U(1,2)]+0.1[−0.04+U(2,1)]+0.1[−0.04+U(1,1)]；U(1,2)=0.8[−0.04+U(1,3)]+0.2[−0.04+U(1,2)]。π 不再变化 ⟹ U^π 是贝尔曼方程解 ⟹ π 最优。
**线性规划**：变量 U(s)，min ΣU(s)，约束 U(s) ≥ ΣP(s′|s,a)[R+γU(s′)]（每 s,a 一条）；证明 MDP 多项式可解，但实践不如动态规划。
**在线 MDP**：expectimax（机会节点可采样；图17-10：以 (3,2) 为根的 4×3 最大化期望树，Up 动作的机会节点出 (3,2) 0.1 / (3,3) 0.8 / (4,2) 0.1）+ 期限截断 + RTDP（已探状态当子 MDP）+ UCT（远视模拟）。
**基廷斯指数计算（重启 MDP 法）**：给臂 M 的每个状态加"退出获无限 λ 序列"⟺ "回到初始 s 重来"的选择，解此 MDP 得最优价值 V，则 index = γ·V。伯努利臂：状态=(成功数 sᵢ,失败数 fᵢ)，下一奖励 1 的概率 s/(s+f)（Beta(1,1) 先验）；截断状态空间内精确近似——指数天然含**探索奖励**：(3,2) 的 0.7057 > (7,4) 的 0.6922，尽管估计值 0.6 < 0.6364。
**UCB**：UCB(i) = 均值估计 + c·√(log g(N)/Nᵢ)，选最大者；g 的选取决定遗憾阶（对数级下界）。**汤普森采样**：从每臂当前后验 Pᵢ 采一个样本，选样本最大者，遗憾同为 O(log t) 阶。
**POMDP 信念更新与信念 MDP**
```
b′(s′) = Forward(b,a,e) = α·P(e|s′)·Σ_s P(s′|s,a)·b(s)         (17-16)
τ(b′|b,a) = Σ_{e: Forward(b,a,e)=b′} Σ_{s′} P(e|s′)·Σ_s P(s′|s,a)·b(s)   (17-17)
ρ(b,a) = Σ_s b(s)·ρ(s,a)      // ⟨τ, ρ⟩ 定义信念空间上可观测 MDP
```
**POMDP 价值迭代（图17-16 POMDP-Value-Iteration，逐行转录）**
```
function POMDP-Value-Iteration(pomdp, ε) returns 一个效用函数
inputs: pomdp = 状态 S、动作 A(s)、转移 P(s′|s,a)、传感器模型 P(e|s)、奖励 R(s,a,s′)、折扣 γ
        ε = 任意状态效用的最大允许误差
local:  U, U′ = 条件规划 p 的集合, 各关联效用向量 α_p
U′ ← 所有一步规划 [a] 的集合, α_[a](s) = Σ_s′ P(s′|s,a)·R(s,a,s′)
repeat
    U ← U′
    U′ ← "一个动作 + 对每种可能的下一个感知从 U 中各选一个后继规划"组成的全部规划,
          效用向量按式(17-18)计算
    U′ ← Remove-Dominated-Plans(U′)
until Max-Difference(U, U′) ≤ ε(1−γ)/γ
return U
式17-18: α_p(s) = Σ_s′ P(s′|s,a)·[ R(s,a,s′) + γ·Σ_e P(e|s′)·α_{p.e}(s′) ]
```
剔除劣势规划与 Max-Difference 通常以线性规划实现；信念空间被非劣势规划的超平面划分为区域，策略=在 b 处取最高超平面并执行其首个动作。深度 d 规划数 N(d)=|A|·N(d−1)^|E|（双指数）——两状态世界 d=8 共 2^255，剔除劣势后仅 144；一般 POMDP 最优策略是 PSPACE 难。
**POMCP（在线）**：粒子滤波维护信念 + UCT 长模拟；复杂度 |A|·(|E|·采样数)^深度，远小于条件规划数；配 DDN 可扩展到极大 POMDP。

## 参考表
**值迭代 vs 策略迭代**
| | 值迭代 | 策略迭代 |
|---|---|---|
| 每轮开销 | O(|S|²·|A|) 级贝尔曼更新 | O(n³) 解线性方程组（精确评估） |
| 收敛 | 效用指数收敛；策略常提前最优 | 有限步内精确终止 |
| 关键性质 | γ-压缩、唯一不动点 | 评估线性（去 max）、每轮策略严格改进 |
| 变体 | 异步/就地更新 | 修正（近似评估）、异步（任意状态子集） |
| 适用 | 中等状态空间、要效用数值 | 要策略、效用不必精确；大空间用修正版 |

**历史效用准则对比**：折扣加性（本章默认，有限上界 R_max/(1−γ)）｜加性无折扣（需适当策略）｜平均奖励（分析复杂）。**MRP vs MDP**：臂=单动作 MDP（MRP）；整体 n 臂老虎机 = 积状态空间 MDP。

## 要点
1. MDP 的解是策略而非计划：无论怎么漂移，查当前状态即知下一步。
2. 折扣不是数值技巧而是偏好假设：偏好平稳性 ⟺ 加性折扣是唯一合法形式。
3. 奖励塑形自由度：R 加势函数梯度 γΦ(s′)−Φ(s) 不动最优策略——奖励工程有理论安全区。
4. 压缩性一站式给出：存在性、唯一性、收敛速率、误差界与终止条件。
5. 策略比效用"粗"：一步前瞻的 MEU 策略常在效用收敛前定型，策略损失由效用误差的 2 倍封顶（式17-13：‖Uᵢ−U‖<ε ⟹ ‖U^πᵢ−U‖<2ε；4×3 世界 i=5 时损失已归零）。
6. 探索是理性而非好奇：基廷斯指数把不确定性折成价格，UCB/汤普森以对数遗憾近似它。
7. POMDP 的正解是信念空间 MDP：信息收集动作（试探、感知）由此自发涌现；精确求解 PSPACE 难，实用出路是粒子滤波 + 蒙特卡罗规划（POMCP）。
