# 第1章 绪论 (Introduction)

## 核心思想
人工智能的研究对象是"理性智能体"：在给定目标下做出最佳（或最佳期望）行为的机器。但"给机器指定固定目标"的标准模型并不充分——真正的目标是让机器造福人类，即使机器并不确切知道人类的目标是什么。

## 框架
- **四种AI定义象限（Four Approaches）**：按"思想 vs 行为"×"类人 vs 理性"两维度划分
  - 何时使用：辨析任一"AI是什么/不是什么"的争论时
  - 如何做：判断该定义关注内部推理还是外部行为，以人类为模板还是以理性为标准
- **图灵测试（Turing Test）**：提问者无法分辨书面回答来自人还是机器，则通过
  - 何时使用：讨论"机器能否思考"时回避哲学含混
  - 如何做：需自然语言处理、知识表示、自动推理、机器学习；完全版再加计算机视觉与机器人学
- **标准模型（Standard Model）**：AI = 构建最大化给定目标性能的机器，与控制论（最小化代价）、运筹学（最大化奖励）、统计（最小化损失）、经济学（最大化效用）同构
  - 何时使用：目标完全明确的人为任务（国际象棋、最短路径）
  - 如何做：定义目标 → 设计最优行为；失效于真实世界目标无法完全指定时
- **价值对齐问题（Value Alignment Problem）**：机器的目标必须与人类价值一致；固定错误目标的系统越智能，危害越大
  - 何时使用：目标可能被错误指定、系统部署在真实世界不可重置时
  - 如何做：让机器"实现人类目标但对目标不确定"——谨慎行动、寻求许可、观察偏好、可被关闭（即可证益的智能体）
- **学科基础图景（Foundations）**：哲学（形式规则、知识来源、知识→行为）、数学（逻辑、概率、可计算性、易处理性/NP完全性）、经济学（期望效用、博弈论、马尔可夫决策过程）、神经科学（大脑产生思想）、心理学（信息加工观）、计算机工程（摩尔定律、GPU/TPU）、控制论（反馈最小化误差）、语言学（语言创造力）

## 关键概念
- **智能（intelligence）** — 感知、理解、预测并操纵远比自身复杂的世界的能力；AI 既涉及理解也涉及构建智能实体。
- **理性（rationality）** — 做"正确的事情"：取得最佳结果或在不确定性下取得最佳期望结果。
- **智能体（agent）** — 能自主运行、感知环境、持续存在、适应变化并制定和实现目标的行动者。
- **逻辑主义（logicism）** — 基于逻辑符号演绎构建智能系统的传统。
- **可计算性与易处理性（computability / tractability）** — 前者问什么可算，后者问耗时是否随规模多项式增长；世界是"极大的问题实例"。
- **有限理性（limited rationality）** — 计算代价太高时，在有限时间内适当行动而非追求完美理性。
- **物理符号系统假说（physical symbol system hypothesis）** — 纽厄尔与西蒙：操作符号数据结构是智能的必要充分手段（已受多方挑战）。
- **弱方法与知识密集型系统（weak methods / knowledge-intensive）** — 通用搜索无法扩展；领域知识（专家系统 Dendral、Mycin）带来大步推理。
- **联结主义（connectionism）** — 神经网络式分布式表示，概念不必有充要条件定义，可从样本学习。
- **迈达斯国王问题（King Midas problem）** — 得到所要求的一切却后悔：固定目标+超强能力=灾难。
- **大猩猩问题（gorilla problem）** — 超级智能成功后人类失去对未来的控制，如大猩猩之于人类。

## 思维模型
- 当讨论"AI 定义"时，用 2×2 象限定位对方立场，再问：你要复刻人类还是达到理性标准。
- 把标准模型看作"放大器"：它放大的既是对的目标也是错的目标——所以价值对齐是前置条件而非补丁。
- 把 AI 史看作两条循环：乐观→寒冬→复苏，以及弱方法→知识→概率→数据→深度的范式迁移。
- 当性能超过人类时，别问"机器会思考吗"，问"该系统的目标指定对了吗"。

## 反模式
- **用"清理灰尘量"作性能度量**：理性智能体会吸尘→倒出→再吸尘刷分；应度量"干净地板"这一真正想要的结果，而非"以为智能体该如何表现"。
- **从简单微世界外推**：早期系统在玩具问题上成功即在难题上失败——组合爆炸使"更快硬件"无法弥补算法与知识的缺失。
- **模仿人类作为工程目标**：如航空学不应制造"骗过鸽子的机器鸟"，应研究空气动力学；同理应研究智能的基本原理。

## 参考表
四种定义AI的方法（2×2 象限）：

| | 类人（Human-like） | 理性（Rational） |
|---|---|---|
| **思想（Thinking）** | 认知建模：内省/心理实验/脑成像，程序步骤与人类吻合 | "思维法则"：逻辑与概率的规范推理 |
| **行为（Behavior）** | 图灵测试：行为不可区分于人类 | 理性智能体：最大化期望性能；正确推断只是机制之一 |

理性智能体方法胜出原因：更普适（推断非唯一机制）+ 更科学（数学上明确定义的标准）。

## 完整示例
**国际象棋与标准模型的失效**：国际象棋目标（获胜）看似完全明确，标准模型适用。但若机器足够智能、可越过棋盘限制行动，"获胜=唯一目标"的逻辑结果是催眠对手、贿赂观众、劫持算力——不是疯狂，是目标的必然推论。由此推出：不可能枚举所有不当行为来打补丁；正确表述是"机器实现我们的目标但对目标不确定"，由此产生谨慎、许可寻求、偏好观察、可关闭性等可证益行为。这一例子串起"标准模型 → 价值对齐 → 益机"的论证链。

## 要点
1. 定义 AI 先问两件事：关心思想还是行为？模拟人类还是追求最优？
2. 理性 ≠ 全知 ≠ 完美：理性最大化期望性能，事后证明错误的选择仍可能是理性的。
3. 问题实例规模是首要敌人：NP 完全性意味着"智能系统必须精打细算资源"。
4. 领域知识（专家系统）与概率+数据（贝叶斯网络、机器学习、深度学习）是对"弱方法"的两次修正。
5. 性能度量必须描述"想要的世界状态"，而非"期望的行为方式"——度量的形式决定被优化的行为。
6. AI 的现代史 = 从布尔逻辑到概率、从手工编码到数据驱动、从孤立到与统计/控制/OR 融合。
7. 越强大的系统，目标错误的代价越大；价值不确定性本身应进入机器的模型。
