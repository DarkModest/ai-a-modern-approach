# 第22章 强化学习 (Reinforcement Learning)

## 核心思想
强化学习研究身处未知 MDP 中的智能体如何仅凭感知与偶发奖励学会最优行为：与"求解 MDP"不同，智能体不知道转移模型和奖励函数，必须靠行动获取信息，并在探索与利用之间权衡。

## 框架
- **被动强化学习（passive reinforcement learning）**：策略固定，学效用 U^π(s)
  - 何时使用：策略评估阶段，或先分析环境再谈改进
  - 如何做：三条路线——直接效用估计（把预期奖励当监督样本）、自适应动态规划（学模型再解贝尔曼方程）、时序差分（每步局部更新）
- **自适应动态规划（adaptive dynamic programming, ADP）**
  - 何时使用：状态空间不大、追求最快收敛（衡量其他算法的基准）
  - 如何做：用计数估计转移模型 P̂(s'|s,a)，代回固定策略贝尔曼方程线性求解或价值迭代；大状态空间不可行（西洋双陆棋约 10²⁰ 个方程）
- **时序差分学习（temporal-difference, TD）**
  - 何时使用：无模型，或要求每次观测只做常数计算
  - 如何做：U(s) ← U(s) + α(R + U(s') − U(s))，迫使相继状态的效用估计一致；可视为 ADP 的粗略但有效的近似，还可用模型生成伪经验（pseudoexperience）加速
- **Q学习（Q-learning）**
  - 何时使用：无模型的主动学习，选动作时不做一步前瞻
  - 如何做：对每次转移 (s,a,R,s') 更新 Q(s,a) ← Q(s,a) + α(R + γ max_{a'} Q(s',a') − Q(s,a))（式22-7）；选动作即 argmax_a Q(s,a)
- **策略搜索（policy search）**
  - 何时使用：可参数化策略并能观测累计奖励；或需直接优化策略表现而非逼近 Q*
  - 如何做：softmax 随机策略 π_θ(s,a) = e^{βQ̂_θ(s,a)} / Σ_{a'} e^{βQ̂_θ(s,a')}（式22-14，β 调节柔和程度），用策略梯度（REINFORCE）或相关采样（PEGASUS）改进参数
- **逆强化学习（inverse reinforcement learning, IRL）**
  - 何时使用：奖励函数难以人工设计但有专家演示（驾驶、行走）
  - 如何做：特征匹配——假设 R 为特征线性组合，找权重使所学策略的特征期望与专家一致，再对恢复的奖励函数求最优策略

## 关键概念
- **奖励（reward）/ 稀疏奖励（sparse reward）** — 反映行为质量的标量信号；绝大多数状态无信息量时称稀疏，是学习困难的主因
- **基于模型 vs 无模型（model-based / model-free）** — 前者拥有或学习转移模型并学 U(s)；后者不学模型，直接学 Q(s,a) 或策略
- **贝尔曼方程（Bellman equation）** — 效用与后继效用的一致性约束；所有被动学习方法共同的均衡条件
- **预期奖励（reward-to-go）** — 从某状态出发到终止的奖励总和；直接效用估计的样本
- **优先扫描（prioritized sweeping）** — 对后继状态刚发生大效用调整的状态优先更新的 ADP 加速启发式
- **GLIE（greedy in the limit of infinite exploration）** — 每个状态-动作对尝试任意多次且最终贪心的探索方案，保证收敛到最优策略
- **探索函数（exploration function）** — f(u,n) 关于效用 u 递增、关于尝试次数 n 递减（如 n<N_e 时取乐观值 R⁺），把乐观先验注入价值迭代
- **离策略 / 同策略（off-policy / on-policy）** — Q 学习评估"改用最优策略后"的价值；SARSA 评估"坚持当前策略（含探索）"的价值
- **信用分配（credit assignment）** — 把迟到的稀疏奖励归因到漫长动作序列中正确步骤的问题
- **势函数塑形（potential-based shaping）** — 伪奖励改写 R′ = R − γΦ(s′) + Φ(s)，可加速学习且不改变最优策略
- **灾难性遗忘 / 经验回放（catastrophic forgetting / experience replay）** — 函数近似遗忘不再访问区域的危险；对策是定期重温旧轨迹
- **玻尔兹曼合理性（Boltzmann rationality）** — 假设专家按 softmax 分布选动作，从而容忍次优演示的 IRL 建模

## 思维模型
- 把 RL 看作"身处 MDP 而非求解 MDP"：模型与奖励都未知，行动本身就是实验
- 把 TD 看作 ADP 的单步采样近似：ADP 调整到与所有可能后继（按概率加权）一致，TD 只与观测到的后继一致——大量转移平均后二者等价
- 把探索看作信息获取：动作既产生奖励也产生信息；乐观初始估计让"探索的好处从未知区域的边缘传回"
- 把分层 RL 看作"局部程序 + 学习填充选择点"：整体效用加性分解为各子程序奖励之和，每项只依赖少数变量

## 反模式
- **贪心智能体（greedy agent）**：只执行当前所学模型的最优动作——学到的模型不同于真实环境，第 8 次试验起锁死在损失 0.235 的次优策略，永不发现更优路线
- **直接效用估计当万能**：忽略贝尔曼约束（效用依赖后继奖励与效用），在过大的假设空间搜索，收敛极慢
- **伪奖励设计不当**：智能体会最大化伪奖励而非真奖励（在球旁"振动"刷接触奖励）——应使用势函数塑形保证最优策略不变
- **奖励函数遗漏因素**：被忽略的因素会被赋极端值，导致不负责任的行为
- **非线性函数近似 + TD 更新**：简单情境下参数可发散到无穷；即便成功也有灾难性遗忘（学太好的自动驾驶忘掉路边危险而冲出公路）——需经验回放
- **模仿学习（imitation learning）**：误差随时间累积、至多复现教师水平且不理解"为什么"；专家知情时会改变行为（边做边讲解），IRL 最优性假设失效，应建模为双人辅助博弈

## 算法要点

被动强化学习三法：
```
直接效用估计：
  每次 trial 结束，对每个访问过的 s 取样本 = 该次 trial 从 s 起的 reward-to-go
  U(s) ← 样本均值                        # 忽略贝尔曼约束 → 收敛慢

ADP（图22-2 Passive-ADP-Learner 逐行）：
  persistent: π（确定性策略）；mdp（转移 P、奖励 R、动作 A、折扣 γ）；
              U（状态效用表，初始空）；N_{s'|s,a}（结果状态计数，初始零）；s,a（先前状态动作，初始空）
  若 s' 是新状态 then U[s'] ← 0
  若 s 非空 then
    增加 N_{s'|s,a}[s,a]；R[s,a,s'] ← r；将 a 加入 A[s]
    P(·|s,a) ← Normalize(N_{s'|s,a}[s,a])
    U ← PolicyEvaluation(π, U, mdp)     # 解固定策略贝尔曼方程（式22-2）
  s, a ← s', π[s']；return a
  # 贝尔曼约束（式22-2）：U^π(s) = Σ_{s'} P(s'|s,π(s)) [R(s,π(s),s') + γ U^π(s')]

TD（图22-4 Passive-TD-Learner 逐行）：
  persistent: π；s；U（效用表，初始空）；N_s（状态出现频率表，初始零）
  若 s' 是新状态 then U[s'] ← 0
  若 s 非空 then
    增加 N_s[s]
    U[s] ← U[s] + α(N_s[s]) × ( r + γ U[s'] − U[s] )    # 式22-3，α 随访问次数递减
  s ← s'；return π[s']
```

主动强化学习（探索性 ADP）：
```
学完整模型（所有动作的结果概率）
价值迭代引入乐观探索函数（式22-5）：
  U⁺(s) ← max_a f( Σ_{s'} P(s'|s,a)[R(s,a,s') + γ U⁺(s')], N(s,a) )
  f(u,n) = R⁺ 若 n < N_e，否则 u
动作：a = argmax_a f( Q⁺(s,a), N(s,a) )   # 用 U⁺ 而非 U 至关重要：探索红利从边界传回
```

Q 学习与 SARSA：
```
Q 学习（off-policy，全程免模型；图22-8 Q-Learning-Agent 逐行）：
  persistent: Q（状态-动作值表，初始零）；N_sa（状态-动作对频率表，初始零）；s,a（初始空）
  若 s 非空 then
    增加 N_sa[s,a]
    Q[s,a] ← Q[s,a] + α(N_sa[s,a]) ( r + γ max_{a'} Q[s',a'] − Q[s,a] )   # 式22-7
  s, a ← s', argmax_{a'} f( Q[s',a'], N_sa[s',a'] )；return a

SARSA（on-policy，应用于每个五元组 (s,a,R,s',a')）：
  Q(s,a) ← Q(s,a) + α ( R(s,a,s') + γ Q(s',a') − Q(s,a) )                 # 式22-8
```

近似 Q 学习 / 函数近似：
```
用参数化 Û_θ 或 Q̂_θ(s,a;θ) 表示（深度网络时输入可为原始像素，d 个输出对应 d 个动作）
监督式（近似直接效用估计）：误差 E_j(s) = ½ (u_j(s) − Û_θ(s))²
  Widrow-Hoff/delta 法则（式22-10）：θ_i ← θ_i + α [u_j(s) − Û_θ(s)] ∂Û_θ(s)/∂θ_i
  线性 Û_θ(x,y)=θ0+θ1x+θ2y（式22-9）的三个更新：
    θ0 ← θ0 + α[u_j(s)−Û_θ(s)]；θ1 ← θ1 + α[u_j(s)−Û_θ(s)] x；θ2 ← θ2 + α[u_j(s)−Û_θ(s)] y
TD 版（式22-11/22-12，梯度由反向传播算）：
  θ_i ← θ_i + α [R(s,a,s') + γ Û_θ(s') − Û_θ(s)] ∂Û_θ(s)/∂θ_i
  θ_i ← θ_i + α [R(s,a,s') + γ max_{a'} Q̂_θ(s',a') − Q̂_θ(s,a)] ∂Q̂_θ(s,a)/∂θ_i
配套：经验回放抗灾难性遗忘；线性+合适特征可证收敛，非线性可能发散
```

策略梯度（REINFORCE）与 IRL：
```
确定性策略：π_θ(s) = argmax_a Q̂_θ(s,a)（式22-13，对 θ 不连续）→ 改用随机 softmax（式22-14）
策略价值 ρ(θ) = 执行 π_θ 的期望预期奖励；梯度用似然比技巧由样本估计，
时序形式（REINFORCE，Williams 1992）：对每个访问状态 s
  ∇_θ ρ(θ) ≈ (1/N) Σ_j u_j(s) ∇_θπ_θ(s,a_j)/π_θ(s,a_j)
随机环境方差大 → 相关采样：预生成固定随机数序列评所有策略 = PEGASUS

IRL 特征匹配：奖励 R(s,a,s') = Σ_i θ_i f_i(s,a,s')（线性组合）
  关键等式：U^π(s) = Σ_i θ_i μ_i(π) = θ·μ(π)，μ_i(π) 为特征期望
  找 θ 使所学策略的特征期望 ≈ 专家轨迹上的平均，再对恢复的奖励求最优策略
```

## 参考表

| 被动 RL 方法 | 需要转移模型 | 更新方式 | 收敛速度 | 每观测计算量 |
|---|---|---|---|---|
| 直接效用估计 | 否 | trial 级样本平均 | 很慢 | 小 |
| ADP | 学习并使用 | 全局一致（所有后继按概率加权） | 最快（基准） | 大，大状态空间不可行 |
| TD | 否 | 单步局部（仅观测到的后继） | 较慢、波动大 | 很小 |

| | Q 学习 | SARSA |
|---|---|---|
| 更新用 Q 值 | max_{a'} Q(s',a')（估计最优动作） | Q(s',a')（实际执行动作） |
| 类别 | 离策略（off-policy） | 同策略（on-policy） |
| 探索的负面奖励 | 不惩罚所选动作 | 惩罚实际动作 |
| 适用 | 可换探索策略、更灵活 | 策略部分受其他智能体/程序控制时 |

## 完整示例
4×3 世界（R(s,a,s′)=−0.04，γ=1，终态 (4,3)=+1、(4,2)=−1）的被动学习演算：

图22-1（转录）：(a) 最优策略——(1,3)(2,3)(3,3) 均向右，(1,1)(1,2) 向上，(2,1)(4,1) 向左，(3,1) 处 Left 与 Up 同为最优。(b) 各状态效用：(1,1)=0.7453、(2,1)=0.6953、(3,1)=0.6514、(4,1)=0.4279；(1,2)=0.8016、(3,2)=0.7003；(1,3)=0.8516、(2,3)=0.9078、(3,3)=0.9578。

三次典型试验（每次转移标注动作与奖励，省略处均为 −0.04）：
```
试验1: (1,1) -Up→ (1,2) -Up→ (1,3) -Right→ (1,2) -Right→ (1,3) -Right→ (2,3) -Right→ (3,3) -Right/+1→ (4,3)
试验2: (1,1) →Up (1,2) →Up (1,3) →Right (2,3) →Right (3,3) →Right (3,2) →Right (3,3) -Right/+1→ (4,3)
试验3: (1,1) →Up (1,2) →Up (1,3) →Right (2,3) →Right (3,3) →Right (3,2) -Up/−1→ (4,2)
```
1. 三次试验产生 reward-to-go 样本：(1,1): 0.76；(1,2): 0.80、0.88；(1,3): 0.84、0.92——直接效用估计对各状态的样本取平均
2. ADP：三次试验中合计在 (3,3) 执行 Right 共 4 次，2 次到 (3,2)、2 次到 (4,3)，故两个转移概率均估计为 1/2；代入贝尔曼方程求解。学习曲线（图22-3）：(2,1) 与 (3,2) 分别在第 14、23 次试验才"发现"通往 +1 的连接；RMS 误差随试验次数平滑下降
3. TD：观测到转移 (1,3)→(2,3)，当前估计 U(1,3)=0.88、U(2,3)=0.96；若假设该转移总发生，则 U(1,3) 应为 −0.04+0.96=0.92，估计偏低 → 上调：U(1,3) ← 0.88 + α(0.92−0.88)。TD 学习曲线（图22-5，单组 500 次试验）比 ADP 波动更大、收敛更慢
4. 主动版对照：贪心 ADP（图22-6）第三次试验发现经 (2,1)→(3,1)→(3,2)→(3,3) 绕远路到 +1 的策略（(1,2) 取 Down），第 8 次试验起锁死（策略损失 0.235，RMS 误差停在约 1）；R⁺=2、N_e=5 的探索性 ADP（图22-7，估计从乐观值 2 起逐步下调）18 次试验即近最优，策略损失快速归零（效用 RMS 不归零是正常的：不再探索无关区域）

## 要点
1. 奖励信号比标注动作便宜得多，但稀疏奖励 + 信用分配使学习艰难：中间伪奖励可大幅加速，但必须用势函数形式（R′ = R − γΦ(s′) + Φ(s)）才不改变最优策略
2. TD 与 ADP 同源：都让状态与后继效用一致，TD 是单转移采样的 ADP；用模型生成伪经验可在二者间插值
3. Q 学习在学习与选动作两个阶段都不需要转移模型——代价是无法前瞻模拟，稀疏奖励、长动作序列时困难（如《蒙特祖马复仇》）
4. 探索不可省：GLIE 保证最终最优；乐观探索函数把探索红利沿状态传回，防止智能体过早变保守
5. 大状态空间必须函数近似：线性 + 合适特征可收敛（特征本身可非线性，如到目标的距离）；深度网络自动学特征（DQN 从像素学 Q）但可能发散或遗忘，需经验回放
6. 分层 RL 用局部程序给出行为骨架，学习只填选择点：效用加性分解使每个子问题只依赖少数变量，学习快得多（keepaway 控球时间从约 10 秒到"永久"）
7. 奖励难写时向专家要信息：模仿学习直接但脆弱；逆强化学习从演示恢复奖励函数，理解"为什么"，甚至可超越专家
