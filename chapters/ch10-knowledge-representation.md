# 第10章 知识表示 (Knowledge Representation)

## 核心思想
大规模知识表示的关键不是为每个领域写专用公理，而是构建可复用的上层本体论（类别、组成、量度、事件、时间、信念），让领域细节挂接到通用框架；再以语义网络/描述逻辑获得高效的类别继承推断，以非单调逻辑与真值维护系统处理"有例外的默认知识"。

## 框架
- **本体论工程（Ontological Engineering）/ 上层本体论（Upper Ontology）**
  - 何时使用：复杂且跨领域的论域（网上购物、车流驾驶），需要不同领域知识可统一组合推理时
  - 如何做：先定义一般概念（事件、时间、对象、物质、信念）并留出填充位，具体知识（机器人、书籍……）后补——类比 Swing 框架定义"窗口"、用户派生"表单窗口"；要求时空等语句在纳秒/米与分钟/公里间同样可用
- **事件演算（Event Calculus）**
  - 何时使用：动作有持续时间、可并发、有进行中状态（后继状态公理的离散瞬时假设不够用）时
  - 如何做：把事件物化为对象（E₁ ∈ Flyings，可附加 Bumpy(E₁) 等任意信息）；用 T(f,t) 断言流在时刻 t 为真、Happens(e,t₁,t₂) 断言发生、Initiates/Terminates 断言启停流；后继状态公理：事件启动或终止流后，若中途无其他事件改变它，流值保持
- **语义网络（Semantic Network）与描述逻辑（Description Logic）**
  - 何时使用：需要类别层级的可视化与高效推断（前者），或类别定义的形式化与易处理性保证（后者）
  - 如何做：网络用带标签连线表示 MemberOf/SubsetOf，单框箭头表示"类别每个成员都有"的属性、双框表示类别整体的属性；继承算法从对象沿 MemberOf→SubsetOf 上溯取第一个值。描述逻辑用 And/All/AtLeast/AtMost 等构件组合定义，主推断为包容（比较定义判子类）与分类（判成员归属），刻意省略否定与析取换取多项式时间
- **限定与缺省逻辑（Circumscription & Default Logic）**
  - 何时使用：规则有例外（鸟会飞）、常识需要"跳到结论"且可因新证据收回时
  - 如何做：限定=指定 Abnormal 谓词"尽可能假"，是模型偏好逻辑（异常最少的模型被偏好；更强更精确的封闭世界假设）；缺省规则 P : J / C 表示 P 成立且结论 C 与 KB 一致（论证 J 不被驳倒）时推出 C，答案取拓展（最大一致结论集）
- **真值维护系统（Truth Maintenance System：JTMS/ATMS）**
  - 何时使用：默认结论要被收回（信念修正）、或在多个假设世界间频繁切换
  - 如何做：JTMS 给每条语句记录论证（推出它的前提集），Retract(P) 只删除所有论证都含 P 的语句，失证语句标"外"不删除以便恢复；ATMS 给每条语句标注使其成立的假设集，同时表示所有考虑过的假设世界，并支持生成最小解释

## 关键概念
- **物化/具体化（Reification）** — 把命题变成可谈论、可附加属性的对象（类别、流、事件都是物化的产物）。
- **继承（Inheritance）** — 对象经所属类别及子类链获得性质；交互发生在对象层面，而推理大多发生在类别层面。
- **不相交（Disjoint）/完全分解（Exhaustive Decomposition）/划分（Partition）** — 无公共成员的类别；覆盖上级类别全体的分解；二者兼得才是划分（北美人的国籍分解非划分：双重国籍）。
- **PartOf 与束（Bunch）** — 部分关系传递且自反（PartOf(Bucharest, Earth)）；BunchOf(s) 是以 s 中元素为部分的最小无结构复合对象——"袋中苹果重两磅"归给束而非集合（集合是抽象数学对象，只有元素没有重量）；属逻辑最小化技术。
- **量度（Measure）与单位函数** — 性质值是抽象"量度对象"，Inches(1.5)=Centimeters(3.81)，单位换算靠等值公理；无公认尺度的量度（习题难度、诗的优美）只需可排序性（定性物理的基础），强加数值尺度是错误。
- **自然类（Natural Kinds）** — 无充要定义的真实世界类别（番茄有黄有绿）；用 Typical(C) 把"对典型实例成立"与"对全体成立"分层（Wittgenstein 家族相似性；Quine："教皇是单身汉？"）。
- **事物与物质（Thing vs Stuff）** — 只由内在性质（密度、沸点、颜色——切半后保留）定义的类别是物质/不可数名词；含任何外在性质（重量、形状——切半后不保留）的是可数事物。
- **命题态度（Propositional Attitude）** — 相信、知道、想要、告知等；它们要求指代不透明性（露易丝知道超人会飞但不知道克拉克会飞），从而引出模态逻辑。
- **非单调性（Nonmonotonicity）** — 新信息可使旧结论被收回（看到千斤顶顶起的车，收回"四个轮子"）；封闭世界假设与语义网络默认值都是非单调推理程序的实例。

## 思维模型
- 当领域复杂且跨领域时，把表示看作"留空待填的上层本体论"，而不是一次性写全的专用公理集。
- 把事件看作时空片段：对象是一般化事件——USA 自 1776 年延续至今；President(USA) 是一个分段的单对象（1789–1797 段是华盛顿），断言用 T(Equals(President(USA), GWashington), 1790)，用函数符 Equals 而非谓词 =（流不能以谓词为参数，逻辑等价也不随时间变化）。
- 当 n 元谓词无法附加额外信息时，就物化它（事件演算、语义网络的事件节点都由此而来）。
- 当规则有例外时，把"鸟会飞"改写为"正常的鸟会飞"（Abnormal 谓词），让模型偏好机制选异常最少的解释。
- 当"语义网络方便"与"逻辑严格"争执时，记住语义网络本身就是逻辑的一种记法——底层概念（对象、关系、量化）相同。

## 反模式
- **用 IsA 混淆子类与成员、把成员属性安到类别头上**：类别没有母亲，不能画 Persons —HasMother→ Females 连线；早期系统因此产生不一致（McDermott："Artificial Intelligence Meets Natural Stupidity"）。
- **给无尺度的量度强加数值**：需要的只是可排序（难度序、得分单调关系），不是数字。
- **为自然类找充要定义**：严格逻辑定义只对人造形式概念（三角形、单身汉）成立；对番茄应区分典型性质与全称性质。
- **假设模态智能体逻辑全知（logical omniscience）**：K 公理使智能体知道全部公理后果，对知识勉强、对信念（实际表示的而非可推导的内容）明显失真。
- **把缺省当确定知识、或把 TMS 当灵丹妙药**：Retract 会级联依赖结论，需论证支持；而真值维护本身至少与命题推断同难（NP 难）。

## 算法要点
**语义网络继承算法**：从对象出发沿 MemberOf 进入类别，再沿 SubsetOf 上溯，遇到的第一个属性值即答案；对象自身更具体的值覆盖（override）类别缺省值——John 的 Legs=1 覆盖 Persons 的默认 2（或建子类 OneLeggedPerson）。多重继承可能返回冲突值（见 10.6）。

**事件演算的流保持公理**（后继状态公理风格）：若 Happens(e,t₁,t₃)、t₁<t₂<t₃、Initiates(e,f,t₂)、t₃<t₄，且在 (t₁,t₄) 内无其他事件启停 f（¬Clipped），则 T(f,t₄)；对偶地由 Terminates 得 ¬T(f,t₄)。可扩展到并发、外因、连续与非确定性事件。

**时间区间（Allen 代数）**：区分瞬间（时长 0）与延续间隔；Begin/End/Time/Duration/Date 锚定绝对时间；区间关系：Meet（相接）、Before、After、During、Overlaps、Starts、Ends、Equal——注意 Overlap 按定义不对称（仅 i 早于 j 开始时为真），为的是公理更简洁。例：伊丽莎白二世的统治 Meets 乔治六世的统治；猫王走红 Overlap 20 世纪 50 年代。

**缺省规则形式（Reiter）**：P(x) : J₁(x),…,Jₙ(x) / C(x)。P 为先决条件，Jᵢ 为论证（任一可证为假则推不出 C），C 为结论；Jᵢ 与 C 中的变量必须都出现在 P 中。拓展（extension）= 含原始事实与缺省结论的最大集合，其中每个缺省结论的论证都与该集合一致；可用规则优先级消解歧义。

**模态知识公理**：分配律 K_A P ∧ K_A(P⇒Q) ⇒ K_A Q；真理性 K_A P ⇒ P（知识=确证为真的信念，柏拉图）；正内省 K_A P ⇒ K_A K_A P。语义：K_A P 在世界 w 为真当且仅当 P 在所有从 w 经可达关系到达（与 A 所知一致）的世界为真。量词与知识互作用的歧义：∃x K_Bond Spy(x)（知道某特定人是间谍）≠ K_Bond ∃x Spy(x)（只知道存在间谍）。线性时态逻辑补充算子：X（下一时刻真）、F（最终真）、G（始终真）、P U Q（Q 前一直真）。

## 参考表

| | 限定（Circumscription） | 缺省逻辑（Default Logic） |
|---|---|---|
| 机制 | 谓词（如 Abnormal）最小化 | 缺省规则 P : J / C |
| 语义 | 模型偏好：异常最少的模型 | 拓展：最大一致结论集 |
| 尼克松菱形 | 两个偏好模型，推理器不可知 | 两个拓展，推理器不可知 |
| 消歧手段 | 优先限定（prioritized circumscription）| 缺省规则优先级 |

| | JTMS（基于论证） | ATMS（基于假设） |
|---|---|---|
| 语句标注 | 论证集（推出它的前提集）| 假设集标签（在哪些假设下为真）|
| 收回 P | 删除所有论证都含 P 的语句；失证语句标"外"留待恢复 | 无须收回，标签自动反映 |
| 状态表示 | 任一时刻只表示一个状态 | 同时表示所有考虑过的假设世界 |
| 擅长 | 信念修正 | 多假设切换（换奥运场地只改一条断言）、生成最小解释（"汽车无法启动"：电瓶没电/没油）|

## 完整示例
**类别与继承（FOL + Classic 记法）**：成员 b ∈ Basketballs；子类 Basketballs ⊆ Balls；全称性质 ∀x Food(x)⇒Edible(x) 加 Fruit⊆Food、Apple⊆Fruit ⟹ 苹果可食用；{本科生, 研究生} 是学生的不相交完全分解（=划分）；单身汉 = And(Unmarried, Adult, Male)；"至少 3 个儿子、至多 2 个女儿、儿子皆无业且娶医生、女儿皆物理或数学教授的男人" = And(Man, AtLeast(3,Son), AtMost(2,Daughter), All(Son, And(Unemployed, Married, Doctor)), All(Daughter, Or(Prof(Physics), Prof(Math))))——描述逻辑对谓词做代数运算，一阶逻辑中没有对应物。

**默认推理（鸟会飞 / 尼克松菱形）**：
- 限定式：Bird(x) ∧ ¬Abnormal₁(x) ⇒ Flies(x)；限定 Abnormal₁ 后，由 Bird(Tweety) 得 Flies(Tweety)；一旦断言 Abnormal₁(Tweety)，结论收回。
- 尼克松菱形：Quaker(Nixon) ∧ ¬Ab₂(Nixon) ⇒ Pacifist(Nixon)；Republican(Nixon) ∧ ¬Ab₃(Nixon) ⇒ ¬Pacifist(Nixon)；限定 Ab₂、Ab₃ 得两个偏好模型/拓展（和平或非和平），推理器不可知；断言"宗教优先于政治"（优先限定）即可消歧。
- 语义网络版：Persons 默认 Legs=2（单框箭头），John Legs=1 覆盖之——继承算法自 John 上溯先遇到 1 即停止。

**超人问题（模态逻辑）**：露易丝不知道超人就是克拉克，但她知道克拉克自己知道：¬K_Loise(Superman=Clark) ∧ K_Loise K_Clark(Superman=Clark)。可达世界例：不知罗马尼亚首都的智能体可到达"首都是索非亚"的世界，但任何智能体都不可达 2+2=5 的世界。

**事件演算（飞行）**：E₁ ∈ Flyings，Happens(E₁,t₁,t₂)；效果为 Terminates(E₁, At(Shankar,SF), t₁)、Initiates(E₁, At(Shankar,DC), t₁)；若无后续 Clipped，则对一切 t₄>t₂ 有 T(At(Shankar,DC), t₄)。

## 要点
1. 交互在对象层面，推理在类别层面——先建分类学层级（分类法是几百年的成熟技术），再填个体。
2. 二元表达的限制逼出物化：事件、类别、流都是被物化的命题（语义网络表示 n 元 Fly 靠事件节点；给事件附加 Bumpy 属性）。
3. 描述逻辑用表达力换易处理性：砍掉否定/析取（仅 Fills/OneOf 允许枚举析取）保证包容检测多项式——代价是要么不能陈述困难问题，要么需要指数级描述。
4. 事件演算优于后继状态公理之处：持续时间、并发、进行中状态、可附加任意信息。
5. 封闭世界假设的严格化就是限定；语义网络默认值是其过程化实现——三种默认机制语义同源。
6. 缺省推理最难的问题在决策：缺省规则实质是"阈值概率"（刹车好用→不用检查就开车），应嵌入概率与效用理论（第 12/14 章方向）。
7. 本体论构建有四条路径：专家写公理（CYC）、从数据库引入（DBpedia）、文本抽取（TextRunner）、众包常识（Open Mind）；谷歌知识图谱综合之（700 亿条事实、约 1/3 查询）。
8. TMS 至少 NP 难：它是假设世界管理的加速器，不是通用推断的解药。
