# 第16章 做简单决策 (Making Simple Decisions)

## 核心思想
概率论描述智能体该**相信**什么，效用理论描述它**想要**什么，决策论把两者结合成"该**做**什么"：理性智能体选择最大化期望效用（MEU）的动作。本章在回合式（单步）决策设定下建立效用公理、多属性效用、决策网络与信息价值。

## 框架
- **最大期望效用原则（Maximum Expected Utility, MEU）**
  - 何时使用：给定信念 P 与效用 U，从候选动作中做单步理性选择
  - 如何做：EU(a|e) = Σ_s′ P(Result(a)=s′|e) U(s′)，选 EU 最大的动作；MEU 形式化而非实现"做正确的事"——估计 P(Result(a)) 需要感知、学习、因果模型
- **效用公理与效用函数存在性（von Neumann–Morgenstern）**
  - 何时使用：需要论证"为什么必须最大化期望效用"或从偏好推出效用
  - 如何做：偏好满足有序性/传递性/连续性/可替换性/单调性/可分解性六公理 ⟹ 存在 U 使 A≻B ⟺ U(A)>U(B)，且彩票效用 = 期望效用；U 唯一至正仿射变换 U′=aU+b（a>0）
- **多属性效用理论（Multiattribute Utility Theory, MAUT）**
  - 何时使用：结果由两个以上属性刻画（机场选址：吞吐/安全/安静/节俭），需"比较苹果与桔子"
  - 如何做：先用严格占优/随机占优筛选项；若属性相互偏好独立（MPI）则价值函数加性可分；若相互效用独立（MUI）则效用函数为乘性形式，各单属性效用可独立评估
- **决策网络（Decision Network / 影响图 Influence Diagram）**
  - 何时使用：需要可执行的表示来综合信念、动作与效用
  - 如何做：贝叶斯网络 + 决策节点（矩形）+ 效用节点（菱形）；简化形式以动作效用函数（Q 函数）直接连接决策与效用
- **完美信息价值（Value of Perfect Information, VPI）**
  - 何时使用：决定在行动前是否购买/收集某项观测（诊断测试、地质调查）
  - 如何做：VPI(E_j) = 对 E_j 的每个取值取平均的"新最佳动作价值"减去当前最佳动作价值；信息只有可能**改变规划**且新规划明显更优时才有价值

## 关键概念
- **彩票（lottery）** — 结果-概率对 [p₁,S₁; …; pₙ,Sₙ]，结果本身可为复合彩票；效用理论的运算对象。
- **序数效用/价值函数（ordinal utility / value function）** — 确定性环境下只需对状态排序，数值大小无关紧要。
- **偏好启发（preference elicitation）** — 通过呈现选择、观察偏好来重建人的效用函数。
- **标准彩票评估（standard lottery）** — 归一化尺度（u⊥=0, u⊤=1）下调节概率 p 至无差异，则 U(S)=p。
- **期望货币价值（EMV）** — 金钱期望值；与 EU 不同——凹效用下 EMV 大的赌局可能效用更低。
- **风险厌恶/风险寻求/风险中性（risk-averse/seeking/neutral）** — 由效用曲线凹/凸/线性决定；确定性等价值（certainty equivalent）与 EMV 之差为保险费（insurance premium），是保险业的基础。
- **乐观者诅咒（optimizer's curse）** — 取 k 个含噪效用估计的最大值引入系统性向上偏差（k=3 约 0.85σ，k=30 约 2σ）；对策是对估计误差建贝叶斯模型。
- **微亡（micromort）与 QALY** — 百万分之一死亡概率的"货币"；质量调整寿命年——医疗安全决策的效用尺度；统计学生命价值（2019 年约 1000 万美元）。
- **确定性效应/模糊厌恶/框架效应/锚定效应** — 阿莱悖论、埃尔斯伯格悖论等人类系统性偏离规范理论的现象（描述性 vs 规范性理论）。
- **随机占优（stochastic dominance）** — 若 A₁ 的属性累积分布总在 A₂ 右侧，则对任何单调不减效用函数 A₁ 期望效用不低于 A₂，可无须数值效用即可淘汰选项。
- **相互偏好独立性（MPI）/ 相互效用独立性（MUI）** — 分别导出加性价值函数（Debreu）与乘性效用函数（Keeney）的表示定理条件。
- **短视信息收集（myopic information gathering）** — 每步贪心选单位成本 VPI 最高的观测；非短视的最优信息收集是超指数的条件规划树（属 POMDP）。

## 思维模型
- 把效用想成温度：仿射变换不改决策，尺度可任意归一化。
- 把每个非确定动作的结果看作一张彩票；理性 = 彩票间偏好与公理一致。
- 当选项在所有属性上一致更好（或累积分布一致更靠右）时，不需要任何效用数值——先占优后效用。
- 把信息获取看作"押注规划会改变"：规划不变，信息分文不值。
- 把未知的自身偏好（榴莲口味）转移到世界中的随机变量（LikesDurian），效用函数即可保持确定性，全部机器照常运转。

## 反模式
- **用 EMV 代替 EU**：100 万现金 vs 掷币赌 250 万——EMV 高的赌局在凹效用下效用更低（U(S_k+1M)=8 > 接受的 0.5×5+0.5×9=7）；亿万富翁则相反。
- **按面值对待效用估计**：从上千候选中选出"治愈 9/10"的药可能差于"治愈 800/1000"的药——高方差估计的最大值几乎必然高估。
- **拒绝为生命定价反而压低生命价值**：石棉案例中机构因道德愤怒拒绝显式定价，其"不拆除"决定隐式赋予了更低价值。
- **假设人类偏好一致稳定**：阿莱悖论（B≻A 且 C≻D 无任何效用函数可同时满足）、框架效应（90% 存活 vs 10% 死亡）——偏好判断可被追问修正，决策支持系统应主动消解矛盾而非硬拟合。
- **对多属性问题直接猜联合效用**：不做 MPI/MUI 检验就指定 dⁿ 个值既不可行也不必要。
- **极小化极大式"健壮"决策当默认**：对其他车辆做最坏假设（都是杀人狂）的自动驾驶汽车最优策略是留在车库；贝叶斯超参数通常更优。

## 算法要点
**决策网络评估**
```
1. 为当前状态设置证据变量
2. 对决策节点的每个可能值 a:
   a. 将决策节点设置为 a（此后如同证据节点）
   b. 用标准概率推断求效用节点各父节点的后验分布
   c. 计算该动作的结果效用（期望）
3. 返回效用最高的动作
```
**标准彩票效用评估**：固定 u⊥=0、u⊤=1；对每个奖励 S，调 p 使智能体在 S 与 [p,u⊤; 1−p,u⊥] 间无差异，则 U(S)=p；此后一切彩票效用由期望唯一确定。
**VPI 一般公式与性质**
```
VPI(E_j) = ( Σ_{e_j} P(e_j|e) · max_a EU(a|e, e_j) ) − max_a EU(a|e)
性质：VPI ≥ 0（期望意义，最坏可忽略信息）；不可加：VPI(E_j,E_k) ≠ VPI(E_j)+VPI(E_k)；
次序无关：VPI(E_j|e) + VPI(E_k|e,e_j) = VPI(E_k|e) + VPI(E_j|e,e_k)
```
**短视信息收集智能体**：循环选使 [VPI(E_j) − C(E_j)] / C(E_j)（单位成本增益）最大的观测 Request(E_j)；无可盈利观测时执行实际动作。
**寻宝/最小成本测试序列**：n 个位置各以独立概率 P(i) 藏宝、检查成本 C(i) 且找到即停，则最优检查顺序按**每单位成本的成功概率 P(i)/C(i) 降序**排列（由相邻子序列交换论证：换位成本变化方向与上下文无关）。
**开关游戏（顺从人类）**：机器人 R 提议动作 a 对主人 H 的效用先验为 P(u)；则直接执行 EU(a)=∫u·P(u)du，而听凭 H 关机 EU(d)=∫_{u>0}u·P(u)du ≥ EU(a)（负效用区归零）。只要 R 不确定 H 的偏好，允许被关闭就是严格更优——顺从是期望效用推理的必然结论，而非硬编码。

## 参考表
**效用公理（理性偏好六约束）**
| 公理 | 内容 | 违反后果 |
|---|---|---|
| 有序性 | 任意两彩票必可比较 | 拒绝决策如拒绝时间流逝 |
| 传递性 | A≻B, B≻C ⟹ A≻C | 1 美分交换环被抽干全部钱 |
| 连续性 | B 介于 A,C 之间 ⟹ 存在 p 使 B ~ [p,A;1−p,C] | 极端厌恶/迷恋 |
| 可替换性 | A~B ⟹ 复合彩票中可互换 | 自相矛盾的定价 |
| 单调性 | 偏好 A≻B ⟹ 选 A 概率更高的彩票 | 反向押注 |
| 可分解性 | 复合彩票可按概率法则化简 | "无趣赌博"不可消 |

**信息价值三情形（图16-8）**：a) 某动作几乎必优——信息无用；b) 选项相当且后果差异大——信息关键；c) 选项相当但差异微小——信息低值。

## 完整示例
**阿莱悖论**：A=80% 得 $4000；B=100% 得 $3000；C=20% 得 $4000；D=25% 得 $3000。多数人选 B（弃 A）且选 C（弃 D）。设 U($0)=0：B≻A ⟹ U(3000) > 0.8·U(4000)；C≻D ⟹ 0.2·U(4000) > 0.25·U(3000) ⟹ U(3000) < 0.8·U(4000)。矛盾——不存在一致的效用函数；解释为确定性效应。
**保险与确定性等价**：多数人接受约 $400 而非 50/50 的 $1000/$0（EMV=$500），差额 $100 为保险费；保险公司因效用曲线在其总资产尺度上近线性而几乎零成本承接——风险偏好差异使双方都获益。
**石油开采权 VPI**：n 块等价区块恰一块含油（净利 C），每块售价 C/n，不买与买无差异（期望利润皆 0）。买了 3 号区块的完美调查：1/n 概率有油→获利 C−C/n；其余情况改买他块，期望利润 C/(n−1)·1... 合计信息后期望利润恰为 C/n——即信息价值 C/n，公司应愿支付其大部分。
**开关游戏数值**：R 对订酒店的 H 价值先验为 [−40,+60] 均匀（均值 +10）；关掉自己 = 0；直接订的 EU=+10 < 等待（0.4×0 + 0.6×30 = 18）。H 的批准把信念截断为 [0,+60]（均值 +30）——H 的选择本身是信息，信息的期望价值非负使顺从成为理性。

## 要点
1. MEU 把外部性能度量转移到内部效用函数：效用作用于下一状态，可逐步指导动作。
2. 效用函数的存在性由偏好公理保证，唯一性仅至正仿射变换；确定性环境退化为序数价值函数。
3. 金钱 ≠ 效用：凹效用解释保险、赌博拒绝与大额风险态度反转（S 形曲线的"绝望区"风险寻求）。
4. 永远警惕乐观者诅咒：被选中的估计几乎必然偏乐观，用估计误差的贝叶斯模型校正后再决策。
5. 占优先行：严格/随机占优能在不指定任何效用数值的情况下淘汰选项。
6. VPI 非负、非可加、次序无关；智能体应按单位成本 VPI 贪心收集信息并在无利可图时停止。
7. 效用不确定时把它搬进世界模型（随机变量），决策机器照常工作——这也是机器顺从人类的形式基础。
