# 第14章 时间上的概率推理 (Probabilistic Reasoning over Time)

## 核心思想
把动态世界建模为"转移模型 + 传感器模型"的（一阶马尔可夫、时间齐次）时序概率模型，则滤波、预测、平滑、最可能解释四大推断任务都可用递归消息传递完成，代价与序列长度成线性。

## 框架
- **隐马尔可夫模型 (hidden Markov model, HMM)**
  - 何时使用：状态由单个离散变量描述的时序过程（多变量可并成单个"大变量"，但代价是 O(d²ⁿ) 的转移矩阵）
  - 如何做：转移矩阵 Tᵢⱼ = P(X_{t+1}=j | X_t=i)；每个时间步构造对角观测矩阵 O_t(i,i) = P(e_t | X_t=i)；滤波 f_{1:t+1} = α O_{t+1} Tᵀ f_{1:t}，后向 b = T O_t b；前向-后向总代价 O(S²t)
- **前向-反向算法 (forward-backward algorithm)**
  - 何时使用：给定 e_{1:t} 计算过去某时刻的 P(X_k | e_{1:t})（平滑），或整个序列的平滑
  - 如何做：前向消息 f_{1:k} 按滤波递归逐存；后向消息 b_{k+1:t}(x_k) = Σ_{x_{k+1}} P(x_{k+1}|x_k) P(e_{k+1}|x_{k+1}) b_{k+2:t}(x_{k+1})，从 b_{t+1:t}=1（全 1 向量）倒推；P(X_k|e_{1:t}) = α f_{1:k} × b_{k+1:t}（逐点乘积）；复用存储的前向结果使整条序列平滑只需 O(t)
- **维特比算法 (Viterbi algorithm)**
  - 何时使用：最可能解释——求最可能产生观测序列的状态序列 argmax P(x_{1:t} | e_{1:t})（语音识别、噪声信道解码）
  - 如何做：与滤波同构，把对 x_t 的求和换成最大值：m_{1:t+1} = O_{t+1} Tᵀ max m_{1:t}；为每个状态记录最佳前驱（回溯指针），末尾取最优终态并沿指针回溯；时间线性、空间线性
- **卡尔曼滤波 (Kalman filtering)**
  - 何时使用：连续状态变量、线性高斯转移与传感器模型（雷达跟踪、过程控制）
  - 如何做：预测 μ̄ = F μ_t，Σ̄ = F Σ_t Fᵀ + Σ_x；更新 μ_{t+1} = μ̄ + K_{t+1}(z_{t+1} − Hμ̄)，Σ_{t+1} = (I − K_{t+1}H)Σ̄，其中 K 为卡尔曼增益矩阵；高斯族在贝叶斯更新下封闭，故信念永远是单个高斯
- **粒子滤波 (particle filtering)**
  - 何时使用：一般动态贝叶斯网络的在线近似滤波——非线性、非高斯、多变量混合
  - 如何做：用 N 个样本（粒子）作为信念状态的表示；每步 ① 每个样本按转移模型 P(X_{t+1}|x_t) 向前传播；② 按新证据似然 P(e_{t+1}|x_{t+1}) 加权；③ 按权重成比例重采样出 N 个无权重新样本
- **动态贝叶斯网络 (dynamic Bayesian network, DBN)**
  - 何时使用：多状态变量的时序过程，需利用稀疏性（表示规模 O(ndᵏ) vs HMM 的 O(d²ⁿ)）
  - 如何做：指定两时间片模板——先验 P(X₀)、转移模型 P(X_t|X_{t-1})、传感器模型 P(E_t|X_t)；按需复制时间片（展开）后用第13章任意推断算法；精确滤波只需滚动保留两个时间片、对上一片做变量消元

## 关键概念
- **马尔可夫假设 (Markov assumption)** — 当前状态只依赖有限个过去状态；一阶形式 P(X_t | X_{0:t-1}) = P(X_t | X_{t-1})，使状态"足以生成"未来
- **传感器马尔可夫假设 (sensor Markov assumption)** — 观测只依赖当前状态：P(E_t | X_{0:t}, E_{1:t-1}) = P(E_t | X_t)
- **转移模型 / 传感器模型 (transition model / sensor model)** — 状态如何演化 / 观测如何由状态产生；箭头从状态指向传感器（因果方向），推断方向则相反
- **时间齐次 (time-homogeneous)** — 转移与传感器规律不随 t 变化，一张 CPT 适用于所有时间步
- **滤波 (filtering / 状态估计)** — 计算 P(X_t | e_{1:t})，即信念状态的递归更新；理性智能体决策的基础
- **预测 (prediction)** — 计算 P(X_{t+k} | e_{1:t})，只前推不更新；远期预测收敛到转移模型的平稳分布 (stationary distribution)
- **平滑 (smoothing)** — 计算 P(X_k | e_{1:t}) (k<t)；因纳入更多证据，永远不差于当时的滤波估计
- **最可能解释 (most likely explanation)** — argmax_{x_{1:t}} P(x_{1:t} | e_{1:t})；必须联合优化整个序列，不能逐步取最大
- **混合时间 (mixing time)** — 马尔可夫过程达到平稳分布所需时间；转移不确定性越大混合越快、远期预测越模糊
- **扩展卡尔曼滤波器 / 切换卡尔曼滤波器 (extended / switching Kalman filter)** — 在均值点局部线性化以处理光滑非线性；或多模型并行加权和
- **持续弧 (persistence arc)** — 同一变量跨时间片的边（如 BMBroken_t-1 → BMBroken_t），建模"一旦故障持续故障"
- **瞬时 / 持续故障模型 (transient / persistent failure model)** — 传感器以小概率输出任意值 / 增广传感器状态变量并配持续弧；信念的"惯性"来自模型必须包含故障可能性
- **Rao-Blackwell化粒子滤波 (Rao-Blackwellized particle filter)** — 对条件独立于采样轨迹的变量子集做精确推断（如每个方格的独立 HMM），只对其余变量采样

## 思维模型
- 把滤波看作两拍循环："预测"（转移模型前推）+"更新"（新证据加权归一化）；消息 f_{1:t} 是沿时间向前传播的信念包
- 把 HMM 状态序列看作图中路径：滤波是路径求和（sum-积），维特比是最优路径搜索（max-积）
- 把粒子滤波看作适者生存的种群：传播—加权—重采样，资源（样本）不断流向后验高概率区域
- 当一阶马尔可夫假设近似不成立时，优先扩状态变量集（Battery、Season、(位置,方向)）而不是提高阶数——升阶总可改写为扩状态
- 建模方向（状态→传感器）与推断方向（传感器→状态）相反，这正是贝叶斯网络的优点

## 反模式
- **每步重算整个感知历史**：更新代价随 t 无限增长；滤波必须递归——每步常数时间与空间（否则有限智能体无法无限期追踪）
- **用逐时间步的平滑后验拼接"最可能序列"**：单步最大化的拼接可能与联合最优序列完全不同（习题14.VITE）
- **对多峰/非线性问题硬套卡尔曼滤波**：单高斯无法表示"钥匙在口袋/床头柜/车里"的多峰信念，鸟避树的均值预测落在树干上
- **传感器模型不含故障模式**：20 次读数 5 之后一次读数 0，简单高斯误差模型就令机器人确信电池耗尽并求救关机——模型必须包含瞬时故障（小概率任意输出）与持续故障（BMBroken 状态变量）
- **对确定性转移用标准粒子滤波**：灰尘地图初始猜对概率 2⁻⁴²，确定性转移使初始猜测永不被证据修正，粒子多样性坍缩到单张错误地图；需 Rao-Blackwellization
- **序贯重要性采样不加重采样**：与证据一致的样本比例随 t 指数下降，10 万样本也在约 20 步后完全失效

## 算法要点

滤波（前向递归，核心方程 14-5）：
```
f_{1:t} = FORWARD(f_{1:t-1}, e_t):
    对每个 x_t:  Σ_{x_{t-1}} P(x_t | x_{t-1}) · f_{1:t-1}(x_{t-1})   // 预测
    乘 P(e_t | x_t) 并归一化 α                                        // 更新
从 f_{1:0} = P(X₀) 开始；每步常数时间与空间
```

平滑（前向-反向）：
```
FORWARD-BACKWARD(e_{1:t}):
    fv[0] ← f_{1:0}
    for i = 1..t: fv[i] ← FORWARD(fv[i-1], e_i)      // 存全部前向消息
    b ← 1（全1向量）
    for i = t..1:
        sv[i] ← NORMALIZE(fv[i] × b)                  // 每步的平滑估计
        b ← BACKWARD(b, e_i):
              对每个 x_{i-1}: Σ_{x_i} P(x_i|x_{i-1}) P(e_i|x_i) b(x_i)
    返回 sv[1..t]                                     // 总时间 O(t)
```
HMM 矩阵形式：f = α O_{t+1} Tᵀ f，b = T O_t b（14-12/14-13）。

维特比解码：
```
m_{1:0} ← P(X₀)
for i = 1..t:
    对每个终态 x_i: m(x_i) ← P(e_i|x_i) · max_{x_{i-1}} [ P(x_i|x_{i-1}) · m_{i-1}(x_{i-1}) ]
    记录达到每个 x_i 的最佳前驱指针
从最优终态沿指针回溯输出序列
```
数值下溢对策：每步归一化（max 不受常数因子影响）或全程用对数概率（log 单调）。

卡尔曼滤波（一维随机游走，转移噪声 σₓ²，传感器噪声 σ_z²）：
```
预测:  σ̄² = σ_t² + σₓ²            （均值不变，方差相加）
更新:  μ_{t+1} = (σ_z²·μ̄ + σ̄²·z_{t+1}) / (σ̄² + σ_z²)
       σ_{t+1}² = (σ̄²·σ_z²) / (σ̄² + σ_z²)
```
新均值是旧均值与新观测按方差的加权平均；方差更新与观测无关且快速收敛到不动点 → K 序列可离线算好。

粒子滤波（递归更新，状态 = 样本集）：
```
PARTICLE-FILTER(S, e_{t+1}, N):
    S' ← { 按转移模型 P(x_{t+1}|x_t) 传播每个 x_t ∈ S }
    w_i ← P(e_{t+1} | x'ᵢ)                // 按证据加权
    S ← 从 S' 中按 w 成比例重采样 N 个（无权重）样本
    返回 S
```
一致性：重采样后期望样本数 ∝ 状态的预测概率 × 证据似然，恰为新的前向消息。

## 参考表

三大时序模型对比：

| 模型 | 状态表示 | 每步滤波代价 | 关键限制 |
|---|---|---|---|
| HMM | 单个离散变量（S 个值） | O(S²) | 原子表示；n 个 d 值变量 → S=dⁿ，矩阵 O(d²ⁿ) |
| 卡尔曼滤波器 | 单个多元高斯 (μ, Σ) | 矩阵运算，方差序列离线可算 | 仅线性高斯；单峰 |
| DBN（精确） | n 个变量的因子化 CPT | O(n·d^{n+k}) | 表示线性于 n，但后验（前向消息）不可分解，精确更新仍指数 |
| DBN + 粒子滤波 | N 个样本 | O(N·每样本局部采样) | 通用近似；确定性转移与传感器故障是弱点 |

推断任务一览：滤波 P(X_t|e_{1:t})（常数时间每步）；预测 P(X_{t+k}|e_{1:t})（纯转移前推，远期收敛平稳分布）；平滑 P(X_k|e_{1:t})（前向-反向，O(t)）；最可能解释 argmax P(x_{1:t}|e_{1:t})（维特比，O(t)）；学习（EM 或贝叶斯更新，第20章）。

## 完整示例

雨伞世界（保安从主管带伞推断下雨）：状态 Rain_t，证据 Umbrella_t。
转移模型 P(R_t|r_{t-1})=0.7，P(R_t|¬r_{t-1})=0.3；传感器模型 P(U_t|r_t)=0.9，P(U_t|¬r_t)=0.2；先验 P(R₀)=⟨0.5, 0.5⟩。转移矩阵 T = [[0.7,0.3],[0.3,0.7]]。

滤波（观测 U₁=true，U₂=true）：
- 第 1 天：预测 ⟨0.5, 0.5⟩ → 加权 ⟨0.9×0.5, 0.2×0.5⟩ = ⟨0.45, 0.10⟩ → 归一化 **f₁ = ⟨0.818, 0.182⟩**
- 第 2 天：预测 ⟨0.818×0.7+0.182×0.3, 0.818×0.3+0.182×0.7⟩ = ⟨0.627, 0.373⟩ → 加权 ⟨0.565, 0.0746⟩ → **f₂ = ⟨0.883, 0.117⟩**（雨持续，下雨概率上升）

平滑 P(R₁ | u₁, u₂)：
- 后向：b₂(r₁) = 0.7×0.9 + 0.3×0.2 = 0.69；b₂(¬r₁) = 0.3×0.9 + 0.7×0.2 = 0.41
- 平滑 = α⟨0.818×0.69, 0.182×0.41⟩ = **⟨0.883, 0.117⟩** > 滤波估计 0.818：第二天带伞提升了第二天下雨的概率，而降雨倾向于持续，回溯提升了第一天的估计。

维特比（观测 [true, true, false, true, true]）：在每个时间步为每个状态维护 m 消息（最佳到达概率）与最佳前驱指针；沿末端最优状态的指针回溯得最可能天气序列，可顺带解决"第三天没带伞是没下雨还是忘带"的歧义。远期预测则收敛到平稳分布 ⟨0.5, 0.5⟩。

## 要点
1. 递归滤波是部分可观测智能体的常态：每步常数时间与空间，代价不随历史增长——式(14-5)是全章核心。
2. 平滑不差于滤波（更多证据）；前向-向后算法靠存储前向消息把整条序列的平滑降到 O(t)。
3. 维特比 = 滤波的 max 版本；序列解码必须联合优化，逐步取最大后验会给出错误答案。
4. 卡尔曼滤波是"高斯族封闭性"的红利：均值更新 = 预测 + 增益×新息（预测观测误差），增益与方差序列离线确定。
5. 粒子滤波的有效性来自重采样把样本聚焦到高概率区域；前提是转移/传感器概率有界地离开 0 与 1。
6. 恢复马尔可夫性靠扩状态（Battery、BMBroken、(位置,方向)），传感器建模（漂移、瞬时故障、持续故障）本身就是子领域。
7. 表示廉价 ≠ 推断廉价：DBN 表示规模线性于变量数，但精确滤波的"常数"是指数级——这正是粒子滤波存在的理由。
