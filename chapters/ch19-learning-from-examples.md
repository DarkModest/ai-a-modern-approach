# 第19章 样例学习 (Learning from Examples)

## 核心思想
学习的目标不是拟合训练集，而是泛化到未观测的样例：在"与数据一致"和"假设简单"之间权衡（奥卡姆剃刀），用留出的测试/验证数据做裁判。本章围绕这一主轴展开决策树、线性模型、非参数模型、SVM 与集成方法，并给出样本复杂性与工程实践的完整图景。

## 框架
- **决策树归纳（Decision Tree Learning，Learn-Decision-Tree）**
  - 何时使用：离散/连续属性的分类与回归（CART），尤其需要可解释模型时
  - 如何做：贪心分治——每次选信息增益最大的属性分裂，递归处理子集；全为同类则成叶；无样例/无属性时返回多数类；事后用 χ² 显著性检验剪枝（先生成后剪枝，优于提前停止）
- **模型选择与交叉验证（Model Selection / k-fold Cross-Validation）**
  - 何时使用：需要在多个假设空间或超参数值中挑选
  - 如何做：训练集训练、验证集选模型、测试集只碰一次（防研究者泄漏）；数据不足时 k 折交叉验证（k=5/10），超参数定后用全部数据重训
- **正则化与最小描述长度（Regularization / MDL）**
  - 何时使用：假设空间大、数据有限、防过拟合
  - 如何做：最小化总代价 Cost(h)=经验损失+λ·复杂度；L1 正则化产生稀疏解（不相关特征权重归零），L2 平滑但旋转不变；MDL 直接最小化"假设编码位数+数据残余编码位数"
- **PAC 学习理论（Probably Approximately Correct Learning）**
  - 何时使用：分析"需要多少样例才能保证泛化"
  - 如何做：N ≥ (1/ε)(ln|H| + ln(1/δ)) 个 i.i.d. 样例后，一致性假设以 ≥1−δ 概率误差 ≤ε；受限假设空间（如 k-DL 决策列表）样本复杂性是 n 的多项式，而全部布尔函数需 2^n 级
- **线性模型家族（Linear Regression / 感知机 / 逻辑斯谛回归）**
  - 何时使用：数值输入的回归，或（近）线性可分的分类
  - 如何做：回归最小化 L2 损失（闭式正规方程 w*=(X^TX)^{-1}X^Ty，或梯度下降）；分类用硬阈值得感知机更新规则（线性可分才收敛，α 需 O(1/t) 衰减），换软阈值（sigmoid）得逻辑斯谛回归，梯度下降稳定收敛、输出可解释为概率
- **支持向量机与核技巧（SVM / Kernel Trick）**
  - 何时使用：中小规模数据、高维输入、无线性可分时
  - 如何做：解对偶二次规划求最大边距分离器（决策只由少数支持向量决定）；数据只以点积出现 → 用核函数 K(x,x') 替换点积（默瑟定理保证对应某特征空间），隐式在数十亿维甚至无限维空间中线性分离
- **集成学习（Ensemble Learning：Bagging / 随机森林 / Stacking / AdaBoost / 梯度提升）**
  - 何时使用：降方差（bagging、随机森林，基模型不稳定如决策树）或降偏差（boosting、stacking，基模型太弱如决策树桩）
  - 如何做：bagging 有放回采样+投票；随机森林再随机化属性选择（每次分裂只看 √n 或 n/3 个属性）+袋外误差评估；AdaBoost 迭代加错分样例权重+加权多数投票；梯度提升让新树拟合损失的负梯度

## 关键概念
- **监督/无监督/强化学习（supervised / unsupervised / reinforcement learning）** — 按反馈类型划分的三种学习：输入-输出对、无标签模式、奖励惩罚。
- **假设空间（hypothesis space）** — 学习器可输出的所有候选函数 h 的集合；选择它就是在表达能力与计算/泛化难度间权衡。
- **泛化（generalization）** — 假设对未见输入仍预测准确的能力，只能在独立测试集上度量。
- **偏差-方差权衡（bias-variance tradeoff）** — 假设空间约束带来的系统性偏离（偏差/欠拟合）与训练集波动带来的假设变化（方差/过拟合）之间的取舍。
- **信息增益（information gain）** — 按属性 A 分裂后熵的期望减少量，决策树选择分裂属性的判据。
- **超参数（hyperparameter）** — 定义模型类而非单个模型的"旋钮"（树节点数、正则化系数 λ、学习率、k），用验证集调优。
- **损失函数（loss function）** — 对错误预测的惩罚：L0/1（错误率）、L1（绝对误差，抗离群）、L2（平方误差，高斯噪声下最大似然）。
- **正则化（regularization）** — 在经验损失上加复杂性惩罚项以偏好更简单的假设。
- **线性可分与决策边界（linear separability / decision boundary）** — 存在直线（超平面）将两类数据完全分开；该超平面即线性分离器。
- **参数/非参数模型（parametric / nonparametric model）** — 前者用固定个数参数概括数据（线性回归），后者用数据本身表示模型（最近邻、SVM、局部加权回归）。
- **维数灾难（curse of dimensionality）** — 高维空间中 k 邻域平均边长 (k/N)^{1/n} 趋近整个空间，近邻推断退化为外推。
- **集成模型（ensemble model）** — 组合多个基模型预测（投票/平均/再加权）以同时减小偏差与方差。
- **样本复杂性（sample complexity）** — PAC 框架下达到给定误差/置信度所需的训练样例数。
- **无悔学习（no-regret learning）** — 在线学习中平均遗憾趋于 0：错误数至多 1.39·M*+O(√...)，即使数据由对手选取。

## 思维模型
- 当属性少、数据多、内存装不下时，把数据本身当模型（非参数）；当数据少时，用强约束的参数模型防过拟合。
- 把正则化看作"给简单假设更高先验概率"的频率派镜像（第20章的 MAP/MDL 会严格化这一点）。
- 把 L1 看作"对坐标轴认真的"惩罚：菱形约束框的角落在轴上，解因此稀疏；L2 是旋转不变的球，适合轴可任意旋转的情形。
- 当验证误差曲线呈 U 形（决策树），选最低点；当它插值后二次下降（深度网络、随机森林、boosting），继续加复杂度反而更优——先认清手里的模型类属于哪一类。
- 把 boosting 看作"让下一个基模型专注上一轮的错题"，把梯度提升看作"让下一棵树拟合损失梯度的负方向"。

## 反模式
- **在训练集上评估、或反复用测试集调超参数**：单个假设没作弊，但整个过程泄漏了测试集信息；测试集必须完全锁定到最后。
- **把一致性当泛化**：12 次多项式能完美穿过 13 个点，恰是过拟合的典型。
- **提前停止代替后剪枝**：XOR 的两个属性单独都无信息，提前停止会错过组合后高信息量的分裂；"先生成后剪枝"能正确处理。
- **固定学习率的感知机规则用于不可分数据**：永远震荡不收敛；学习率需按 O(1/t) 衰减。
- **高维中用 1-近邻/不归一化距离**：维度单位不统一会改变最近邻；k 过小过拟合、过大欠拟合，用交叉验证定 k。
- **在不平衡类上报告准确率**：全判多数类即得 99.99%；应重采样、加权损失或换 ROC/AUC 度量。
- **小数据上未做平滑的最大似然**（见第20章）：未出现事件的概率被置 0。

## 算法要点
**决策树归纳（贪心+熵）**
```
Learn-Decision-Tree(examples, attrs):
  if 全为正/全为负: return 叶(Yes/No)
  if attrs 空: return 叶(Plurality-Value(examples))
  A ← argmax_{a∈attrs} Gain(a)          # Gain(A)=B(p/(p+n)) − Σ_k (p_k+n_k)/(p+n)·B(p_k/(p_k+n_k))
  tree ← 以 A 为根的新测试节点
  for A 的每个值 v_k:
    ex_k ← {e ∈ examples : e.A = v_k}
    子分支 ← (ex_k 空? 叶(Plurality(examples)) : Learn-Decision-Tree(ex_k, attrs−{A}))
  return tree
剪枝：对每个仅挂叶的测试节点算 Δ=Σ_k 实际偏差，若低于 χ²_{d−1} 阈值(5%)则删测试换叶
```

**梯度下降（单变量线性回归，L2 损失）**
```
w ← 权重空间任一点
repeat:  w_i ← w_i + α · Σ_j (y_j − h_w(x_j)) · x_j,i     # 批梯度下降，凸，收敛到全局最小
SGD: 每步随机取大小为 m 的小批量代替全体（计算/100，噪声仅×10，整体快约10倍）；α 可按 O(1/t) 衰减保证收敛
```

**感知机 / 逻辑斯谛回归更新**
```
感知机:  w_i ← w_i + α · (y − h_w(x)) · x_i        # 仅错分样例改变权重；线性可分才收敛
逻辑斯谛: h_w(x)=g(w·x), g(z)=1/(1+e^{−z}), g'=g(1−g)
         w ← w + α · (y − g(w·x)) · g'(…)·x        # 沿 y−预测 差方向；可微、噪声数据上稳定
```

**SVM 对偶与核技巧**
```
max_α Σ α_j − ½ ΣΣ α_j α_k y_j y_k (x_j·x_k)   s.t. 0≤α_j, Σ α_j y_j = 0   # 凸二次规划
分离器: h(x) = sign(Σ_j α_j y_j (x_j·x) + b)；非支持向量 α_j=0
核技巧: 把每个 x_j·x 替换为 K(x_j,x)（多项式核、高斯核），等价于在 F(x) 定义的高维空间中求最大边距分离器，无须显式计算 F(x)
软边距: 允许样例越界，按距离比例受罚
```

**非参数：kNN / 局部加权回归（回归+分类通用骨架）**
```
预测 x_q: 找 NN(k, x_q)；分类取多数票（k 取奇数），回归取均值/中位数/局部线性拟合
局部加权回归: 对每个查询点解 加权最小二乘 ∑_j K(Distance(x_q,x_j))·(y_j−w·x_j)²，核宽度 w 由交叉验证定
加速: k-d 树（样例数≫维数）或局部敏感哈希 LSH（多随机投影+哈希桶并集，近似近邻）
```

## 参考表
损失函数与正则化选择：

| 度量 | 形式 | 适用/性质 |
|---|---|---|
| L0/1 损失 | 错=1 对=0 | 最小化错误率；不可导 |
| L1 损失 | \|y−ŷ\| | 拉普拉斯噪声下最大似然；对离群值稳健 |
| L2 损失 | (y−ŷ)² | 高斯噪声下最大似然；回归默认 |
| L1 正则化 | Σ\|w_i\| | 稀疏解、自动特征选择；所需样例对不相关特征数是对数级 |
| L2 正则化 | Σw_i² | 平滑、旋转不变；样例需求对不相关特征数是线性级 |

集成方法对比：

| 方法 | 降偏差/方差 | 基模型训练数据 | 并行性 | 关键机制 |
|---|---|---|---|---|
| Bagging | 方差 | 自助重采样 | 可并行 | 多数投票/平均 |
| 随机森林 | 方差 | 重采样+随机属性子集 | 可并行 | 不剪枝；袋外误差评估；加树不增验证误差 |
| Stacking | 偏差 | 同一数据、不同模型类 | 可并行 | 用验证集训练元学习器组合基模型预测 |
| AdaBoost | 偏差 | 迭代重加权 | 序贯 | 错分样例加权+加权投票；弱学习器→训练集完美拟合 |
| 梯度提升 | 偏差 | 全数据残差/梯度 | 半并行 | 新树拟合损失负梯度；学习率+树大小正则化（XGBoost） |

## 完整示例
**餐厅等待问题**：预测布尔输出 WillWait，输入 10 个离散属性（Alternate、Bar、Fri/Sat、Hungry、Patrons∈{None,Some,Full}、Price、Raining、Reservation、Type、WaitEstimate）。训练集仅 12 个样例，而属性组合共 3^6·2^4·4·4≈9216 种——归纳的本质是用 12 个已知输出对其余 9204 种组合做最佳猜测。

分裂过程：按 Type（4 值）分裂后每个子集正负各半，熵几乎不降；按 Patrons 分裂后 None→全 No（叶）、Some→全 Yes（叶）、Full→仍混合（继续按 Hungry 等分裂）。信息增益证实直觉：Gain(Patrons)≈0.54 为全属性最大（p=n=6 时根熵 B(0.5)=1 位），故 Patrons 被选为根。学到的树与作者原始树不同但与全部样例一致且更简单（省去 Raining、Reservation），还发现隐藏模式"SR 周末会等泰国菜"。学习曲线显示：100 个样例随机划分训练/测试、20 次重复取均值，准确率随训练集增大单调升至约 95%（"快乐图"）。同一数据上：决策列表稍逊于决策树；朴素贝叶斯（第20章）更低——因为真实函数是决策树、不满足条件独立；未提升的决策树桩仅 81%，AdaBoost(K=5) 提升到 93%，K=20 时训练误差归零而测试准确率仍继续升至 98%（K=137 后才回落）。

## 要点
1. 模型选择与模型优化是两个任务：先选假设空间（超参数），再在其中训练；验证集管前者，测试集只在最后用一次。
2. 偏差-方差权衡无处不在：线性欠拟合、12次多项式过拟合，正则化和剪枝都是在两者间找平衡点。
3. 完全数据+表格 CPT 的最大似然就是条件频率，且各参数可独立估计（第20章会严格化）；同理，多变量线性回归有闭式解（正规方程）。
4. 核技巧的本质：凡是只以点积形式使用数据的算法都可以"核化"，在极高维空间中高效学习非线性边界。
5. 集成的数学：5 个 75% 正确且独立的分类器多数投票正确率约 89%，17 个约 99%——前提是错误不相关，故随机森林靠随机化属性去相关。
6. 插值临界点之后验证误差仍可下降（boosting、随机森林、深度网络）：奥卡姆剃刀不是普适定律，"合适"比"简单"更重要。
7. 在线场景放弃 i.i.d. 假设也能学：随机加权多数算法对任意样例序列的遗憾有上界，可做到无悔。
